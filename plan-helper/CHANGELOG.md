# plan-helper - 更新日志

## [0.5.0] - 2026-09-21

### 计划生命周期与管理
- 增加可恢复的计划归档、归档列表和读取恢复流程。
- 增加 plans 级管理统计与整合数据接口。
- 完善计划管理需求对应的 API 回归测试。

## [0.4.0] - 2026-09-21

### 完整性修复
- 新建计划默认填充当前日期，用户界面统一显示 `yyyy/mm/dd`。
- 新建计划支持同时录入章节、任务和预计时长。
- 增加计划、章节和任务编辑入口及对应 API。
- 设置与存档按钮接通真实操作，并提供备份状态反馈。
- 移除 plan-helper 日历视图；日历职责归 time-helper。

## [0.2.0] - 2026-09-20

### 界面现代化
- 新增 Web UI（基于 Vue 3 + 原生 HTTP server）
- 卡片式布局展示计划列表，显示进度条、截止日期、优先级
- 计划详情页：分区任务列表、分组标签、进展时间线
- 日历视图：月历网格，按日期标记计划状态
- 模板管理页面：内置模板与自定义模板浏览
- 侧边栏导航，支持折叠
- 深浅色模式自动切换
- 响应式布局，适配移动端
- 拖拽调整计划顺序
- 完整的组件状态设计（hover/focus/active/disabled/loading/error）

### 计划制定增强
- 模板系统：内置工作日/休息日/备考冲刺模板
- 快速复制昨日计划（自动查找并复制）
- 智能建议：基于历史数据推荐模板，分析高频任务
- 冲突检测：时间溢出/重复任务/不合理分配提醒
- 自定义模板的保存/加载/删除

### 进展记录（log）
- 快速记录：点击计划项直接标记完成，输入实际时间
- 进度条实时更新
- 时间线形式的历史日志查看
- 日历视图查看每日计划/完成情况

### API 层完善
- 统一 APIResponse 格式（success/code/data/error/timestamp）
- Plan CRUD：创建/查询/列表/更新/删除
- Section/Task/Log 完整操作接口
- 持久化接口：保存/加载计划、注册表
- 统计接口：进度概览、完整计划数据
- 编写完整 API 文档（docs/API_SPEC.md）

### 数据健壮性
- 数据导出：单计划/全部/目录批量导出
- 数据导入：从 JSON/文件/目录批量导入
- 自动备份：带时间戳的备份文件，支持恢复
- 数据验证：结构完整性检查（head/main/log）
- 边界测试：10 项测试覆盖 ID 冲突、空计划、时间溢出等

### 其他
- 更新 VERSION 至 0.2.0
- 新增 UI 设计方案文档（docs/DESIGN_SPEC.md）
- 注册新模块到 __init__.py
