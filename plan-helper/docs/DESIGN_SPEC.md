# plan-helper UI 设计方案

> 版本: 0.2.0 | 更新日期: 2026-09-20

---

## 1. 美学方向

**参考品牌**: Linear + Notion + Todoist 的融合风格

- Linear 的克制与高效感：信息密度高但不拥挤
- Notion 的模块化卡片设计：每个功能块独立且可组合
- Todoist 的清晰层级：优先级颜色系统，进度可视化

**关键词**: 克制、信息密度、留白呼吸感、微交互反馈

## 2. 字体系统

|------|------|------|------|
| 页面大标题 | Inter / 思源黑体 CN | 24px | 600 |
| 卡片标题 | Inter / 思源黑体 CN | 16px | 600 |
| 正文/任务描述 | Inter / 思源黑体 CN | 14px | 400 |

- 等宽字体: `"JetBrains Mono", "Fira Code", monospace`

| 侧    +----------------------------------------+
| 边    |                                        |

## 5. 动效策略

| 动效类型 | 时长 | 缓动 | 场景 |
|---------|------|------|------|
| 卡片悬停 | 150ms | ease-out | 阴影提升 |
| 进度条更新 | 300ms | ease-in-out | 数值变化 |
| 页面切换 | 200ms | ease | 淡入淡出 |
| 拖拽反馈 | 100ms | ease | 缩放 + 阴影 |
| 完成动画 | 400ms | spring(1,80,10) | 勾选 + 划线 |

- 尊重 `prefers-reduced-motion` 设置
- 所有动效可通过设置全局关闭

## 6. 间距与排版

### 间距节奏 (基准 4px)
```
--space-xs:   4px    (图标与文字间距)
--space-sm:   8px    (紧凑元素间距)
--space-md:   16px   (卡片内边距)
--space-lg:   24px   (区块间距)
--space-xl:   32px   (页面边距)
--space-2xl:  48px   (大区块分隔)
```

### 排版规则
- 行高: 标题 1.3, 正文 1.6, 紧凑 1.2
- 最大阅读宽度: 720px
- 卡片内最大行宽: 45em

## 7. 组件状态

每个可交互组件包含以下状态:
- **Default**: 基础外观
- **Hover**: 微妙的背景/阴影变化
- **Focus**: 蓝色边框环 (`box-shadow: 0 0 0 2px var(--border-focus)`)
- **Active/Pressed**: 轻微缩放 (scale: 0.98)
- **Disabled**: 降低透明度 (opacity: 0.5) + 禁用指针
- **Loading**: 骨架屏或旋转指示器
- **Error**: 红色边框 + 错误信息提示

## 8. 页面规划

### 8.1 计划列表页 (Dashboard)
- 卡片式布局展示所有活跃计划
- 每张卡片显示: 名称、进度条、截止日期、优先级、任务完成比
- 支持按状态/优先级/日期筛选排序
- 空状态: 友好引导创建第一个计划

### 8.2 计划详情页
- 甘特图/时间轴视图展示任务安排
- 左侧: 任务列表 (可拖拽排序)
- 右侧: 时间轴甘特图
- 底部: 进展日志时间线
- 顶部: 计划元信息 + 整体进度

### 8.3 日历视图
- 月历网格展示每日计划/完成情况
- 颜色编码: 绿(完成) > 蓝(进行中) > 灰(无计划) > 红(逾期)
- 点击日期查看当日详情

### 8.4 模板管理
- 预置模板: 工作日、休息日、自定义
- 快速复制: 复制昨日/上周同日计划
- 模板编辑器: 可自定义模板内容
