# 08 视觉方向

- 决策：D-017
- 日期：2026-10-27
- 状态：已决定（由设计代决，用户确认写入文档）

## 1. 方向

**克制、精确、密度适中。** 目标是“专业工具”，不是课程设计，也不是通用后台模板。

参考的是 Linear / Vercel / Notion 的**纪律**，不是照搬它们的视觉：中性表面、单一强调色、清晰的层级、稳定的几何关系、克制的动效。

## 2. 默认主题

默认提供两套基础主题，其余主题通过 `.t3el` 包扩展：

| 主题 | 表面 | 文字 | 强调色 |
|---|---|---|---|
| Paper & Ink（浅色） | 暖白纸面 `#F7F7F5` / 卡片 `#FFFFFF` | 墨色 `#1C1C1A` | 深青 `#1F6F5C` |
| Graphite（深色） | 石墨 `#151615` / 卡片 `#1E201F` | 近白 `#F2F2EF` | 浅青 `#5DBFA6` |

- 强调色只用于主操作、选中态、焦点环；不用于大面积背景。
- 危险色、警告色、成功色独立，不复用强调色。
- 装饰渐变、纹理、粒子只属于主题包，不进入基础层。

## 3. 字体与字号

- 西文：Inter Variable；中文：Noto Sans SC（子集）。
- 回退：`-apple-system, "Segoe UI", "Microsoft YaHei", sans-serif`。
- 正文 14px / 行高 1.55；次要 13px；标注 12px；**任何常驻文本不小于 12px**。
- 标题：页面 20px/600，区块 16px/600，卡片 14px/600。
- 数字使用 tabular-nums；时间、金额、计数必须对齐。
- 不使用 7–10px 文本；Alt 快捷键提示不常驻。

## 4. 间距与几何

- 间距阶梯：4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48。
- 页面边距：桌面 32，平板 20，移动 16。
- 控件高度：紧凑 32，默认 36；触控目标不小于 44×44。
- 圆角：4 / 8 / 12 / 16 / full；默认 8。
- 边框：1px 低对比；阴影只用于浮层与弹窗，不用于普通卡片堆叠。
- 内容最大宽度 1280；侧栏 240；主区使用 `minmax(0, 1fr)`。
- 禁止固定高度承载可变内容；禁止用绝对定位拼页面结构。

## 5. 布局与响应式

- 七档视口：320 / 390 / 768 / 1024 / 1280 / 1440 / 1920。
- 使用 CSS Grid / Flex + 容器查询；断点服务于内容，而不是设备名。
- 所有 grid/flex 子项 `min-width: 0`；长文本截断策略显式声明。
- 浮层（Dialog/Popover/Toast/FAB）走 portal + 统一 z-index 阶梯。
- 主题在 L0–L2 不得改变几何布局；L3 需要完整信任后才可任意修改。

## 6. 动效

- 时长：120 / 180 / 240ms；缓动 `cubic-bezier(0.2, 0, 0, 1)`。
- 路由：180ms 淡入 + 4px 位移。
- 弹窗：180ms 缩放 0.98 → 1 + 淡入。
- 列表增删：FLIP；主题切换：240ms 交叉淡化。
- 只动 `transform` / `opacity`；不触发布局。
- 尊重 `prefers-reduced-motion`；装饰层可单独关闭。
- 流畅感优先来自即时反馈、骨架屏、乐观更新，而不是装饰动画。

## 7. 交互状态

每个可交互元素必须覆盖：默认、悬停、聚焦、按下、禁用、加载、错误。

- 焦点环：2px 强调色 + 2px offset，始终可见。
- 禁用态不只靠降低透明度，必须有语义提示。
- 空状态必须包含：一句说明 + 一个明确的下一步操作。
- Toast 合并/限流，不堆叠遮挡内容。
- 不使用仅悬停才出现的必要信息。

## 8. 明确禁止

- 模块缩写（TH/PH/TD）出现在用户主界面
- 巨幅时钟/数字占据整列而右侧大片空白
- 彩虹式状态色、装饰性渐变进入基础组件
- 常驻的 “Alt 1” 快捷键提示
- 悬浮按钮遮挡正文、页脚或空状态
- 小于 12px 的常驻文本
- 用固定像素拼出会随窗口变化的布局

## 9. 验收

- 七档视口截图；无横向溢出、无重叠。
- 浅色 / 深色 / 3 套参考主题下布局一致。
- 键盘可完成主路径；WCAG AA。
- 与旧版截图对照，人工评审“是否像一个产品”。

## 10. 与权限的关系

- L0–L2 主题：只能改外观，不得改变几何布局；全部纳入视觉回归。
- L3 主题：经用户完整信任后可任意修改布局；不纳入通用布局回归，但必须提供“恢复默认外观”入口与重置能力。
