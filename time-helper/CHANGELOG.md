## [1.1.0] - 2026-09-20

### 新增
- **主页图表化改造**
  - 替换文字统计为 SVG 环形进度条显示总完成度
  - 各分类改为可视化进度条（色彩映射 + 超出检测）
  - 主页添加收件箱按钮（Inbox 图标），带未读数红点
  - 打卡提醒徽章（完成100%未打卡时显示红点脉冲）
  - **收件箱下拉面板**：主页点击右上角收件箱图标，展开消息预览面板
  - 面板显示最新 10 条消息，含图标、标题、预览和相对时间
  - 未读消息蓝点标识，一键「全部已读」
  - 有未读消息时收件箱图标周期性抖动提醒

- **日历 UI 现代化重设计**
  - 添加月度概览卡片（有记录天数、已打卡天数、平均完成度）
  - 每日格子显示完成度背景色 + 底部进度小条 + 打卡火焰标记
  - 颜色映射：100% 绿色、70%+ 黄色、40%+ 橙色、<40% 红色
  - 未来日期灰显不可点击
  - 添加图例说明各颜色含义
  - **年度热力图**：GitHub 风格贡献图，展示最近 26 周活跃度
  - **月份切换动画**：左右滑动过渡效果
  - **日期详情弹窗**：点击任意日期格子弹出环形完成度 + 分类统计 + 记录摘要
  - 弹窗内可跳转到完整详情页

- **专用打卡界面**（/checkin）
  - 显示连续打卡数、最长连续、累计打卡数
  - 等级系统（初始→起步→一周→两周→月度→季度→半年→年度）
  - 最近7天可视化（火焰标记打卡日）
  - 打卡历史列表（最近14条）
  - 打卡动画（数字递增 + 粒子爆发）
  - 支持从打卡界面直接打卡
  - **打卡热力图**：26 周打卡日历，橙色调火焰主题

- **事件系统扩展**
  - 新增 7 种事件类型：半程完成、打卡完成、连续打卡里程碑、空闲提醒、周报摘要、每日首条记录、记录删除
  - 新增触发方法：checkHalfProgress、checkStreakMilestone、triggerIdleReminder、triggerWeeklySummary、triggerDailyFirstRecord

- **收件箱分类过滤**
  - 三种分类标签：成就 🏆 / 事件 📋 / 提醒 🔔
  - 各分类显示消息计数
  - 支持一键切换，快速定位关心的消息类型

- **完整 API 层**（src/api/index.ts）
  - 7 大模块接口：ConfigApi、PlanApi、RecordApi、CheckinApi、EventApi、AnalyticsApi、UtilsApi
  - 统一 ApiResponse 响应格式
  - 支持周报、月度趋势、综合摘要查询（供外部模块调用）
  - **API 文档**（docs/API.md）：完整方法签名、参数说明、使用示例

- **可复用热力图组件**（src/components/ContributionHeatmap.vue）
  - SVG 实现，支持三种颜色模式（progress/checkin/hours）
  - 自动月份标签、星期标签、图例
  - 可配置周数、单元格大小
  - 点击事件支持日期导航

### 优化
- 主页导航从 4 列改为 5 列，新增「打卡」按钮
- 事件管理页面新增完整事件类型列表和测试支持
- 打卡成功后自动检查里程碑事件
- 日历视图数据加载并行化，提升性能

## 版本说明

- **正式版**：如 `1.0.0`，制作安装包发布
- **开发版**：如 `1.0.1-dev.123`，仅在开发环境使用，版本号自动递增

版本号格式：`主版本.次版本.修订号`
- 主版本：重大更新，不兼容的改动
- 次版本：新增功能，向下兼容
- 修订号：问题修复，向下兼容
