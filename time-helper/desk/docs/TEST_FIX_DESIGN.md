# time-helper 测试结论修复设计

## 设计目标

修复主题设置的草稿生命周期、合并计划工作台的记录与日计划管理入口，并降低主页中心操作卡片的 hover 干扰。

## 主题设置

- 进入主题页面时记录已保存主题快照。
- 选择主题或修改参数后立即应用到应用级主题状态，用户可以即时预览。
- 页面不提供“保存”按钮。
- 离开主题页面时，只有草稿与快照不一致才询问是否保存：保存则持久化，放弃则恢复快照；无变化直接返回。
- 取消/返回不清空输入，也不产生额外备份。

## 统一计划工作台

- 移除“今日记录 / 计划管理”两个顶层 Tab。
- 同一页面同时展示今日记录列表、今日计划摘要和计划管理入口。
- 计划编辑、规则配置和临时切换作为同一工作台内的二级视图进入，并提供明确返回路径。
- 保留“新增记录”作为页面主操作，计划管理入口使用次级操作样式。

## 主页中心操作卡片

- 普通状态保持透明/主题背景。
- hover/focus 仅增强边框轮廓和轻微阴影，不填充整块背景。
- 保留键盘 focus-visible 的高对比轮廓。
- 尊重减少动画设置，不依赖颜色作为唯一信息。

## 验证

- 切换主题后离开并返回，分别验证保存、放弃和无变化三条路径。
- 在同一计划工作台同时验证记录增删改和计划编辑入口。
- 验证主页操作卡片文字在 hover/focus 状态下仍清晰可读。
