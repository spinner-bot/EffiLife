# 0260 统一非阻塞反馈设计

## 决策

确认使用全局 Toast 替代设置页的浏览器原生 `alert`。实现已完成：新增 Toast 服务与宿主组件，设置页的导出、导入、恢复、反馈和配置保存均已迁移。

## 原因

原生 `alert` 会阻塞主窗口、打断键盘操作，也无法与 EffiLife 的主题和多语言层级保持一致。全局 Toast 可以复用已有本地化文案，并为桌面端和移动端提供统一反馈位置。

## 验证

- `npm run build`：通过，`1875 modules transformed`。
- 全局 Toast 使用主题 token，并覆盖成功、错误、普通信息、关闭和减少动画状态。
- 设置页源码契约测试确认不再调用 `alert`。
