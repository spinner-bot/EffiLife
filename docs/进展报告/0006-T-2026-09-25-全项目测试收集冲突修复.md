# 全项目测试收集冲突修复

**文档性质**：临时实施报告

**创建时间**：2026-09-25（Asia/Shanghai）

**创建作者**：Codex

**触发原因**：执行项目级 pytest 时，`plan-helper/test_api.py` 和 `to-dos/test_api.py` 具有相同模块名，pytest 发生 import file mismatch，导致全项目测试无法收集。

## 1. 修复

新增根目录 `pytest.ini`：

- 将自动收集范围固定为根目录 `tests/`；
- 使用 `importlib` 导入模式，减少不同模块测试文件名冲突；
- 保留各模块独立脚本测试的手动执行方式。

## 2. 影响

该配置只修复测试收集，不改变业务代码和模块内部测试。以后项目级回归使用：

```text
python -m pytest -q
```

各模块专项测试仍可使用其原有命令，例如：

```text
python plan-helper/test_api.py
```

## 3. 状态

修复后需重新执行完整回归，并将最终结果补入后续报告。
