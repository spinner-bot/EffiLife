# 计划关联网关与配套服务托管

**文档性质**：临时实施报告
**创建时间**：2026-09-25（Asia/Shanghai）
**创建作者**：Codex

**依据**：`plan-helper/modules/plan.py`、`plan-helper/modules/api.py`、`docs/设计方案/0002-计划关联待办交互方案.md`。

## 1. 已完成

- 新增 time-helper `PlanGateway`，从 plan-helper 的 `/api/plans` 读取计划摘要。
- 待办中心新增关联计划选择：
  - 创建待办时可选择计划；
  - 编辑待办时可修改或取消关联；
  - 列表显示计划名称摘要；
  - 计划服务不可用时不阻断普通待办 CRUD。
- 启动器为“EffiLife 统一工作台”增加 plan-helper API companion：
  - 若 `8765` 已有服务则复用；
  - 否则由启动器启动；
  - 主工作台退出时只回收自己启动的 companion，不影响外部服务。
- 增加适配器回归测试，验证 plan-helper 的任务内部 ID、显示 ID 以及嵌套 group 原样保留。

## 2. 结构边界

plan-helper 的 `Plan` 仍保持 `main → section → plan` 的有序槽位结构，软删除后的显示编号和内部编号不在待办侧重算。待办只保存稳定的 `related_plan_id`，不会把 section、任务编号或嵌套 group 扁平化。

## 3. 验证

- 启动器通过 Python 编译检查。

- 全项目 Python 测试继续作为提交门禁。

- 计划摘要依赖 plan-helper API 已有计划注册表；没有计划时选择器为空是正常状态。
- 当前只做计划级关联，尚未在待办中直接绑定 `A1` 等 plan-helper 任务引用；这需要同步完成、软删除和日志语义的进一步定义。
