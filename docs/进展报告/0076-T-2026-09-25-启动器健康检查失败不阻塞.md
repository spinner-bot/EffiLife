# 0076-T-2026-09-25 启动器健康检查失败不阻塞

## 问题

启动器启动主服务后会等待 HTTP 健康检查。如果子进程仍然存在但服务一直没有响应，旧逻辑会忽略失败结果并继续等待子进程退出，可能造成启动器长期卡住。

## 处理

- 健康检查失败时立即终止主服务进程。
- 通过既有 `finally` 路径清理本次启动的 companion 服务。
- 增加回归测试，确认失败分支不会调用阻塞性的 `process.wait()`。

## 验证

- `python -m pytest tests/test_launcher.py -q`
- `python -m py_compile launcher/start.py`
- `git diff --check`
