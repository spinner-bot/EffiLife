# 0084-T-2026-09-25 统一设置页数据统计来源

## 问题

存档导出已改为优先读取 IndexedDB，但设置页的数据统计仍同步读取 localStorage，可能出现“统计显示为空、导出却包含数据”的不一致。

## 处理

- `getDataStats` 改为异步读取统一记录源。
- 设置页使用响应式统计初值，避免异步加载期间模板访问未定义字段。

## 验证

- `npm run build`（`time-helper/desk`）
- `python -m pytest -q --disable-warnings --maxfail=1`
- `git diff --check`
