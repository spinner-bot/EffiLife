# 修复正式前端构建门禁

**文档性质**：临时实施报告  
**创建时间**：2026-09-25（Asia/Shanghai）  
**创建作者**：Codex

## 1. 问题

此前 Vite 可以打包，但正式 `npm run build` 在 `vue-tsc` 阶段失败，无法作为可靠发布门禁。错误来自旧组件的类型和未使用符号，包括热力图、存储测试、Tauri fs API、签到页等。

## 2. 修复

- 修正热力图 `weeks` prop 与 computed 同名造成的模板类型冲突。
- 移除未使用 import/变量，修正存储测试的错误相对路径。
- 将 Tauri fs 已废弃的 `createDir` 替换为当前 `mkdir` API。
- 使用浏览器标准 `ReturnType<typeof setTimeout>` 替代 NodeJS 命名空间依赖。
- 修正签到结果空值收窄，保留原有动画逻辑。

## 3. 验证

- 正式命令 `npm run build`：通过，包含 `vue-tsc` 和 Vite 构建，1849 个模块完成。
- 根目录 Python 测试：`21 passed`。
