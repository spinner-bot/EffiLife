# 统一工作台表单标签收敛

## 1. 背景

依据 UX 规范复核统一工作台，发现计划详情的进度、Section 编辑字段，以及待办分类管理的部分字段仅依赖 placeholder 或缺少标签关联。

## 2. 实现

- 为计划进度内容、Section 名称和说明补充可见标签与稳定 `id`。
- 为待办分类创建和分类编辑的名称、颜色、难度字段补充可见标签与唯一字段 ID。
- 为新增的计划进度标签补充中英文 i18n 资源。
- 保留原有 v-model、校验、提交和主题样式，未改变业务逻辑。

## 3. 验证

- 全量 Python 测试：`293 passed`。
- 前端 `vue-tsc` 与 Vite 生产构建：通过。
- `git diff --check`：通过。
