# 前端多语言基础接入

**文档性质**：临时实施报告
**创建时间**：2026-09-25（Asia/Shanghai）
**创建作者**：Codex

**依据**：`docs/设计方案/0006-前端多语言基础接入方案.md`。

## 1. 已完成

- 新增前端 `src/i18n/index.ts`：
  - 支持 `zh-CN` / `en-US`；
  - locale 持久化到 `efflife_locale`；
  - 点号翻译键、缺失回退和参数插值；
  - 响应式切换，无需刷新页面。
- 新增可复用 `LocaleSwitcher` 组件，并接入设置主页面。
- 统一待办中心核心文案、优先级、筛选、编辑、空态和错误提示接入翻译 catalog。
- 首页计划、日历、打卡、待办、设置导航接入翻译 catalog。
- 首页日期和待办截止日期改用当前 locale 的 `Intl` 格式化。

## 2. 迁移策略

本阶段只迁移统一工作台和主导航，旧页面暂时保留原文案；catalog、locale 状态和组件接口已固定，后续迁移计划、存档和设置子页面不需要重新设计基础设施。

## 3. 验证

- Vite 生产构建通过：`1846 modules transformed`。
- `LocaleSwitcher`、`TaskCenterView`、`HomeView`、`SettingsView` 相关 `vue-tsc` 诊断为 0。
- locale 持久化逻辑使用现有浏览器存储，不新增依赖。

## 4. 下一步

继续将计划工作台和存档管理迁移到同一 catalog，并将语言偏好纳入统一 `.efl` 的 `app` 数据集，确保跨设备导入后语言设置可恢复。
