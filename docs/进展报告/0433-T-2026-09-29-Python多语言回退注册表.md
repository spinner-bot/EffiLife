## 1. 发现的问题

统一前端语言注册表规定英文目录缺失翻译时回退到简体中文，但 Python `common.i18n` 仍固定回退到英文目录。sidecar、迁移脚本和前端可能因此显示不同语言。

## 2. 本次完成

- 新增 `LOCALE_FALLBACKS` 注册表。
- 当前登记 `zh-CN -> zh-CN`、`en-US -> zh-CN`，与前端语言定义一致。
- 未知语言同样回退到默认语言，不再隐式偏向英文。
- 从 `common` 公共入口导出 fallback 注册表，便于集成层和测试复用。
- 增加自定义语言目录测试，覆盖缺失键回退、已存在键优先和未知语言场景。
