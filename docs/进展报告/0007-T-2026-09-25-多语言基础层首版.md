# 多语言基础层首版

**文档性质**：临时实施报告

**创建时间**：2026-09-25（Asia/Shanghai）

**创建作者**：Codex

**触发原因**：统一产品后需要让桌面壳、Python 服务和未来其他前端共享 locale、回退和翻译 key 约定。现有界面文本仍大量散落，因此先建立基础层，不在本阶段大范围替换 UI 文本。

## 1. 已完成

新增 `common/i18n.py` 和两套资源：

- `common/locales/zh-CN.json`；
- `common/locales/en-US.json`。

`I18n` 提供：

- 可用语言枚举；
- 当前语言切换；
- 点号分隔的嵌套 key 查询；
- 当前语言 → 英文 → key 原文的回退；
- `{name}` 参数插值；
- 读取外部 JSON 语言目录。

## 2. 设计边界

本阶段不把三个现有模块的全部硬编码文本强行替换，也不引入前端第三方 i18n 依赖。统一桌面壳阶段将使用相同 key 和 JSON 资源，前端可以按构建目标加载资源。

## 3. 验证

执行：

python -m pytest -q tests/test_i18n.py tests/test_adapters.py tests/test_data_exchange.py tests/test_data_manager_bundle.py tests/test_integration.py --disable-warnings --maxfail=1
