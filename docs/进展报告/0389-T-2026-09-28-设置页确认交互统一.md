# 设置页确认交互统一

## 1. 目标

延续 0388，将设置页中存档、恢复、数据清理和主题编辑相关的原生确认框迁移到统一应用壳的主题化确认服务，避免高风险操作存在两种交互体系。

## 2. 实现

- `SettingsView.vue` 的主题未保存、数据重置、存档导入、旧待办导入、备份恢复和刷新提示改用 `requestConfirm()`。
- `ArchiveService.importArchiveWithDialog()` 支持异步确认回调，Tauri 预览确认完成后才处理存档数据。
- 危险写入操作统一传入 `tone: 'danger'`。
- 更新 Tauri 存档确认和主题持久化契约测试。

## 3. 验证

- Python 全量测试：`289 passed`。
- 前端生产构建：通过，`1874 modules transformed`。
- `SettingsView.vue` 与 `ArchiveService.ts` 已无直接原生 `confirm()` 调用。

## 4. 保留事项

兼容性的旧计划详情、事件管理页面仍有少量旧交互，暂不在本次设置页迁移中扩大范围；后续在兼容路由退役时一并清理，避免同时维护两套业务页面。
