# 0175-T-2026-09-28 统一存档恢复反馈多语言化

## 1. 发现

统一 `.efl` 存档的设置页面和文件对话框已经支持双语，但 plan-helper 快照收集、缓存回退和导入恢复阶段的警告仍由 `ArchiveService` 直接生成中文。英文模式下，导入结果会出现语言混杂。

## 2. 调整

- 移动端快照缺失、plan-helper 不可连接和缓存回退原因接入 catalog。
- 本地快照保存失败、事件计划未恢复、恢复失败和导入成功/带提示结果接入 catalog。
- 使用参数化翻译保留底层异常详情，不改变存档协议和回滚行为。

## 3. 验证

- `npm run build`：通过，1864 个模块转换成功。
- 完整 Python 回归测试：56 passed，9 warnings。
- 既有前端 catalog parity 测试覆盖新增中英文键。
