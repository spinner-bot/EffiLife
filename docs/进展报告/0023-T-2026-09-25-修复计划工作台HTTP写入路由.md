# 修复计划工作台 HTTP 写入路由

**文档性质**：临时实施报告  
**创建时间**：2026-09-25（Asia/Shanghai）  
**创建作者**：Codex

## 1. 问题

事件计划工作台首版能够读取和创建计划，但新增章节、任务、完成任务和新增日志的 POST 路由从 `/api/plans/{id}/...` 路径中使用了错误的分段下标。服务端会尝试把字符串 `plans` 转换为计划 ID，导致 HTTP 400。

## 2. 修复

- 统一修正 `plan-helper/web/server.py` 中章节、任务、完成和日志 POST 路由的计划 ID解析位置。
- 保持原有计划数据结构、稳定任务 ID和软删除语义不变，仅修复 HTTP 边界层参数读取。

## 3. 验证

- 启动真实 `plan-helper/web/server.py` 服务。
- 通过 HTTP 创建计划、创建章节、创建任务并读取完整计划。
- 结果：`PLAN_WORKSPACE_API=ok`。
