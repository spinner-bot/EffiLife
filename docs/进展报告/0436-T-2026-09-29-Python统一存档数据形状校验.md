## 1. 背景

Python `read_workspace_bundle()` 原先只检查 canonical 数据集名称是否齐全，不检查顶层容器形状。这样 malformed `.efl` 可能通过 Python 预检，却在统一前端导入时失败。

## 2. 本次完成

- 增加工作区 canonical 数据集形状校验：`app` 为对象、`records` 为日期到数组的对象、`todos` 与 `todo_categories` 为数组、`plan_helper` 为对象。
- 对 `records` 日期桶单独校验，并在错误信息中带出日期。
- `plan_helper.plans` 存在时要求为数组。
- 只收紧 `read_workspace_bundle()`，不改变通用 `read_bundle()` 的兼容范围。
- 修正一条测试 fixture，使其符合统一协议的 `records` 对象结构。
