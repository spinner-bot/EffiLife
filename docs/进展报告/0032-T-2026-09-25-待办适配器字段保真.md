# 待办适配器字段保真

**文档性质**：临时实施报告  
**创建时间**：2026-09-25（Asia/Shanghai）  
**创建作者**：Codex

## 1. 问题

公共 `TodoAdapter` 在 to-dos 与统一模型转换时只保留基础任务字段，原模块的高级优先级和时间关联字段会丢失。

## 2. 修复

- `UnifiedTodo` 增加 `priority_rank`、`urgent`、`important`、`start_time`、`estimated_time`。
- 适配器双向保留上述字段，以及 `related_time_record_ids`、子任务、重复规则、置顶和排序等已有字段。
- 缺少新增字段的旧数据继续使用兼容默认值。
