# 0094-T-2026-09-27 启动器复用已运行前端

## 问题

统一启动器使用 Vite 的 `strictPort`。当目标端口已经有前端实例运行时，启动器仍会尝试启动第二个实例；第二个实例会立即退出，导致启动器把“已有可用服务”显示成启动失败。

## 处理

- 在启动主服务前检查其 HTTP 地址。
- 若主服务已经可访问，则复用该实例，不再创建重复进程。
- 启动器仍保持运行，退出时只清理本次启动的配套服务，不触碰外部已有的前端实例。
- 增加启动器单元测试，确保复用路径不会调用 `subprocess.Popen`。
