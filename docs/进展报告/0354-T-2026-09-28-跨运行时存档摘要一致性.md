# 0368-T-2026-09-28 跨运行时存档摘要一致性

## 发现

审计统一 `.efl` 导出链路时发现，Python 公共层按排序键 JSON 计算 SHA-256，而前端按对象运行时插入顺序序列化。两端数据内容可能相同，但摘要不同，导致跨运行时校验失败。

## 实施

- 在 `ArchiveService.ts` 增加递归对象键排序的 `canonicalJson()`；
- 五个规范数据集统一使用规范化序列化结果生成文件和摘要；
- 增加前端归档契约测试；
- 保留数组顺序和旧版存档导入路径。

## 验证

本报告提交前执行定向归档测试、Python 全量测试和前端生产构建。

## 后续
