# 统一事件计划工作台首版

**文档性质**：临时实施报告  
**创建时间**：2026-09-25（Asia/Shanghai）  
**创建作者**：Codex

## 1. 本阶段目标

在统一应用壳中建立计划领域入口，使原有 time-helper 的时间计划与 plan-helper 的事件计划形成清晰的同域工作台，同时保留 plan-helper 的章节、任务、嵌套组和稳定内部编号语义。

## 2. 已完成

- 新增 `/plans` 计划中心路由，并将首页主导航指向计划中心。
- 将时间计划与事件计划拆分为两个入口：时间计划继续进入原有时间工作流，事件计划进入 plan-helper 工作区。
- 新增事件计划列表、创建、打开、名称与日期修改、章节创建、任务创建、完成和软删除界面。
- 创建计划只要求名称和日期，日期默认填充当前日期；计划创建后直接进入可编辑详情，而不是生成空壳后失去入口。
- 任务显示使用后端计算的 `display_id`，写操作使用稳定的 `internal_id`，避免软删除后编号压缩造成误操作。
- 章节详情展示组信息但暂不伪造组编辑能力，保留后续实现嵌套组编辑的边界。
- 使用统一主题 CSS 变量，能够跟随基础浅色、深色及 th 主题架构；增加移动端布局和减少动态效果偏好适配。
- 在多语言基础中补充计划中心、事件计划编辑器及状态文案的中英文键值。

## 3. 重要实现约束

- `plan-helper` 的原始数据结构仍由后端负责维护，前端不重建章节、组或软删除槽位。
- 计划元数据保存后重新读取完整计划，避免更新接口返回摘要时覆盖当前详情状态。
- 本阶段没有创建分支，也没有修改用户已有的 `time-helper/desk/package-lock.json` 与 `docs/req/7[ph][td]-优化.txt`。
