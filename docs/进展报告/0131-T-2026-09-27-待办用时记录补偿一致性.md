# 0131-T-2026-09-27 待办用时记录补偿一致性

## 本次目标

修复统一任务中心“记录用时”操作的跨模块一致性问题：时间记录先写入统一记录库，待办累计用时随后更新；若后一步失败，可能留下无法关联到待办累计数据的孤立时间记录。

## 实现内容

- 为 `DataService` 增加按稳定记录 ID 和日期删除时间记录的方法。
- 记录用时过程中保存每条时间记录的 `{ id, day }` 引用，跨午夜拆分记录时仍能准确定位原始数据。
- 待办累计用时更新失败时，按记录引用逐条执行补偿删除。
- 补偿删除也发生失败时，显示明确的“未能全部回滚”错误，而不是伪装成普通失败。
- 保留原始待办更新异常；补偿成功时不改变原有错误提示语义。
