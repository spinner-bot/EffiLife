# 0078-T-2026-09-25 统一启动器真实服务冒烟验证

## 验证范围

使用 `python launcher/start.py --unified` 启动统一工作台及 Plan Helper companion，验证两者能够在真实 HTTP 服务中同时就绪。

## 结果

- 前端 `http://127.0.0.1:1420/`：HTTP 200。
- Plan Helper API `http://127.0.0.1:8765/api/plans`：HTTP 200。
- API 预检 `OPTIONS /api/plans`：HTTP 204。
- 预检允许方法包含 `GET, POST, PUT, DELETE, OPTIONS`。
- 预检允许请求头包含 `Accept, Content-Type`。
- 通过 Ctrl+C 停止 launcher 后，前端与本次启动的 companion 均正常退出。

这证明统一启动器、前端入口、Plan Helper API 和 CORS 契约在实际进程环境中能够连通。
