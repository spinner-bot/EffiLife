# 0143-T-2026-09-27 启动器终端入口稳定性与可读性

## 背景

统一启动器是当前测试阶段的主要入口，但旧菜单元数据在不同 Windows 终端代码页下容易显示为乱码，影响模块选择和故障判断。

## 本次处理

- 保留既有统一启动、配套服务探活、端口复用和退出清理逻辑。
- 将启动器菜单的模块名称与说明统一为 ASCII-safe 文本，避免旧终端代码页破坏入口信息。
- 增加代码页安全的菜单渲染函数，并统一交互提示为可读文本。
- 更新启动器回归测试，锁定统一工作台必须为首个入口及端口参数不变。

## 验证

- `python -m pytest -q tests/test_launcher.py`：8 passed。
- `python -m pytest -q`：44 passed，9 warnings（既有集成测试返回值告警）。
- `python launcher/start.py --unified`：Vite `1420` 与 plan-helper `8765` 均启动，Ctrl+C 后两个端口均已释放。
- `npm run build`（`time-helper/desk`）：通过。
