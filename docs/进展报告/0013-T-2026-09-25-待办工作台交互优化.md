# 待办工作台交互优化

**文档性质**：临时实施报告
**创建时间**：2026-09-25（Asia/Shanghai）
**创建作者**：Codex

**依据**：`docs/设计方案/0001-统一待办工作台交互优化.md`、`docs/req/7[ph][td]-优化.txt`、`docs/spec/UI 设计理念.md`、`docs/spec/UX 设计理念.md`。

## 1. 已完成

- 待办条目正文保持左对齐。
- 优先级标签移至条目右端，避免抢占任务标题的首要视觉位置。
- 创建待办表单增加“新建待办”和“优先级”可见标签。
- 增加条目内编辑入口，支持修改标题和优先级。
- 编辑保存期间禁用保存按钮，保存失败保留用户输入并展示错误。
- 已完成任务的完成按钮禁用，避免重复写入完成时间。
- 增加编辑、聚焦、禁用和减少动画状态，继续使用统一主题令牌。

## 2. 数据安全

编辑仍通过 `TodoService.update()` 完成。更新时保留原任务的 ID、创建时间、子任务、重复规则、计划关联和其它扩展字段，不会因为只编辑标题和优先级而覆盖模型数据。

## 3. 验证

- Vite 生产构建通过：`1841 modules transformed`。
- `vue-tsc --noEmit` 中未出现 `TaskCenterView` 或 `todoService` 新诊断。

## 4. 后续

待办工作台下一步接入计划引用选择和子任务展开；计划引用必须建立在 plan-helper 原始数据结构的明确适配上，不直接把时间类别误当成事件计划。
