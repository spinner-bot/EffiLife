# [完成] 移动端 EFL 分享导出真实冒烟

## 背景

移动端 WebView 不一定能够稳定地把下载文件交给用户，因此 EffiLife 的 `.efl` 导出优先使用系统分享面板，只有不支持文件分享时才回退到普通下载。此前该分支主要由静态契约测试覆盖。

## 实施

- 为浏览器冒烟脚本增加 `--mobile-archive-share-flow`。
- 使用真实移动 User-Agent 和移动 viewport，并注入受控的 Web Share 文件能力模拟，验证应用实际进入 `navigator.share({ files })` 分支。
- 同时处理移动设置页首次进入时的本地恢复确认层，避免启动恢复对话框遮挡归档入口。
- 增加脚本契约测试，锁定分享路径和失败提示。

## 真实验证

执行：

```text
python scripts/smoke_browser_workspace.py --url http://127.0.0.1:1420 --mobile-archive-share-flow
```

结果：`ok: true`；移动导航、TH 快速记录入口、主题/语言持久化以及 `.efl` 文件分享路径均通过，分享文件名以 `.efl` 结尾。

## 边界

本次验证了 WebView 运行时分支和文件对象生成，不等同于 Android 系统真实分享面板验收。真实设备仍需确认系统分享目标、取消分享和权限行为；iOS 继续不在当前范围内，阶段保持第 0 阶段。
