# 统一工作区跨窗口刷新

## 1. 问题

工作区事件总线已经存在，但 Pinia 只在应用启动时加载配置、计划、规则和今日记录。跨窗口写入后，当前窗口的首页和旧兼容页面可能保持旧快照。

## 2. 实现

- `app` store 新增 `refreshWorkspaceData()`，统一重载四类共享状态。
- 保存配置、计划和规则后发出工作区变更事件。
- `App.vue` 订阅 `plans`、`records`、`settings`、`archive` 事件并触发刷新，卸载时解除订阅。
- 新增运行时同步契约测试。

## 3. 验证

本轮将执行全量 Python 测试、`git diff --check` 和前端生产构建；不修改用户保留的 `package-lock.json` 与需求文件。
