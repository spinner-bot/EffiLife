# 0083-T-2026-09-25 修复存档时间记录主数据源

## 问题

时间记录同时存在 IndexedDB 和 localStorage，但 `.efl` 导出只读取 localStorage。清理 localStorage 后，应用仍可能从 IndexedDB 读取记录，而导出会静默遗漏这些记录。

## 处理

- 导出时优先读取 IndexedDB `records` store。
- 同日期 IndexedDB 数据覆盖 localStorage 兼容快照。
- IndexedDB 不可用时保留 localStorage 回退。
- 保持设置页旧同步统计接口不变，降低本次改动范围。

## 验证

- `npm run build`（`time-helper/desk`）
- `python -m pytest -q --disable-warnings --maxfail=1`
- `git diff --check`
