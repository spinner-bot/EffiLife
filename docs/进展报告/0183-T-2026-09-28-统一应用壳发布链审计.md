## 2. 结论

- launcher 的统一入口为 `python launcher/start.py --unified`，旧 plan-helper/to-dos 入口仅保留兼容迁移用途。

- release workflow 覆盖 Windows NSIS、Linux deb 和 macOS dmg；正式安装包不依赖测试 launcher。
