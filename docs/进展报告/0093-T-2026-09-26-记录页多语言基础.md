# 0093-T-2026-09-26 记录页多语言基础

## 变更目的

统一记录管理页与应用现有的 `zh-CN` / `en-US` 多语言基础，避免切换 English 后仍出现大量中文界面。

## 实施内容

- 为 `RecordsView.vue` 接入 `useI18n()`。
- 将记录页标题、导航、空状态、编辑/删除按钮、表单标签、输入模式、校验提示和删除确认提示改为翻译键。
- 在中英文语言目录中补齐记录页所需的翻译项。
- 保留记录业务逻辑、时间校验和冲突检测行为不变。

## 验证计划

- 执行桌面端 `npm run build`。
- 执行根目录 Python 测试。
- 执行 `git diff --check`。
