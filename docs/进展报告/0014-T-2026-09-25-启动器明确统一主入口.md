# 启动器明确统一主入口

**文档性质**：临时实施报告
**创建时间**：2026-09-25（Asia/Shanghai）
**创建作者**：Codex

**触发原因**：统一工作台已经承载主题、计划入口和待办中心，但启动器菜单仍把三个模块以同等地位呈现，容易让用户继续把 EffiLife 当成三个独立软件使用。

## 1. 已完成

- 首个菜单项命名为“EffiLife 统一工作台”。
- 主入口描述改为计划、待办、时间记录与主题的统一入口。
- plan-helper、to-dos CLI、to-dos Web 标注为“兼容入口”，定位为迁移与调试工具。
- 保留兼容入口，不破坏原始模块数据迁移和回归测试流程。

## 2. 设计边界

本次只调整产品入口信息和用户预期，没有删除旧模块，也没有把尚未完成的功能宣传为已融合。统一工作台仍是唯一推荐日常使用入口。

## 3. 验证

- 通过 Python 编译检查启动器语法。
- 后续启动器运行时验证继续使用已有的服务健康检查逻辑。
