# 0176-T-2026-09-28 待办服务错误多语言化

## 1. 发现

待办页面的主要操作已经使用双语 catalog，但 `TodoService` 在分类、任务、子任务和用时记录失败时直接抛出中文错误。页面会优先展示异常自身的 message，因此英文模式下这些错误绕过了 `tasks.error.*` fallback。

## 2. 调整

- 待办服务接入统一 `translate()`。
- 分类无效/不存在、默认分类删除、任务/子任务不存在、标题为空和用时范围错误全部使用 `tasks.error.*` 双语键。
- 保持服务异常类型、数据校验条件和 IndexedDB 写入逻辑不变。
- 新增待办服务 i18n 静态契约测试。

## 3. 验证

- `npm run build`：通过，1864 个模块转换成功。
- 完整 Python 回归测试：57 passed，9 warnings。
