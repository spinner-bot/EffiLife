# to-dos/ui 本地数据迁移

**文档性质**：临时实施报告  
**创建时间**：2026-09-25（Asia/Shanghai）  
**创建作者**：Codex  
**触发原因**：旧版 to-dos Web UI 的 localStorage 数据尚未进入统一任务中心。

## 1. 本次完成

- 新增统一应用启动时的 `to-dos-data` 迁移。
- 迁移任务和分类到统一 IndexedDB，使用现有归一化器补齐字段。
- 按任务/分类 ID 合并，不覆盖统一库已有数据。
- 原始 localStorage 数据保留，使用版本化标记保证迁移幂等。
- 迁移异常不会阻塞应用启动，清除尝试状态后可在后续启动重试。
- 新增设计方案 `0022-to-dos-ui本地数据迁移方案.md`。

## 2. 验证

- `npm run build`（`time-helper/desk`）：通过，1849 个模块转换。
- 公共 Python 测试：`28 passed`。
- to-dos API：`36/36` 通过。
- plan-helper API：`13/13` 通过。

## 3. 迁移边界

当前只迁移旧 UI 的任务和分类；筛选器、排序偏好和界面设置属于旧 UI 表现层，不进入统一任务数据域。原始键保留，方便用户回退或重新导出。
