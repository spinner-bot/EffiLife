# [完成] Windows 升级验收入口接入

## 背景

仓库已有 `scripts/smoke_windows_upgrade.py`，能够在隔离目录中安装旧版、覆盖安装新版、检查桌面程序与 Plan Helper sidecar，并完成卸载清理。但原发布工作流只执行单版本安装/卸载冒烟，升级脚本没有可重复的 CI 入口。

## 实施

- 为 `workflow_dispatch` 增加可选输入 `previous_installer_url`。
- 手动发布验证时，Windows runner 会下载指定旧版 NSIS 安装包。
- 在同一隔离安装目录执行旧版安装→新版覆盖安装→文件完整性检查→卸载清理。
- 支持传入隔离数据探针目录，确认升级和卸载流程不会破坏应用外部数据目录。
- 未提供旧版安装包 URL 时，普通构建和现有安装生命周期冒烟保持原行为。

## 验证

- `python -m pytest -q tests/test_release_metadata.py tests/test_windows_installer_upgrade_smoke.py tests/test_windows_installer_smoke.py`：通过。
- `python -m pytest -q`：由发布工作流执行完整回归。

## 边界

本次接入的是可重复的升级验收入口，不宣称当前开发机已经完成真实旧版/新版覆盖安装。正式验收需要在 Windows runner 的手动工作流中提供真实旧版安装包 URL；自动更新插件和签名发布仍未接入。
