# 0734-T：首页平板工作台布局

日期：2026-10-01  
范围：`time-helper/desk/src/views/HomeView.vue`

## 问题

首页仅在 900px 以上启用桌面横向布局。761–899px 的平板宽度仍使用 600px 居中容器，造成两侧空间浪费，三模块摘要和统计内容呈现得过于接近移动端。

## 处理

- 新增 761–899px 平板断点。
- 首页主内容改为可伸展横向工作台，最大宽度提升到 900px。
- 时钟、日期和签到信息在平板上左对齐，和桌面层级保持一致。
- 保留 760px 以下移动端单列、纵向输入与紧凑操作布局。

## 验证

- 首页布局契约测试：5 passed
- 全量 Python 测试：628 passed
- `time-helper/desk` `npm run build`：通过，1874 modules transformed

## 后续

仍需在真实平板设备或浏览器设备模拟器中进行视觉验收，重点检查 761、899、900px 边界及主题背景下的对比度。
