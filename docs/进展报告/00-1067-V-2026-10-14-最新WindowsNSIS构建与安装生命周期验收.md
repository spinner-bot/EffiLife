# [完成] 最新 Windows NSIS 构建与安装生命周期验收

## 目标

验证当前主线源码能够生成可交付的 Windows x64 NSIS 安装包，并确认全新安装、文件落地和卸载清理链路可用。

## 执行内容

在当前主线源码上重新执行：

```text
npm run tauri build -- --bundles nsis
```

构建使用版本 `1.7.0`，包含最近的数据恢复与空数据清理修复。

随后执行：

```text
python scripts/verify_release_artifacts.py --directory time-helper/desk/src-tauri/target/release/bundle/nsis --extension .exe --version-file time-helper/VERSION
python scripts/check_release_config.py
python scripts/smoke_windows_installer.py --installer EffiLife_1.7.0_x64-setup.exe --target <isolated-temp-directory> --version-file time-helper/VERSION
```

## 结果

- Rust release 构建成功，NSIS 打包成功。
- 产物校验通过：`EffiLife_1.7.0_x64-setup.exe`，版本与 `time-helper/VERSION` 一致。
- 发布配置检查通过：Windows 当前用户安装策略与发布约束有效。
- 全新安装通过，以下文件均正确落地：
  - `efflife-desk.exe`
  - `efflife-plan-helper.exe`
  - `uninstall.exe`
- 静默卸载通过，隔离安装目录已被清理。

## 边界与后续

当前仓库没有可安全识别的同产品历史 EffiLife 安装包或版本标签，因此本次只确认了全新安装/卸载生命周期，未虚构覆盖升级验证结果。目录中的旧“浪兮效率时钟”安装器属于其他产品，不能作为 EffiLife 升级基线。

覆盖升级验证仍由 CI 的可选 `previous_installer_url` 入口承接；获得同产品旧版安装包后，再执行真实旧版到新版的数据保留验证。
