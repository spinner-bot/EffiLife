# 统一存档导入一致性

**文档性质**：临时实施报告  
**创建时间**：2026-09-25（Asia/Shanghai）  
**创建作者**：Codex

## 1. 问题

公共统一存档导入器按数据集逐个写入目标目录。多数据集导入时，如果后续目标冲突，前面的数据集可能已经落地，形成部分导入。

## 2. 修复

- 导入前完整解析并预检所有目标文件。
- 覆盖模式先写入目标目录下临时目录，成功后再进行替换。
- 无论成功或失败均清理临时目录。
- 保持 `effilife.bundle 1.0.0` 协议和数据集命名不变。

## 3. 验证

- 新增“冲突预检不产生部分写入”测试。
- 新增“覆盖导入完成且临时目录清理”测试。
- Python 测试：`19 passed`。
- `python -m compileall -q common`：通过。
