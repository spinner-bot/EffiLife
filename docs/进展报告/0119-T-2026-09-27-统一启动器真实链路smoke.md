## 验证目标

确认统一启动器能同时拉起统一前端和 plan-helper companion，并在 Ctrl+C 后清理本轮启动的服务。

## 结果

- `python launcher/start.py --unified` 成功启动 Vite，监听 `127.0.0.1:1420`。
- plan-helper API 的 `/api/plans` 返回 HTTP 200。
- Ctrl+C 后 plan-helper 输出 `Server stopped.`。
- 复核端口：1420 closed，8765 closed，未发现本轮启动服务残留。

## 结论

测试启动链路在当前 Windows 开发环境通过。正式安装包仍需在具备 Rust/NSIS 的发布环境执行 Tauri 构建验收。
