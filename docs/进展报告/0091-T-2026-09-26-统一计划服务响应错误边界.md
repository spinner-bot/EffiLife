# 0091-T-2026-09-26 统一计划服务响应错误边界

## 问题

计划网关直接调用 `response.json()`。服务异常返回空内容、HTML 或其他非 JSON 内容时，前端会暴露底层解析错误，无法区分 HTTP 错误和服务返回的业务错误。

## 处理

- 增加统一 `readPayload` 响应解析器。
- 统一处理空响应、无效 JSON、HTTP 状态错误和 API `success=false`。
- 计划列表、任务列表以及其他计划请求共用同一解析路径。

## 验证

- `npm run build`（`time-helper/desk`）
- `python -m pytest -q --disable-warnings --maxfail=1`
- `git diff --check`
