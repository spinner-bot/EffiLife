# 0168-T-2026-09-28 计划记录同屏管理增强

## 1. 背景

测试结论要求“记录与日计划管理”彻底合并为一个工作界面。此前 `PlanView` 已将管理摘要放入记录页，但计划管理仍主要通过入口卡片进入二级视图，用户仍需离开记录上下文才能完成常用计划操作。

## 2. 本次调整

- 在记录列表同屏的“今日计划”区域直接提供当前计划选择器。
- 支持在同一工作台直接切换今日计划，不必进入“临时变更”页面。
- 支持直接编辑当前计划。
- 支持直接创建新的日计划。
- 保留计划模板列表、日程规则和临时变更等完整管理视图，用于高级操作。
- 计划选择器同时显示计划类型，减少多个计划同名或类型不明造成的误操作。

## 3. 语义与数据约束

- 仍通过 `appStore.changeTodayPlan` 切换计划，不改变现有计划、记录和规则的数据结构。
- 当前计划编辑和新建仍复用既有 `openEditPlan`、`openCreatePlan` 流程。
- 本次只调整工作台入口与交互布局，不引入日历功能。

## 4. 验证

- `npm run build`：通过，`vue-tsc` 与 Vite 构建成功，转换 1864 个模块。
- `git diff --check`：通过（仅保留 Git 对现有文件换行符的提示）。

## 5. 后续

- 继续检查计划编辑器在空计划、嵌套组和软删除编号场景下的端到端表现。
- 在真实桌面启动器与移动候选端完成可用性验证后，再更新跨端完成度审计。
