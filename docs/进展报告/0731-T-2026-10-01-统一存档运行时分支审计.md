# 统一存档运行时分支审计

**文档性质**：阶段审计报告  
**创建时间**：2026-10-01（Asia/Shanghai）  
**创建者**：Codex

## 1. 核验范围

- 浏览器、Tauri 桌面和移动 WebView 是否使用同一 `effilife.bundle` 数据协议。
- Tauri 桌面导入是否使用原生文件对话框，浏览器/移动端是否使用 WebView 文件选择器。
- 移动导出是否优先系统分享，分享不支持时是否回退下载。
- 用户取消选择、取消确认或取消分享时，是否不会误报成功或触发二次下载。
- 导入失败时是否保留检查点和回滚路径。

## 2. 结果

- 五个规范数据集（`app`、`records`、`todos`、`todo_categories`、`plan_helper`）在所有运行时共用同一协议和校验逻辑。
- Tauri 桌面通过原生 dialog/fs 读写；浏览器和 Tauri Mobile 通过文件 input 与 WebView 能力完成导入。
- 移动导出优先 `navigator.share({ files })`，用户主动取消返回取消结果，不触发下载；能力不足或分享异常才回退下载。
- 导入流程先预览、确认，再写入；写入前保留双层存储检查点，失败时执行回滚。
- PH 不可用时保留缓存/快照状态并在结果中给出警告，不伪装成完整实时数据。
