# 0087-T-2026-09-26 计划中心异步操作防重

## 问题

计划中心的多个写操作共享加载状态，但函数入口没有统一拒绝重复触发。用户快速双击创建、编辑、记录进度或删除按钮时，可能产生并发请求。

## 处理

- 在计划创建、元数据编辑、分区、任务、分组、日志、完成、归档、恢复和删除函数入口增加 `isLoading` 互斥保护。
- 保持现有错误提示和 finally 清理逻辑不变。
- 不改变 Plan Helper 数据结构或接口语义。

## 验证

- `npm run build`（`time-helper/desk`）
- `python -m pytest -q --disable-warnings --maxfail=1`
- `git diff --check`
