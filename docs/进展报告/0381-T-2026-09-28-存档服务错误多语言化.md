# 存档服务错误多语言化

## 1. 背景

统一存档页面已经支持中英文，但 ArchiveService 的解析、校验、plan-helper 响应和回滚错误仍有部分直接写死文本，英文模式下会出现语言混杂。

## 2. 实现

- 将 manifest、协议、数据集、待办、分类、时间记录和 plan-helper 错误迁移到 `settings.archive.*` 双语 catalog。
- 将导入失败和回滚失败消息统一通过 `translate()` 生成，并保留数据集名称、HTTP 状态和底层原因等动态信息。
- 更新存档结构测试，使其验证 i18n key 而不是依赖具体中文文本。

## 3. 验证

- 全量 Python 测试：`295 passed`。
- 前端 `vue-tsc` 与 Vite 生产构建：通过。
- `git diff --check`：通过。
