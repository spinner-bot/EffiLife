# 0733-T：主题内部导航出口审计

日期：2026-10-01  
范围：`time-helper/desk/src/views/SettingsView.vue`

## 发现

主题设置页使用 SettingsView 内部视图切换。此前 `navigateTo()` 直接切换到存档、恢复等面板，不经过 Vue Router，因此不会触发 `onBeforeRouteLeave`；也不会经过主题页的返回按钮逻辑。用户在主题页修改后点击这些入口，草稿可能被放弃，形成“预览已改变、再次进入又恢复”的表现。

## 处理

- 将内部导航改为异步出口。
- 当主题草稿有变化时，复用主题退出确认与自动保存流程。
- 用户取消确认时保持当前主题页和草稿不变，不推进导航历史。
- 主题页仍不显示独立保存按钮；返回按钮、路由离开、内部面板切换三类出口现在共用同一保护逻辑。

## 验证

- 主题定向测试：26 passed
- 全量 Python 测试：627 passed
- `time-helper/desk` `npm run build`：通过，1874 modules transformed

## 后续

真实 Tauri 运行环境仍需手动确认弹窗交互、退出后重启读取主题以及跨窗口刷新；这些不应由静态契约测试替代。
