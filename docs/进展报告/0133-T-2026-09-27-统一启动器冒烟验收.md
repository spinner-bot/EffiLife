# 0133-T-2026-09-27 统一启动器冒烟验收

## 验收范围

验证测试启动方式下，统一工作台前端和 plan-helper 配套服务能否由同一个启动器协同启动，并在退出后释放端口。

## 结果

- `python launcher/start.py --unified` 成功启动 Vite 工作台：`127.0.0.1:1420`。
- plan-helper API 成功启动并响应：`127.0.0.1:8765`。
- 工作台向 `/api/plans` 发起请求并得到 HTTP 200，证明前端与计划服务已联通。
- 发送 Ctrl+C 后两个子服务均正常停止。
- 退出后检查端口：1420、8765 均已关闭。

## 结论

当前启动器作为测试入口可继续使用。正式版本仍应以 Tauri 安装包及内置 sidecar 为交付入口，启动器不替代正式打包链路。
