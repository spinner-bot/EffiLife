# 0189-T-2026-09-28 自动补卡主记录一致性

## 1. 本次目标

修复自动补卡及收件箱补卡仍直接读取旧版 `localStorage` 时间记录的问题，确保补卡判定与统一数据层保持一致。

## 2. 实施内容

- `CheckinSystem` 的完成记录查询改为异步优先读取 IndexedDB `RECORDS` 主存储。
- 仅在主存储没有该日期记录或读取失败时，回退读取旧版 `efflife_records_YYYY-MM-DD` 本地缓存。
- 自动补卡、指定日期补卡、昨日完成记录查询统一改为异步调用链。
- 应用启动检查和事件收件箱补卡入口补齐 `await`，避免数据尚未读取完成就作出补卡决定。
- 新增静态回归测试，覆盖主记录读取和启动调用链。
