# 0089-T-2026-09-26 任务中心异步操作防重

## 问题

待办创建和完成操作在请求进行期间没有独立的互斥状态。快速重复点击可能创建重复待办，或重复触发计划任务同步。

## 处理

- 为创建操作增加 `creatingTodo` 状态。
- 为完成操作增加按待办 ID 的 `completingTodoId` 状态。
- 请求期间禁用对应按钮，并在 finally 中恢复状态。

## 验证

- `npm run build`（`time-helper/desk`）
- `python -m pytest -q --disable-warnings --maxfail=1`
- `git diff --check`
