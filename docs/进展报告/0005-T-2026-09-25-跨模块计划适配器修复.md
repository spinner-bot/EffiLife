# 跨模块计划适配器修复

**文档性质**：临时实施报告

**创建时间**：2026-09-25（Asia/Shanghai）

**创建作者**：Codex

**触发原因**：检查统一 API 适配器时发现，计划任务提取逻辑错误地使用任务内容作为任务 ID，且日期格式未标准化。这会破坏计划与待办的跨模块关联。

## 1. 变更

修复 `common/api_gateway/adapters.py`：

- 统一把 `[年, 月, 日]` 转换为 `YYYY-MM-DD`；
- 任务 ID 优先使用 `internal_id`，兼容旧 API 的 `id`；
- 过滤软删除任务；
- 不再把任务内容误当成任务 ID。

## 2. 设计影响

该修复保持了 plan-helper 的内部编号和历史引用语义，同时让统一层获得稳定任务 ID。显示编号和内部编号的分离仍由 plan-helper API 负责，统一适配器只消费内部引用。

## 3. 验证

执行：

```text
python -m pytest -q tests/test_adapters.py tests/test_data_exchange.py tests/test_data_manager_bundle.py tests/test_integration.py --disable-warnings --maxfail=1
python -m py_compile common/api_gateway/adapters.py
git diff --check
```

结果：`13 passed`。
