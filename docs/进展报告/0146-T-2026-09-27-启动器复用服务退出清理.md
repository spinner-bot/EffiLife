# 0146-T-2026-09-27 启动器复用服务退出清理

## 发现

启动器检测到统一工作台已经运行时，会进入无限等待循环。若被复用的前端随后退出，启动器仍然存活，可能留下无端口的 Python 进程，并干扰后续启动与 sidecar 构建。

## 处理

- 复用已有前端时持续探测其 URL；服务不可达后自动退出复用分支。
- 继续保留 Ctrl+C 退出路径及配套服务的 `finally` 清理。
- 增加回归测试，验证复用前端停止后 launcher 会返回，不会启动重复前端。

## 验证

- `python -m pytest -q tests/test_launcher.py`：9 passed。
- `python -m pytest -q`：46 passed，9 warnings（既有集成测试返回值告警）。
- `python -m py_compile launcher/start.py`：通过。
- 已清理本轮确认属于 EffiLife 测试实例的遗留 launcher 进程；未处理其他项目进程。
