# 0170-T-2026-09-28 统一存档服务多语言补齐

## 1. 发现

设置页面已经使用统一 i18n catalog，但 `.efl` 存档服务内部仍直接写死文件对话框标题、文件类型名称、无效文件提示和 plan-helper 不可用警告。切换到 English 后，这些由服务层返回的文字仍会显示中文，破坏统一应用壳的语言一致性。

## 2. 调整

- `ArchiveService` 改用统一 `translate()` 获取导出/导入对话框标题。
- 文件类型名称、`.efl` 校验失败提示和事件计划快照不可用警告加入双语 catalog。
- 不改变 `.efl` manifest、dataset 名称、导入校验、回滚和 plan-helper 数据语义。

## 3. 验证

- 前端 i18n key parity 测试覆盖新增键，确保 `zh-CN` 与 `en-US` 同步。
- 运行 `npm run build` 验证 TypeScript 与生产构建。
- 运行完整 Python 回归测试，确认跨模块数据契约不受影响。
