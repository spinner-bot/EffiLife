# Windows 启动解释器可配置化

**文档性质**：临时实施报告  
**创建时间**：2026-10-01（Asia/Shanghai）  
**创建者**：Codex

## 1. 背景

Windows 启动脚本此前优先调用系统 `py -3`。在同时安装多个 Python、虚拟环境或便携式 Python 的机器上，启动器可能使用与用户测试环境不同的解释器，进而导致 PH sidecar 或诊断命令表现不一致。

## 2. 修复

- 增加 `EFFILIFE_PYTHON` 环境变量，允许正式部署或测试明确指定 Python 解释器。
- 未设置时保留原有 `py -3`/`python` 自动选择逻辑。
- 透传 launcher 退出码，便于脚本和 CI 判断启动结果。
- 增加 `EFFILIFE_NO_PAUSE=1` 非交互模式，避免自动化调用被批处理的 `pause` 阻塞。

## 3. 验证
