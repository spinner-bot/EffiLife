# 0132-T-2026-09-27 扩大待办用时补偿范围

## 发现的问题

上一轮补偿已覆盖“时间记录全部写入后，待办累计用时更新失败”的路径，但跨午夜拆分写入本身也是多步操作。如果中途某一条记录写入失败，之前已经写入的记录同样可能残留。

## 调整

将补偿逻辑覆盖整个记录用时事务链：从第一条时间记录开始写入，到待办累计用时更新成功为止。任一步失败，均按已登记的稳定 ID 和日期回滚已完成写入；回滚失败时继续显示明确的部分回滚错误。

这样同时覆盖：

- 单日记录写入失败；
- 跨午夜拆分记录的中途写入失败；
- 待办累计用时更新失败。
