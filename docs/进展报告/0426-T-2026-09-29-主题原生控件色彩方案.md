## 1. 触发原因

th 丰富主题已经通过统一 CSS token 应用于工作台页面，但浏览器原生表单控件可能仍采用系统默认色彩，深色和高级主题下出现视觉割裂。

## 2. 目标与实际完成情况

- 在主题 token 中增加 `color-scheme`；
- 根据主题背景色亮度推导 `dark` 或 `light`；
- 对无法解析的自定义颜色安全回退 `light`；
- 继续复用 App 根元素的统一 token 应用流程，不修改主题数据结构和 Canvas 动效；
- 增加主题契约测试。

## 5. 风险与下一步

- 自定义颜色目前只对十六进制背景进行亮度判断，复杂 CSS 颜色表达式使用安全的浅色回退。
- 后续如引入主题编辑器的自定义 CSS 色值，可再扩展颜色解析器，但不应让主题应用过程抛出异常。
