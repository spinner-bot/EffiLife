# 0155-T-2026-09-27 计划重置缓存一致性

## 问题

桌面端重置计划时，Plan Helper 服务不可用会被静默忽略，但本地 `PLAN_HELPER_SNAPSHOT` 仍可能保留旧事件计划。随后导出使用缓存兜底时，已重置的数据会重新出现。

## 调整

- `clearPlanHelperData` 现在先清理统一本地计划快照，再尝试清理桌面 Plan Helper 服务。
- 服务停止不再影响本地重置语义；服务恢复后不会收到旧缓存数据。
- 移动端和桌面端共用相同的本地清理路径。

## 数据边界

只改变“重置计划”的清理顺序，不改变 `.efl` 格式、原始 plan 快照结构、嵌套组或软删除语义。

## 验证

- 前端 `vue-tsc + vite build`：通过。
- Python 全量测试：`47 passed`。
- `git diff --check`：通过。
