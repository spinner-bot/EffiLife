# DataManager 接入统一交换协议

**文档性质**：临时实施报告

**创建时间**：2026-09-25（Asia/Shanghai）

**创建作者**：Codex

**触发原因**：统一数据交换层首版已经完成，需要接入现有共享数据管理器，形成未来统一设置页、备份页和导入导出的稳定调用入口。

## 1. 实施原则

- `DataManager` 自动导出跨模块引用；
- 各领域模块通过 `datasets` 参数提供自己的 canonical 数据；
- `DataManager` 不读取或强制改写模块私有存储；
- 导入默认只校验和读取，不自动覆盖本地数据。

## 2. 已完成

新增方法：

```python
DataManager.export_bundle(output_path, datasets=None, metadata=None)
DataManager.read_bundle(bundle_path)
```

导出包自动加入 `cross_refs` 数据集，使计划、待办和时间记录之间的引用关系能够随统一备份移动。模块数据仍通过适配器提供，避免在共享层复制三套领域逻辑。
