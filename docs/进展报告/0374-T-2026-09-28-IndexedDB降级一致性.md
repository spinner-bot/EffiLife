# 0374-T-2026-09-28 IndexedDB 降级一致性

## 发现

历史对象存储 keyPath 与通用 `set()` 的逻辑 key 不一致，造成浏览器中部分数据实际长期落在 localStorage；raw 待办存储在 IndexedDB 不可用时也无法读取或写入。

## 实施

- 通用写入按活动 keyPath 补齐 `date/id` 等字段；
- raw 集合增加独立 localStorage 回退读写；
- 删除和清空同时清理两类回退键；
- 增加存储契约测试，防止 keyPath 和 raw fallback 回退。

## 验证

提交前执行前端类型检查/生产构建和 Python 全量回归；真实浏览器 IndexedDB 故障注入仍列入后续端到端验收。
