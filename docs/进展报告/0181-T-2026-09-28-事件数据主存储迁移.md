# 0181-T-2026-09-28 事件数据主存储迁移

## 1. 目标

事件设置、事件收件箱、预警收件箱和每日去重标记此前只使用 localStorage。统一存档虽然可以写入 IndexedDB，但运行时不会读取这些主数据。

## 2. 调整

- 四类事件数据均增加 IndexedDB 水合和持久化。
- 保留 localStorage 兼容镜像及旧数据迁移路径。
- 保持现有同步查询和操作 API，新增 `whenReady()`。
- 应用启动在事件检查、自动补卡和背景音乐启动前等待三类已迁移服务完成水合。
- 每日触发标记改为内存状态驱动，避免每次查询重新依赖旧镜像。
