# 旧版存档缺失计划快照保护进展记录

## 1. 发现的问题

旧版单文件 `archive.json` 缺少 `planHelper` 时，解析器原先补成明确不可用的空计划快照。导入流程因此可能清空当前 plan-helper 数据，破坏旧存档导入的安全性。

## 2. 本次完成

- `ArchiveData.planHelper` 改为可选，并抽出非空的 `PlanHelperData` 类型供实时导出使用。
- 旧版缺少计划快照时保留 `undefined`，导入跳过 plan-helper 写入与清理。
- 旧版明确声明不可用时，继续执行现有清理和警告语义。
- canonical `.efl` 仍要求 `plan_helper` 数据集存在。
- 增加回归断言，覆盖缺失字段保护。
