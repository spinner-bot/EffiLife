# 计划工作台 Transition 根节点门禁

**文档性质**：临时实施报告  
**创建时间**：2026-10-01（Asia/Shanghai）  
**创建者**：Codex

## 1. 背景

计划工作台曾出现 Vue 编译器错误：`<Transition> expects exactly one child element or component`。原因是多个管理视图分支直接成为 Transition 的兄弟节点。

## 2. 当前约束

- `PlanView.vue` 的 `tab-fade` Transition 只保留一个稳定的 `pv-panel` 根节点。
- PH/TH 兼容工作台的概览、计划、编辑计划、规则、编辑规则和临时变更视图仍由同一根节点内的条件分支承载。
- 本次只增加结构回归门禁，不改变 PH 数据结构或工作台业务逻辑。

## 3. 验证

- 新增 `tests/test_transition_root_contract.py`，覆盖单根节点和全部管理视图分支。
- 前端生产构建已在同一代码基线通过；后续由 GitHub CI 持续复核。
