# 0092-T-2026-09-26 统一计划服务网络错误提示

## 问题

当 Plan Helper 未启动、端口不可访问或网络连接中断时，浏览器 `fetch` 会直接抛出底层异常。不同页面可能显示不一致且难以理解的错误文本。

## 处理

- 增加统一 `fetchPlan` 网络请求包装器。
- 将网络异常转换为“计划服务不可用，请确认服务已启动”。
- 保留现有响应状态和业务错误解析。
- 保持计划服务不可用时任务中心和时间计划仍可使用的降级策略。

## 验证

- `npm run build`（`time-helper/desk`）
- `python -m pytest -q --disable-warnings --maxfail=1`
- `git diff --check`
