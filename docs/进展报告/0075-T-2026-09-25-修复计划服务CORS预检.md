# 0075-T-2026-09-25 修复计划服务 CORS 预检

## 问题

统一前端和 Plan Helper API 使用不同端口。浏览器发送 JSON `POST`、`PUT` 或 `DELETE` 前会先发送 `OPTIONS` 预检，但服务端此前没有处理该方法，导致真实浏览器中的计划写操作可能失败；直接调用 API 的测试无法覆盖这个问题。

## 处理

- 为 `/api/` 增加 `OPTIONS` 预检响应。
- 为预检和 JSON 响应统一补充允许的方法与请求头。
- 增加真实 HTTP 服务级回归测试，验证前端来源、POST 方法和 `Content-Type` 请求头。

## 验证

- `python -m pytest tests/test_plan_server_cors.py -q`
- `python -m py_compile plan-helper/web/server.py`
- `git diff --check`
