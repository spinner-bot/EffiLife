# 主题分类注册表派生进展记录

- 状态：[完成]
- 创建时间：2026-09-29
- 执行者：Codex
- 关联方案：`docs/设计方案/0440-主题分类由注册表派生方案.md`

## 1. 背景

主题名称、描述和分类已经集中到 `ThemeEngine` 注册表，但设置页仍为四个固定分类各维护一段模板。新增主题分类需要同时修改页面，削弱了统一主题架构的可扩展性。

## 2. 本次完成

- 新增 `getAvailableThemeCategories()`，按主题注册表首次出现顺序去重派生分类。
- 设置页改为循环渲染分类和主题卡片，移除四段重复模板。
- 分类标题继续通过 i18n key 渲染，主题名称和描述继续使用注册表元数据。
- 从主题模块入口导出分类派生函数，保持公共主题模块边界一致。
- 增加回归断言，防止设置页重新硬编码分类。

## 3. 验证

- `python -m pytest -q tests/test_settings_theme_i18n.py`：10 passed。
- `python -m pytest -q`：420 passed。
- `npm run build`：成功，`vue-tsc` 与 `vite build` 均通过。
- `git diff --check`：通过。
- Tauri 原生安装包：当前环境没有 Rust/Cargo，未执行原生打包。

## 4. 结果

后续新增已有分类的主题只需修改 `ThemeEngine` 注册表；新增分类也会自动进入设置页分组，不再需要同步修改视图模板。
