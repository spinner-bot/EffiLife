# 待办数据模型兼容层

**文档性质**：临时实施报告
**创建时间**：2026-09-25（Asia/Shanghai）
**创建作者**：Codex

**触发原因**：检查 to-dos 原始模型后发现，统一待办首版只覆盖了最小 CRUD 字段。若直接在该模型上继续更新任务，可能丢失子任务、重复规则和优先级计算相关数据。

## 1. 已完成

- `UnifiedTodo` 补齐 to-dos 的关键兼容字段：
  - `subtasks`；
  - `recurrence`；
  - `deadline_warning_days`；
  - `sort_order`；
  - `priority_rank`、`urgent`、`important`；
  - `start_time`、`estimated_time`。
- 新增 `TodoSubtask` 和 `TodoRecurrence` 类型。
- `TodoService.normalize()` 在更新任务时保留这些字段，避免“读取后更新”造成数据丢失。
- 待办 ID 生成增加不支持 `crypto.randomUUID()` 的 WebView 降级路径。

## 2. 兼容边界

本次只调整统一模型和规范化逻辑，没有改变 to-dos 原始数据的字段含义，也没有把子任务扁平化为单一任务 ID。子任务仍然保持嵌套数组结构，后续可在统一页面中实现展开、完成和排序。

## 3. 验证计划

- 使用 Vite 生产构建验证类型与模板编译。
- 使用 `vue-tsc --noEmit` 对比本轮是否引入新增诊断。
- 下一阶段为子任务和重复任务补充服务层操作，并接入统一导入导出迁移器。
