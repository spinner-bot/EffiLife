# 归档操作区响应式布局

**文档性质**：临时实施报告  
**创建时间**：2026-10-01（Asia/Shanghai）  
**创建者**：Codex

## 1. 问题

设置页的统一数据归档操作（导出、导入、旧待办导入）原本在所有屏幕尺寸都纵向排列。桌面和平板上因此出现不必要的长页面，操作区没有利用横向空间。

## 2. 修复

- 桌面和平板将三个归档操作排列为等宽三列。
- 移动端（宽度不超过 680px）恢复纵向按钮，保证触控目标和文字有足够空间。
- 不改变统一 `effilife.bundle` 数据协议、导入确认和回滚逻辑。

## 3. 验证

- 增加设置页归档操作区响应式契约测试。
- 运行 PH/设置布局专项测试、全量 Python 测试和 TH 生产构建。
