# HOTL-1 导航与验证状态审计

**文档性质**：阶段审计报告  
**创建时间**：2026-10-01（Asia/Shanghai）  
**创建者**：Codex

## 1. 本次核验范围

- 桌面顶栏是否同时暴露 PH（计划）、TH（时间/记录）、TD（待办）独立入口。
- 移动底部导航是否保留同样的三个独立入口。
- `/plan`、`/management` 等旧入口是否继续正确导向 PH 工作台，而不是重新拆出旧页面。
- `/calendar` 是否仅作为历史兼容重定向，不重新引入日历功能。
- 全局搜索结果是否分别导向计划、待办、时间记录领域。

## 2. 结果

上述入口和边界均已由当前源码与契约测试确认：

- PH 使用 `/plans`，TH 使用 `/time` 与 `/records`，TD 使用 `/tasks`。
- 桌面导航与移动底部导航均有独立入口，并按当前路由输出 `aria-current`。
- 旧 `/plan`、`/management` 入口导向统一 PH 工作台；旧 `/calendar` 导向记录页。
- 全局搜索覆盖待办、活动计划、归档计划/任务及时间记录。
