# 0171-T-2026-09-28 统一应用引导更新

## 1. 发现

整合后的应用已经使用全局导航和独立工作台路由，但首次使用引导仍引用旧版 `.nav-btn`、计划 tab、日历详情和旧管理入口。引导因此可能无法找到目标元素，且文案不会随语言切换。

## 2. 调整

- 将实际运行的主引导收敛为当前统一应用壳的六步流程：欢迎、计划、待办、时间记录、设置、完成。
- 导航目标改为全局导航中的真实链接，不再依赖已经移除的旧 tab/class。
- 引导标题、说明、跳过确认、操作提示和按钮全部接入 `zh-CN` / `en-US` catalog。
- 保留旧步骤对象作为迁移历史，运行时覆盖为当前统一流程，避免破坏已有引导状态存储接口。
- 增加静态契约测试，锁定统一导航选择器并检查引导文案的双语键。

## 3. 验证

- `npm run build`：通过，1864 个模块转换成功。
- `python -m pytest -q tests/test_frontend_guide.py tests/test_frontend_i18n.py`：3 passed。
- 完整 Python 回归测试将在提交前执行。
