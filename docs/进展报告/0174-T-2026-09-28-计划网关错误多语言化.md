# 0174-T-2026-09-28 计划网关错误多语言化

## 1. 发现

计划网关已承担桌面、浏览器和移动快照三种运行时，但通用响应错误、移动快照缺失、目标任务不存在等错误仍在服务层直接写死中文。英文模式下，计划页和待办计划同步失败时会混入中文提示。

## 2. 调整

- `planGateway` 的通用服务错误、任务服务错误和移动快照错误改用 i18n catalog。
- `runtimeCapabilities` 的移动端不可用原因改用 catalog。
- 保留后端返回的具体 `payload.error`，只有通用 fallback 由前端本地化。
- 增加计划网关 i18n 静态契约测试，并由既有 catalog parity 测试校验双语键集合。

## 3. 约束

- 不改变计划原始数据结构、稳定任务引用、移动端快照编号或 API 协议。
- 不把后端领域错误强行翻译，避免丢失 plan-helper 的具体诊断信息。

## 4. 验证

- `npm run build`：通过，1864 个模块转换成功。
- 计划网关与 i18n 测试：2 passed。
- 完整 Python 回归测试：56 passed，9 warnings。
