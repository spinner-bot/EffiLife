# [完成] 首页打卡提醒行动入口验收

## 问题

首页在今日计划完成后会显示“可打卡”提醒，但原实现是带指针样式的 `div`，没有点击处理，也无法通过键盘聚焦。提醒因此与实际行动路径断开。

## 实现

- 将提醒改为原生 `button`，补充 `aria-label` 和明确的 `type`。
- 点击提醒直接进入 `/checkin`，复用首页已有打卡入口和现有打卡业务判定。
- 增加焦点、悬停和按下状态；触控高度保持 44px。
- 未修改 TH 数据结构、完成度计算、打卡判定或事件系统。
- 新增设计方案 `docs/设计方案/0075-首页打卡提醒行动入口方案.md`。

## 验收

- `python -m pytest tests/test_home_navigation_deduplication.py -q`：`3 passed`。
- `npm run build`：Vue 类型检查和 Vite 生产构建通过，1880 个模块转换成功。
- `python scripts/smoke_browser_workspace.py --url http://127.0.0.1:1420`：`ok: true`；统一导航、首页 TH 快速记录、主题/语言持久化、移动导航和确认框可访问性通过。
- 静态检查确认提醒使用按钮语义，并含 `/checkin` 路由动作。

## 边界

本次只修复首页提醒的可达性，不改变“计划完成后才可打卡”的业务规则。阶段保持第 0 阶段。
