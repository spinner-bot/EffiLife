# 0145-T-2026-09-27 发布工作流补齐 PH 侧车构建

## 发现

多平台 Tauri 发布 workflow 原先直接执行 `npm run tauri build`，但没有在干净 CI 环境生成 Plan Helper sidecar。若 runner 没有仓库外预置的二进制，正式安装包无法完成或缺少事件计划服务。

## 处理

- 在安装 PyInstaller 后、Tauri 打包前调用 `python scripts/build_plan_helper_sidecar.py`。
- 侧车构建脚本继续从当前 Rust host 自动识别目标 triple，输出到 Tauri 约定的 `src-tauri/binaries` 目录。
- 增加发布元数据回归测试，确保 sidecar 步骤位于 Tauri 打包步骤之前。

## 验证

- `python -m pytest -q tests/test_release_metadata.py tests/test_sidecar_build.py`：6 passed。
- `python scripts/build_plan_helper_sidecar.py --target x86_64-pc-windows-msvc --dry-run`：通过。
- 本机实际 PyInstaller 构建：成功生成并写入 Windows sidecar。
- 首次复制失败原因为旧测试 sidecar 进程占用目标文件；确认其命令行均为本项目测试实例后停止，重试成功。没有处理不属于本项目的进程。

## 交付边界

Linux/macOS 的实际 runner 安装包仍需 CI 环境执行；本机缺少 Rust/Cargo，不能代替多平台 Tauri 安装验收。
