# th 主题桥接与统一设计令牌

**文档性质**：临时实施报告

**创建时间**：2026-09-25（Asia/Shanghai）

**创建作者**：Codex

**触发原因**：最终产品必须保留 time-helper 的基础主题和高级主题架构，并让计划、待办等领域页面在统一桌面壳中自动继承主题。原实现只在 `App.vue` 中写入少量变量，无法覆盖其他模块需要的交互和状态令牌。

## 1. 已完成

在 `time-helper/desk/src/theme/ThemeEngine.ts` 新增 `getThemeCssVariables()`，将所有主题统一转换为 CSS 设计令牌，包括：

- 背景层级：背景、卡片、浮层、悬停；
- 文字层级：主文字、次文字、弱化文字、禁用文字；
- 边框和交互：边框、悬停边框、主色、主色悬停/激活、弱主色；
- 状态色：成功、警告、错误、信息及对应背景；
- 高级效果：渐变、毛玻璃、阴影、文字光晕。

`time-helper/desk/src/App.vue` 改为批量注入这些令牌，而不是维护一组局部变量。未来 plan-helper / to-dos 进入统一桌面壳后，只需使用相同 CSS 变量即可继承 th 主题，不需要复制主题实现。

## 2. 保留内容

- 未改变 `ThemeEngine` 的高级主题预设；
- 未改变 Canvas、粒子和动画渲染；
- 未改变用户已有主题配置格式；
- 主题切换仍通过原有响应式配置触发。
