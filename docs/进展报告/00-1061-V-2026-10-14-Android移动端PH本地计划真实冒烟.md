# [完成] Android 移动端 PH 本地计划真实冒烟

## 背景

Android 构建不携带桌面 Plan Helper sidecar，移动端通过 IndexedDB 中的 PH 原始计划快照提供本地能力。此前自动化只验证了移动导航和首页入口，没有在真实移动 User-Agent 下验证 PH 创建与编辑。

## 实施

- 扩展 `scripts/smoke_browser_workspace.py`，新增 `--mobile-ph-plan-flow`。
- 该流程使用 Android User-Agent 和移动 viewport，验证移动 PH 本地快照的创建与编辑，不依赖桌面 sidecar。
- 新增移动冒烟契约测试，锁定命令入口和关键验收断言。

## 真实验证

执行：

```text
python scripts/smoke_browser_workspace.py --url http://127.0.0.1:1420 --mobile-ph-plan-flow
```

结果：`ok: true`；移动导航、TH 快速记录入口、主题持久化、语言持久化，以及 PH“创建含 section/task 的整份计划→编辑计划名称”全部通过。

## 边界

本次是浏览器移动运行时验收，不等同于 Android 真机安装验收。Android ARM64 APK 已完成构建和静态校验；真实设备触控、系统文件选择器、分享面板和升级仍需 Android 设备或模拟器继续验证。iOS 仍不在当前范围内，阶段保持第 0 阶段。
