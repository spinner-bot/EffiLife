# 统一数据交换层首版

**文档性质**：临时实施报告

**创建时间**：2026-09-25（Asia/Shanghai）

**创建作者**：Codex

**触发原因**：三个模块的内部数据格式和存储方式不同，需要先建立统一、可迁移、可校验的跨模块导入导出边界，再逐步融合功能。

## 1. 设计决策

本阶段不直接重写任何模块的内部数据结构，而是建立统一交换包：

```text
EffiLife Bundle (.efl)
├── manifest.json
└── data/
    ├── plans.json
    ├── todos.json
    └── time_records.json
```

这样可以把“模块内部模型”和“产品级数据交换协议”解耦，降低迁移风险。

## 2. 已完成

新增 `common/data_exchange.py`，提供：

- `export_bundle()`：将多个 JSON 数据集导出为 ZIP 包；
- `inspect_bundle()`：只校验包和读取 manifest；
- `read_bundle()`：校验并读取所有数据集；
- `import_bundle()`：安全导入到指定目录，默认禁止覆盖已有文件。

协议包含：

- `format: effilife.bundle`；
- `format_version`；
- 创建时间；
- 数据集清单；
- 导出元数据。

写出过程使用临时文件并原子替换，避免中断留下半成品。数据集名称经过路径安全校验，导入前会检查 manifest、数据集声明和 JSON 内容。
