# 0383-T-2026-09-28 时间记录与待办双向导航

## 本次目标

补齐统一工作台中“待办 → 时间记录”和“时间记录 → 待办”的双向可达路径。

## 实施结果

- 记录列表的关联待办由静态文本改为可访问按钮，可返回待办中心并定位目标待办。
- 支持 `/records?todo=<id>`：目标待办存在时自动打开新增记录表单并预选关联关系。
- 保留原有关联保存、重复保护、删除清理和历史记录跳转逻辑。
- 增加导航契约测试与中英文文案。

## 验证

- `python -m pytest -q tests/test_record_todo_navigation.py`
- 桌面端 `npm run build`

## 后续

后续可继续把记录列表从“仅今日”扩展为统一时间轴筛选，但不在本次导航修复中改变既有日期语义。
