# 启动器主前端身份探测

**文档性质**：临时实施报告  
**创建时间**：2026-10-01（Asia/Shanghai）  
**创建者**：Codex

## 1. 问题

统一启动器会复用 1420 端口上已经返回 HTTP 200 的服务。仅凭状态码无法确认该服务是 EffiLife；端口被其他开发服务器占用时，启动器可能打开错误页面并误判为成功。

## 2. 修复

- 在 TH 前端入口增加稳定的 `application-name=EffiLife` 标记。
- 启动器对 1420 端口的复用检查要求同时匹配该身份标记。
- PH `/api/health` 的专用身份检查和其他模块服务的通用检查保持不变。
- 增加“其他 200 服务必须被拒绝、EffiLife 标记必须被接受”的回归测试。

## 3. 验证

- 启动器专项测试和全量 Python 测试将在提交前执行。
- 前端生产构建验证入口 HTML 和 Vue 类型检查。
