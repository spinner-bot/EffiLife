# 0264 发布版本源同步

## 本次进展

发现并修复桌面发布版本漂移：`time-helper/VERSION` 已经是 `1.6.1`，而前端包、Tauri 清单和 Cargo 清单仍是 `1.6.0`。

使用既有 `scripts/sync_desktop_version.py` 将三个桌面清单统一到版本源 `1.6.1`，没有修改用户已有的 `package-lock.json`。

## 验证

- 发布元数据测试现在同时读取 `time-helper/VERSION`，要求它与 package、Tauri、Cargo 四处完全一致。
- 发布工作流仍会在构建前执行同步脚本，防止后续打标签发布再次漂移。
