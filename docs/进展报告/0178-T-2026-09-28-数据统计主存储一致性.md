# 0178-T-2026-09-28 数据统计主存储一致性

## 1. 发现

存档导出已经优先读取 IndexedDB，但设置页的“当前数据”统计仍直接读取 localStorage。迁移完成后，两套镜像可能出现差异，导致用户看到的统计与实际工作台及导出内容不一致。

## 2. 调整

- `getDataStats` 对配置和计划统一通过 `readCoreJSON` 查询 IndexedDB。
- 事件设置和打卡仍按其当前运行时实现读取 localStorage，避免统计与实际模块状态分叉；音频设置已迁移到 IndexedDB 主存储。
- 核心数据保留 localStorage 作为 IndexedDB 不可用时的兼容回退。
- 记录导出不再把 IndexedDB 与旧 localStorage 日期集合合并，避免已删除的旧日期重新出现在存档中。
- 增加静态契约测试，防止统计逻辑退回旧镜像优先。
