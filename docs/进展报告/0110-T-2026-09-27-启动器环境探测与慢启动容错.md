# 0110-T-2026-09-27 启动器环境探测与慢启动容错

## 问题

统一启动器过去只要在 PATH 中找到 npm shim，就可能进入前端开发模式；当 Node 实际不可用时，用户只能看到后续命令失败。服务就绪等待时间也固定为 30 秒，慢机器或首次启动容易误报失败。

## 处理

- npm 探测现在要求 Node 运行时同时存在。
- 前端依赖检查要求 `node_modules/vite` 存在，避免不完整依赖目录被误判为已安装。
- 新增 `EFFILIFE_STARTUP_TIMEOUT`，启动等待限制在 5 到 180 秒之间，默认 30 秒。
- 增加启动器超时边界测试。

## 验证

- `python -m pytest -q tests/test_launcher.py`：8 passed。
- `python -m py_compile launcher/start.py`：通过。
- `git diff --check`：通过。
