# 0101-T-2026-09-27 计划服务启动竞态缓冲

## 问题

正式 Tauri 启动时会先异步拉起 Plan Helper sidecar。前端窗口可能在 sidecar HTTP 端口刚创建、但尚未开始响应的短时间内发出计划请求，若只尝试一次会暂时显示服务不可用。

## 处理

- 统一 `fetchPlan` 增加有限指数退避重试，最长约 3 秒。
- 保留 AbortSignal 取消语义，不对已取消请求继续重试。
- 最终失败仍返回统一的“计划服务不可用，请确认服务已启动”提示。
- 不改变 API 路径、响应格式或开发环境端口契约。

## 验证

- 前端生产构建。
- Python 全量测试。
- Tauri Rust 构建仍需发布环境 Cargo 工具链验收。
