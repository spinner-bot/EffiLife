# 主题多语言契约门禁进展记录

- 状态：[完成]
- 创建时间：2026-09-29
- 执行者：Codex
- 关联方案：`docs/设计方案/0441-主题注册表多语言契约方案.md`

## 1. 背景

主题注册表已经保存名称、描述和分类的翻译 key，但此前只检查字段结构，没有验证这些 key 是否同时存在于中英文目录。新增主题时可能因此出现运行时显示原始 key 的问题。

## 2. 本次完成

- 从 `ThemeEngine.ts` 注册表提取所有主题翻译 key。
- 契约测试要求每个 `nameKey`、`descriptionKey`、`categoryKey` 在中英文目录各存在一次。
- 同时检查主题 `type` 唯一，避免注册表重复导致主题卡片 key 冲突。
- 保留现有运行时 fallback，不改变用户数据或主题渲染逻辑。

## 3. 验证

- `python -m pytest -q tests/test_settings_theme_i18n.py tests/test_locale_registry.py`：13 passed。
- `git diff --check`：通过。
- 主题注册表当前全部翻译 key 均已在两套语言目录中登记。

## 4. 后续约束

新增主题时必须同步提交注册表条目和两套语言目录；测试会在漏加任一翻译时直接失败。
