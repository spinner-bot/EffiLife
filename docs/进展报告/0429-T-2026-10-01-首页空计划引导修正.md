# 首页空计划引导修正

**文档性质**：临时实施报告  
**创建时间**：2026-10-01（Asia/Shanghai）  
**创建者**：Codex

## 1. 问题

首页今日进度为空时，按钮虽然文案是“前往管理”，但实际使用旧的 `/plan` 兼容路由。该路由默认重定向到时间工作台，首次启动用户无法直接进入 PH 计划中心创建完整计划。

## 2. 修复

- 空计划状态直接跳转 `/plans`，进入 PH 计划工作台。
- 保留 `/plan` 旧书签兼容重定向，不改变 TH 时间工作台入口。
- 增加首页引导回归测试，锁定 PH/TH 入口边界。

## 3. 验证

- 首页工作流定向测试与全量 Python 测试将在提交前执行。
- TH 前端生产构建由 CI 与本地 Node 环境持续验证。
