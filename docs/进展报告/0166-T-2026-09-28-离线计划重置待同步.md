# 0166-T-2026-09-28 离线计划重置待同步

## 问题

此前重置计划时，如果 Plan Helper 服务离线，只能清除本地快照，服务器上的旧计划仍可能在服务恢复后回流。

## 调整

- 增加本地 `PLAN_HELPER_RESET_PENDING_KEY` tombstone。
- 重置计划时先清空本地快照并标记待同步。
- Plan Helper 网关在任何正常读写前自动提交 `{ plans: [], replace: true }`；成功后清除标记。
- 存档导出遇到待同步标记时，不接受服务器旧数据，继续使用本地清空状态并给出降级提示。
