# 默认待办分类本地化展示

## 1. 问题

待办默认分类的稳定 ID 已统一为 `default`，但历史持久化名称通常是中文。English 界面直接显示该名称时会出现语言混杂。

## 2. 实现

- 增加 `tasks.defaultCategory` 中英文资源。
- `TaskCenterView` 增加展示层 `categoryLabel()`，覆盖分类摘要、筛选下拉框、编辑下拉框和分类管理列表。
- 仅映射内置名称 `默认`/`Default`；用户自定义分类名称保持原样。
- 未改变分类 ID、存档内容、任务关联或删除规则。
