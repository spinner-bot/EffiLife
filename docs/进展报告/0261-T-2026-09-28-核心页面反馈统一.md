# 0261 核心页面反馈统一

## 本次进展

在 0260 的全局 Toast 基础上，继续迁移统一工作台中的核心页面：

- 时间记录页：输入校验与冲突提示。
- 计划管理页：计划、分类和规则校验，以及今日计划切换结果。
- 事件/打卡管理页：打卡结果与规则校验。

这些页面不再调用浏览器原生 `alert`，反馈不会阻塞用户继续编辑，也会继承当前主题和语言。
