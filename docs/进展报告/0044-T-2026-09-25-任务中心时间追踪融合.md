# 任务中心时间追踪融合

**文档性质**：临时实施报告  
**创建时间**：2026-09-25（Asia/Shanghai）  
**创建作者**：Codex  
**触发原因**：统一任务中心已有时间字段，但没有实际记录用时的操作，无法闭环替代原 to-dos 时间追踪。

## 1. 本次完成

- `TimeRecord` 增加可选 `id` 和 `todo_id`，兼容既有手工时间记录。
- `TodoService.trackTime` 增加分钟校验、累计用时和时间记录引用回写。
- 任务详情增加“记录用时”表单，默认 25 分钟，可记录 1–1440 分钟。
- 记录动作同时写入 time-helper 当日时间记录和任务 `time_spent`。
- 时间记录内容使用任务标题，标签使用任务分类，方便在原有记录视图中回溯。
- 新增设计方案 `0020-任务中心时间追踪融合方案.md`。

## 2. 验证

- `npm run build`（`time-helper/desk`）：通过，1849 个模块转换。
- Python 统一测试：`26 passed`。
- to-dos API：`36/36` 通过。
- plan-helper API：`13/13` 通过。

## 3. 边界

- 本次是手动记录时长，不引入后台自动计时或隐藏行为；后续如增加专注计时器，应复用同一 `trackTime` 入口。
- 删除任务不会删除历史时间记录，避免破坏时间统计；记录保留 `todo_id` 以便后续审计。
