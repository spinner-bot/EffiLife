# 旧版存档缺失记录字段保护进展记录

- 状态：[完成]
- 创建时间：2026-09-29
- 执行者：Codex
- 关联方案：`docs/设计方案/0444-旧版存档缺失记录字段保留方案.md`

## 1. 发现的问题

旧版单文件 `archive.json` 缺少 `records` 字段时，解析器原先将其变为空对象。导入流程随后把空对象当作明确的空数据集，清空当前时间记录，存在误删风险。

## 2. 本次完成

- `ArchiveData.records` 改为可选字段。
- 旧版存档缺失 `records` 时保留 `undefined`，导入流程不会进入记录清空分支。
- 关联修复仍使用临时空映射，避免无记录字段导致校验异常。
- 旧版显式 `{}` 仍按明确空数据集处理。
- canonical `.efl` 仍要求 `records` 数据集存在，未改变新协议门禁。
- 更新存档契约测试，覆盖该兼容语义。
