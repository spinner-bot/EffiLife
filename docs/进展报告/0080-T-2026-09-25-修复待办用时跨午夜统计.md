# 0080-T-2026-09-25 修复待办用时跨午夜统计

## 问题

待办用时记录原先以当前日期保存，并直接把结束时间格式化为时分。接近午夜时会生成类似 `23:50–00:15` 的记录，日报统计和重叠判断会得到错误结果，且待办只关联一个记录 ID。

## 处理

- 跨午夜用时按自然日拆分。
- 当天最后一段使用 `24:00` 明确表示午夜边界。
- 待办保存全部关联记录 ID。
- 时间解析器支持合法的 `24:00` 边界值。

## 验证

- `npm run build`（`time-helper/desk`）
- `python -m pytest -q --disable-warnings --maxfail=1`
- `git diff --check`
