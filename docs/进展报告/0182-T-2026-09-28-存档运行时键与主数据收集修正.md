# 0182-T-2026-09-28 存档运行时键与主数据收集修正

## 1. 发现

事件、音频和打卡服务已迁移到 IndexedDB 后，存档收集仍读取旧 localStorage 镜像；同时存档中的打卡键名和每日触发键名与运行时常量不一致，可能导致导出遗漏或恢复写入错误位置。

## 2. 调整

- `collectAllData` 对音频、事件收件箱、预警收件箱、每日触发和打卡统一使用 IndexedDB 主存储读取。
- 修正打卡兼容键为 `efflife_checkin_data`。
- 修正每日触发兼容键为 `efflife_daily_triggers`。
- 保留 localStorage 作为 IndexedDB 不可用时的回退，并让导入、重置与运行时使用同一键名。

## 3. 验证

- 存档主存储与运行时键契约测试：6 passed。
- 完整 Python 回归：67 passed，9 warnings。
- 前端构建：当前环境未提供 npm/node 命令。
