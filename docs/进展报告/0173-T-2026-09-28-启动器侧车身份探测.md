# 0173-T-2026-09-28 启动器侧车身份探测

## 1. 发现

launcher 之前判断 companion 是否已运行时只检查 `http://127.0.0.1:8765` 是否返回非 5xx。端口被其他本地服务占用时，launcher 可能错误复用该服务，统一工作台随后进入计划功能异常状态。

## 2. 调整

- 统一工作台 companion metadata 增加 `/api/health` 健康地址。
- launcher 复用和启动等待均优先探测健康地址。
- 健康响应必须包含 `plan-helper` 服务身份与状态字段，普通端口响应不再视为可用。
- 前端主服务的既有通用 HTTP 探测行为保持不变。
- 增加启动器健康身份探测测试。

## 3. 契约一致性

launcher、Tauri release 和 plan-helper 均使用同一 `/api/health` 身份契约，避免开发启动与正式安装包的可用性判断不一致。

## 4. 验证

- `python -m pytest -q tests/test_launcher.py`：应覆盖 companion 健康地址、身份校验和既有启动清理行为。
- 完整 Python 回归测试将在提交前执行。
