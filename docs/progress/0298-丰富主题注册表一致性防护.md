# 丰富主题注册表一致性防护

## 背景

EffiLife 的主题选择由 `ThemeEngine` 注册表驱动。主题设置页保存的是 `theme.type`，真正的视觉样式则由引擎中的预设决定。如果新增主题时只加入可选列表、没有加入引擎预设，用户会看到主题可以选择和保存，但应用会回退到默认样式，重新出现“主题无法切换”的问题。

## 本次处理

- 增加注册表一致性测试，自动提取所有可选主题类型。
- 将基础主题（纯色、渐变、玻璃、霓虹）与丰富主题区分处理。
- 要求每个丰富主题类型都存在对应的 `themePresets` 渲染预设。

## 验证

- 主题专项测试：10 passed
- 全量测试：604 passed
- 桌面端构建：成功，1874 个模块转换

## 结论

主题选择列表和 ThemeEngine 之间增加了自动化契约，后续新增丰富主题时不会再出现“可以保存但视觉不生效”的静默退化。
