# TH 按钮提交边界收紧

## 背景

统一工作台中的 TH 计划页面包含多个导航、切换、编辑和删除操作。它们都由点击事件驱动，不应依赖浏览器对 `button` 的默认类型推断，避免页面后续嵌入表单时出现意外提交。

## 本次处理

- 为 PlanView.vue 中所有带点击行为的按钮显式声明 `type="button"`。
- 覆盖顶部导航、计划管理、规则管理、临时切换、记录编辑以及跨行模板按钮。
- 增加静态回归测试，使用模板标签解析而不是单行匹配，能够检查跨行书写的按钮。

## 验证

- 计划页面按钮契约测试通过。
- 提交前执行完整 Python 测试、桌面端构建和发布配置检查。

## 结论

TH 仍然保持时间维度模块定位；本次只收紧原生按钮语义，不改变计划、规则和记录业务逻辑。
