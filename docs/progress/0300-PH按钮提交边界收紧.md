# PH 按钮提交边界收紧

## 背景

PH 详情页同时包含计划元信息、日志、模块、任务和嵌套分组等多个表单。普通操作按钮如果依赖 HTML 默认的 `button` 类型，未来被移动到表单容器后可能意外触发提交，造成保存、删除或编辑动作串扰。

## 本次处理

- 计划中心所有带 `@click` 的普通操作按钮显式声明 `type="button"`。
- 保留真正的提交按钮为 `type="submit"`，不改变创建、编辑、记录和分组保存流程。
- 增加静态契约，防止新增普通点击按钮重新依赖默认提交行为。

## 验证

- PH 编辑器专项测试通过
- 全量测试与桌面构建将在提交前执行

## 结论

PH 的交互按钮与表单提交边界更加明确，降低复杂编辑页面中误提交和操作串扰的风险。
