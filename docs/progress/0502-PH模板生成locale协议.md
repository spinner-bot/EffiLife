# 0502 PH 模板生成 locale 协议

## 本次变更

- `POST /api/plans/from-template` 支持可选 `locale` 字段。
- 统一工作台创建模板计划时传递当前 locale。
- Plan Helper 对内置模板生成英文内容副本；中文或未知语言保持原始中文模板。
- 自定义模板不自动翻译，避免改写用户模板内容。
- `plan-helper/docs/API_SPEC.md` 已同步声明 HTTP 请求字段、兼容行为和数据边界。
- 使用深拷贝和递归替换，原始模板注册表不会被英文创建污染。

## 验证

- Python 测试验证英文分组、任务和任务组内容，以及原始模板不变。
- 前端契约测试验证当前 locale 被传递。
- 前端多语言覆盖、全量测试和生产构建通过。
