# 历史记录搜索深链定位

日期：2026-10-02

## 问题

全局搜索可以定位到任意日期的 TH 记录，并通过 `/day/:date?record=...` 打开详情页。详情页原先只添加高亮样式，没有滚动到目标记录；当一天记录较多时，搜索结果的定位效果不完整。

## 调整

- 为历史记录生成稳定 DOM 锚点。
- 数据加载完成或 `record` 查询参数变化后，自动滚动目标记录到视口中央。
- 同时把详情页列表键从数组下标改为稳定记录键，降低刷新和删除后的 DOM 复用风险。

## 验证

- 搜索、历史身份键和新增契约测试：19 passed。
- `npm run build`：通过。
