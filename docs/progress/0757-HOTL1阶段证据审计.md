# 0757 HOTL-1 阶段证据审计

日期：2026-10-01

## 背景与目标

HOTL-1 要求 EffiLife 将 TH、PH、TD 融合到同一应用壳和工作流中，同时保持三者的领域边界：PH 管理完整事件计划，TD 管理单条快速待办，TH 管理时间记录与统计。审计目标是把当前代码证据与仍未完成的真实环境验收区分开。

## 逐项证据

### 1. 模块定位与协作

状态：已验证（配置/契约层）。

- `time-helper/desk/src/router/index.ts` 暴露 `/plans`、`/tasks`、`/time`、`/records` 独立入口。
- `tests/test_module_boundaries.py` 验证 PH 不直接拥有 TD 数据、TD 不直接编辑 PH 计划、TH 记录只保留显式关联。
- `tests/test_plan_raw_archive.py` 验证 PH 原始 `head/main/log`、软删除槽位、嵌套组和日志在交换中保留。

### 2. 首页工作流

状态：已验证（源代码与契约测试）。

- `HomeView.vue` 展示 TH 今日统计、PH 事件计划摘要和 TD 待办摘要，并提供独立深链。
- `tests/test_module_boundaries.py` 验证首页是跨模块仪表盘，而不是把三个实体合成一种数据。

### 3. 桌面/平板/移动布局

状态：已验证（静态布局契约）；真实浏览器视觉验收待 Node 工具链恢复后执行。

- `HomeView.vue` 桌面断点使用 1180px 工作区；PH 使用 1080px，TD/记录使用 1180px。
- `tests/test_desktop_workspace_layout.py` 共 13 项断言覆盖桌面宽屏、平板导航和移动堆叠。
- `tests/test_ph_responsive_layout.py` 覆盖移动任务行显式网格，避免按钮进入隐式列造成重叠。

### 4. 主题

状态：已验证（持久化契约）；真实桌面构建待补。

- `ThemeEngine.ts` 保留基础主题与丰富 TH 主题注册表。
- `SettingsView.vue` 使用脱离式草稿实时预览，离开主题设置时弹窗确认并保存，不提供独立保存按钮。
- `tests/test_theme_persistence_contract.py` 覆盖退出保存、竞态、双语提示和无保存按钮约束。
- 提交 `79229ca` 修复退出保存后的旧快照刷新竞态。

### 5. 独立日历入口

状态：已验证（统一桌面源代码）。

- 应用壳不再提供日历导航入口，`/calendar` 仅保留旧书签到 `/records` 的兼容重定向。
- `tests/test_unified_navigation_contract.py`、`tests/test_frontend_guide.py` 覆盖入口和引导文案。
- 归档的旧 Android 生成物仍可能含历史 CalendarView，不作为当前桌面应用源代码；恢复移动开发时必须重新生成并验收资源。

### 6. 统一启动、存档、导入导出、多语言

状态：已验证（Python 集成/契约层；前端构建待补）。

- `common/data_exchange.py` 与 `ArchiveService.ts` 统一使用 `effilife.bundle`、canonical datasets、校验和与导入回滚。
- `tests/test_data_exchange.py`、`tests/test_unified_archive_contract.py`、`tests/test_cross_runtime_archive_contract.py` 覆盖跨运行时结构与完整性。
- `common/i18n.py`、前端 `i18n/index.ts` 及 `tests/test_i18n.py`、前端键覆盖测试建立可扩展 locale 基础。
- `launcher/start.py`、`tests/test_launcher.py` 覆盖统一启动器服务复用、生命周期归属和诊断。

### 7. 发布与多端

状态：部分验证。

- `scripts/check_release_config.py` 当前通过；桌面发布矩阵覆盖 Windows NSIS、Linux deb/AppImage、macOS dmg。
- `scripts/sync_desktop_version.py` 已同步 package、lockfile、Tauri 和 Cargo 版本；发布 workflow 已在 `npm ci` 前执行同步。
- 本机缺少 Node/npm，无法执行桌面真实构建；GitHub API 当前受 403 限制，最新提交的远端状态暂未重新读取。
- Android 开发归档明确说明历史 APK 闪退与暂缓恢复，不能把静态 Android 生成物视为已完成移动验收。
