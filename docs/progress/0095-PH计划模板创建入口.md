# 0494 PH 计划模板创建入口

## 本次变更

- 接通统一计划工作台已有的模板查询接口和模板创建接口。
- 新建计划弹窗在桌面 Plan Helper 可用时显示模板选择；模板服务不可用或移动端运行时不伪造模板列表，仍使用手工首个行动路径。
- 模板创建后直接进入同一计划详情编辑器，不复制模板数据、不改变原始 plan 结构。
- 模板计划同样可以选择同步生成 TD 待办；同步失败不阻断计划创建。

## 验证

- `python -m pytest -q tests/test_plan_creation_flow.py`：6 passed。
- `npm run build`：通过，`vue-tsc` 与 Vite production build 均成功。

## 约束

模板入口是 PH 的创建辅助，不改变 PH 与 TD 的定位边界；TD 仍是独立的单条待办，只通过显式计划任务引用关联。
