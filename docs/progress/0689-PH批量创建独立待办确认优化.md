# 1195 PH 批量创建独立待办确认优化

日期：2026-10-10  
类型：交互优化与回归报告

## 背景

PH 支持用户主动将未完成计划任务复制为 TD，但批量操作原先会立即创建多条待办。由于 PH 与 TD 必须保持独立，批量操作需要在执行前明确告知其数量和独立生命周期。

## 实现

- 批量创建前增加确认弹窗，显示将创建的待办数量。
- 中英文确认文案明确说明：新 TD 不会随 PH 任务自动完成或修改。
- 无可创建任务时直接返回，不打开无意义的确认弹窗。
- 保留原有显式创建入口；取消确认不会产生任何数据变更。

## 验证

- PH/TD 及多语言定向测试：23 passed。
- `time-helper/desk` 执行 `npm run build`：通过，Vite 转换 1877 个模块。

## 结论

跨模块操作现在是可见、可取消的用户主动行为，不会让批量复制看起来像 PH 与 TD 的自动合并。
