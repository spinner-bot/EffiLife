# 00-1160-T-2026-10-14 TD 页面联动失败可重试

## 类型与阶段

T（技术实现）。当前仍为第 0 阶段；本报告只递增序列号，不增加阶段。

## 问题

首页已经支持 PH/TD 联动失败后的原地恢复，但 TD 独立页面在完成关联待办时仍只显示错误文本，没有重试入口；批量完成失败时也无法明确保留失败的具体待办。

## 实现

- TD 单条完成发生 PH→TD 投影失败时，保留具体失败待办。
- TD 页面错误区域增加“重试同步 TD”动作，并保持 `role="alert"` 可访问语义。
- 重试只补写尚未成功的 TD 投影，不重复执行已经完成的 PH 任务。
- 批量完成中记录当前失败待办，用户可从同一错误区域恢复。
- 重试成功后更新待办、清除错误状态并显示恢复反馈；失败时保留错误状态。

## 边界

现在首页、PH 计划中心和 TD 独立页面均具备联动失败后的恢复入口。TH、PH、TD 仍保持各自领域边界；本轮没有把跨存储操作伪装成事务，也没有改变 PH 原始数据结构。
