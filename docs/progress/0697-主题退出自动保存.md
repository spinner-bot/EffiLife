# 0697：主题退出自动保存

## 背景

主题编辑器原来同时提供实时预览、保存按钮和退出确认。实际使用中保存后退出可能再次进入草稿/回滚分支，用户感觉主题没有被修改；保存按钮也增加了不必要的操作步骤。

## 实现

- 主题选择和参数修改继续实时预览。
- 离开主题面板时自动持久化当前主题，移除保存按钮和退出确认。
- 持久化失败时保留在主题面板并提示错误，避免用户误以为设置已经保存。
- 中英文状态文案明确说明“退出主题面板时自动保存”。
