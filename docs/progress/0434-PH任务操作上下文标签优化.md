# 0860 PH 任务操作上下文标签优化

## 背景

计划详情中的同一任务行包含完成、记录、编辑和删除多个操作。此前这些按钮的无障碍名称只有“完成任务”“编辑任务”等通用文本；当读屏用户在多个任务之间移动时，无法判断当前操作对应哪一条计划任务。

## 本次调整

- 所有任务行操作标签加入 PH 的稳定显示编号和任务内容。
- 中文和英文目录均新增对应文案，继续通过统一 i18n 注册表提供文本。
- 不改变内部任务编号、软删除、嵌套分组或 PH/TD 模块边界。

- `python scripts/run_integration.py test`：55/55 passed
- 前端构建：提交前重新执行
