# 统一工作台过渡与记录身份复核

日期：2026-10-02

## 复核结果

此前用户报告的 `PlanView` `<Transition>` 多根节点问题当前已有稳定根节点契约：概览面板是唯一直接根节点，其他管理视图嵌套在其条件分支内。对应测试继续通过。

同时发现兼容工作台的记录列表仍使用“开始时间+标签”作为 `TransitionGroup` 键。相同时间和标签的两条记录可能发生键冲突，编辑或删除后会造成 Vue DOM 复用错误。

## 调整

- 优先使用时间记录自身的稳定 `id`。
- 对旧数据使用日期、开始/结束时间、标签和索引组成回退键。
- 不改变记录数据结构和 PH/TD 边界。

## 验证

- 过渡根节点、兼容记录身份和 TH 记录身份测试：4 passed。
- `npm run build`：通过。
