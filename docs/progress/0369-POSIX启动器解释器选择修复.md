# 0794 POSIX 启动器解释器选择修复

## 问题

Windows 启动器已经支持通过 `EFFILIFE_PYTHON` 指定解释器，但 POSIX 启动脚本固定使用 `python3`。在虚拟环境、便携式 Python 或打包环境中，这会导致启动器使用错误的运行时。

## 调整

- POSIX 启动脚本与 Windows 入口统一支持 `EFFILIFE_PYTHON`；
- 指定解释器不存在或不可执行时以 127 退出并给出明确错误；
- 使用 `exec` 转交进程，使退出码和信号行为保持透明；
- 默认仍使用 `python3`，不改变普通开发环境的启动方式。

## 验证

- 增加启动器契约测试；
- 未改变统一工作区默认入口或 legacy 菜单行为。
