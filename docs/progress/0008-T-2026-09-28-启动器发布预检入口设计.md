# 启动器发布预检入口设计

## 背景

正式安装包的版本、Tauri 配置、Plan Helper sidecar 和发布矩阵已有独立校验脚本，但启动器的诊断入口无法直接调用它。开发者在准备发布时需要记忆另一条脚本路径，且无法获得统一的 JSON 输出。

## 方案

- 为 `launcher/start.py` 增加只读参数 `--release-check`。
- 复用 `scripts.check_release_config.validate()`，不复制发布规则。
- 输出 `{ok, errors}` JSON；检查失败返回退出码 1。
- 参数优先于普通启动流程，不创建进程、不启动服务、不修改工作区数据。
- 保留原 `scripts/check_release_config.py` 作为 CI 和 npm 发布命令入口。
