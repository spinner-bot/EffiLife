# TD 与 PH 边界审计

日期：2026-10-02

## 背景

本轮探索了在 TD 工作区直接展示 PH 计划任务并提供深链的方案。全量测试证明，当前 HOTL 一号规范明确要求 TD 保持独立工作区，不能在 TD 页面直接读取或展示 PH 任务标识。

## 结论

- 不在 `TaskCenterView.vue` 中读取 `related_plan_id` 或 `related_plan_task_id`。
- 不向 TD 工作区增加 PH 编辑或计划任务跳转控件。
- PH↔TD 的关联数据、归档修复和统一搜索继续由统一服务/应用壳协调，不能改变模块职责边界。

- 已移除不合规实现，待回退提交后重新执行全量测试。
