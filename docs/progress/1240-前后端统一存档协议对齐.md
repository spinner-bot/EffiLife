# 1240｜前后端统一存档协议对齐

## 变更

前端 `ArchiveService.ts` 与 Python `common/data_exchange.py` 现在对首版 `.efl` 数据集名称使用相同迁移规则：

- `time_records` 兼容为 `records`。
- `plans` 兼容为 `plan_helper`。
- 缺失 `todo_categories` 兼容为空数组；显式错误类型仍拒绝。
- canonical 数据集优先，不覆盖新协议数据。
