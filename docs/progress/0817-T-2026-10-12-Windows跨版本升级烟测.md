# 0817｜Windows 跨版本升级烟测

类型：T（桌面升级验证）  
日期：2026-10-12  
状态：[进行中]

## 1. 目的

补充单版本安装/卸载之外的升级证据，验证仓库现有旧版 Windows 安装包可以被当前 1.7.0 NSIS 安装包覆盖升级，并且升级后仍可正常卸载。

## 2. 验证结果

- 使用旧版 `artifacts/releases/浪兮效率时钟_v1.0.11（desk_发布版）.exe` 在隔离目录安装：退出码 0。
- 使用 `EffiLife_1.7.0_x64-setup.exe` 对同一隔离目录执行静默覆盖安装：退出码 0。
- 升级后检查通过：`efflife-desk.exe`、`efflife-plan-helper.exe`、`uninstall.exe` 均存在。
- 升级后桌面程序文件版本为 `1.7.0`，文件大小为 13,528,064 bytes。
- 升级后的卸载程序执行成功，隔离目录已清理。

## 3. 边界

- 本次证明旧版到 1.7.0 的本机安装覆盖链路可用，但不替代真实用户数据迁移、断电恢复、签名/时间戳和正式发布渠道验收。
- 正式升级策略仍应在发布环境使用签名产物、真实用户数据副本和保留/迁移策略继续验收。
