# 1215｜统一存档导出目录记忆修复

日期：2026-10-10  
状态：已完成并推送

## 背景与问题

桌面 Tauri 导出统一 `.efl` 存档后，旧逻辑把包含 `efflife_archive_` 的文件名前缀写入本地存储。下一次打开保存对话框时，这个前缀会被直接用作默认路径，导致当天日期和 `.efl` 扩展名不再由导出流程生成，跨日期重复导出时尤其不直观。

## 实施内容

1. 新增 `archiveDefaultPath`，将持久化值解释为目录，并按当前导出日期重新组合完整文件名。
2. 导出成功后只保存用户实际选择的目录。
3. 同时兼容 Windows `\\` 和 Unix `/` 路径分隔符，并清理目录末尾重复分隔符。
4. 增加契约测试，锁定目录记忆与完整默认文件名行为。

## 兼容性

旧版本已经保存的文件名前缀仍可被读取为路径字符串，但新一轮保存会将其作为目录前缀使用；不修改 `.efl` 协议、数据集、导入恢复逻辑或三模块数据边界。
