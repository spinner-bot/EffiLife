# TD 待办深链失效提示

日期：2026-10-09

## 背景

首页、全局搜索和其他工作区可以通过 `?todo=` 打开 TD 待办。待办被归档或删除后，TD 之前会静默停留在列表页，用户无法判断目标不存在还是加载失败。

## 目标与非目标

目标是让失效待办深链给出清晰、可翻译且不阻断工作的提示。

本次不恢复已删除待办、不改变归档语义、不把 TH/PH 数据并入 TD，也不把提示升级为阻断性错误。

## 实现

- `TaskCenterView.vue` 增加 `missingTodoTargetId` 状态。
- 目标待办不存在时显示非阻塞状态提示，仍保留待办中心全部功能。
- 合法目标仍按 active/completed/all 状态切换并滚动高亮。
- 路由切换和无目标访问会清理旧提示。
- 中英文 catalog 增加 `tasks.todoTargetMissing`。

## 兼容性

既有 `/tasks?todo=<id>` 深链格式不变；只有无法定位目标时增加反馈，不影响待办存储、计划关联或时间记录关联。
