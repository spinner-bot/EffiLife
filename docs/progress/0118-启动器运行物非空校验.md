# 启动器运行物非空校验

日期：2026-09-30

## 问题

统一启动器在打包模式和无 Node 的静态回退模式中，原先只检查 EXE 或 `dist/index.html` 是否存在。损坏的零字节文件会被误判为可启动，直到子进程启动时才失败。

## 处理

- 增加统一的非空普通文件检查。
- Tauri release/debug 二进制和静态 `index.html` 均必须通过该检查。
- 保持开发模式优先使用 npm、打包模式禁止回退到 npm 的既有边界不变。
- 增加零字节二进制和静态页面的回归测试。

## 验证

- 启动器专项测试通过。
- 随后执行项目全量 Python 回归。
