# 1019 首页摘要首次加载态

## 背景

统一首页会并置 TH、PH、TD 的摘要。三个摘要分别从不同存储或服务读取，首次进入首页时，旧界面会先显示默认的 `0`、`0/0` 或“暂无计划”，直到异步读取完成。用户容易把短暂的初始化状态误认为真实数据为空。

## 实现

- 为首页摘要增加一次性的 `workspaceSummaryReady` 状态。
- 首次读取完成前，摘要卡显示中性占位符和加载提示，不伪造模块数据。
- 时间统计、PH 计划摘要和 TD 待办分别继续保留自己的不可用错误状态。
- 后续定时刷新不再切换回加载态，避免页面闪烁。
- 为统计卡和今日待办增加轻量加载反馈，并适配减少动态效果偏好。

## 边界

本次只改善统一首页的读取反馈，不合并 TH、PH、TD 的实体、入口或生命周期，也不改变统一存档协议和主题架构。

## 验证

- `python -m pytest -q`
