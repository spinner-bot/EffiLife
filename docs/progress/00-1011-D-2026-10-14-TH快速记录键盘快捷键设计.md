# [设计] TH 快速记录键盘快捷键

## 创建信息

- 创建时间：2026-10-14
- 执行者：Codex
- 所属阶段：第 0 阶段（阶段未递增）
- 类型：桌面端交互设计

## 背景

首页已经提供 TH“记录时间”按钮，但桌面端时间记录属于高频动作；用户在工作页面中不应为了记录一次时间而先切回首页。

## 设计决策

- 使用 `Ctrl+Shift+T`（macOS 使用 `⌘+Shift+T`），语义为“Time capture”。
- 在输入框、文本域、下拉框和可编辑元素中不拦截快捷键，避免破坏用户输入。
- 快捷键只导航到 `/time?compose=1`，由 TH 自己打开既有表单并处理焦点、取消、校验和保存。
- 在 TH 全局导航项的 `aria-keyshortcuts` 中声明快捷键，同时保留现有 `Alt+3` 模块导航。
- 不新增全局计时器，不把 PH 或 TD 任务转换成 TH 数据。

## 非目标

- 不在快捷键处理器中复制记录表单逻辑。
- 不改变移动端触控导航；移动端继续使用首页入口和底部导航。
- 不改变主题、语言、存档或数据格式。

## 验收条件

- 桌面页面按 `Ctrl+Shift+T` 后进入 TH 并打开记录表单。
- 聚焦输入控件时快捷键不触发导航。
- 生产构建和浏览器烟测通过，TH 现有快速记录路径保持可用。
