# 0642 归档 PH 任务纳入统一搜索

## 背景

统一搜索此前可以找到活动 PH 计划、活动 PH 任务和归档 PH 计划，但归档计划内部任务没有索引。归档计划仍可能被 TD 或 TH 记录引用，仅能搜索到计划标题不够精确。

## 实现

- Plan Helper 在归档摘要中增加只读 `tasks` 投影，按 PH 原始内部编号和当前显示编号同时保留任务身份。
- 移动端从已有归档快照生成同样的任务投影，桌面端由归档 API 生成同构投影。
- GlobalSearch 索引归档任务，并使用 `archive=<file>&task=<internal_id>` 精确打开归档 PH 任务。
- 不改变归档文件原始 payload、任务编号规则、软删除或嵌套组结构。

## 兼容性

- `tasks` 是可选摘要字段，旧缓存/旧归档没有该字段时仍可搜索归档计划本身。
- 活动 PH 任务搜索路径保持不变。
- TD、TH 关联数据和统一存档协议不变。
