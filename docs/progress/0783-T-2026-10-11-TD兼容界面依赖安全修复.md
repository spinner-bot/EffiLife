# TD 兼容界面依赖安全修复

日期：2026-10-11

## 背景

TD 兼容 Web 界面在真实 `npm audit` 中发现 8 项依赖告警。审计结果表明，其中 `source-map-js` 可以在不改变构建框架主版本的情况下升级；其余告警由 Tailwind 3 的旧依赖链引起，npm 建议通过 Tailwind 4 破坏性升级修复。

## 目标与非目标

目标是先修复可安全隔离的 `source-map-js` 高危告警，并保留 Tailwind 3 的兼容性边界。

非目标是本次直接迁移 Tailwind 4；该迁移需要单独评估配置、PostCSS 和样式回归。

## 影响范围

仅涉及 `to-dos/ui/package.json`、`to-dos/ui/package-lock.json` 及依赖契约测试；不影响统一工作台、PH 数据结构或 `.efl` 存档。

## 实施内容

- 增加 npm `overrides.source-map-js`，锁定到 `^1.2.2`；
- 更新锁文件到 `source-map-js@1.2.2`；
- 增加测试，防止安全覆盖丢失或未经迁移意外升级 Tailwind 主版本。

## 兼容性与迁移说明

TD 兼容 UI 的 Tailwind 版本仍为 3.x，现有样式和构建方式不变。后续若处理剩余 7 项告警，应单独建立 Tailwind 4 迁移任务并进行完整视觉回归。
