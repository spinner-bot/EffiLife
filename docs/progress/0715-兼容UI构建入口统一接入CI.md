# 1225｜兼容 UI 构建入口统一接入 CI

日期：2026-10-10  
状态：已完成并推送

## 背景

普通 CI 与桌面发布工作流此前在 `to-dos/ui` 直接执行 `npm run build`，绕过了已经能够复用启动器 Node 环境的 `scripts/build_todos_ui.py`。这使 Windows 自定义 Node 目录、本地构建和远端构建存在行为差异，也是 run fail 风险的来源之一。

## 实施内容

- 普通 CI 的兼容 UI 构建改为 `python scripts/build_todos_ui.py`。
- 桌面发布兼容性 job 同样改用统一入口；依赖安装仍在 `to-dos/ui` 执行 `npm ci`。
- 更新桌面发布配置检查和 CI/发布 workflow 契约测试。
- 移动端 Tauri 的原生 `beforeBuildCommand` 保持不变。
