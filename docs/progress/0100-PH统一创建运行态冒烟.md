# 0499 PH 统一创建运行态冒烟

## 检查范围

在不写入用户数据的前提下，对当前已运行的开发集成环境执行只读请求：

- `http://127.0.0.1:1420/`
- `http://127.0.0.1:8765/api/plans`
- `http://127.0.0.1:8765/api/templates`

## 结果

- 统一前端返回 HTTP 200，SPA 入口正常。
- Plan Helper 计划列表返回 `success: true`、空计划集和 `count: 0`，与首次启动真实空状态一致。
- 模板接口返回 `success: true` 和可用模板列表，满足统一创建弹窗的模板选择契约。
- 未执行 POST 创建，避免对用户本地计划数据产生副作用。

## 结论

PH 手工首个行动创建和模板创建的服务端依赖均可达；后续真实写入验收应使用隔离数据目录或专用测试环境。
