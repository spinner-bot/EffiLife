# 1186 首页统一刷新入口实现

日期：2026-10-09  
类型：实现报告

## 背景与目标

统一首页同时展示 TH、PH、TD 摘要。此前各模块只有独立重试入口，用户在跨模块操作后缺少明确的一键刷新动作。本次按 [1185 设计报告](1185-首页统一刷新入口设计.md) 增加统一刷新入口。

## 实现内容

- 首页标题区域新增统一刷新按钮。
- 按钮复用 `refreshWorkspaceSummaries()`，一次刷新 TH 今日数据、PH 计划摘要和 TD 待办摘要。
- 刷新期间按钮禁用并暴露 `aria-busy`，图标提供旋转反馈；减少动效设置下关闭旋转动画。
- 新增中英文 `home.refreshWorkspace` 文案。
- 增加首页回归契约，确认按钮、状态和三模块协调器均存在。

## 兼容性与边界

未改变 PH、TD、TH 的数据模型、服务边界、统一存档协议或现有独立重试逻辑。刷新仍使用原有请求序列化、请求编号和不可用状态处理。移动端沿用同一入口和触控尺寸；本次未替代真实移动设备视觉验收。
