# 0595｜全局搜索模块身份标识

## 背景

全局搜索已经统一索引 TH 时间记录、PH 计划/计划任务和 TD 待办，但结果行原先主要依靠图标区分来源。计划与计划任务都使用 PH 图标，TD 待办与 PH 任务在长列表中不够直观，不利于体现“功能融合但领域独立”的产品定位。

## 实施

- 为搜索结果增加双语模块标签：`TH · 记录`、`PH · 计划`、`PH · 任务`、`TD · 待办`。
- 结果的原有深链和搜索排序逻辑保持不变。
- 保留图标作为快速识别，同时使用文字标签提升可读性和无障碍理解。
- 新增模块标签覆盖测试，确保两个语言目录都存在对应文案。

## 验证

- `python -m pytest -q tests/test_global_search.py`
- 后续执行全量 Python 测试与桌面端构建。
