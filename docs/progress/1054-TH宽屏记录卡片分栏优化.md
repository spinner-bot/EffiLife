# 1054 TH 宽屏记录卡片分栏优化

日期：2026-10-02

## 问题

TH 记录页已经在宽屏下使用双列记录卡片，但每张卡片内部仍将时间、内容、关联待办和操作按钮纵向排列，信息密度和扫描效率仍偏向移动端。

## 实现

- 在宽度 `>= 1100px` 时，将单条记录内部调整为三列：时间与标签、记录内容及关联待办、编辑/删除操作。
- 长内容和关联待办使用最小宽度与省略策略，避免操作区被挤出或横向溢出。
- `<= 1099px` 保持原有卡片流式布局，移动端不引入桌面密度。
- 增加桌面内部栏位的回归断言。

## 验证

- TH 桌面布局、记录联动与时间边界专项测试：`30 passed`。
- Python 全量测试：`809 passed in 7.73s`。
- 桌面前端生产构建：`vue-tsc` 通过，Vite 完成 `1877 modules transformed`，构建成功。

## 影响范围

仅改善 TH 记录页桌面端的信息扫描和操作定位，不改变记录数据、PH/TD 联动、时间校验或移动端布局。
