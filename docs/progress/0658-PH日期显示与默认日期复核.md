# 1164 PH 日期显示与默认日期复核

日期：2026-10-09  
类型：计划工作台日期语义回归防护

## 背景与目标

早期 PH 曾出现日期显示为 `yyyy/mm/日`、日字段未补零，以及创建计划时没有默认当前日期的问题。统一工作台和兼容入口都需要持续保持同一日期语义。

## 复核结果

- 统一 PH 工作台创建和编辑表单使用本地 `YYYY-MM-DD` 日期输入，并默认填充当前日期。
- 计划日期展示使用当前语言的 `Intl.DateTimeFormat`，明确要求两位月份和两位日期。
- 兼容 PH Web 入口继续使用本地年月日组件和两位月份/日期格式。
- 新增契约测试，覆盖统一入口和兼容入口，防止未来重构回退。

## 边界

本轮只固定日期输入和显示语义，不改变 PH Plan 数据结构、嵌套组、编号算法、日志或 TD 独立实体边界。代码与报告直接提交到 `main`，不创建分支。
