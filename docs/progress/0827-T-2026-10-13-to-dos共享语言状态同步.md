# 0827｜to-dos 共享语言状态同步

类型：T（兼容入口多语言基础）  
日期：2026-10-13  
状态：[进行中]

## 1. 目的

使 to-dos 兼容入口的多语言状态真正接入统一工作区，而不是只在启动时读取一次 `efflife_locale`。

## 2. 本阶段实现

- 监听 `storage`、`effilife:locale-changed` 和 `effilife:workspace-changed` 事件，同步共享语言状态。
- `setLocale` 更新共享存储后发出同窗口语言事件，兼容其他工作区根组件同步刷新。
- 设置面板刷新频率、待办表单重复规则和截止提醒选项改为 computed 文案，语言变化后会重新生成。
- 增加共享语言事件与响应式选项契约测试，多语言定向测试共 10 项。

## 3. 验证

- `python scripts/build_todos_ui.py`：通过，Vue/Vite 构建转换 1768 个模块。
- `python -m pytest -q tests/test_todos_legacy_i18n.py`：通过，10 passed。

## 4. 边界

- 只同步语言显示状态，不改变 to-dos 数据结构、存储键、导入导出和优先级业务逻辑。
- iOS 端仍按用户决定暂不推进；桌面统一壳和 Android 构建边界不受本阶段改变。
