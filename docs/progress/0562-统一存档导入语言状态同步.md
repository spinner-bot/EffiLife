# 1068｜统一存档导入语言状态同步

## 发现的问题

统一 `.efl` 存档包含 locale，但导入时只写入 `localStorage`。如果用户不立即重载页面，当前窗口仍使用旧语言；HTML `lang/dir` 和其他窗口也不会同步。

## 实施内容

- 存档导入改为调用 i18n 的 `setLocale`。
- 由统一语言边界负责持久化、HTML 元素同步和跨窗口广播。
- 增加存档语言导入契约测试。

## 验证结果

- 存档语言导入契约测试通过。
- 既有 i18n 覆盖测试和桌面构建作为回归验证。

## 边界说明

只改变存档导入后的语言状态同步，不改变存档格式、数据集内容、回滚和 PH 快照策略。
