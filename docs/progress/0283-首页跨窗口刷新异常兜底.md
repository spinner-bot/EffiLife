# 0685：首页跨窗口刷新异常兜底

## 背景

首页会在其他窗口修改计划、记录或设置后延迟刷新三个模块摘要。此前该延迟回调直接等待 `Promise.all`，任一存储读取失败都会形成未处理 rejection，影响运行时稳定性。

## 实现

- 为首页跨窗口摘要刷新增加 `try/catch`。
- 失败时保留当前已渲染界面，并记录诊断信息；后续工作区事件或周期刷新仍可重试。
- 不改变 PH、TD、TH 的数据职责和刷新内容。
