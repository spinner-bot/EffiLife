# 0810 桌面发布并发与超时控制

## 日期

2026-10-01

## 背景

EffiLife 桌面发布包含兼容 UI、Windows NSIS、Linux DEB/AppImage 和 macOS DMG 多个 job。移动发布已经具备目标隔离和超时控制，但桌面发布没有明确的并发组与 job 超时，异常 runner 可能长期占用发布资源。

## 实施

- 按 Git ref 为桌面发布 workflow 设置并发组。
- 不自动取消同 ref 的已有发布，避免多平台安装包被中途终止。
- 兼容 UI 与 publish job 设置 15 分钟超时；平台安装包 build job 设置 45 分钟超时。
- 不改变 tag 触发规则、四平台矩阵、sidecar、校验和、manifest 或发布步骤。

## 验证

- `python -m pytest -q tests/test_release_metadata.py`：`15 passed`。
- `python -m pytest -q`：`673 passed`。
- `git diff --check`：通过，仅有 Git 的换行符提示。

## 未验证项

当前机器没有 Cargo/Rust，四平台真实安装包仍需 GitHub 原生 runner 完成；本次只增强 workflow 的运行边界。
