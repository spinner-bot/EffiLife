# 移动工程路径文档一致性

日期：2026-09-30

## 背景

Tauri 的 iOS 初始化工程使用共享的 Apple 原生工程目录 `time-helper/desk/src-tauri/gen/apple`，而不是按平台名称推导的 `gen/ios`。构建环境预检脚本已经完成修正，但历史设计文档仍存在旧路径描述，容易误导后续发布维护。

## 本次处理

- 更新多端构建预检方案中的验收标准，将 iOS 工程路径统一为 `src-tauri/gen/apple`。
- 更新对应进展记录，明确 iOS 使用共享 Apple 工程目录。
- 保留 0518 工作流文档中对旧路径的反例说明，作为防回归提示。

## 验证

- `tests/test_build_environment.py`：覆盖 iOS 使用 `gen/apple` 的报告契约。
- `tests/test_mobile_workflow.py`：覆盖移动端工作流路径与构建边界。
- `python scripts/check_build_environment.py --target ios`：在当前机器缺少 Xcode/Rust 时正确报告环境缺项，并显示 `gen/apple`。
