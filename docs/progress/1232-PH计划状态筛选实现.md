# 1232｜PH 计划状态筛选实现

## 变更

在 PH 计划中心增加“全部 / 进行中 / 已完成”状态筛选，并与原有名称、编号、日期搜索组合使用。

状态判定保持保守：只有存在至少一个任务且已完成任务数不少于任务总数时才归入“已完成”；空计划归入“进行中”，避免空计划被误报为完成。

## 边界保持

- 只筛选 PH 计划摘要，不修改 plan 数据结构、任务编号、嵌套组、执行日志或 TD 链接。
- TD 仍保持独立生命周期；筛选器不读取或改变 TD 状态。
- 桌面端横向使用工具栏空间，移动端自动纵向排列。
