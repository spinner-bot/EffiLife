# 1016 旧版存档主题兼容规范化

## 发现

统一存档同时支持 canonical `manifest.json + data/*.json` 和早期 `archive.json`。1015 已覆盖 canonical 路径，但旧版解析分支仍会把配置原样带入导入流程，存在绕过主题规范化边界的可能。

## 修复

旧版 `archive.json` 解析完成后，同样对 `legacy.config` 执行 `normalizeConfig`，再交给统一安装与回滚流程。这样旧存档、canonical 存档和正常设置保存使用同一份主题配置形状。

## 兼容性

- 仍保留旧版存档中的其他字段和已有迁移逻辑。
- 不改变旧存档识别、待办/记录关联修复或 PH 快照处理。
- 仅补齐配置缺失字段，不覆盖用户已经存在的主题字段。
