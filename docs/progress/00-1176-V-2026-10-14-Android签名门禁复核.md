# 00-1176-V-2026-10-14 Android 签名门禁复核

## 类型与阶段

V（验证验收）。当前仍为第 0 阶段；本报告只递增序列号，不增加阶段。

## 复核结果

- Android 正式签名只从 GitHub Secrets 读取 keystore、store password、alias 和 key password。
- 正式开关开启后，任一签名凭据缺失或无效都会使签名步骤失败，不会误把未签名 APK 当作正式包。
- 未开启正式发布开关时允许生成未签名测试 APK，便于本地和 CI 做构建验证。
- 签名脚本会先 zipalign、再签名和验证，验证成功后才替换未签名输入文件。

## 当前状态

本地没有受控正式 keystore，因此本轮不生成、不提交或推送任何密钥。Android 发布链已具备正式签名接入点，待发布凭据由产品发布环境配置后即可执行正式签名门禁。

## 边界

本轮不修改签名策略、不改变 Android 产物、不实施 iOS，也不宣称无设备条件下的运行时验收。
