# 1038 PH 与 TD 模块边界专项审计

日期：2026-10-02

## 审计目标

依据 HOTL-1，确认 PH 的基本单元仍然是完整计划，TD 的基本单元仍然是单条待办；统一工作台只能提供协同入口，不能把两者合并成同一类实体。

## 当前证据

- PH 使用独立入口 `/plans`，TD 使用独立入口 `/tasks`。
- 首页工作流摘要为三个独立入口：时间、PH 计划、TD 待办。
- PH 与 TD 在全局搜索中使用不同的结果类型和不同的深链接。
- PH 页面和 TD 页面分别展示 `moduleLabel` 与 `moduleDescription`，并分别提供中英文文案。
- TD 与 PH 的关联字段仅用于可选引用、完成联动和归档恢复，不改变两边的基本数据结构；无关联时两者均可独立工作。
