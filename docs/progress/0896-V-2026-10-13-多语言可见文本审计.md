# 0896 多语言可见文本审计

- 创建时间：2026-10-13
- 作者/执行者：Codex
- 状态：[完成]
- 阶段：第 0 阶段

## 触发原因

产品目标要求支持多语言。为避免新增设置/事件界面时绕过统一 i18n，本轮对核心 Vue 页面和组件执行可见文本审计，并结合现有 i18n 契约测试验证中文与英文资源覆盖。

## 审计结果

- 核心视图中的可见自然语言文本均通过 `t(...)`、动态本地化数据或技术标识/单位输出；未发现新增的硬编码自然语言文案。
- `localStorage`、`IndexedDB`、`TH`、`PH`、`TD` 等属于技术标识或产品模块标识，保留原文符合跨语言识别需要。
- 近期补齐的设置输入标签使用现有翻译键，不新增语言资源缺口。

## 验证

```text
python -m pytest tests -k i18n -q
88 passed, 1024 deselected

python -m pytest tests/test_api_i18n.py tests/test_settings_input_labels.py -q
4 passed
```

专项覆盖包括前端 key 覆盖、字面量 key、初始化、设置主题、日期、计划中心、恢复、待办和版本文案等契约。

## 结论与边界

当前源码级多语言覆盖有测试证据；真实浏览器切换语言后的长文本布局、RTL 语言和移动真机字体渲染仍未验证，不能以静态 key 覆盖替代视觉验收。

## 下一步

继续以新增用户可见文案必须进入 i18n 资源为门禁，并在后续真实设备验收中补充长文本和窄屏布局检查。
