# 1141 TH 记录删除稳定身份保护

日期：2026-10-05  
类型：实现报告

## 背景与目标

TH 的统一记录页、兼容计划工作台和历史详情页都允许删除记录。确认弹窗等待期间，跨窗口刷新可能改变记录数组顺序；若继续按旧下标删除，存在误删其他记录的风险。目标是让三条 TH 入口保持一致的稳定身份删除语义。

## 实现与兼容性

- 删除确认前捕获请求记录，确认后按稳定 `id` 在当前列表重新定位；
- 目标不存在时终止删除并显示本地化提示；
- 成功删除后仍清理 TD 的时间记录反向引用；
- 无 ID 的历史兼容记录保留原有下标回退路径；
- 不改变 TH 记录格式、PH/TD 关联或统一归档协议。
