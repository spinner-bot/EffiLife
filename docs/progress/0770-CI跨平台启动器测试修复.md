# 0770 CI 跨平台启动器测试修复

## 远端证据

GitHub Actions run `36820148028`（提交 `4b66a51`）在 `Run full Python test suite` 步骤失败，Node/npm 安装成功；后续集成、构建步骤因此被跳过。失败集中在启动器测试，而不是前端构建或统一数据层。

## 根因

启动器测试通过修改 `os.name` 伪造 Windows，然后对当前 runner 的临时 `PosixPath` 拼接 Windows 路径。Windows 开发机上的测试无法暴露该问题；Linux runner 会在路径构造阶段失败。空白自定义目录测试也错误地把 Windows 默认目录写死。

## 修复

- 动态自定义 Node 目录测试按当前平台的 `node_tool_filename()` 选择文件名，不再伪造平台类型。
- 空白环境变量测试按当前平台断言默认目录语义。
- 保留 POSIX 文件名规则的纯函数测试，避免跨平台路径类型冲突。
