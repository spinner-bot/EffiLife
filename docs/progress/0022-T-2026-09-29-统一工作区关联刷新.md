# 统一工作区关联刷新

## 背景

计划、待办和时间记录已经通过 `related_plan_*`、`todo_id` 与 `related_time_record_ids` 建立关联，但待办中心此前没有订阅统一工作区事件。用户在其他窗口或模块完成计划、删除时间记录、修改待办后，待办中心可能继续显示旧的关联状态。

## 本次调整

- 待办中心订阅 `workspaceEvents`。
- 接收到待办、计划、记录或归档变更时，重新加载待办、分类和必要的计划任务数据。
- 组件卸载时解除监听，避免路由切换后重复刷新。
- 增加契约测试，固定统一工作区刷新入口和监听生命周期。

## 验证

- Python 测试：312 passed。
- `time-helper/desk` 生产构建：通过，1874 modules transformed。

## 边界

本次不改变 Plan Helper 原始任务标识、软删除和嵌套组语义，只补足统一工作区的显示刷新链路。
