# 统一存档空主存储一致性

## 背景

统一存档以 IndexedDB 为记录主存储，并保留 localStorage 作为旧版本兼容镜像。原实现只有在 IndexedDB 返回至少一条记录时才认为读取成功；当主存储成功为空时，会错误回退到旧镜像，可能让已删除的时间记录重新出现在导出文件中。

## 调整

- 将“IndexedDB 成功返回空集合”视为有效的权威空数据。
- 仅在 IndexedDB 读取抛出异常时使用 localStorage 兼容回退。
- 保持旧版本迁移和 IndexedDB 不可用环境的兼容行为。
- 增加空主存储回归测试，防止存档导出复活过期数据。
