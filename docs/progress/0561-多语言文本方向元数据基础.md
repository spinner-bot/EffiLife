# 1067｜多语言文本方向元数据基础

## 变更目的

为后续扩展 RTL 语言预留应用壳能力。语言切换此前只维护 locale code 和 fallback，新增 RTL 语言时无法由语言定义驱动 HTML 根节点方向。

## 实施内容

- `LocaleDefinition` 增加 `direction: 'ltr' | 'rtl'`。
- 中文和英文明确声明为 `ltr`。
- locale 同步时同时更新 `document.documentElement.lang` 与 `document.documentElement.dir`。
- 未知定义安全回退到 `ltr`。
- 增加方向元数据契约测试。

## 验证结果

- 方向元数据契约测试通过。
- 现有多语言覆盖测试与桌面构建将作为回归验证。

## 边界说明

本次不改变中英文界面排版，也不伪造 RTL 翻译；只建立可扩展的语言元数据边界。
