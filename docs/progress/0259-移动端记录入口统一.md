# 0660-移动端记录入口统一

## 日期

2026-10-01

## 背景与问题

桌面导航提供 TH 的记录入口，但移动底部导航只有首页、计划、时间、待办和设置。移动用户必须从计划或待办的关联入口间接进入记录页，无法直接查看时间历史，不符合三模块统一工作台的入口原则。

## 目标与范围

- 为移动端补充独立的记录入口。
- 保持桌面导航和移动底部导航的布局差异。
- 不改变记录路由、数据结构或记录页面行为。

## 实现

- 在移动底部导航加入 `/records` 与 `/day` 的活动状态判断。
- 移动底部导航由五列调整为六列等宽布局，确保记录入口与其他一级模块同级。
- 更新导航可访问性契约测试，验证桌面与移动两套记录入口都声明当前页语义。

## 兼容性

仅增加移动端导航入口；既有桌面入口、深链接、记录与日详情路由保持不变。移动端仍使用独立底部导航，不引入日历功能。

## 验证

- 运行导航相关 Python 契约测试。
- 运行完整 Python 测试集。
- 使用项目约定 Node 工具链运行桌面端前端构建。
