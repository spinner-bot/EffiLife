# 0812 主题退出持久化修复

日期：2026-10-01

## 背景

主题设置已经取消独立保存按钮，采用“编辑时预览、退出时确认并保存”的交互。但在设置页退出期间，应用级刷新可能替换运行时配置，导致保存数据以预览对象为基准，出现确认退出后主题恢复旧值的风险。

## 本次目标

确保主题退出确认后的持久化数据始终来自已保存快照与当前编辑草稿，不受运行时刷新对象影响；保留取消退出时的草稿预览，并维持丰富主题字段。

## 实现

- `buildDraftTheme()` 改用 `savedThemeSnapshot` 作为未编辑字段的基准。
- 运行时 `config` 仅用于应用预览，不再作为退出保存草稿的源对象。
- 保留退出确认、持久化读回校验和失败时保留 dirty 状态的行为。
- 更新主题持久化契约测试，明确禁止从实时预览对象组装草稿。
