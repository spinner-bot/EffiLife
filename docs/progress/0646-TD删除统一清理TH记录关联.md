# 1152 TD 删除统一清理 TH 记录关联

日期：2026-10-05  
类型：TH/TD 数据完整性修复

## 背景与问题

任务中心页面删除 TD 时会主动清理 TH 记录中的 `todo_id`，但其它直接调用 `TodoService.remove` 的入口没有同等保证，可能留下孤立的时间记录反向引用。

## 实现

- 将 `DataService.unlinkTodoFromRecords` 下沉接入 `TodoService.remove`。
- 删除 TD 前清理 TH 记录中的反向字段，但不删除时间记录历史。
- 清理失败只记录警告，仍继续删除 TD，避免服务边界被辅助镜像问题阻断。
- 保留页面层清理逻辑，兼容已有调用路径并避免行为回退。

## 验证

- TD 删除与记录关联专项测试：7 passed。
- 项目全量测试：907 passed。
- `time-helper/desk`：`npm run build`，通过，1877 modules transformed。

## 提交与边界

代码与报告直接提交到 `main` 并推送。TH 历史记录仍由 TH 保留，TD 删除不会删除历史投入数据。
