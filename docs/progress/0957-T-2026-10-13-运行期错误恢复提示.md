# [完成] 运行期错误恢复提示

## 问题

工作台已有启动失败重试界面，但运行期 Vue 组件异常或未处理 Promise 拒绝可能只在控制台出现，用户看到的可能是局部空白或失去响应，缺少明确的恢复入口。

## 实现

- 在应用入口注册 Vue 全局错误处理器，并捕获未处理 Promise 拒绝。
- 通过统一运行期错误事件交给应用壳处理，避免业务组件直接依赖通知服务。
- 增加双语、可访问的错误提示条，展示有限诊断信息并提供重新加载、关闭提示两个操作。
- 错误提示只显示首个错误，避免同一故障连续触发时遮蔽工作台；重新加载仍由用户主动确认。

## 验证

- 运行期错误恢复、启动水合、可访问性与本地化专项：14 passed。
- 桌面端生产构建：Vite 1879 modules，成功。

## 边界

- 该机制是运行期恢复提示，不替代启动初始化错误页、数据恢复面板或底层故障修复。
- 未将完整堆栈直接展示给用户；当前仅展示错误消息和来源，后续可接入受控诊断导出。
