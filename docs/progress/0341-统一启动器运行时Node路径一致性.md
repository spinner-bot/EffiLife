# 0765 统一启动器运行时 Node 路径一致性

## 问题

环境诊断脚本会在调用时读取 `EFFILIFE_NODE_DIR`，但统一启动器在模块导入时就固定 Node 目录。嵌入式启动、安装包启动或宿主进程稍后注入环境变量时，可能出现“诊断可用、实际启动找不到 Node/npm”的不一致。

## 处理

- 启动器改为每次查找 Node/npm 或构造子进程环境时读取当前 `EFFILIFE_NODE_DIR`。
- 空白环境变量按未配置处理，继续使用 Windows 默认开发工具目录。
- 增加自定义目录和空白配置回归测试。

## 验证

本记录对应的启动器测试与完整 Python 测试应通过；前端构建继续使用同一自定义 Node 目录验证。
