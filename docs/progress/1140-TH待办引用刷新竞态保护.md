# 1140 TH 待办引用刷新竞态保护

日期：2026-10-05  
类型：实现报告

## 背景与目标

记录页和历史详情页都需要读取 TD 列表来显示待办标题、计划上下文和记录关联。跨窗口修改、归档导入或网络恢复可能在短时间内触发多次读取，旧响应返回较晚时会覆盖最新引用状态。目标是保护 TH 的跨模块只读引用，不改变 TD 实体或 TH 记录数据。

## 实现与兼容性

- 为记录页待办选择器增加请求序列号，仅允许最新列表响应写入状态；
- 为历史详情页待办标题映射增加独立请求序列号，过期成功/失败结果均丢弃；
- 保留现有不可用提示、重试入口和归档刷新行为；
- 关联仍是只读显示/跳转，不把 PH 或 TD 的生命周期并入 TH。
