# 0744 模块边界契约固化

## 背景

HOTL-1 评审指出 PH、TD 的基本单元不同，不能因为统一应用壳和数据层而把它们合并。此前多处跨页面操作使该边界容易在后续迭代中回退。

## 实现

新增 `tests/test_module_boundaries.py`，固定以下架构不变量：

- PH 只编辑计划、章节、计划条目、分组和执行日志。
- TD 只编辑待办、优先级、分类和待办自身的状态。
- TH 记录页只保留时间记录与 TD 的明确关联，不打开 PH 编辑入口。
- 主页只展示跨模块摘要和独立跳转，不承担跨模块编辑。
- `/plans`、`/time`、`/tasks`、`/records` 保持独立工作区。
- 历史 `related_plan_id` / `related_plan_task_id` 字段继续保留，仅用于兼容旧数据，不成为新 UI 的编辑入口。

## 验证

- 新增 6 条模块边界契约测试。
- 本次提交前执行全量 Python 测试和桌面端生产构建。
