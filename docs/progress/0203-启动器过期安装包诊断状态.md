# 0604 启动器过期安装包诊断状态

## 背景

启动器 doctor 已经能够检测安装包文件名版本，但旧安装包存在时仍显示为“not found”，随后才在信息区提示版本不匹配。这个状态对开发者和发布人员不够明确，容易把“存在但过期”误解为“没有构建过”。

## 实现

- doctor 将非空安装包状态明确分为 `available`、`stale (version mismatch)` 和 `not found`。
- 保持 JSON `--diagnose` 的原始逐文件信息不变，脚本消费者无需迁移。
- 不自动删除或覆盖旧安装包；发布前仍须通过 release workflow 生成当前版本的安装包。

## 验证

- 新增 doctor 输出契约测试，确认过期安装包显示为 stale。
- 待运行 launcher 定向测试和全量 Python 测试后提交。
