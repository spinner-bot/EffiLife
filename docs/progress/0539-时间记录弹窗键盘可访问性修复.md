# 1045 时间记录弹窗键盘可访问性修复

日期：2026-10-02

## 问题

TH 时间记录的新增/编辑弹窗缺少标准对话框语义，打开后不会自动聚焦，关闭后也不会恢复原触发控件焦点；键盘用户可以通过 Tab 离开弹窗并操作被遮罩的页面。

## 实现

- 增加 `role="dialog"`、`aria-modal="true"` 和本地化标题关联。
- 打开新增或编辑表单后自动聚焦弹窗内第一个可交互控件。
- 统一遮罩点击、关闭按钮、取消按钮、Esc 和保存完成后的关闭路径。
- 增加 Tab/Shift+Tab 焦点循环，并在关闭后恢复触发控件焦点。

## 验证

- 记录弹窗、确认弹窗和布局专项测试：`10 passed`。
- Python 全量测试：`799 passed in 7.67s`。
- 桌面前端生产构建：`vue-tsc` 通过，Vite 完成 `1877 modules transformed`，构建成功。

## 影响范围

仅改善 TH 记录弹窗的键盘和辅助技术交互，不改变时间记录数据结构、TD 关联或 PH/TD 模块边界。
