# [完成] Vue 按钮类型可访问性门禁

## 背景

统一工作台包含大量表单、弹窗和卡片操作。未声明按钮类型的控件在表单上下文中可能被浏览器解释为提交按钮，导致误提交或意外关闭流程。

## 实现

- 对 `time-helper/desk/src` 下全部 Vue 文件增加静态契约检查。
- 每个原生 `<button>` 开始标签必须显式声明 `type`，当前交互按钮统一使用 `button`，提交按钮由表单语义明确控制。
- 将检查纳入 Python 测试套件，后续新增页面会自动受到门禁保护。

## 验证

- 当前源码审查未发现缺失类型的按钮。
- 新增契约测试通过；全量回归将在提交前执行。

## 边界

- 该门禁只覆盖按钮类型误判，不替代逐页面的可访问名称、焦点顺序、读屏和真实触控设备验收。
