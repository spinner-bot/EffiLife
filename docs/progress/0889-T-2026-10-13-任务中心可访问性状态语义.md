# 0889 任务中心可访问性状态语义

- 创建时间：2026-10-13
- 作者/执行者：Codex
- 状态：[完成]
- 阶段：第 0 阶段

## 触发原因

产品级可访问性审计发现，任务中心的分类管理、分类列表展开和任务详情展开均可通过鼠标或键盘触发，但此前没有通过 `aria-expanded` 与 `aria-controls` 暴露当前状态及关联内容。读屏用户无法确认控件是展开还是收起，也无法建立操作控件与内容区域的关系。

## 本次目标与完成情况

已为以下交互补齐状态语义：

1. 分类管理按钮关联分类管理面板并暴露展开状态。
2. 更多分类按钮关联分类列表并暴露展开状态。
3. 空分类按钮关联空分类列表并暴露展开状态。
4. 每条任务的详情按钮关联对应详情区域并暴露展开状态。

未改变现有业务状态、数据结构、布局和交互逻辑。
