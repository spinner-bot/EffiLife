# 1086 首页详细工作区模块层级标识

## 背景

首页已经提供 TH、PH、TD 的摘要卡和独立入口，但详细工作区的标题层级仍主要依赖标题文字。快速扫描时，PH 的事件计划与 TD 的快速待办容易被看成同一种“任务列表”。

## 调整

- TH 今日进度、PH 事件计划、TD 今日待办的详细面板均显示稳定的模块代码。
- TH 与 PH 同时显示对应的工作流说明；TD 保留“下一步行动”语义。
- 使用主题变量绘制代码徽标，兼容浅色、深色及 TH 丰富主题，不改变任何数据结构、路由或模块边界。

## 验证

- 首页模块身份契约测试
- 首页桌面/平板布局测试
- 桌面生产构建
