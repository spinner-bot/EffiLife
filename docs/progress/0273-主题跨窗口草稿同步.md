# 0675：主题跨窗口草稿同步

## 背景

设置页会监听其他窗口的设置/归档变更并刷新主题快照，但此前只更新已保存快照，不更新编辑控件。设置页处于干净状态时，外部新主题可能被误判为本地草稿；后续保存还可能用旧草稿覆盖外部主题。

## 实现

- 抽取 `syncThemeDraft()`，统一同步主题类型及四类主题参数。
- 外部刷新完成后，若本地没有未保存修改，同步编辑控件到外部主题。
- 若本地已有修改，只更新保存快照并保留本地草稿，让脏状态继续提示用户确认。
- 取消编辑也复用同一草稿同步逻辑，避免两套字段赋值漂移。
- 增加回归测试锁定“干净同步、脏稿保留”语义。

## 兼容性

- 不改变主题数据结构、ThemeEngine 注册表、持久化格式或跨窗口事件协议。
- 不改变 PH、TD、TH 的独立职责。
