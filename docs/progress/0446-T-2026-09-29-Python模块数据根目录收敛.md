## 问题

统一环境变量已经覆盖 DataManager、launcher、Plan Helper 与 Tauri，但 AuthManager 和 to-dos 存储在设置该变量时仍使用旧模块目录，可能造成用户、待办与其它工作区数据分叉。

## 变更

- AuthManager 使用 `<EFFILIFE_DATA_DIR>/user`。
- TodoStorage 使用 `<EFFILIFE_DATA_DIR>/modules/to-dos`。
- 显式 `data_dir` 参数和未设置环境变量的历史路径保持不变。
- 增加统一根目录专项测试与设计文档。
