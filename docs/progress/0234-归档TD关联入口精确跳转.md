# 0635-归档 TD 关联入口精确跳转

## 背景

统一搜索已能按归档文件定位 PH，但首页和 TD 中心的关联计划按钮仍只传数字计划 ID，无法在计划已归档时直接进入恢复入口。

## 实现

- 首页与 TD 中心读取归档索引后，归档关联优先传递归档文件名。
- 活动计划关联继续使用原有 `plan` 参数，保持 PH/TD 的正常双向跳转。
- 任务索引参数继续保留，恢复后仍可回到原任务定位。

## 验证

- 首页、TD 中心与计划深链契约测试。
- 完整 Python 测试套件。
- 桌面端 TypeScript/Vite 构建。
