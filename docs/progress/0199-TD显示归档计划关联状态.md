# 0600｜TD 显示归档计划关联状态

## 背景

归档计划的 TD–PH 关联现在会被正确保留，但 TD 原先只显示计划 ID/名称，用户无法判断它不在活动计划列表的原因。

## 实施

- TD 加载活动计划时同步读取 PH 归档摘要。
- 归档计划仍显示为可点击关联，不清除 `related_plan_id` 和 `related_plan_task_id`。
- 计划和计划任务引用旁显示双语“已归档”状态。
- 保持活动计划优先显示实时名称，归档项回退到归档名称或 ID。

## 验证

- 新增 TD 归档状态回归测试。
- 继续执行全量 Python 测试与桌面端生产构建。
