# 1053 PH 宽屏计划中心分层优化

日期：2026-10-02

## 问题

PH 的详情页已经采用左右工作区，但计划中心列表页在桌面端仍将活动计划卡片和归档列表纵向排列。用户需要在同一页面并置多个计划推进时，归档内容会把活动计划推得很长，不利于扫描和持续推进。

## 实现

- 在宽度 `>= 1100px` 时，将 PH 列表页分为“活动计划主区”和“归档侧栏”。
- 活动计划在主区保持整份计划卡片展示，并在主区内采用双列卡片布局。
- 加载、空状态、搜索无结果和归档不可用状态继续沿用原有反馈逻辑。
- `<= 1099px` 继续使用单列响应式布局，避免平板和移动端内容过窄。
- 保持 PH 计划、章节、任务、嵌套分组的数据结构与操作边界不变。

## 验证

- PH 桌面布局、响应式和模块边界专项测试：`35 passed`。
- Python 全量测试：`808 passed in 7.65s`。
- 桌面前端生产构建：`vue-tsc` 通过，Vite 完成 `1877 modules transformed`，构建成功。

## 影响范围

仅改善 PH 计划中心在桌面端的空间利用和信息扫描，不改变 PH 与 TD 的定位，也不改变计划数据或移动端布局。
