# 1147 主存储缺键的兼容镜像恢复

日期：2026-10-05  
类型：统一数据恢复可靠性修复

## 背景与问题

统一工作区以 IndexedDB 为主存储，并保留 `localStorage` 镜像。此前只有 IndexedDB 抛异常时才走镜像回退；如果 IndexedDB 正常打开但某个键缺失，仍存在的兼容数据不会被读取，用户会看到默认空数据。

## 实现

- 新增通用 `readLegacyMirror` 安全读取函数。
- 配置、计划、日程规则、手动计划和日期记录在主存储缺键时均尝试读取镜像。
- 保持主存储优先；空数组、空对象等合法数据不会被误判为缺失。
- 镜像解析失败时安静回退默认值，不阻塞应用启动。
