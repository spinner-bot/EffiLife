# 0681：普通设置跨窗口草稿保护

## 背景

主题设置已经具备跨窗口草稿保护，但普通时间显示、阈值和 AM/PM 设置仍由配置深度监听直接覆盖。用户在一个窗口编辑尚未保存的普通设置时，另一个窗口的配置变更可能丢失这份草稿。

## 实现

- 为普通设置建立独立的持久化快照和当前草稿比较。
- 外部配置刷新时，仅在没有本地草稿时同步表单控件。
- 成功保存后更新快照；保存失败仍保留草稿以便重试。
- 增加回归契约测试锁定跨窗口保护行为。

## 兼容性

- 不改变配置字段、保存接口、主题架构或跨窗口事件协议。
- 不改变 PH、TD、TH 的独立数据职责。
