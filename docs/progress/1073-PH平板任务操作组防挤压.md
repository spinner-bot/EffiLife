# 1073 PH 平板任务操作组防挤压

日期：2026-10-02

## 问题

PH 详情任务行原先把记录、编辑、删除按钮分别放在多个固定网格列中。平板宽度下任务标题可用空间会被操作列挤压，窄窗口容易出现漂移或拥挤。

## 实现

- 将任务操作按钮收束到独立的 `event-task-actions` 操作组。
- 桌面端保持任务编号、内容、时长和操作区横向排列。
- 761–1099px 平板端将操作组流式换行到内容区。
- 760px 以下移动端按“内容 → 时长 → 操作”纵向层级排列。
- 不改变 Plan 数据结构、复合任务编号、嵌套 group、日志或任何 PH/TD 关联语义。

## 验证

- 更新 `test_ph_responsive_layout.py`，锁定平板与移动端断点契约。
- 后续执行全量测试与桌面生产构建。
