# 0668：启动器过期安装包诊断去重

## 背景

`launcher/start.py --diagnose` 会把“存在但版本不匹配”的旧安装包同时归入“没有可用安装包”和“安装包过期”两类提示。对于用户而言，这会产生重复且看似矛盾的诊断结果。

## 实现

- 将安装包状态分为可用、过期和缺失三类。
- 只有没有可用且没有过期文件时才报告 `installer-artifact-missing`。
- 发现非空但版本不匹配的文件时只报告 `installer-artifact-stale`。
- 保留 `--doctor` 的人类可读过期状态和现有版本提取逻辑。
- 更新启动器回归测试，明确两类提示互斥。

## 兼容性

- 不改变启动模式、端口、Tauri 二进制发现或安装包文件验证规则。
- 仅改变诊断提示分类，不影响实际启动和发布流程。

## 验证

- 启动器测试覆盖旧版本安装包只产生过期提示。
- 提交前执行全量 Python 测试与前端构建。
- 当前真实工作区诊断中的 `1.0.11` 安装包将被识别为过期，而不再重复报告缺失。
