# 0739 事件图标语义化

日期：2026-10-01

## 背景

统一工作台的首页通知和事件弹窗已经通过 `notificationIcons.ts` 使用主题感知的 Lucide 图标，但 `EventSystem` 仍在新事件 payload 的 `icon` 字段中写入 emoji。该字段目前不作为渲染来源，却会污染新数据并与统一视觉规范冲突。

## 目标与非目标

目标是让新生成事件携带稳定的语义图标 ID，并继续由事件类型映射到统一图标组件。

非目标是不迁移或删除历史收件箱中的 emoji 字段，不改变事件类型、提示文案、音效和用户操作流程。

## 实现

- 将事件生成器中的 emoji 值替换为 `trophy`、`check-circle`、`alert-triangle`、`file-text` 等语义 ID。
- 遗漏打卡提醒同样写入 `trophy`。
- `EventPopup.vue` 和 `HomeView.vue` 继续使用 `getNotificationIcon(event.type)` / `getNotificationIcon(entry.type)`，确保主题颜色和尺寸由组件控制。
- 增加契约测试，禁止新事件生成逻辑恢复 emoji，并锁定两个用户可见通知面板的统一图标映射。

## 影响范围与兼容性

仅影响新事件的可选 `icon` 字段；历史事件仍可读取。PH、TD、TH 数据结构、统一存档协议和事件类型均未改变。
