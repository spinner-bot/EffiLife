# CI 依赖安全门禁

日期：2026-10-11

## 背景

TD 兼容 UI 的遗留 CSS 工具链已移除，当前依赖审计为 0 vulnerabilities。此前 CI 只执行 `npm ci` 和构建，没有明确阻止后续依赖更新重新引入高危漏洞。

## 目标与非目标

目标是在 TD 兼容 UI 构建前执行 `npm audit --audit-level=high`，将高危或更高等级依赖问题尽早暴露在 CI 中。

非目标是改变构建工具、自动运行 `npm audit fix` 或在 CI 中强制升级依赖。

## 影响范围

仅涉及 `.github/workflows/ci.yml` 和对应契约测试；不改变应用运行时、数据格式或启动器。

## 实施内容

在 TD 兼容 UI 的 `npm ci` 与构建步骤之间增加安全审计步骤，并验证其工作目录和步骤顺序。

## 验证命令及结果

```text
to-dos/ui: npm audit --audit-level=high
  found 0 vulnerabilities

python -m pytest -q tests/test_ci_workflow.py
  7 passed
```

## 兼容性与迁移说明

该门禁只读取 npm 审计结果，不修改依赖，不影响本地启动、统一存档或三模块职责边界。

## 提交与推送

本报告与 CI 门禁一起提交并推送；实际提交哈希以 Git 记录为准。

## 未验证项与后续事项

尚未在 GitHub Actions 远端运行本次变更后的完整流水线；本地已完成等价 npm 审计和契约测试。
