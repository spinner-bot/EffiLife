# 核心组件可访问性文案国际化

## 背景

统一工作区的主要页面已经使用 locale registry，但两个核心组件仍存在可访问性缺口：分类图标缺少名称时回退到硬编码英文，打卡热力图的标题属性为空。

## 调整

- 分类图标预览接入 `useI18n`，无自定义名称时使用双语 `tasks.categoryIcon`。
- 打卡热力图使用已有的 `checkin.heatmap` 作为辅助标题。
- 保留自定义图标名称、ASCII 标记和视觉布局行为不变。
- 增加组件级回归测试，防止出现空或硬编码辅助文本。

- 桌面端生产构建：`npm run build` 通过
- 全量测试：727 passed
- `git diff --check`：通过
