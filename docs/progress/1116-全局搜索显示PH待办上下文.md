# 1116 全局搜索显示 PH 待办上下文

日期：2026-10-05  
类型：实现报告

## 背景

全局搜索已经覆盖 TH 时间记录、PH 计划/任务、TD 待办和归档计划，但关联 PH 的 TD 结果只显示待办自身信息。用户从统一搜索入口无法直接判断该待办属于哪个计划任务。

## 目标与非目标

目标是让全局搜索中的关联 TD 结果显示只读的 PH 计划 ID 与任务内部 ID，并允许通过这些标识检索。非目标是从搜索入口编辑 PH、改变 TD/PH 所有权或合并两类实体。

## 实现与兼容性

- `GlobalSearch.vue` 新增 TD 搜索详情格式化函数；
- 当 TD 同时具有 `related_plan_id` 与 `related_plan_task_id` 时显示 PH 来源上下文；
- 搜索文本追加两个关联标识，保留原有标题、描述、标签和截止日期检索；
- 新增中英文 `search.todoPlanContext` 文案；
- 未关联 PH 的 TD、归档数据、TH 记录和既有深链路行为保持不变。
