# 0693：计划跨窗口刷新队列

## 背景

计划中心原来在本地创建、编辑、归档等操作进行时直接忽略工作区变更事件。另一个窗口此时完成的计划更新会因此丢失，当前窗口只有重新导航后才可能看到新数据；这与统一工作区的跨窗口同步目标不一致。

## 实现

- 为计划中心增加外部变更来源队列，合并 `todos`、`plans`、`archive` 事件并串行刷新。
- 本地 mutation 期间暂存事件，`isLoading` 恢复为 false 后再处理，避免与本地写入并发读取。
- 单个来源刷新失败只记录警告并继续处理其余来源，不阻断计划中心。
- 更新计划中心同步回归门禁，确保队列和保存完成后的排空逻辑持续存在。
