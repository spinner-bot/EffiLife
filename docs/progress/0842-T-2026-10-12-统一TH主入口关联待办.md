# 0842｜统一 TH 主入口关联待办

类型：T（TH/TD 工作流一致性）  
日期：2026-10-12  
状态：[进行中]

## 1. 问题

统一记录页 `/records` 已支持将时间记录关联到 TD 待办，但主 TH 工作台 `/time` 的新增、编辑记录表单没有该入口。因此用户从主入口记录时间时，无法建立统一工作流关联；编辑主入口记录也无法同步待办累计用时。

## 2. 实施

- 在 `PlanView.vue` 接入 `TodoService` 和待办选项加载，并在 TD/归档工作区变化后刷新选项。
- 主 TH 记录表单增加“关联待办”选择，并保留已归档或已取消待办的既有关联可编辑性。
- 新建记录调用 `trackTime`；同一关联记录调整时调用 `adjustTrackedTime`；更换关联时解除旧关联并建立新关联。
- 主入口新增记录统一生成 `TR-*` 标识，确保 TD 反向引用与删除清理始终有稳定目标。
- 删除记录继续通过既有 `unlinkTodoFromTimeRecord` 清理关联。
- 未改变 PH 计划结构、嵌套组语义或 TH `TimeRecord` 数据结构。

## 3. 验证

- `npm run build`（`time-helper/desk`）：通过，1879 modules transformed。
- 新增 `tests/test_plan_view_todo_linking.py`，覆盖主入口选择、累计同步、工作区刷新契约。

## 4. 边界

本次只补齐 TH 主入口与 TD 的统一记录工作流；真实桌面运行和完整回归将在提交前一并执行。
