# 中等宽度应用壳布局设计

日期：2026-10-11

## 背景

当前应用壳在 `<=820px` 有平板收缩规则，在 `>=1200px` 使用左侧工作台；821–1199px 仍沿用完整横向导航。该区间常见于小型桌面窗口和横向平板，完整显示模块代码、文字、快捷键和搜索按钮可能造成导航拥挤或压缩内容区。

## 目标与非目标

- 目标：在 821–1199px 保持横向桌面导航，同时优先保留模块图标、名称和独立 PH/TH/TD 入口；隐藏低优先级快捷键和冗余模块代码，避免导航溢出。
- 非目标：不把中等宽度布局改成移动底栏；不改变路由、键盘快捷键、模块职责或数据结构；不影响 `>=1200px` 左侧工作台和 `<=680px` 移动底栏。

## 设计决策

1. 821–1199px 使用紧凑横向导航，搜索控件保留图标并隐藏辅助文字/快捷键。
2. 821–1020px 进一步隐藏 PH/TH/TD 的重复模块代码和品牌文字，使入口标签保持可读。
3. 链接允许收缩但不隐藏，导航仍通过文字和图标表达功能；焦点、悬停、选中和禁用状态沿用现有 token。
4. 通过 CSS 媒体查询实现，不引入 JavaScript 屏幕宽度状态，避免 resize 状态与移动端导航发生竞争。

## 验收条件

- `App.vue` 存在 821–1199px 的紧凑规则和 821–1020px 的进一步收缩规则。
- 该区间没有隐藏任何核心模块入口。
- 前端生产构建和应用壳布局契约测试通过。
- 移动端与宽桌面现有媒体查询保持不变。
