# 1138 TH 兼容计划记录稳定编辑

日期：2026-10-05  
类型：实现报告

## 背景与目标

统一应用中的 `/time` 仍保留 TH 原有的兼容计划工作台入口。该入口同样允许编辑今日时间记录，而统一壳或其他窗口刷新可能改变记录数组顺序。目标是让兼容入口与独立记录页采用一致的稳定身份编辑语义。

## 实现与兼容性

- 编辑表单保存当前记录的稳定 `id`；
- 保存前按 ID 重新定位当前记录，避免数组下标变化导致误更新；
- 记录不存在时拒绝保存并提示用户重新打开；
- 保留原有 TH 计划、记录、todo 关联、冲突检测和历史入口；
- 不改变 PH、TD 数据结构或统一归档协议。
