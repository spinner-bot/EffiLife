# 0863 主题预览状态无障碍提示

## 背景

主题页采用“实时预览，离开时确认保存”的交互，页面底部已有说明，但此前只是普通文本。读屏用户在修改主题后无法稳定获得这条持久化状态提示。

## 本次调整

- 将主题预览说明标记为 `role=status` 和 `aria-live=polite`。
- 保留现有无保存按钮、退出确认和持久化回读设计。
- 不改变主题数据结构、丰富主题注册表或统一应用壳变量。

## 验证

- `python -m pytest -q`：提交前执行
- `npm run build`（`time-helper/desk`）：提交前执行
