# 0634-归档搜索精确恢复入口

## 背景

全局搜索中的归档 PH 结果原先只携带数字计划 ID。若该 ID 已被活动计划复用，点击历史结果会误打开活动计划，无法定位待恢复的归档文件。

## 实现

- 归档搜索结果改用唯一归档文件名作为路由参数。
- 计划中心按归档文件精确展示恢复入口，不再被同 ID 活动计划抢占。
- 恢复 API 统一返回恢复后的计划 ID；恢复成功后自动进入恢复的计划详情。
- 保留旧的 `plan` 查询参数，用于活动计划和旧书签兼容。

## 验证

- 全局搜索与计划中心深链测试。
- 完整 Python 测试套件。
- 桌面端 TypeScript/Vite 构建。
