# 1238｜统一存档旧数据集别名迁移实现

## 实现

统一 Python 交换层现在可以读取首版数据集命名：

- `time_records` 映射为 canonical `records`。
- `plans` 数组包装为 `plan_helper.plans`，并补充空 `archives`。
- 缺少 `todo_categories` 时使用空数组。
- canonical 名称优先；旧名称保留，不覆盖任何 canonical 数据。
- 旧 `plans` 不是数组时直接拒绝，避免猜测 PH 内部结构。

## 不变性

迁移只改变外层数据集容器，不触碰 PH 任务编号、嵌套组、TH 记录、TD 待办或跨模块引用字段。
