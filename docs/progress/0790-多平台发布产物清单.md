# 0790｜多平台发布产物清单

## 状态

已完成，2026-10-01。

## 背景与目标

桌面发布工作流已经验证非空安装包并上传 SHA-256 文件，但发布后的自动工具还需要从文件名和目录约定推断版本、平台和产物大小。为正式多平台交付增加稳定的机器可读清单。

## 实现

- 新增 `scripts/generate_release_manifest.py`。
- 每个平台构建生成 `schema/product/version/target/artifacts` 清单。
- 每个 artifact 记录相对路径、字节数和 SHA-256；清单本身放在安装包目录外，避免被纳入自身哈希。
- Windows NSIS、Linux DEB、Linux AppImage、macOS DMG 四个平台均写入明确 target，并与安装包和 checksum 一起上传。
- 不改变 Tauri bundle、sidecar、安装包命名或发布 tag 规则。

## 验证

- 新增 manifest 生成与工作流上传契约测试。
- 需运行完整 pytest、发布契约测试和 CI 验证。

## 未验证项

真实平台安装包仍需在 GitHub release runner 上构建；本机缺少 Rust/Cargo，不能把本机脚本验证当作安装验收。
