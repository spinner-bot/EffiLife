# 1187 首页摘要同步时间设计

日期：2026-10-09  
类型：设计报告

## 背景

首页已有统一刷新入口和旋转反馈，但刷新结束后用户无法判断摘要数据更新时间，尤其在跨窗口同步、网络恢复或部分模块降级时不够明确。

## 目标与非目标

目标是在首页显示最近一次摘要协调器完成读取的本地时间，并随当前语言格式化。

非目标是把时间戳写入业务数据、改变模块刷新策略，或把“刷新完成”误认为所有模块都成功；各模块已有的不可用状态仍然是权威状态。

## 设计决策

- 时间戳仅存在于首页运行时状态，刷新协调器的 `finally` 阶段更新。
- 使用本地 `toLocaleTimeString`，避免硬编码日期格式并支持中英文。
- 初次摘要尚未完成时不显示时间；刷新失败但协调器完成后仍显示本次读取完成时间，同时保留各模块错误提示。
- 桌面端显示辅助文字，窄屏隐藏辅助文字，仅保留刷新按钮，避免挤压标题区域。

## 验收标准

1. 首页刷新完成后显示最近同步时间。
2. 时间显示使用当前语言，且不进入任何存档或业务数据。
3. 刷新按钮、不可用提示和减少动效行为不变。
4. 回归测试、前端构建和全量 Python 测试通过。
