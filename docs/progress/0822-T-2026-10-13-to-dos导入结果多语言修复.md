# 0822｜to-dos 导入结果多语言修复

类型：T（兼容入口多语言一致性）  
日期：2026-10-13  
状态：[进行中]

## 1. 问题

to-dos 兼容入口虽然已经将导入弹窗迁移到翻译键，但 store 仍直接返回中文导入成功/失败消息，界面还通过查找“成功”判断状态。这会导致英文环境出现中文提示，并使成功样式判断依赖具体语言文字。

## 2. 修复

- 在兼容 i18n 基础中增加导入成功、数据格式错误和 JSON 解析失败翻译键。
- store 使用 `translateLegacy` 生成当前语言的导入结果消息。
- 主工作区使用 `importSucceeded` 布尔状态控制成功样式，不再解析展示文本。
- 增加契约测试，防止重新引入语言相关的字符串判断。

## 3. 验证

- `python scripts/build_todos_ui.py`：通过，1768 个模块构建成功。
- `tests/test_todos_legacy_i18n.py`：7 项通过。
