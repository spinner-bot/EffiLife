# 0667：TH 日计划类型显示多语言化

## 背景

TH 的日计划数据沿用历史兼容值 `切分制` 和 `分配制`。这些值参与冲突判断和数据保存，不能直接改名；但此前部分列表和选择器把它们直接渲染，英文界面会出现中文。

## 实现

- 在 `PlanView.vue` 增加 `planTypeLabel` 显示层映射。
- 保留原始 `plan_type` 值用于逻辑判断、表单提交和旧数据兼容。
- 计划选择器、计划管理列表、临时切换列表统一使用本地化标签。
- 增加回归测试，确保不再直接渲染存储值。

## 兼容性

- 不改变 TH 数据结构、内部枚举值或服务接口。
- 中文继续显示原有“切分制/分配制”，英文显示对应英文翻译。
