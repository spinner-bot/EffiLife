# TD 兼容界面按钮语义收紧

## 背景

统一应用壳已经使用 TH 桌面端的 TD 工作台，但仓库仍保留 `to-dos/ui` 兼容界面。该入口的筛选、设置、导入导出、待办操作按钮仍有部分依赖浏览器默认类型，容易在复用到表单容器时产生隐式提交。

## 处理

- 为 TD 兼容界面组件和主视图的点击按钮统一增加 `type="button"`。
- 覆盖筛选栏、图标选择器、设置面板、待办操作菜单和导入导出工具栏。
- 新增跨组件静态契约测试。
- 不改变 TD 单条待办模型、优先级和导入导出逻辑。

## 结论

兼容 TD 入口与统一应用壳的按钮语义保持一致，降低旧入口继续使用时的交互差异。
