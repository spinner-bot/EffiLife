# 1123 旧版计划归档形状迁移

日期：2026-10-05  
类型：实现报告

## 背景

统一归档格式的新版本使用 `planHelper.available` 标记计划数据是否完整，但早期 `archive.json` 可能只有 `planHelper.plans` 和 `archives` 字段。若直接按新类型读取，会把旧计划误判为不可用并跳过恢复。

## 实现与兼容性

- 新增 `normalizeImportedPlanHelper`，统一处理 canonical `plan_helper` 和旧版 `archive.json`；
- 旧数据存在计划数组且未明确声明 `available: false` 时，自动归一化为可用快照；
- 显式 `available: false` 仍进入不完整归档保护逻辑，不清空目标计划；
- 旧归档缺少整个 `planHelper` 字段时，继续保留目标端现有快照；
- 计划任务关联修复使用归一化后的 PH 快照，避免迁移前后语义不一致。
