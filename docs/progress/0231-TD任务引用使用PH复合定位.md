# 0632-TD 任务引用使用 PH 复合定位

## 背景

PH 的任务编号（如 A1）只在单份计划内有意义。TD 中同时存在多份 PH 计划时，任务中心原先使用全局 A1/A2 映射显示任务，当前选中的另一份计划可能覆盖真实引用，造成错误信息。

## 实现

- TD 页面改为显示存储的 PH 内部任务索引，确保引用始终准确。
- 点击仍通过 `related_plan_id + related_plan_task_id` 回到对应计划和任务。
- 移除无法区分计划上下文的全局任务索引，不改变 TD 数据结构或 PH 编号规则。
