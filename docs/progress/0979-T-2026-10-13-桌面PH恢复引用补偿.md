# [完成] 桌面 PH 恢复引用补偿

## 背景

移动端 PH 恢复已经具备 TD 引用迁移回滚，但桌面端服务恢复后的 TD 引用迁移仍是逐项写入；中途失败时可能出现部分 TD 已指向新计划、部分 TD 仍指向旧计划。

## 实现

- 记录桌面恢复过程中每个已成功迁移的 TD ID。
- 后续 TD 更新失败时，仅回滚已经成功迁移的对象。
- 保留服务端恢复结果和回滚失败的诊断错误，不报告为成功。
- 与移动端使用一致的逐项写入补偿策略。

## 验证

- PH 桌面/移动归档恢复和统一存档专项：`19 passed`。
- 桌面端生产构建：Vite `1879 modules`，成功。
- 全量 Python 回归将在提交前执行。

## 边界

服务端已完成的归档恢复无法由前端撤销；本次确保客户端 TD 引用不会部分迁移。真实服务端故障注入仍需受控环境验收。
