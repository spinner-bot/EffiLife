# 0840 主题退出保存以持久化结果为准

## 背景

主题页不提供独立的“保存”按钮，用户修改后立即预览，离开主题设置时通过确认弹窗保存。此前退出保存虽然会调用持久化服务并进行读取校验，但校验后的规范化主题没有重新回写当前运行态；在跨窗口刷新、主题字段补全或退出时序交错的情况下，界面可能出现“保存后退出又恢复旧主题”。

## 调整

- 保存主题后再次通过启动同路径读取配置。
- 使用读取到的 `persistedConfig.theme` 作为持久化结果，而不是继续沿用编辑草稿。
- 将该结果同步回 Pinia 运行态、干净快照和编辑器草稿。
- 保留“修改即时预览、退出弹窗确认”的交互，不增加主题保存按钮。

## 验证

- `python -m pytest -q tests/test_theme_persistence_contract.py`
- `npm run build`
