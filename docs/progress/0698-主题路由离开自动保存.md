# 0698：主题路由离开自动保存

## 背景

主题面板已改为通过内部返回动作自动保存，但用户也可能直接点击全局导航离开设置页。此时组件会被路由卸载，若没有离开守卫，主题草稿无法稳定进入持久化存储。

## 实现

- 增加 `onBeforeRouteLeave` 守卫，覆盖全局导航等所有路由离开路径。
- 离开主题面板时自动保存；保存失败返回 `false`，阻止离开并保留编辑状态。
- 与主题面板内部返回动作共用同一个持久化函数，不恢复保存按钮或确认弹窗。
