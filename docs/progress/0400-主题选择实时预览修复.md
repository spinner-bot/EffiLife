# 0826 主题选择实时预览修复

日期：2026-10-01

## 发现

受控 Vite + CDP 交互验收中，主题面板可以打开并显示 22 个可选卡片，但点击非当前主题后活动主题没有变化，退出也没有触发确认。这与用户反馈“主题修改不了”一致。

## 修复

- 新增 `selectTheme(type)` 显式选择函数。
- 选择时立即更新分离的主题草稿并调用 `previewTheme()`，不再只依赖 Vue watcher 的异步调度。
- 主题卡片改为调用 `selectTheme(theme.type)`。
- 增加运行契约测试，锁定选择、预览和脏状态链路。

## 验证

- `python -m pytest -q tests/test_theme_selection_runtime_contract.py tests/test_theme_persistence_contract.py`：16 passed
- 在 `time-helper/desk` 执行 `npm run build`：通过（1874 modules）
- Vite + 受控 Edge CDP 实际交互：关闭首次引导浮层后，点击主题卡片将活动主题切换为“渐变”；点击返回出现确认弹窗；确认后返回设置主页；重新进入主题面板后活动主题仍为“渐变”。
- 主题面板无“保存主题”按钮，持久化通过退出确认完成。
