# 0809 移动构建并发与超时控制

## 日期

2026-10-01

## 背景

移动端真实构建 workflow 需要安装 SDK、初始化 Tauri 原生工程并执行平台构建，耗时和失败模式明显不同于普通前端 CI。原 workflow 没有并发组或 job 超时，重复手动触发可能长期占用 runner。

## 实施

- 使用 `github.ref + inputs.target` 作为并发隔离键，Android 和 iOS 目标互不取消。
- 同一目标的手动构建不自动取消，避免杀掉正在生成发布产物的任务。
- Android 与 iOS job 均设置 45 分钟超时，防止原生工具链异常导致无限等待。
- 增加 workflow 契约测试，锁定并发键、取消策略和两个 job 的超时。

## 验证

- `python -m pytest -q tests/test_mobile_workflow.py`：`4 passed`。
- `python -m pytest -q`：`673 passed`。
- `git diff --check`：通过，仅有 Git 的换行符提示。

## 未验证项

真实 Android/iOS 原生构建和设备验收仍需通过具备对应 SDK、签名条件和设备的发布环境执行。
