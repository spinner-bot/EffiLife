# 启动器帮助入口与无副作用诊断

日期：2026-09-30

## 发现

启动器原本只识别若干诊断和发布参数，未识别 `--help`/`-h`。用户查看帮助时会落入默认分支，启动统一工作区并可能打开浏览器，属于启动器交互上的意外副作用。

## 处理

- 增加 `--help` 与 `-h` 帮助入口。
- 帮助输出覆盖默认启动、诊断、发布校验、打包模式和兼容菜单等现有选项。
- 帮助命令在模块构建前返回，不启动 plan-helper、Vite 或浏览器。
- 增加启动器回归测试，锁定“帮助只读、无启动副作用”的行为。

## 验证

- `python -m pytest -q tests/test_launcher.py`：47 passed。
- `python launcher/start.py --help`：正确输出帮助并立即退出。
