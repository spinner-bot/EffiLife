# 0824｜to-dos 默认分类显示多语言

类型：T（兼容入口多语言一致性）  
日期：2026-10-13  
状态：[进行中]

## 1. 目的

修复英文环境下系统默认分类仍显示中文的问题，同时保持分类数据和用户自定义分类名称的兼容性。

## 2. 本阶段实现

- 在共享 i18n 中增加 `defaultCategory` 文案及 `translateLegacyCategoryName` 显示层映射。
- 侧栏、待办条目和创建/编辑表单统一通过分类 ID 映射系统默认分类。
- 仅对 `default` ID 且名称为历史默认值的分类进行映射，不修改 localStorage 数据，不覆盖用户重命名后的分类。
- 增加默认分类显示边界契约测试，多语言契约测试共 9 项。

## 3. 验证

- `python scripts/build_todos_ui.py`：通过，Vue/Vite 构建转换 1768 个模块。
- `python -m pytest -q tests/test_todos_legacy_i18n.py`：通过，9 passed。

## 4. 边界

- 本阶段只处理显示层本地化，不改变 to-dos 数据结构、筛选、优先级算法和导入导出协议。
- 默认分类仍使用原有稳定 ID，PH、TH 及统一工作台不受本阶段改动影响。
