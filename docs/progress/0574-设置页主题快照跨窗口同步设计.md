# 设置页主题快照跨窗口同步设计

## 背景

设置页使用 `savedThemeSnapshot` 判断主题是否有未保存修改。跨窗口配置刷新时，应用状态会更新，但设置页原先没有同步这个快照，因此另一窗口保存主题后，本窗口可能继续显示错误的“未保存”状态并在离开时再次询问。

## 方案

- 设置页订阅统一工作区事件，仅处理 `settings` 和 `archive` 来源。
- 事件到达时以已经刷新到 app store 的主题配置更新 `savedThemeSnapshot`。
- 本页主题编辑使用 `previewConfig`，不广播工作区事件，因此不会被外部同步逻辑清除 dirty 状态。
- 组件卸载时移除监听，避免设置页反复进入造成监听器累积。

## 验收

- 外部保存或存档恢复后，设置页主题快照同步。
- 本页未保存预览仍可触发离开确认。
- 监听器具备卸载清理，相关测试和构建通过。
