# 0865 任务中心筛选页签键盘导航

## 背景

任务中心的筛选页签已经使用 `tablist`、`tab`、`tabpanel` 语义，但页签间缺少标准键盘导航。键盘用户需要连续按 Tab 才能移动到下一个筛选项，且无法使用 Home/End 快速定位。

## 本次变更

- 为三个任务筛选页签建立统一顺序：进行中、全部、已完成。
- 支持 `ArrowLeft`、`ArrowRight` 循环切换筛选页签。
- 支持 `Home`、`End` 跳转到首尾页签。
- 切换筛选状态后，将焦点移动到新的活动页签，保持 roving tabindex 行为。
- 增加静态回归测试，防止页签按钮失去键盘导航契约。

## 验证

- `python -m pytest -q`
