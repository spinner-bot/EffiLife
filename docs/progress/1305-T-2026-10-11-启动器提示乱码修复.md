# 启动器提示乱码修复

日期：2026-10-11

## 背景

真实启动器检查发现，统一工作台复用已运行服务时输出了一条编码损坏的提示。该问题不影响服务本身，但会降低启动状态的可理解性，尤其是在 Windows 中文终端中。

## 目标与非目标

目标是修复该条用户可见提示，并防止同一乱码字符串回归。

非目标是修改启动流程、端口策略或服务复用逻辑。

## 影响范围

仅涉及 `launcher/start.py` 的终端提示和启动器回归测试；不改变 TH、PH、TD 数据、协议或存档。

## 实施内容

将乱码提示统一为“使用已运行的主服务”，并加入源码级回归断言。

## 验证命令及结果

```text
python -m pytest -q tests/test_launcher.py tests/test_launcher_startup_hints.py tests/test_launcher_port_configuration.py
  通过

python scripts/smoke_startup.py
  ok: true
  frontend_ready: true
  plan_helper_ready: true
  ports_released: true
```

## 兼容性与迁移说明

这是纯提示文本修复，不需要数据迁移，不影响现有启动参数和已运行服务复用行为。
