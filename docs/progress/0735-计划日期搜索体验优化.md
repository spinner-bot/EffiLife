# 1252 计划日期搜索体验优化

## 本次完成

计划中心和全局搜索原先直接把 PH 日期数组拼成 `YYYY-M-D`，导致用户使用 `YYYY/MM/DD`、`YYYY.MM.DD` 或补零格式搜索时可能找不到计划。本次新增 `dateSearchTokens/dateSearchText` 共享服务：

- 保留 `[year, month, day]` 原始存储，不迁移数据、不改变 API；
- 同时支持补零的 ISO、斜杠、点号格式，以及不补零的连字符格式；
- 计划、归档计划、计划任务的搜索均使用同一令牌生成规则；
- 对缺失或异常日期安全返回空令牌，不阻断整个搜索索引。

## 验证结果

- 日期搜索及两个入口契约测试：8 passed；
- 全量 Python 回归：990 passed；
- 前端生产构建：成功，1878 modules transformed。
