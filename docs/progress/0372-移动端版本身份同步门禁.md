# 0797 移动端版本身份同步门禁

## 问题

移动端 Tauri 配置此前只有构建边界，没有显式声明产品名、版本和 identifier。桌面版本同步脚本也不会更新移动配置，存在移动包元数据落后于桌面发布版本的风险。

## 调整

- `tauri.mobile.conf.json` 显式声明 EffiLife 产品身份；
- 版本同步脚本同时更新桌面与移动 Tauri 配置；
- 移动发布预检校验版本、产品名和 identifier 与仓库/桌面配置一致；
- 增加版本身份回归测试。

## 验证

- 移动配置预检与发布元数据测试通过后再执行全量回归；
- 不改变移动端无 sidecar 的运行边界。
