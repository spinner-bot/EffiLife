# 0596｜统一存档移动端快照重复写入修复

## 背景

统一存档导入已经区分桌面端 Plan Helper 服务和移动端本地快照。审计发现，导入包含有效计划快照时，通用快照保存逻辑已经写入一次，移动端分支又重复写入同一 IndexedDB 键；这不会改变结果，但增加了无必要的 I/O，并让分支职责不清晰。

## 实施

- 保留通用的有效快照写入和错误提示逻辑。
- 移动端分支只负责处理“快照不可用”的清理与警告，不再重复写入有效快照。
- 保持桌面端向 Plan Helper 服务恢复数据的流程不变。
- 增加源码回归测试，确保该导入阶段只写入一次移动端计划快照。

## 验证

- `python -m pytest -q tests/test_archive_primary_storage.py`
- 继续执行全量 Python 测试与桌面端生产构建。
