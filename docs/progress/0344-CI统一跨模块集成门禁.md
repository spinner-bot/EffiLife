# 0768 CI 统一跨模块集成门禁

## 背景

仓库已有 `scripts/run_integration.py test`，能够真实注册统一模块、执行跨模块引用和 dashboard 流程；此前主 CI 和桌面发布矩阵主要依赖 pytest，未直接执行这条集成入口。

## 处理

- 主 CI 在完整 Python 测试后执行 `python scripts/run_integration.py test`。
- 桌面发布矩阵在发布契约测试后执行同一集成套件。
- 增加 workflow 契约测试，防止后续重构误删该门禁或改变执行顺序。

## 验证边界

本地集成套件当前 55/55 通过；该变更会让后续 GitHub Actions 在真实 runner 上直接报告跨模块链路状态，但不能替代 Tauri 原生安装和移动真机验收。
