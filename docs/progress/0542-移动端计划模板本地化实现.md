# 移动端计划模板本地化实现

日期：2026-09-30

## 背景与目标

移动端此前无法读取桌面端模板服务，计划创建页的模板入口因此退化为空列表。此阶段为移动端补齐与桌面端一致的三类内置模板，同时保持 PH 原始 Plan 数据结构与既有跨端边界不变。

## 实现结果

- 移动端本地提供工作日、休息日、备考冲刺三个内置模板。
- 模板名称、说明、section、任务内容全部使用统一 i18n key，支持中英文切换。
- 模板创建先写入完整 `head/main/log` Plan，再按原始 group 范围写入任务组；创建结果进入现有计划编辑器。
- 桌面端仍使用 Plan Helper `/api/templates` 与 `/api/plans/from-template`，未改变服务端模板、自定义模板或归档协议。
- 未自动生成 TD；只有用户在创建/编辑流程中明确开启关联时才生成待办。

## 非目标与兼容性

- 不改变 Plan 的编号、软删除、嵌套 group、log 语义。
- 不在移动端伪造 PH 自定义模板文件系统或独立计划归档列表；统一 `.efl` 存档仍是跨设备迁移入口。
- 不改变桌面端模板 API 和既有模板数据。

## 提交与边界

实现提交后将核对 `main` 与 `origin/main`。本阶段未验证真实移动端构建产物和真实设备上的触控布局；这属于后续跨端验收项。
