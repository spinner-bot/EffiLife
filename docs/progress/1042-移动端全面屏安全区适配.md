# 1042 移动端全面屏安全区适配

日期：2026-10-02

## 问题

统一应用壳的移动底部导航和内容区域已经使用 `env(safe-area-inset-bottom)`，但 HTML viewport 未声明 `viewport-fit=cover`。在 iOS 全面屏设备上，安全区变量可能无法按预期参与布局，底部导航存在贴近手势区域的风险。

## 实现

- 将桌面前端 viewport 声明扩展为 `viewport-fit=cover`。
- 保留已有底部导航、内容区、搜索弹窗和 Toast 的安全区 padding 逻辑。
- 不改变桌面端 viewport 行为和统一导航结构。

## 验证

- 统一导航与桌面/移动布局专项测试：`31 passed`。
- Python 全量测试：`794 passed in 7.68s`。
- 桌面前端生产构建：`vue-tsc` 通过，Vite 完成 `1877 modules transformed`，构建成功。

## 影响范围

仅改善移动端系统安全区适配，不改变 PH、TD、TH 的数据和业务逻辑。
