# 0691：旧版待办迁移结果提示

## 背景

统一应用启动时会自动迁移旧版 `to-dos-data`，但迁移完成后用户没有反馈，无法判断历史数据是否已经进入统一工作台。提示如果早于应用壳水合完成，又可能无法被 Toast 容器接收。

## 实现

- 保存自动迁移结果，在统一工作台完成 hydration 后显示中英文成功提示。
- 只有实际迁移待办或分类时才提示，空迁移和失败重试不打扰用户。
- 不改变迁移的非破坏性策略、重复项跳过和工作区广播行为。

- `git diff --check`：通过（受保护的既有 lockfile 变更未纳入本次提交）。
