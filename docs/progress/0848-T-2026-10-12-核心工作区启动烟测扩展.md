# 0848｜核心工作区启动烟测扩展

类型：T（产品级启动验收）  
日期：2026-10-12  
阶段：0  
状态：[进行中]

## 1. 背景

原统一启动烟测只验证首页 HTML 标识和 Plan Helper health。对于产品化应用，这不足以证明核心工作区入口可达；路由配置错误可能在启动健康检查通过后才暴露。

## 2. 实施

- 在 `scripts/smoke_startup.py` 增加核心入口集合：`/time`、`/plans`、`/tasks`、`/records`、`/settings`。
- 启动后逐一请求这些路由，并验证统一应用 identity。
- 将各路由结果写入机器可读输出；任一路由失败都会使烟测失败。
- 更新启动烟测契约测试，防止核心入口检查被移除。

## 3. 验证

- 相关启动器/CI 测试：`91 passed`。
- `python scripts/smoke_startup.py`：通过。
  - 五个核心路由全部为 `true`；
  - PH health：通过；
  - 退出后端口释放：通过。
- Python 全量测试：`1073 passed`。

## 4. 边界

本次验证的是启动后 HTTP 路由可达和应用壳 identity，不替代真实浏览器点击、表单交互、桌面窗口视觉和移动设备验收。
