# 1023 PlanView 今日计划选择器响应式设计

## 日期

2026-10-02

## 背景

PlanView 概览中的今日计划卡同时显示计划说明、当前计划下拉框和创建入口。桌面端适合保持一行，但移动端可用宽度不足时，固定横向布局会压缩下拉框并使创建按钮难以触控。

## 目标与非目标

- 目标：桌面端保持紧凑的横向选择器；移动端将标签独占一行，选择器和操作按钮保持完整触控区域。
- 目标：计划卡标题与编辑工具在窄屏下允许自然换行。
- 非目标：不改变当前计划切换、创建计划或 PH/TH/TD 数据边界。

## 设计决策

- 只在现有移动断点 `680px` 下改变布局，不影响平板和桌面工作区。
- 计划下拉框使用可伸缩宽度，创建按钮保持不可压缩。
- 复用现有主题 Token、按钮组件样式和全局焦点状态。
