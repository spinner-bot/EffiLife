# 启动器过期安装包识别

日期：2026-09-30

## 发现

启动器此前只判断安装包文件是否存在且非空。开发目录中可能残留旧版本 Tauri 安装包，导致诊断把旧构件误报为当前版本可发布构件。

## 处理

- 从 Tauri 安装包文件名提取语义版本号（如 `1.0.11`）。
- 将构件版本与当前应用版本比较，并在诊断中输出 `artifact_version` 与 `version_matches`。
- 旧版本构件保留在诊断结果中，便于追踪，但不计入当前版本可用安装包。
- 新增 `installer-artifact-stale` 提示，明确要求重新构建后再分发。
- 未包含版本号的自定义构件继续按非过期处理，兼容已有测试夹具和平台命名差异。

## 验证

- `tests/test_launcher.py`：48 passed。
- 当前本地 `1.0.11` 安装包被正确识别为过期；应用当前版本为 `1.7.0`。
