# 系统减少动态效果设计

日期：2026-10-11

## 背景

EffiLife 的 `MotionManager` 已根据 `prefers-reduced-motion: reduce` 停止主题画布和粒子 JavaScript 动画，但各视图仍可能通过 CSS transition/animation 产生运动。只处理 Canvas 会造成无障碍设置不完整。

## 目标与非目标

- 目标：系统要求减少动态效果时，统一降低应用壳及路由视图的 CSS animation、transition 和平滑滚动行为。
- 非目标：不删除主题视觉层、不覆盖用户主动关闭动效的设置语义、不改变正常模式下的动画时长。

## 设计决策

- 在应用壳的全局样式中增加 `@media (prefers-reduced-motion: reduce)` 规则，覆盖所有后代元素及伪元素。
- 将动画时长压缩到近似零、限制重复次数，并将滚动行为改为即时；保留布局、颜色和状态反馈。
- JavaScript 动效继续由 `MotionManager` 管理，CSS 规则作为独立的系统级安全边界。

## 验收条件

- `App.vue` 具有全局 reduced-motion 规则，且不只针对启动页。
- 现有 `MotionManager` reduced-motion 契约和前端生产构建继续通过。
- 正常模式的主题和页面动画代码不被删除或改变。
