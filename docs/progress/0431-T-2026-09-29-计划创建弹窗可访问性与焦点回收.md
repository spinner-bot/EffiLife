# 计划创建弹窗可访问性与焦点回收

## 背景

计划创建已经采用“名称与日期快速创建，随后进入详情页编辑”的两阶段流程，但创建弹窗此前只依赖视觉层的关闭行为。键盘用户缺少标准对话框语义，关闭后焦点也不会回到触发入口，降低了桌面端连续操作的可预测性。

## 本次变更

- 为创建弹窗补充 `role="dialog"`、`aria-modal` 和标题关联。
- 打开弹窗后将焦点放到计划名称字段，避免用户再次寻找输入位置。
- 支持遮罩点击和 Esc 关闭，并集中使用同一个关闭函数。
- 关闭后尝试将焦点还给原触发元素；触发元素已被卸载时安全跳过。
- 保持移动端布局、默认当前日期和创建后进入全屏详情编辑流程不变。
