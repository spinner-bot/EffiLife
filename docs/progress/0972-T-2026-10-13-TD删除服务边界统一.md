# [完成] TD 删除服务边界统一

## 背景

TD 任务中心的单项和批量删除入口曾先在视图层调用 TH 解绑，并吞掉异常；随后 `TodoService.remove` 又重复执行一次解绑。该实现既重复写入，也可能掩盖第一次跨模块失败。

## 实现

- 移除任务中心两条删除路径中的重复 TH 解绑调用。
- 统一由 `TodoService.remove` 负责“先解绑 TH、后删除 TD”的服务边界事务。
- 视图层只处理服务成功或失败结果，不再静默吞掉跨模块错误。
- 保留批量删除的逐项处理和已完成数量反馈语义。

## 验证

- TD 删除、批量操作与 TH 引用专项：`14 passed`。
- 桌面端生产构建：Vite `1879 modules`，成功。
- 全量 Python 回归将在提交前执行。

## 边界

服务边界的解绑回滚由 `DataService.unlinkTodoFromRecords` 提供；本次不改变 TD 删除历史 TH 记录的既有语义，也不改变 TD 时间累计值。
