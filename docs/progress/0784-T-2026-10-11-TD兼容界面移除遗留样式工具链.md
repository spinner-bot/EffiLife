# TD 兼容界面移除遗留样式工具链

日期：2026-10-11

## 背景

在 1306 报告中完成 `source-map-js` 安全修复后，审计仍显示 7 项告警。进一步检查确认 TD 兼容 Web 界面未使用 Tailwind 工具类，组件样式均由现有 CSS 提供；Tailwind 3、PostCSS 和 Autoprefixer 是未使用的遗留开发依赖。

## 目标与非目标

目标是移除未使用工具链，减少依赖面并清除由其引入的审计告警，同时保持界面源码、样式入口和构建命令行为不变。

非目标是迁移到 Tailwind 4；后续若重新引入工具链，应单独设计并进行视觉回归。

## 影响范围

仅涉及 `to-dos/ui` 的依赖清单、样式入口和无用配置文件，以及依赖契约测试。PH、TH、统一工作台、数据模型和 `.efl` 存档不受影响。

## 实施内容

- 移除 `tailwindcss`、`postcss` 和 `autoprefixer` 开发依赖；
- 删除 `tailwind.config.js`、`postcss.config.js`；
- 删除未使用的 `@tailwind` 指令；
- 更新锁文件并增加防回归测试。

## 兼容性与迁移说明

TD 兼容 UI 仍由 Vue/Vite 构建，组件现有 CSS 保留不变，不需要数据迁移。依赖安装后审计依赖数量由 180 降至 108。

## 验证命令及结果
