# 1072 统一存档预览区分移动端计划快照

日期：2026-10-02

## 问题

移动端 PH 不连接桌面 Plan Helper 服务，统一存档中的计划数据来自 IndexedDB 本地快照；旧预览只根据“可用/不可用”判断，导致移动端本地快照被误标为“实时快照”。

## 实现

- `PlanHelperData` 增加可选来源：`live`、`cache`、`snapshot`。
- 存档预览新增 `snapshot` 状态，并在中英文界面显示“移动端本地快照 / mobile local snapshot”。
- 桌面实时服务、桌面缓存回退和移动端本地快照保持独立语义。
- 不改变 canonical datasets、存档协议版本、数据内容或 PH/TD 职责边界。

- 增补 `test_archive_preview.py` 契约测试。
- 后续执行 Python 全量回归和桌面生产构建。
