# 0611｜PH 归档数据根修复

## 背景

活动计划已由 sidecar 的 `--data-dir` 正确承载，但 PH 归档 API 原先默认将文件写到 `modules/api.py` 所在的源码目录 `plan-helper/data/archives`。正式安装包中这会造成用户数据与程序目录分离，甚至可能因权限不足而归档失败。

## 目标与范围

- sidecar 运行时的归档计划必须写入统一用户数据根。
- 保留 source/dev 模式下原有归档默认路径和显式 `archive_dir` 参数兼容性。
- 不改变归档 JSON 格式、恢复逻辑或 PH 计划语义。

## 实现

- `api.py` 增加归档目录解析函数，支持 `EFFILIFE_PLAN_ARCHIVE_DIR`。
- `server.py` 在显式 `--data-dir` 模式下将归档目录绑定到 `<data-dir>/data/archives`。
- 增加真实 sidecar HTTP 测试：创建计划、归档计划，并检查归档文件位置。

## 兼容性与架构决策

只有统一桌面 sidecar 设置运行时归档根；开发模式不传 `--data-dir` 时继续使用 PH 原始目录。Tauri 默认根目录因此包含 `plan/`、`data/system/registry/` 和 `data/archives/`，便于统一备份和迁移。

## 验证

