# 移动发布工作流依赖闭环

## 背景

移动边界工作流已经补齐 pytest 安装，但手动 Android/iOS 构建工作流仍在配置 Python 后直接运行 `python -m pytest`。因此静态边界检查虽然可用，真正触发移动构建时仍可能因 runner 未预装 pytest 而失败。

## 实施

- 在 Android 和 iOS job 中分别显式安装 pytest。
- 将桌面发布和移动发布工作流中的 checkout、setup-node、setup-python action 升级到当前 Node 运行时版本，统一 CI 行为并消除 Node 20 弃用警告。
- 保留桌面 sidecar 与移动无 sidecar 的构建边界，不改变构建目标或产物路径。
- 更新工作流契约测试，防止未来删除测试依赖安装步骤。

## 验收

- 移动发布两个 job 都在 pytest 测试前显式安装依赖。
- 工作流契约测试和全量 Python 测试通过。
- 工作流 YAML 中不再使用旧版 checkout/setup-node/setup-python action。
