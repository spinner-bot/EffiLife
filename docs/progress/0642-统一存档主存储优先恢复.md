# 1148 统一存档主存储优先恢复

日期：2026-10-05  
类型：统一存档可靠性修复

## 背景与问题

`.efl` 导入的可选数据集同时写入 IndexedDB 和旧版 `localStorage` 镜像。原流程先写镜像，受限浏览器拒绝镜像写入时会阻断主存储恢复，导致有效存档被回滚。

## 实现

- `writeJSON` 将兼容镜像写入改为尽力同步，失败只记录警告。
- `restoreOptionalJsonDataset` 改为先提交 IndexedDB，再更新兼容镜像。
- 显式清空数据集时同样先清空主存储，再尝试删除镜像。
- 保持旧版镜像格式、空值语义和导入回滚机制不变。

- 存档写入顺序与既有存档测试：19 passed。
- 项目全量测试：904 passed。
