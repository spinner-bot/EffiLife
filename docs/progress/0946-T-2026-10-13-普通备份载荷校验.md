# [完成] 普通备份载荷校验

## 问题

备份记录本身虽已校验模块名、时间戳和 `data` 字段，但普通模块恢复此前会直接把任意 JSON 写入 IndexedDB。损坏或伪造的 `config`、`plans`、`schedule_rules`、`manual_plans` 备份可能污染主存储。

## 实现

- `config`、`plans`、`manual_plans` 要求对象载荷。
- `schedule_rules` 要求数组载荷。
- 不符合模块数据形状时在写入前抛出明确错误。
- 保持单日/全量 `records` 的专用校验和 `archive_import` 的完整快照校验。
