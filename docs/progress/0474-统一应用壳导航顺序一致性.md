# 0900 统一应用壳导航顺序一致性

## 背景

统一应用壳桌面导航此前把“时间记录”放在“待办”之前，但快捷键定义为待办 Alt+4、记录 Alt+5，移动端导航又采用待办在前的顺序。三处顺序不一致会增加模块入口的认知成本，也弱化 PH/TD/TH 的独立边界表达。

## 调整

- 桌面端统一为 Home、Plans、Time、Tasks、Records、Settings。
- 保持 Tasks 与 Records 的独立路由、引导目标和快捷键不变。
- 增加导航契约测试，防止桌面顺序再次偏离快捷键和移动端。

## 验证

- 新增统一应用壳导航顺序测试。
- 完整测试与桌面生产构建将在提交前执行。
