# TH 日详情待办失效关联反馈

## 背景

记录页已经能够识别失效的 TD 待办关联，但日详情页仍然对所有 `todo_id` 提供无条件跳转。两个 TH 入口的关联反馈不一致，删除待办后会出现无法定位的空目标。

## 调整

- 日详情页独立读取 TD 待办标题索引，用于判断引用是否仍存在。
- 已确认失效的引用显示不可用文案并禁用跳转。
- TD 存储暂时不可读时保持原始引用和跳转能力，不把临时故障当作删除。
- 增加中英文文案和边界测试。
- 不修改历史时间记录，也不自动清理 TD/TH 关联。

- 桌面端生产构建：`npm run build` 通过
- 全量测试：731 passed
