# 0912 统一应用壳离线状态提示

日期：2026-10-02

## 背景

统一工作台已经具备本地优先存储和计划服务缓存能力，但应用壳没有把浏览器当前的网络状态反馈给用户。用户在断网时看到计划服务不可用或缓存快照，容易误判为数据丢失。

## 本次迭代

- 在统一应用壳监听 `online` / `offline` 事件。
- 离线时显示可访问性状态提示，明确本地数据仍可使用、联网后再同步计划服务。
- 提供中英文文案，适用于桌面端与移动端布局。
- 增加源码契约测试，覆盖状态初始化、事件清理和双语文案。

## 边界

该提示只反映浏览器网络连通状态，不把它当作后端健康检查，也不改变现有本地存储、缓存和同步策略。

## 验证

- `python -m pytest -q tests/test_offline_status_contract.py`
- `npm run build`
