# 1025 首页收件箱日期本地化设计

## 日期

2026-10-02

## 背景

首页收件箱的相对时间在最近几天使用本地化文案，但超过一周后退回硬编码的 `MM-DD` 字符串。该写法既不随当前语言变化，也没有利用浏览器的区域日期规则。

## 目标与非目标

- 目标：让收件箱历史日期使用应用当前 locale 的短日期格式。
- 目标：保持“刚刚、分钟前、小时前、天前”等相对时间行为不变。
- 非目标：不改变通知数据、排序、存档协议或模块边界。

## 设计决策

使用 `Date.prototype.toLocaleDateString(locale.value, { month: 'short', day: 'numeric' })` 作为超过一周的 fallback。它复用现有 i18n 响应式 locale，中文和英文可分别得到自然的短日期形式，并避免新增翻译键。
