# 1216｜统一存档旧路径前缀兼容修复

日期：2026-10-10  
状态：已完成并推送

## 背景

1215 将存档导出路径改为记忆目录，但复核发现旧版本已经写入的 `.../efflife_archive_` 前缀不能直接当作目录，否则升级后的首次导出会多出一层同名目录。

## 实施内容

- `getDownloadPath` 读取旧值时移除末尾 `efflife_archive_`，保留 Windows/Unix 分隔符及根路径。
- `setDownloadPath` 同样归一化传入值，避免再次写回旧格式。
- 新增旧路径前缀兼容契约测试。
