# 0649｜首页时间记录实时同步

## 背景

统一首页的 TH 摘要使用 `appStore.todayRecords` 计算当天记录时长。记录页保存数据后会广播 `records` 工作区变更，但首页原先只刷新 TD 摘要和 PH 计划摘要，导致 TH 数值可能在下一次定时刷新前保持旧值。

## 目标

让首页控制台在任一模块写入时间记录后及时反映最新 TH 数据，完成统一工作区的数据刷新闭环。

## 实现

在首页的工作区变更防抖回调中加入 `appStore.refreshTodayData()`，与 TD、PH 摘要并行刷新。保留 80ms 防抖，避免同一批跨模块事件造成重复读取。

## 兼容性

只改变首页刷新时机，不改变记录格式、PH/TD 数据结构、存储协议或移动端导航。

## 验证

- 首页工作区回归断言更新，确认 TH/PH/TD 三类摘要均参与刷新。
- 完整 Python 测试。
- 前端构建由 GitHub CI 验证。
