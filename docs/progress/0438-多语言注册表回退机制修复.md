# 0864 多语言注册表回退机制修复

## 背景

前端多语言注册表已经为每种语言声明了 `fallback`，但翻译函数仍把缺失文案固定回退到简体中文。这样新增语言时，即使注册了其他 fallback，也不会真正生效。

## 本次调整

- 翻译查找顺序改为：当前语言目录、当前语言运行时补充目录、注册表声明的 fallback 目录、fallback 运行时补充目录、键名本身。
- 保留当前 zh-CN/en-US 行为不变。
- 增加契约测试，防止以后重新引入硬编码回退。

## 验证

- `python -m pytest -q tests/test_locale_registry.py`：提交前执行
- `python -m pytest -q`：提交前执行
- `npm run build`（`time-helper/desk`）：提交前执行
