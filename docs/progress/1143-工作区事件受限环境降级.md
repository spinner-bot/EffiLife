# 1143 工作区事件受限环境降级

日期：2026-10-05  
类型：可靠性优化

## 背景与目标

统一工作区通过 `BroadcastChannel` 在多窗口之间传播计划、待办、记录和设置变化。但部分嵌入式 WebView 或隐私模式可能暴露接口却拒绝发送，导致其它窗口无法及时刷新。本阶段补充低成本的浏览器存储事件降级通道。

## 非目标

- 不改变 TH/PH/TD 的数据模型、存储位置或关联语义。
- 不将兼容版 `to-dos/ui` 重新并入统一前端。
- 不把工作区事件键当作业务数据或导出数据。

## 实现

- `workspaceEvents.ts` 发送事件时优先使用 `BroadcastChannel`。
- 通道不存在或发送失败时，将最小事件信封写入专用 `effilife_workspace_event` 键。
- 其它窗口监听 `storage` 事件并校验来源、事件类型后刷新对应数据。
- 保留同窗口 `CustomEvent`，因此不会改变现有页面内刷新路径。
- 对受限 `localStorage` 环境做容错，不影响当前窗口已完成的操作。

## 兼容性与风险

该键只承担通知，不保存工作区内容；页面启动时不会依赖它恢复数据。现有 `BroadcastChannel` 环境继续使用原路径，避免同一事件重复传播。业务数据仍由统一 IndexedDB/DataService 负责持久化。

- 事件信封包含唯一 `id`，连续相同来源的通知不会因存储值未变化而被浏览器合并。
- 本次变更未触及用户保护文件：`plan-helper/test.py`、`time-helper/desk/package-lock.json`、`docs/HOTL/`、PH 导出示例。
