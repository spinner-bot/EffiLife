# 0795 发布清单与上传产物筛选一致性

## 问题

桌面与移动构建目录通常还包含映射文件、临时中间文件或其他构建输出。此前 checksum/manifest 默认递归扫描整个目录，但工作流上传步骤只上传安装包、APK 或 iOS bundle，可能产生“清单记录存在但下载包中没有对应文件”的不一致。

## 调整

- checksum 生成器和 release manifest 生成器支持扩展名与 bundle 扩展名筛选；
- 桌面端按矩阵中的 installer extension 筛选；
- Android 仅纳入 `.apk`；
- iOS 纳入 `.ipa` 及 `.app` bundle 内文件；
- 生成清单与上传步骤使用同一产物范围。

## 验证

- 增加筛选行为测试；
- 保留无筛选参数时的兼容行为；
- 真实平台构建仍由对应 GitHub runner 执行。
