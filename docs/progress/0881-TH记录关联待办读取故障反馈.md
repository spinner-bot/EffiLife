# TH 记录关联待办读取故障反馈

## 背景

TH 记录编辑器需要读取 TD 待办列表以建立可选关联。此前读取失败时会静默展示空选择器，用户无法判断是没有待办还是 TD 存储暂时不可用。

## 本次调整

- 增加待办选项读取不可用状态。
- 读取失败时禁用不完整的关联选择器，并展示状态提示和重试入口。
- 保留当前编辑记录中的已有待办 ID，避免读取故障导致关联被静默清除。
- 读取成功后恢复正常关联选择。
- 不改变 TH 记录、TD 待办或跨模块关联的数据结构。

## 验证

- 记录工作区契约测试覆盖不可用状态与重试入口。
- `time-helper/desk` 生产构建。
- 提交前执行全量 Python 回归。
