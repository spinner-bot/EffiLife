# 1117 i18n 跨窗口存储回退

日期：2026-10-05  
类型：实现报告

## 背景

EffiLife 的语言选择已经通过统一 i18n 注册表持久化，并使用工作区事件同步。但部分受限 WebView 可能不支持或拒绝 `BroadcastChannel`，这会使不同窗口之间的语言切换缺少可靠回退。

## 目标与非目标

目标是在不改变现有工作区事件协议的前提下，为语言切换增加浏览器原生 `storage` 事件回退。非目标是修改主题持久化、增加新的语言、改变统一数据格式或替换 BroadcastChannel。

## 实现与兼容性

- `workspaceEvents.ts` 监听 `efflife_locale` 对应的 `storage` 事件；
- 事件被视为远程 `settings` 变更，交由既有 `App.vue` 的 `refreshLocaleFromStorage()` 处理；
- 清理订阅时同步移除 storage 监听，避免重复回调和窗口生命周期泄漏；
- BroadcastChannel、同窗口 CustomEvent 和现有 workspace source 类型保持兼容。
