# 0636-桌面 PH 归档冲突恢复一致化

## 背景

移动端恢复归档时会在历史 ID 被占用后自动分配空闲 ID，但桌面端 Plan Helper 原先直接报错。统一入口因此在不同运行时产生不一致行为。

## 实现

- 桌面端恢复保留历史 ID 空闲时的原行为。
- 历史 ID 已被占用时，使用 `Plan.request_id()` 的既有最小空闲 ID 规则恢复。
- API 仍返回实际恢复后的计划对象，前端可以据此进入正确详情页。
- 不改变 PH 的基本信息、计划模块、执行记录或 ID 数据结构。

## 验证

- 新增桌面端占用 ID 恢复测试。
- 完整 Python 测试套件。
- 桌面端 TypeScript/Vite 构建。
