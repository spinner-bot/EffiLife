# 1056 主题目录桌面网格优化

日期：2026-10-02

## 问题

主题设置页虽然已经提供基础主题和丰富主题，但桌面端仍将所有主题按单列长列表展示，浏览成本较高；分类标题也没有明确的语义关联和主题数量提示。

## 实现

- 主题分类改为语义化 `section`，并通过 `aria-labelledby` 关联分类标题。
- 每个分类显示当前主题数量，帮助用户快速判断主题目录范围。
- 桌面端主题卡片使用两列网格，窄屏回落为单列，保持移动端可读性。
- 增加键盘操作的 `:focus-visible` 反馈，不改变主题选择、预览和持久化逻辑。

## 验证

- 新增主题目录布局契约测试，覆盖语义分组、数量提示、桌面网格、窄屏回落和键盘焦点样式。
- 继续执行主题选择与持久化专项测试及桌面生产构建。

## 影响范围

仅优化设置页主题目录的浏览和可访问性；所有主题类型、主题配置和保存流程保持不变。
