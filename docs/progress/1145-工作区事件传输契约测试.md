# 1145 工作区事件传输契约测试

日期：2026-10-05  
类型：统一工作区可靠性验证

## 背景

工作区事件同时服务于统一应用壳、多窗口刷新和受限 WebView 降级。上一阶段加入了 `localStorage` 传输和唯一事件 ID；如果后续重构只保留 `BroadcastChannel`，或忘记来源过滤，跨模块界面会出现静默不刷新的问题。

## 实现

新增 `tests/test_workspace_event_transport.py`，固定验证：

- 专用降级存储键及写入路径存在；
- `storage` 事件解析路径存在；
- 每次事件包含唯一 ID，连续同源事件不会被合并；
- 跨窗口消息仍校验 `origin` 并标记为远程事件。

测试只约束通信契约，不改变业务数据和 PH/TD/TH 边界。

## 验证

- 工作区事件与全局搜索专项：21 passed。
- 项目全量测试：899 passed。
- 前一阶段桌面构建仍通过：1877 modules transformed。

## 提交与边界

测试与报告直接提交到 `main` 并推送。该契约测试不能替代真实多窗口 WebView 人工验收，后者仍属于发布前边界。
