# 00-1186-T-2026-10-14 TD 切换编辑对象保护

## 类型与阶段

T（实现记录）。当前仍为第 0 阶段；本报告只递增序列号，不增加阶段。

## 背景

TD 编辑草稿已经具备“取消”放弃确认，但用户在编辑待办 A 时直接点击待办 B 的编辑入口，仍可能用 B 的字段覆盖 A 的未保存内容。这个入口同样属于编辑草稿的结束动作。

## 实现内容

- 切换到另一个待办编辑前检查当前草稿是否已修改。
- 有未保存修改时复用统一的放弃确认文案和确认服务。
- 用户拒绝时保留原待办编辑现场；确认后才切换编辑对象。
- 保存进行中不允许启动新的编辑对象。
- 不改变待办数据模型、保存 API 或 PH/TH 关联语义。

TD 编辑草稿的取消、切换和保存三种结束路径现在具有一致的保护语义，避免误覆盖未保存内容。
