# 0852 统一搜索键盘导航优化

日期：2026-10-02

## 背景与目标

统一搜索已覆盖 TD、PH、TH 的主要可检索数据，但结果较多时，键盘用户只能逐项按方向键移动，选中项离开可视区域后无法确认当前位置。本次优化只调整搜索交互，不改变三模块的数据边界、路由或存档格式。

## 实施内容

- 在 `GlobalSearch.vue` 中增加 `Home`/`End` 快速跳转到首项和末项。
- 选中结果发生变化时，调用 `scrollIntoView({ block: 'nearest' })`，确保结果在滚动容器内保持可见。
- 保留既有的方向键、Enter 打开、Escape 关闭、焦点恢复和 `aria-activedescendant` 语义。

## 兼容性与影响范围

- 仅影响统一搜索弹窗的前端交互。
- 不改变 PH 的嵌套组、任务编号、软删除或归档逻辑。
- 不改变 TD/TH 的数据模型，也不影响移动端触摸点击；移动端仍可使用结果按钮。

## 验证

- `python -m pytest -q tests/test_global_search.py`：应通过。
- `npm run build`：须在 `time-helper/desk` 目录执行。

## 未验证项与后续

原生桌面安装包和移动端产物仍需具备 Rust/Cargo、Android SDK/ADB、Xcode 及签名条件的环境验证，本次不处理该外部条件。
