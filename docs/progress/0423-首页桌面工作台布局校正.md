# 0849 首页桌面工作台布局校正

## 背景

HOTL-1 的 B 级评审指出，首页在桌面浏览器中仍接近移动端的窄列卡片布局，宽屏两侧空间没有被有效利用。

## 本次调整

- 900px 及以上窗口将首页工作区扩展到 1180px。
- 桌面端改为左对齐的控制台层级，时钟、工作流摘要和内容卡片使用完整横向空间。
- 概览区保留时间统计与计划总览的横向分栏，并扩大计划总览的最低宽度，避免文字和按钮挤压。
- 760px 以下移动端、761–899px 平板横向布局继续使用各自断点，不与桌面规则混用。

## 验证

- 新增 `tests/test_home_desktop_layout.py`，锁定桌面宽度、横向摘要和三段响应式断点。
- 后续门禁需执行首页相关 Python 测试及桌面端 `npm run build`。
