# 0782 兼容模块默认入口边界审计

## 审计结论

- `launcher/start.py` 默认启动编号 `1` 的 EffiLife 统一工作区。
- PH 兼容服务、TD 兼容 CLI 和 TD 兼容 Web 仅在显式 `--legacy-menu` 中可选。
- 统一工作区内部通过 `/plans`、`/tasks`、`/time`、`/records` 提供三个领域的独立入口，不依赖旧兼容 UI。
- README 已将旧 TD Web 入口限定为迁移和调试用途。

## 设计边界

兼容模块保留用于迁移、故障排查和旧数据处理，不作为新的产品主入口；这保持 PH、TD 的领域独立性，同时避免用户进入两套互不一致的待办存储界面。

## 验证

现有 launcher 默认入口、legacy menu、模块边界和路由契约测试覆盖该边界；本审计不删除兼容代码，也不改变显式 legacy 菜单行为。
