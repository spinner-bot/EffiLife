# 0626-启动器发布工具链预检

## 背景

`launcher/start.py --release-check` 原先只验证发布 workflow 和桌面/移动边界配置。配置通过并不代表当前机器真的具备 Rust、Android 或 iOS 构建条件，容易把“可发布配置”和“本机可构建”混为一谈。

## 实现

- 发布检查现在额外输出 `environment`，分别报告 `desktop`、`android`、`ios` 的工具链、SDK、生成工程和缺失项。
- 增加 `build_ready` 汇总字段，明确当前环境是否可直接完成全部目标构建。
- 保留原有 `ok` 和退出语义：它继续表示仓库发布配置是否有效，不会因为开发机缺少 Rust/SDK 而掩盖配置检查结果；真实构建前应同时查看 `build_ready`。
- 检查过程只读，不启动服务、不安装依赖、不修改仓库或数据。

## 验证

- `python -m pytest -q tests/test_launcher.py`。
- `python launcher/start.py --release-check`：配置检查通过，并报告当前机器缺少的构建工具链。
