# 0823｜to-dos 优先级与频率多语言收尾

类型：T（兼容入口多语言一致性）  
日期：2026-10-13  
状态：[进行中]

## 1. 目的

继续将 to-dos 兼容入口的用户可见文本收敛到共享多语言基础，消除组件直接读取配置中文标签造成的语言切换遗漏。

## 2. 本阶段实现

- 待办创建/编辑表单的优先级选项改为使用共享翻译键，保留原有优先级值、颜色和业务计算。
- 待办条目的优先级提示改为使用当前语言；负分和历史“过期”显示在条目层转换为当前语言。
- 设置面板的分数刷新频率单位改为共享翻译键，支持中文与英文。
- 扩展 `tests/test_todos_legacy_i18n.py`，覆盖优先级提示、过期分数和频率单位，当前共 8 项契约测试。

## 3. 验证

- `python scripts/build_todos_ui.py`：通过，Vue/Vite 构建转换 1768 个模块。
- `python -m pytest -q tests/test_todos_legacy_i18n.py`：通过，8 passed。
- `git diff --check`：本阶段新增内容无格式错误；输出中的既有 trailing whitespace 位于用户保护文件 `plan-helper/test.py`，未修改。

## 4. 边界

- 本阶段只调整用户可见文案映射，不改变 to-dos 数据结构、优先级算法、导入导出或 PH/TH 领域边界。
- 兼容入口仍有历史注释及少量低频文本待后续按实际用户可见性继续清理。
