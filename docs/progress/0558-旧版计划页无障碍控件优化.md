# 1064｜旧版计划页无障碍控件优化

## 变更目的

统一工作台仍保留 TH 旧版计划页。该页面的记录、计划、规则操作按钮主要使用图标，部分控件只有 `title`，对键盘用户和读屏工具的可识别性不稳定。

## 实施内容

- 为记录编辑/删除、计划编辑/删除、规则编辑/上移/删除按钮补充显式 `aria-label`。
- 为计划项目删除按钮补充标题和显式可访问名称。
- 为记录弹窗关闭按钮补充取消语义的可访问名称。
- 增加 `tests/test_plan_accessibility_contract.py`，防止后续模板调整重新丢失控件名称。

## 验证结果

- `python -m pytest -q tests/test_plan_accessibility_contract.py tests/test_mobile_workflow.py`：5 passed。
- `time-helper/desk` 执行 `npm run build`：通过，1877 modules transformed。

## 边界说明

本次只改善控件语义，不改变计划数据结构、编号规则、删除策略或业务行为。
