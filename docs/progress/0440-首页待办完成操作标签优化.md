# 0866 首页待办完成操作标签优化

## 背景

首页“下一步行动”列表允许直接完成待办，但完成按钮的无障碍标签只有“完成任务”，读屏用户无法区分同一列表中的多个待办。

## 本次变更

- 完成按钮标签改为包含对应待办标题。
- 为中文和英文目录增加 `tasks.completeLabelFor` 资源。
- 保留任务中心原有的通用完成标签，避免改变其他场景的语义。
- 增加回归测试，确保首页动作和双语资源同步存在。

## 验证

- `python -m pytest -q tests/test_home_todo_workspace.py`
- `python -m pytest -q`
- `npm run build`（`time-helper/desk`）
