# 存档导入跨窗口语言同步设计

## 问题

统一存档包含 locale。导入存档的窗口会 reload，因此语言立即生效；其他已打开窗口收到 `archive` 工作区事件后只刷新数据和配置，模块级 `currentLocale` 仍保持旧值，导致同一工作区短暂或持续显示不同语言。

## 方案

- 在 i18n 层提供 `refreshLocaleFromStorage()`，只读取并应用已持久化的受支持 locale，不重复写入存储。
- 应用壳收到 `archive` 事件时先同步 locale，再刷新共享数据。
- 窗口从后台恢复可见时也执行一次同步，覆盖未收到广播的 WebView/浏览器场景。
- 保留当前窗口导入后的 reload 行为，确保主题、配置和兼容服务状态完整初始化。

## 验收标准

1. 跨窗口存档导入后，其他窗口的响应式文案切换到存档语言。
2. 不支持或损坏的 locale 不会覆盖当前语言。
3. 现有存档格式、主题配置和数据刷新流程不变。
4. i18n 与应用壳同步契约测试、桌面生产构建通过。
