# 1128 表单校验多语言化

日期：2026-10-05  
类型：实现报告

## 背景与目标

统一工作台已经使用双语目录，但通用表单校验 composable 的兜底消息仍直接拼接中文。未来新增字段规则时，切换到 English 会出现混合语言。

## 实现与兼容性

- `useFormValidation` 的 required、长度、数值、格式和通用失败消息统一通过 i18n 注册表生成；
- 中文和英文目录新增同一组 `validation.*` 键；
- 业务传入的自定义 required/validator 文案行为保持不变；
- 不改变 PH/TH/TD 数据结构、校验规则或主题持久化逻辑。

## 实际验证

- `python -m pytest -q tests/test_frontend_i18n.py tests/test_frontend_i18n_coverage.py` → `8 passed`；
- `$env:PATH = 'F:\\dev-tools\\node;' + $env:PATH; npm run build`（目录：`time-helper/desk`）→ Vite 构建通过（1877 modules）；
- `python -m pytest -q` → `880 passed`。

## 提交与推送

- 实现提交：`f407416 fix(i18n): localize generic validation messages`；
- 报告提交后推送至 `origin/main`；
- 工作直接在 `main`，不创建分支。

## 未验证项与边界

- 未覆盖用户自定义 validator 返回的自定义字符串，它仍由业务负责本地化；
- 主题保存后退出恢复问题继续暂缓。
