# 0680：主题草稿监听边界修复

## 背景

主题设置页已增加跨窗口“干净同步、脏稿保留”策略，但通用配置深度监听仍会在 `appStore.config` 更新时直接写入主题编辑控件，导致外部刷新再次覆盖本地未保存主题草稿。

## 实现

- 通用配置监听只同步时间阈值、秒显示、24 小时制和 AM/PM 设置。
- 主题控件不再由通用监听无条件覆盖。
- 主题初始化、跨窗口刷新、取消编辑仍统一使用 `syncThemeDraft()`。
- 增加契约测试，确保普通配置监听不会重新引入主题草稿覆盖。

## 兼容性

- 不改变主题数据结构、ThemeEngine、保存/取消流程或跨窗口事件协议。
- 不改变 PH、TD、TH 的独立数据职责。
