# 启动器发行物状态诊断

日期：2026-09-30

## 背景

启动器原先只报告 Tauri 裸二进制候选路径。裸二进制可以用于测试启动，但不等同于可交付的 Windows NSIS、Linux DEB/AppImage 或 macOS DMG 安装包，诊断信息容易造成误判。

## 本次处理

- 增加跨平台安装包产物路径审计：Windows 检查 `bundle/nsis/*.exe`，Linux 检查 `bundle/deb/*.deb` 与 `bundle/appimage/*.AppImage`，macOS 检查 `bundle/dmg/*.dmg`。
- 诊断结果新增 `installer_artifacts`，记录候选路径、存在性、非空状态和文件大小。
- `--doctor` 明确显示“正式安装包可用”或“仅裸二进制/源码工作区”。
- 安装包缺失只作为信息提示，不阻断开发启动或已存在裸二进制的测试启动。

## 验证

- `python -m pytest -q tests/test_launcher.py --disable-warnings --maxfail=1`：44 passed
- `python -m pytest -q --disable-warnings --maxfail=1`：469 passed

## 边界

本次只改进状态可见性和诊断，不在当前缺少完整 Rust/平台 SDK 的环境中伪造安装包，也不把本地裸 EXE 宣称为正式发行物。正式安装包仍由桌面发布工作流在对应平台生成并校验。
