# 0658｜首页计划概览交互语义

## 背景

首页 PH 概览卡片原先整体声明为 `role="link"` 并可点击，同时内部包含多个计划行 `<button>`。交互元素嵌套会造成键盘焦点和辅助技术语义冲突。

## 实现

- 将外层改为普通 `section`。
- 将“打开计划中心”改为独立、可聚焦的按钮。
- 保留每个活动计划行的独立按钮和深链行为。
- 移除外层容器的键盘点击处理，避免重复触发。

## 兼容性

不改变 PH 计划统计、计划行深链或首页数据来源，仅修正交互语义和焦点边界。

## 验证

- 首页深链和交互语义回归测试。
- 完整 Python 测试。
- 前端构建由 GitHub CI 验证。
