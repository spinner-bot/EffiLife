# 0920 TH 记录页历史入口

日期：2026-10-02

## 背景

统一导航中的 TH 记录页原本只展示今天的记录，历史日期详情虽然已有 `/day/:date` 路由，却缺少从记录页直接进入的入口。这降低了历史记录功能的可发现性，也容易被误解为没有历史能力。

## 本次迭代

- 在 `/records` 增加日期选择器和“查看历史”入口。
- 默认填充当前日期，点击后进入现有 `/day/:date` 历史详情页。
- 保持记录页只负责今日记录，历史页继续负责指定日期统计与详情。
- 不引入日历模块或新的数据结构。
- 增加双语、无日历入口契约测试和进展文档。

## 验证

- `python -m pytest -q tests/test_records_history_entry_contract.py`
- `npm run build`
