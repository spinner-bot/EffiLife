# 0695：存档导入结果提示时序

## 背景

浏览器和移动端通过文件选择器导入存档后，设置页先发送成功 Toast，随后立即刷新页面。页面刷新会销毁 Toast 宿主，用户无法稳定看到导入结果，尤其是存在关联修复或计划快照警告时容易误判导入失败。

## 实现

- 导入成功后先保留结果 Toast，再复用已有的重载确认文案询问用户。
- 用户取消重载时留在当前工作台，由统一工作区广播刷新数据；用户确认后才执行页面重载。
- 桌面 Tauri 原生文件对话框路径保持原有确认重载行为不变。
