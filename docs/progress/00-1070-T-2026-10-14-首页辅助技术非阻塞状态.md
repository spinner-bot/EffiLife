# 首页辅助技术非阻塞状态

**报告类型**：实现报告  
**阶段**：第 0 阶段  
**日期**：2026-10-14（Asia/Shanghai）

## 问题

首页 TH/TD 已按模块独立加载，但根容器的 `aria-busy` 仍等待整个工作区，包括可选 PH 服务。PH 服务慢时，屏幕阅读器会错误地认为已可用内容仍处于整体加载状态。

## 调整

- 根容器忙碌状态改为基于 TH/TD 首屏数据刷新状态。
- PH 继续在自己的区域显示加载或不可用状态，不阻塞已就绪模块的辅助技术访问。
- 保留各模块已有的 `role=status` 加载和错误反馈。

## 边界

本次只调整可访问性状态表达，不改变数据读取、模块边界或 PH 服务行为；阶段保持第 0 阶段。
