# 1221｜主题控件语义标签实现

日期：2026-10-10  
状态：已完成并推送

## 背景

主题设置页的丰富主题编辑器已有可见字段名称，但颜色、滑块和渐变方向控件仅通过相邻 `<span>` 展示文字，键盘和辅助技术无法稳定建立字段关系。这与项目 UX 表单规范不一致。

## 实施内容

- 为纯色、渐变、玻璃、霓虹主题的 13 个控件增加唯一 `id`。
- 将可见字段文字改为对应的原生 `label[for]`，保留既有视觉结构和主题 token。
- 新增语义关联契约测试。
- 不改变主题预览、退出自动保存、主题注册表或配置数据结构。
