# 0615｜移动端归档恢复 ID 一致性

## 背景

TD 与 PH 任务的关联使用 `related_plan_id`。移动端归档恢复若无条件生成新计划 ID，会使恢复后的 PH 计划与原 TD 关联断开。

## 实现

- 恢复移动端归档时先检查归档原始计划 ID。
- 原 ID 未被活动计划占用时保留原 ID；只有发生冲突时才生成新的最大 ID。
- 保留归档快照，不改变 PH 归档的可恢复性。

## 架构决策

该规则与桌面 PH `restore_archive` 的自然行为一致，并保持 TD 的跨模块引用稳定；ID 冲突时的换 ID 是必要的安全退让。
