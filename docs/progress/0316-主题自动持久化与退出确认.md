# 0740 主题自动持久化与退出确认

## 背景

用户反馈主题修改在退出后会恢复旧值，并明确主题设置不需要独立的保存按钮，只需要在离开主题设置时提供确认提示。

## 目标与非目标

- 目标：主题编辑实时预览、自动持久化，避免工作区刷新覆盖刚编辑的主题；离开主题设置时仅确认退出。
- 目标：滑块等连续控件使用短暂防抖，避免每次微调都写入存储。
- 非目标：不改变已有主题类型、主题引擎或主题配置数据结构。

## 实现与决策

- 主题编辑器仍使用与 Pinia 脱离的草稿对象，编辑时立即预览。
- 草稿变化后 250ms 自动保存；保存过程复用原有持久化与工作区刷新保护逻辑。
- 离开主题设置前，确认框只负责确认退出；若仍有防抖保存或保存请求，则先等待其完成。
- 主题面板继续不提供保存按钮，状态提示改为“已自动保存，退出主题面板时仅需确认”。
- 失败时保留脏状态并阻止离开，便于用户重试。
