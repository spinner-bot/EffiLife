# 1107 音频设置交互语义收口

## 背景

音频设置中的自定义背景音乐条目使用 `div[role=button]` 承载选择操作，同时在内部放置删除按钮。该结构对键盘与辅助技术不友好：一个交互控件内部嵌套另一个交互控件，焦点和点击边界都不清晰。

## 本次调整

- 将自定义背景音乐条目拆分为独立的“选择按钮”和“删除按钮”；
- 用 `aria-pressed` 表达当前背景音乐选择状态；
- 保留原有选择、删除逻辑与布局意图；
- 增加静态契约测试，避免交互语义回退。

## 验证

- `python -m pytest -q`
- `npm run build`（`time-helper/desk`）
