# 统一待办枚举数据归一化

日期：2026-09-30

## 发现

统一 Todo 服务接收来自旧版待办、归档文件和计划关联操作的数据。此前 `status`、`priority`、`recurrence` 只做了空值回退，未知字符串会直接写入统一存储，可能导致筛选、优先级算法和跨模块同步出现不可预测状态。

## 处理

- 为待办状态、优先级和重复规则建立明确的允许值集合。
- 在所有统一待办写入路径（创建、更新、导入归一化）统一回退非法枚举值。
- 保留合法值和现有数据结构，不改变 PH/TD 的职责边界。

- Todo 数据/适配器/交换专项测试：24 passed。
- 前端生产构建：`vue-tsc && vite build`，1874 个模块通过。
