# 00-1033-V-2026-10-14-启动器 Windows 进程树退出清理实现验收

## 结论

已修复 Windows 下 npm shim 已退出但 Vite 子进程残留的问题。该问题会造成 1420 被占用、启动器连续递增端口，并污染启动器测试。

## 实现

- `terminate_process()` 在 Windows 下无论父 shim 是否已退出，都对 launcher-owned PID 执行递归进程树清理。
- 保留 POSIX 进程组终止和超时兜底。
- 增加测试覆盖“shim 已退出但仍需 taskkill 进程树”的状态。

## 验证

- `python -m pytest -q tests/test_launcher.py`：85 passed。
- `python -m py_compile launcher/start.py`：通过。
- 已确认并清理本机残留的 1420、1421、1422、1423 和 8765 项目启动进程；清理后启动器固定端口测试恢复通过。

## 环境边界

当前终端编排环境不能可靠向交互 PTY 转发 Ctrl+C，因此未将该工具行为作为手工退出证据。代码级进程树清理契约和启动器测试已通过；真实用户终端仍应由 Ctrl+C 触发同一 `finally` 清理路径。
