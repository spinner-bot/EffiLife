# 1212｜多语言运行时解析一致性修复

日期：2026-10-10  
状态：已完成并推送

## 背景与目标

1211 已建立可注册语言目录，但浏览器初始化与运行时切换使用了两套解析规则：初始化支持语言前缀匹配，`setLocale` 却只接受完整语言代码。注册表还会把大小写不同的同一语言代码重复注册。本次修复统一这两条路径，保证可扩展多语言基础在实际切换时也成立。

## 实施内容

1. `setLocale` 复用 `resolveRegisteredLocale`，因此 `en`、`en-US` 及注册语言的大小写变体遵循同一精确/前缀解析规则。
2. 注册语言代码时采用大小写不敏感的重复检查，避免目录、选项列表和持久化值出现语义重复。
3. 更新语言注册表契约测试，保留现有中英文目录和中文 fallback 行为。

## 兼容性与边界

- `zh-CN`、`en-US` 的现有值和显示不变。
- 未知语言仍回退到 `zh-CN`。
- 不修改存档协议、模块数据关系、主题系统或语言文案目录。
