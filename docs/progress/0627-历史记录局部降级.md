# 1133 历史记录局部降级

日期：2026-10-05  
类型：实现报告

## 背景与目标

TH 历史日期详情由统计、时间记录和当天计划三类数据组成。当天计划属于辅助上下文，原先任一读取失败都会阻断整个详情页。目标是保留可用的历史记录和统计，并明确标记计划信息不可用。

## 实现与兼容性

- `DayDetailView` 使用 `Promise.allSettled` 独立读取三类数据；
- 统计或记录读取失败时仍沿用原有整体错误与重试行为；
- 仅计划读取失败时，历史记录和统计继续显示，计划区域显示局部不可用提示；
- 不改变 TH 记录格式、TD 关联、PH 数据或日期解析逻辑。
