# 1196 PH 与 TD 独立生命周期文案校准

日期：2026-10-10  
类型：文案与契约修正

## 发现

PH 页面在生命周期纠偏后仍保留“两个入口同步完成状态”的旧提示。这会与当前实现矛盾，使用户误以为创建关联 TD 后，PH 和 TD 会继续自动同步。

## 修正

- 中文提示改为：可将计划任务复制为独立待办，创建后分别管理，不自动同步完成状态。
- 英文提示同步表达 independent todos 和 separate management。
- 增加契约测试，禁止旧的“同步完成状态”文案回归。

## 验证

- PH/TD 与多语言定向测试：12 passed。
- `time-helper/desk` 执行 `npm run build`：通过，Vite 转换 1877 个模块。
