# 首页重点计划排序优化

日期：2026-10-14  
类型：T（技术实现）  
阶段：00  

## 1. 问题

统一工作台首页的“当前重点”会从未完成计划中取前两个计划并展示任务。此前直接使用服务返回顺序，返回顺序不等于用户当前的工作优先级，可能导致未来日期计划排在今日或已逾期计划之前。

## 2. 实现

在 `HomeView.vue` 增加本地计划日期优先级：

1. 已逾期计划；
2. 今日计划；
3. 未来计划；
4. 无有效日期计划。

同一优先级内按日期升序排列，仍只加载前两个计划详情，并保留首页最多展示五条任务的性能边界。该调整不改变 PH 数据结构、不改变计划完成语义，也不把 PH 任务强行转换成 TD 数据。

## 3. 验证

- `python -m pytest -q tests/test_home_plan_focus.py tests/test_home_workflow_summary.py`：19 passed
- `npm run build`（`time-helper/desk`）：Vue 类型检查与 Vite 生产构建通过，1881 modules

## 4. 产品价值

用户打开首页后更容易直接看到当前应处理的计划任务，减少在 PH 中寻找今日工作的操作成本；后续可继续围绕“继续工作”入口改善 PH、TD、TH 的衔接。
