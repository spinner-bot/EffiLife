# 0617｜统一导入保留归档 TD 关联

## 背景

PH 归档快照已进入 `.efl`，但导入时 TD→PH 任务关联修复只索引活动计划。指向归档计划的合法 TD 关联会被误清除，破坏归档恢复后的跨模块协同。

## 实现

- `repairImportedTodoPlanLinks()` 同时索引活动 `plans` 和 `archives[].payload.plan`。
- 活动计划与归档计划继续保持不同存储语义；归档计划不会被重新激活，仅用于验证引用有效性。
- 增加归档快照导入关联契约测试。
