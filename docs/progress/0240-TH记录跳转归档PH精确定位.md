# 0641 TH 记录跳转归档 PH 精确定位

## 背景

TH 的时间记录可以关联 TD，TD 又可能关联 PH 任务。RecordsView 原先从记录打开 PH 时只传递计划 ID；当活动计划与归档计划出现重复 ID 时，路由无法区分两者。

## 实现

- RecordsView 同时加载活动 PH 摘要和归档摘要。
- 仅当归档计划 ID 不被活动计划占用时，才使用归档文件名作为精确路由上下文。
- 活动计划优先使用 `plan=<id>`；归档计划使用 `archive=<file>`，并继续保留任务复合定位参数。
- 监听计划/归档工作区变化，及时刷新跳转上下文。

## 兼容性

- 不改变 TH 记录、TD 关联或 PH 数据结构。
- 保留原活动计划路由格式；服务不可用时回退到旧 ID 路由。
- 不改变移动端记录编辑流程。

## 验证

- 新增重复 ID 归档跳转契约测试。
- 既有记录导航测试继续覆盖活动计划和 TD 跳转。
