# 发布清单产品前缀过滤

日期：2026-10-11

## 背景

本地历史构建目录同时存在当前 `EffiLife` 安装包和旧品牌安装包。原有 checksum/manifest 生成器只按扩展名收集文件，可能把旧产物误纳入当前发布清单。

## 目标与非目标

目标是为发布生成器增加可选产品前缀过滤，并让桌面发布工作流明确使用 `EffiLife` 前缀。

非目标是删除历史构建产物、改变校验清单 schema 或修改 Android 文件命名策略。

## 影响范围

- `scripts/generate_checksums.py`；
- `scripts/generate_release_manifest.py`；
- `.github/workflows/tauri-desktop-release.yml`；
- `tests/test_release_checksums.py`。

## 实施内容

- 两个生成器增加 `--prefix` 参数和对应 Python API 参数；
- 过滤按文件 basename、大小写不敏感执行；
- 桌面 CI 生成 checksum 和 manifest 时使用 `--prefix EffiLife`；
- 增加当前/旧品牌混合目录测试，确认旧文件被排除。

## 兼容性与迁移说明

不传 `--prefix` 时保持原有收集行为，现有 Android 和其他调用方不受影响。发布清单格式仍为 `effilife.release-manifest.v1`。
