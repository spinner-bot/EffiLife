# 0774 移动构建工作流边界复核

## 复核结果

- `tauri-mobile-boundary.yml` 负责共享前端构建、移动配置和契约门禁，不上传或宣称移动安装包。
- `tauri-mobile-build.yml` 仅通过手动触发，并按 `all`、`android`、`ios` 选择目标平台。
- Android 使用 Ubuntu runner、Java 17、Android SDK 和 Rust Android targets，初始化 Tauri Android 工程后构建 APK。
- iOS 使用 macOS 14 runner 和 Rust Apple targets，初始化共享 Apple 工程后构建 app bundle。
- 两个平台均不构建桌面 Plan Helper sidecar，符合移动端本地计划快照边界。

## 验证边界

移动边界 workflow 最近一次远端运行成功；手动 Android/iOS 原生构建 workflow 尚未由当前环境触发。真实 SDK 构建产物、签名、安装、升级和设备交互仍需发布环境执行，不能用配置复核替代。
