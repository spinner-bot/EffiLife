# 0689：统一待办子任务数据校验

## 背景

统一待办导入此前只验证主任务和跨模块引用字段，`subtasks` 可能以非数组或缺少标题的对象进入 IndexedDB。任务中心随后按数组使用该字段，损坏存档可能导致页面运行时异常。

## 实现

- 对待办子任务进行统一归一化：清理标题、补齐缺失 ID、规范完成状态和完成时间。
- 导入时拒绝非数组子任务及缺少有效标题的子任务对象。
- 保留合法历史子任务及其完成状态，不改变 TD 的单条待办边界，也不改变 PH 的嵌套组结构。

## 兼容性

- 缺少子任务字段的旧待办仍按空数组处理。
- 合法但缺少子任务 ID 的旧数据会获得新的稳定运行时 ID。
