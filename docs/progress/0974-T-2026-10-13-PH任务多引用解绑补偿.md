# [完成] PH 任务多引用解绑补偿

## 背景

一个 PH 任务可能关联多个 TD。`unlinkTodosFromPlanTask` 原先逐个更新 TD，若中途失败，已处理的 TD 会失去引用，未处理的 TD 仍保留引用。

## 实现

- 记录本次已修改的 TD 快照。
- 任一 TD 更新失败时，恢复之前已经解绑的 TD 计划引用。
- 将原始错误继续抛给 PH 删除入口，由入口保留 PH 数据并允许重试。
- 不改变任务编辑、完成、软删除编号或嵌套组语义。

## 验证

- PH 引用解绑、节/任务删除专项：`12 passed`。
- 桌面端生产构建：Vite `1879 modules`，成功。
- 全量 Python 回归将在提交前执行。

## 边界

当前补偿覆盖 TD 记录已完成的服务写入；若补偿写入自身失败，会保留错误并依赖启动修复扫描发现和修正残留引用。该路径仍不是跨 TD 对象的原生 IndexedDB 单事务。
