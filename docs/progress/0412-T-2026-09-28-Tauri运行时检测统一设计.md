# Tauri 运行时检测统一设计

## 问题

多个前端模块通过 `window.__TAURI__` 判断桌面运行时。Tauri 2 的官方 API 提供的是 `@tauri-apps/api/core` 的 `isTauri()`，不同构建配置下不应依赖未声明的全局对象；检测不一致会让正式桌面包误走浏览器存储、文件对话框和 Plan Helper 运行时分支。

## 方案

- 在 `runtimeCapabilities` 集中调用官方 `isTauri()`。
- ArchiveService、备份服务和设置页全部复用 `isTauriRuntime()`。
- 移动端平台检测增加 iPadOS 桌面 UA 的触控识别，并由备份服务复用同一判定。
- 不改变浏览器开发模式、移动端不启动 Python sidecar 的边界。
