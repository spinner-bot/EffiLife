# 0764 主题退出保存竞态与字段保留修复

## 结论

修复设置页主题“确认保存后退出又恢复旧主题”的竞态，并保证基础主题编辑器保存时不丢失丰富主题字段。

## 变更

- 主题保存期间忽略由本次保存触发的 `settings` 工作区刷新事件，避免退出过程中旧快照覆盖刚写入的主题。
- 主题草稿构造先保留当前主题对象，再覆盖编辑器负责的字段，避免 `ink`、`tech`、`nature`、`custom`、粒子等未在基础面板编辑的字段被删除。
- 保持“退出时弹窗确认并保存”的交互，不增加主题保存按钮。
- 增加静态契约测试，锁定保存竞态防护和丰富字段保留行为。
