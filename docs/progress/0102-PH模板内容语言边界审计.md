# 0501 PH 模板内容语言边界审计

## 审计结论

- Plan Helper 当前模板 API 没有 locale 参数，内置模板的分组、任务和说明会直接写入新建 PH 的原始 plan 数据。
- 统一工作台已将模板选择器的名称和说明做展示层本地化；自定义模板继续显示服务端原文。
- 不在前端擅自翻译模板生成内容，避免把展示语言混入 PH 领域数据、破坏存档保真或使语言切换改写用户计划。

## 后续协议门槛

若未来要求模板生成内容也随语言变化，需要在 Plan Helper API 增加显式 locale 版本协议，并为模板领域数据建立双语资源；现阶段保持原始模板内容不变是更安全的兼容边界。
