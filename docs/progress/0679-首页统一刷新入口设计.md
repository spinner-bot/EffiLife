# 1185 首页统一刷新入口设计

日期：2026-10-09  
类型：设计报告

## 背景

统一首页同时展示 TH、PH、TD 三个工作流摘要。当前每个模块在不可用时都有自己的重试入口，但用户在完成跨模块操作或恢复网络后，没有一个明确的“一键刷新整个工作台”操作。

## 目标与非目标

目标是在首页标题区域提供一个可访问的统一刷新按钮，重新读取 TH 今日数据、PH 计划摘要和 TD 待办摘要，并明确显示刷新中的状态。

非目标是改变任何模块的数据模型、刷新来源或实体边界；不新增后台定时任务，也不把三个模块合并成一种数据结构。

## 设计决策

- 复用现有 `refreshWorkspaceSummaries()` 协调器，继续保持刷新串行化和请求竞态保护。
- 统一刷新按钮只负责触发已有读取流程，不绕过各模块自己的不可用状态与重试逻辑。
- 使用 `RefreshCw` 图标、`aria-label` 和 `aria-busy` 表达状态；刷新期间禁用按钮并使用轻量旋转动画。
- 新增中英文 i18n 键，按钮不会依赖硬编码文案。
- 保持移动端按钮在标题区域可触达，使用现有触控尺寸规范。

## 验收标准

1. 首页存在统一刷新入口，点击后会调用三模块摘要协调器。
2. 刷新期间按钮有禁用和可访问状态，结束后恢复。
3. 既有模块独立重试、不可用提示、串行队列和跨窗口刷新行为不变。
4. 中英文文案、前端构建和回归测试通过。
