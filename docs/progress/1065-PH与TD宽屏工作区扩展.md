# 1065｜PH 与 TD 宽屏工作区扩展

## 变更目的

HOTL-1 要求桌面/平板采用横向分层布局。此前 PH、TD 已具备内部双栏或多栏结构，但外层内容宽度仍约束在 1080px 和 1180px，宽屏桌面会产生明显的大面积空白。

## 实施内容

- PH 计划中心在 1100px 以上扩展至最多 1440px 工作区。
- TD 待办中心在 1100px 以上扩展至最多 1280px 工作区。
- 使用 `calc(100vw - ...)` 保留安全边距，避免超宽屏内容贴边。
- 平板与移动端原有断点和布局不变。
- 增加宽屏容器契约测试。

## 验证结果

- `tests/test_wide_workbench_container_contract.py`：已增加，待构建后验证。
- 桌面生产构建将验证 PH/TD Vue 样式编译。

## 边界说明

本次只改变桌面外层布局宽度，不改变 PH 的嵌套组、编号、日志数据结构，也不改变 TD 的待办算法与数据字段。
