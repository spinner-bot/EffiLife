# 统一品牌文案与引导多语言一致性

日期：2026-09-30

## 发现

统一应用壳已经使用 EffiLife 导航和引导，但设置页版本信息、中文首页标题和旧引导定义仍残留历史产品名。设置页的硬编码文案也无法随语言切换更新。

## 处理

- 设置页版本信息改为复用 `home.appTitle` i18n key。
- 中文 `home.appTitle` 与 `home.footer` 统一为 EffiLife 品牌文案。
- 引导系统的历史欢迎文案同步改为 EffiLife。
- 增加品牌回归测试，防止可见页面重新出现旧产品名。

## 验证

- 前端生产构建：`vue-tsc && vite build`，1874 个模块通过。
- 引导与设置相关测试：16 passed。
