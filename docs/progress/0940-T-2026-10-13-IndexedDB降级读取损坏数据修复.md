# [完成] IndexedDB 降级读取损坏数据修复

## 问题

当 IndexedDB 不可用或读取失败时，存储层会从 localStorage 降级读取。原实现对普通键值存储直接执行 `JSON.parse`，一旦降级镜像本身损坏，异常会再次向上抛出，调用方无法获得稳定的“数据缺失”结果。

## 实现

- 普通 `get()` 降级读取增加空值与 JSON 解析保护。
- 损坏镜像按不可恢复的单条数据处理并返回 `null`，不影响其他存储操作。
- 记录 warning，保留故障可诊断性。
