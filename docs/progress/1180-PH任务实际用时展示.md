# 1180 PH 任务实际用时展示

日期：2026-10-09  
类型：实现报告

## 背景

TH 与 TD 的关联用时已经能够同步到 TD `time_spent`，但 PH 任务行仍只显示计划预估分钟，用户看不到已投入时间。

## 实现

- PH 刷新关联 TD 时建立任务 ID到累计分钟的只读内存映射。
- 同一 PH 任务存在多个关联 TD 时累加其 `time_spent`。
- 只有存在有效关联的任务显示“已投入 N 分钟”；TD 读取失败时清空映射，不伪造 0 分钟。
- 新增中英文文案，保留 PH 对 Plan 结构和日志的唯一编辑权。

## 兼容性

不新增 PH 数据字段、不写回计划服务、不改变 TD 关联字段和 `.efl` 存档协议；移动端沿用同一只读展示逻辑。
