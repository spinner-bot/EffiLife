# 0696：旧版待办导入提示一致性

## 背景

统一存档导入已经避免成功 Toast 被立即重载销毁，但兼容旧版待办的专用导入入口仍然在提示后直接刷新页面，导致同一设置页中两种导入流程的反馈行为不一致。

## 实现

- 旧版待办导入成功后保留成功提示，并等待用户确认 `reloadNow` 后再重载。
- 用户取消重载时保留当前页面，由迁移完成时发出的工作区事件刷新其他入口。
- 不改变旧版待办的非破坏性迁移逻辑和重复项处理策略。
