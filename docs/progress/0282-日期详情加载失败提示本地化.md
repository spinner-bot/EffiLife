# 0684：日期详情加载失败提示本地化

## 背景

日期详情页的加载异常已经有异常边界，但此前只记录控制台 warning。用户在存储暂时不可用时会看到空状态，却没有明确的本地化反馈。

## 实现

- 增加中英文 `dayDetail.loadFailed` 文案。
- 日期详情首次加载失败时显示错误 toast，同时保留控制台诊断信息。
- 不改变记录、日计划和 PH/TD 关联读取逻辑。
- 增加回归测试确保两种语言均注册该键。

## 兼容性

- 不改变 TH 数据结构、统一存档协议或页面返回路径。
- 不改变 PH、TD、TH 独立职责。
