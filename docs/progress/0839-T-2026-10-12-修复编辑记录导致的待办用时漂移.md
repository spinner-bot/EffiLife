# 0839｜修复编辑记录导致的待办用时漂移

类型：T（TH/TD 统一数据一致性）  
日期：2026-10-12  
状态：[进行中]

## 1. 问题

编辑一个已经关联 TD 待办的 TH 时间记录时，原实现只更新记录本身，不调整待办的 `time_spent`。例如 60 分钟改为 30 分钟后，待办累计用时仍显示 60 分钟，造成统一工作区统计漂移。

## 2. 实施

- `TodoService` 新增 `adjustTrackedTime`，对已有累计用时执行受校验的正负差值调整。
- `RecordsView` 编辑同一待办关联记录时，根据新旧记录分钟数计算差值并更新 TD 聚合值。
- 如果旧关联反向记录 ID 缺失，则沿用既有 `trackTime` 逻辑补齐关联和累计值。
- 保留删除记录时不倒扣历史累计的既有语义，避免改变历史数据策略。

## 4. 边界

本次只修复同一 TD 关联记录的编辑差值，不改变 PH 整体计划、任务编号、嵌套 group、TH 记录结构或 TD 独立实体边界。
