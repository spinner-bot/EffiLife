# 0792 移动端发布产物清单一致性

## 结论

Android 与 iOS 发布工作流已复用桌面端的标准 release manifest 生成器。

## 调整

- Android APK 构建后生成 `EffiLife-android.manifest.json`；
- iOS app bundle/ipa 构建后生成 `EffiLife-ios.manifest.json`；
- manifest 与 SHA-256 校验文件一起上传；
- 两个平台均从 `time-helper/VERSION` 读取版本，并写入明确 target。

## 验证

- 增加移动工作流契约测试；
- 未改变移动端构建、产物验证或上传目录规则；
- 真实 Android/iOS 构建仍需由 GitHub 对应 runner 执行。
