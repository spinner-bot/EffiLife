# 启动器多端发布门禁

日期：2026-09-30

## 变更

`python launcher/start.py --release-check` 现在同时执行：

- 桌面发布配置检查：版本、sidecar、安装包矩阵、构建与发布工作流；
- 移动发布边界检查：移动 Tauri 配置不携带桌面 sidecar，且使用独立前端构建命令。

输出保留顶层 `ok` 与 `errors`，并增加 `checks.desktop`、`checks.mobile` 分项，便于人工诊断和自动化门禁消费。检查为只读，不需要 Node、Rust、Android 或 iOS SDK。

## 验证

- `python launcher/start.py --release-check`：desktop 与 mobile 均为 `ok: true`。
- `python -m pytest -q tests/test_launcher.py`：包含联合门禁断言。
