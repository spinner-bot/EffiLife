# 计划重置标记超时契约补充

日期：2026-10-01

## 核对结果

统一计划数据在本地清空、Plan Helper 暂时离线时，会写入 reset tombstone。下次正常读写前，`syncPendingPlanHelperReset` 会尝试把空数据同步到服务端；当前实现已有 4 秒 `AbortController` 超时，并在 `finally` 中清理计时器。

## 处理

为该现有行为补充契约测试，固定以下不变量：

- 重置同步请求必须有明确的超时上限；
- 请求必须使用独立的 `AbortController`；
- 请求结束后必须清理超时计时器。

这不会改变 reset tombstone 的语义，也不会在服务不可用时误删本地快照。

## 验证

- 计划重置契约测试通过。
