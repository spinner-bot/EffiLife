# 移动端计划归档边界提示

日期：2026-09-30

## 问题

移动端计划页使用本地原始 Plan 快照，支持创建、编辑、分组、完成和日志写回；但计划文件归档/恢复仍依赖桌面 Plan Helper 或统一 `.efl` 存档。原有归档面板在移动端只显示“没有归档计划”，容易被理解为归档数据丢失。

## 变更

- `/plans` 的两个归档面板在移动端显示已有的本地快照/桌面归档边界说明。
- 仅在非移动端且确实没有归档时显示“没有归档计划”。
- 不改变 PH 数据结构、移动端快照内容或 `.efl` 存档协议。
