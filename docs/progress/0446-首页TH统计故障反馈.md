# 0872-首页 TH 统计故障反馈

## 背景

首页此前已对 PH 计划服务和 TD 待办存储提供不可用提示与重试，但 TH 今日统计刷新失败时只记录控制台警告。界面可能继续展示旧数据，或落入“没有计划”的空状态，无法区分真实空数据和读取故障。

## 本次变更

- 增加 TH 今日统计不可用状态。
- 定时刷新、跨窗口工作区刷新和用户手动重试统一调用 `refreshTimeSummary`。
- 读取失败时显示双语提示和就地重试按钮，不伪装成空计划。
- TH 统计故障不会阻断首页 PH、TD 和收件箱区域。
- 不改变 TH 记录结构、统计算法或存储协议。

## 验证

- `python -m pytest -q tests/test_home_workflow_summary.py`
- `python -m pytest -q`
- `npm run build`（`time-helper/desk`）
