# 1052 TD 宽屏工作台左右分区优化

日期：2026-10-02

## 问题

HOTL-1 指出桌面端不应沿用移动端的纵向卡片堆叠。TD 页面在宽屏下仍把录入、筛选、分类管理和任务结果全部排成单列，桌面空间利用率不足，任务列表也需要不必要地向下滚动。

## 实现

- 在宽度 `>= 1100px` 时，将 TD 工作台改为左右分区：左侧负责快速录入、筛选、批量操作和分类管理，右侧展示任务结果。
- 将加载、存储不可用和空结果状态纳入右侧结果区，保证不同状态不会破坏布局。
- 保持 `<= 1099px` 的单列布局，移动端继续使用原有紧凑交互。
- 增加宽屏工作台布局回归测试，并同步更新存储不可用状态测试契约。

## 验证

- TD 宽屏布局及相关专项测试：`28 passed`。
- Python 全量测试：`808 passed in 7.68s`。
- 桌面前端生产构建：`vue-tsc` 通过，Vite 完成 `1877 modules transformed`，构建成功。

## 影响范围

仅改善 TD 的桌面端信息层级与空间利用，不改变 TD 的优先级算法、数据结构、TH 联动或移动端布局。
