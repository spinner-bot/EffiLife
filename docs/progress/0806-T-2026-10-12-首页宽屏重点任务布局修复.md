# 首页宽屏重点任务布局修复

## 背景

HOTL-1 要求桌面端利用横向空间，并避免模块卡片错位。首页在 `900px` 以上使用左侧时钟栏和右侧工作流栏，但 PH“重点任务”卡片没有声明网格列位置，浏览器会将它自动放入左栏后续网格行。

## 调整

- 将 `.focus-plan-card` 与 TH、PH、TD 其他工作区卡片统一固定到桌面右栏（`grid-column: 2`）。
- 保留 681–899px 平板断点的既有布局，不改变移动端单列布局。
- 添加静态回归测试，防止后续样式整理再次遗漏该卡片。

## 验证

- `python -m pytest tests/test_home_desktop_layout.py -q`
- 随后执行完整 Python 回归测试。
