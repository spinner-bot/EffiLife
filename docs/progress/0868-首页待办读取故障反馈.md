# 0868-首页待办读取故障反馈

## 背景

首页读取 TD 待办摘要失败时，原逻辑会清空摘要并继续渲染“今天没有待办”。这会把存储或迁移故障误判为空数据，降低统一控制台的可靠性。

## 本次变更

- 增加首页待办摘要不可用状态。
- 读取失败时展示明确的双语提示，不再伪装成空列表。
- 提供就地重试按钮，重试仍复用 `refreshTodoSummary`，不离开首页。
- 计划、时间和收件箱摘要仍按原逻辑运行，TD 单模块故障不会阻断统一控制台。
- 不改变待办数据结构、优先级算法或存储写入逻辑。

## 验证

- `python -m pytest -q tests/test_home_todo_workspace.py`
- `python -m pytest -q`
- `npm run build`（`time-helper/desk`）
