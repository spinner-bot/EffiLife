# 0677：统一工作区刷新串行化

## 背景

应用壳会在跨窗口事件、窗口重新可见和归档变更时刷新 TH、PH 及共享配置。原实现允许多个 `refreshWorkspaceData()` 同时读取，慢请求可能在新请求之后完成并覆盖较新的内存状态。

## 实现

- 为工作区刷新增加共享 Promise，重叠调用复用同一刷新流程。
- 刷新期间若收到新的请求，设置待刷新标记并在当前读取完成后再执行一轮。
- 保持原有错误向调用方传播，应用壳已有 warning 兜底不变。
- 增加回归契约测试，锁定串行与不丢请求的行为。

## 兼容性

- 不改变 PH、TD、TH 数据结构、存档协议或跨窗口事件名称。
- 只调整读取调度，保存与主题架构保持不变。
