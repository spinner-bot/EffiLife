# 0441｜引导移动端可见目标修复

日期：2026-09-29  
类型：T（跨端体验修复）  
范围：`time-helper/desk`

## 问题

统一壳同时渲染桌面导航和移动底部导航。两端入口使用同一个语义标识后，旧的 `document.querySelector()` 仍可能先选中被 CSS 隐藏的桌面节点，导致移动端引导遮罩位置错误，点击校验也可能失效。

## 修复

- `GuideOverlay` 新增可见目标筛选：优先选择尺寸有效且未被 `display:none`/`visibility:hidden` 隐藏的候选元素。
- 高亮目标和动作目标统一使用可见目标查找逻辑。
- 增加回归测试，锁定桌面/移动双导航同时存在时的选择行为。

## 验证

- 引导相关测试：6 passed
- 桌面生产构建：通过，1874 modules transformed

## 边界

该修复只改进引导定位，不改变统一壳路由、导航顺序、主题或数据存储行为。
