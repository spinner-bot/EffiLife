# TH 模块上下文入口

## 1. 问题

PH 与 TD 页面已有页面内模块切换条，但 TH `/time` 仍只有全局导航。用户从深层页面进入 TH 后，模块身份和切换路径不一致。

## 2. 调整

`PlanView.vue` 增加与 PH、TD 一致的 TH/PH/TD 上下文切换条：

- TH 当前入口明确标记为 active；
- PH 与 TD 保持独立路由，点击只进行模块导航，不合并业务数据；
- 嵌入式 TH 视图不显示该导航，避免重复壳层；
- 移动端允许横向滚动，避免压缩或覆盖操作区。

## 3. 验证

```text
python -m pytest -q tests/test_module_navigation_identity.py
6 passed in 0.17s

npm run build
vue-tsc passed; vite build succeeded
```

本次调整只强化三模块的入口一致性，不改变 TH 的时间记录模型，也不改变 PH/TD 的职责边界。
