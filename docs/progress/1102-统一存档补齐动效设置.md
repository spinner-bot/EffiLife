# 1102-统一存档补齐动效设置

## 问题

`.efl` 统一存档已经覆盖应用配置、计划、时间记录、待办、音频、事件和打卡数据，但 TH 动效管理器把帧率、粒子、主题画布和过渡动画设置保存在独立的 `efflife_motion_settings` 键中，原有存档链路没有导出或恢复它们。

## 调整

- 将动效存储键导出为明确的运行时契约常量。
- 导出时把动效设置纳入 `app` 数据集，因此不改变 `.efl` 的数据集集合和校验协议。
- 导入时恢复动效设置；旧存档缺少该字段时保留当前设备设置，避免向后兼容时误清空用户偏好。
- 存档导入完成后刷新 MotionManager，使用户选择暂不重载页面时动效设置也立即生效。
- 存档管理页的数据统计同时显示动效设置是否存在，避免统一数据范围不可见。
- 增加运行时键与导入/导出契约测试。
