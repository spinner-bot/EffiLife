# 0808 移动原生构建前置诊断

## 日期

2026-10-01

## 背景

移动端手动 workflow 已包含 Tauri Android/iOS 原生工程初始化、构建、非空产物校验、SHA-256 和 manifest 校验，但原生工具链诊断没有放在工程初始化之后。工具链或生成工程缺失时，失败可能延迟到 Tauri 构建命令，错误定位不够直接。

## 实施

- Android 初始化完成后执行 `python scripts/check_build_environment.py --target android`。
- iOS 初始化完成后执行 `python scripts/check_build_environment.py --target ios`。
- 保留移动端无 Plan Helper sidecar 的边界，不改变构建命令、产物目录或上传协议。
- 增加 workflow 契约测试，确保两个原生诊断步骤不会被删除。

## 验证

- `python -m pytest -q tests/test_mobile_workflow.py`：`4 passed`。
- `python -m pytest -q`：`673 passed`。
- `git diff --check`：通过，仅有 Git 的换行符提示。
