# 0654｜全局搜索对话框语义关联

## 背景

全局搜索已经支持快捷键、键盘结果导航和 `combobox/listbox` 语义，但统一壳的触发按钮与搜索对话框之间没有显式 ARIA 关系。

## 实现

- 搜索触发按钮增加 `aria-haspopup="dialog"`、动态 `aria-expanded` 和 `aria-controls`。
- 搜索对话框增加稳定 ID，并通过 `aria-labelledby` 关联可见标题。
- 增加结构回归测试，确保入口与 dialog 不会失去关联。

## 兼容性

不改变搜索索引、路由、键盘选择或数据读取逻辑，仅补充辅助技术语义。

## 验证

- 全局搜索相关测试。
- 完整 Python 测试。
