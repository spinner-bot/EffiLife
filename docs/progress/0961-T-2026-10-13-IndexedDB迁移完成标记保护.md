# [完成] IndexedDB 迁移完成标记保护

## 问题

迁移使用的通用存储读写函数会在 IndexedDB 不可用时降级到 localStorage。原逻辑在迁移前通过这些带降级的函数读取已有数据，可能将“仍在 localStorage 中”误判为“已经迁移到 IndexedDB”，随后写入迁移完成标记。

## 实现

- `runMigration()` 在创建迁移备份和执行数据迁移前，先通过 `openDB()` 确认原生 IndexedDB 连接可用。
- IndexedDB 不可用时直接返回失败，不执行任何数据迁移，也不写入完成标记。
- 保留应用运行期的 localStorage 降级能力；本次只收紧迁移事务边界，避免把降级读取当成迁移成功。

## 验证

- 新增迁移失败保护契约测试。
- 迁移专项与全量回归将在提交前执行。

## 边界

- 本修复不删除原始 localStorage 数据，迁移失败后可在 IndexedDB 恢复时重试。
- 真实浏览器禁用 IndexedDB、恢复权限后的重试仍需设备/浏览器运行时验收。
