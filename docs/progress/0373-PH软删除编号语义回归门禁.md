# 0798 PH 软删除编号语义回归门禁

## 复核结论

PH 继续使用原始有序槽位保存任务和日志引用，同时在序列化时按活动任务动态生成显示编号。删除 A2 后，用户看到的是 A1、A2；内部引用仍能区分原始 A1、A3。组仍以范围表达，因此嵌套组语义保持不变。

## 调整

- 增加 API 级回归测试，覆盖三任务、删除中间任务、嵌套组和历史日志引用；
- 固定校验 `display_id` 与 `internal_id` 的差异及组 key 的保留；
- 未修改 PH 原始数据结构，也未实现尚未批准的硬删除 `pur_*` 行为。

## 验证

- 该测试纳入全量 pytest；
- 统一前端仍使用显示编号展示，内部编号用于稳定编辑、日志和关联。
