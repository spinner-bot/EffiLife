# 1069｜统一工作台异步反馈无障碍语义

## 发现的问题

PH、TD 的异步错误和 PH 保存成功信息原先只是视觉文本。操作失败或完成后，读屏用户无法稳定收到反馈。

## 实施内容

- PH 列表页和详情页错误使用 `role="alert"`。
- PH 保存成功信息使用 `role="status" aria-live="polite"`。
- TD 错误信息使用 `role="alert"`。
- 增加统一工作台反馈语义契约测试。

## 验证结果

- 针对性契约测试通过。
- 桌面生产构建与完整 Python 测试作为回归验证。

## 边界说明

本次只补充异步反馈的可访问语义，不改变错误处理、保存流程或模块边界。
