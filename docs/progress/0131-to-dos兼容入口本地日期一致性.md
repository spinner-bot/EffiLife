# to-dos 兼容入口本地日期一致性

日期：2026-09-30

## 发现

to-dos 兼容 UI 的“今天截止”筛选和备份文件名使用 UTC 日期。用户处于本地时区跨越 UTC 日期边界时，可能看到错误的今日待办或得到错误日期的备份文件名。

## 处理

- 增加本地日历日期键生成函数，替换今日筛选中的 UTC 截取。
- 备份文件名改为使用本地年月日。
- 保持 ISO 时间戳存储格式不变，仅修正面向用户的日历日期语义。

## 验证

- to-dos 日期专项测试：6 passed。
- to-dos 前端生产构建：`vue-tsc && vite build`，1767 个模块通过。
