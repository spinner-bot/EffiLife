# 首页收件箱语义交互优化

日期：2026-10-09

## 背景

首页收件箱中的通知条目通过 `div role="button"` 模拟按钮。虽然已有键盘事件处理，但这会增加交互维护成本，也让浏览器、辅助技术和触摸设备无法直接获得原生按钮语义。

## 目标与非目标

目标是让通知条目使用原生按钮，同时保持点击后标记已读、焦点陷阱和收件箱布局不变。

本次不改变事件数据结构、通知排序、已读持久化或事件管理页的既有交互。

## 影响范围

- `time-helper/desk/src/views/HomeView.vue`：首页收件箱条目模板与样式。
- `tests/test_inbox_accessibility_contract.py`：语义交互契约。

## 实现

- 将首页收件箱条目从 `div[role=button]` 改为 `button type="button"`。
- 删除仅为模拟 Enter/Space 行为而存在的键盘处理函数。
- 为按钮补齐宽度、边框、字体、背景和文本对齐样式，使原生按钮不改变视觉布局。
- 保留现有 `aria-label`、点击标记已读和面板 Tab 焦点管理。

## 兼容性

事件管理页中的规则条目仍保留其原有自定义键盘交互；本次只收敛首页通知条目，不改变其他模块协议或持久化数据。
