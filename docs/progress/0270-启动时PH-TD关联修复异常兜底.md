# 0672：启动时 PH-TD 关联修复异常兜底

## 背景

统一工作区启动后会异步修复 PH 任务与 TD 的关联。该维护操作不应阻塞首屏，但原调用没有 Promise 异常边界；计划服务暂时不可用时，浏览器会出现未处理 rejection。

## 实现

- 为启动后的 `repairTodoPlanTaskLinks()` 增加 `.catch()`。
- 失败时记录可诊断的 warning，不影响已完成的启动流程和首屏使用。
- 增加静态回归测试，确保该异步维护调用始终具备异常边界。

## 兼容性

- 不改变 PH/TD 关联修复规则、稳定任务 ID 或缓存降级策略。
- 不把可恢复的后台维护失败升级为启动失败。

- `python -m pytest -q`：580 passed。
