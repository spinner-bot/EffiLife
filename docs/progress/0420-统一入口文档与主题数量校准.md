# 0846 统一入口文档与主题数量校准

## 发现

README 中仍保留早期“12 种内置主题”的描述，而当前 ThemeEngine 已注册 21 个主题。集成文档中的 Python 示例还直接使用 `from to-dos...`，由于目录名含连字符，该写法不能作为普通 Python 导入执行。

## 调整

- 将 README 的主题数量更新为当前 21 个，并说明基础与丰富主题分类。
- 将集成文档示例改为先把 `to-dos` 加入 `sys.path`，再从其 `src.api` 导入，和实际启动器适配方式一致。

## 边界

这是文档与入口示例校准，不改变三个领域模块的独立边界，也不把兼容 Python API 当作统一前端的正式运行入口。
