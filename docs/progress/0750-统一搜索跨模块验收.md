# 0750 统一搜索跨模块验收

## 验收范围

检查统一应用壳中的全局搜索是否覆盖三个领域，同时确认搜索结果不会把 PH 与 TD 合并为同一种数据。

## 结果

- TD：待办标题、描述、标签，跳转 `/tasks?todo=...`。
- PH：活跃计划、归档计划、活跃计划任务、归档计划任务，跳转 `/plans` 并携带计划/任务定位参数。
- TH：时间记录内容和标签，跳转 `/day/:date` 并携带记录定位参数。
- 搜索索引在统一工作区事件、页面重新可见和搜索框打开时刷新。
- PH 与 TD 使用独立结果类型、独立路由和各自领域服务；本次未发现需要跨域编辑或改变数据语义的缺口。

## 验证依据

- `GlobalSearch.vue` 的 `SearchResult.kind`、各领域加载器和深链路由。
- `tests/test_global_search.py` 的全域索引、深链、刷新和可访问性契约测试。
- Python 全量测试基线：633 passed。
