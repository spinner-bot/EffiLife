# 00-1166-V-2026-10-14 Windows 跨版本升级数据保留验收

## 类型与阶段

V（验证验收）。当前仍为第 0 阶段；本报告只递增序列号，不增加阶段。

## 验证对象

- 历史安装包：`浪兮效率时钟_v1.0.11（desk_发布版）.exe`。
- 当前安装包：`EffiLife_1.7.0_x64-setup.exe`。
- 安装目标与数据目录均为项目 `artifacts` 下一次性隔离路径。

## 验证步骤与结果

执行 `scripts/smoke_windows_upgrade.py` 完成：

1. 安装历史版本；
2. 使用当前版本覆盖升级；
3. 检查桌面主程序、Plan Helper sidecar 和卸载程序均存在；
4. 卸载当前版本并确认隔离安装目录删除；
5. 对用户数据探针做字节级校验。

结果：退出码 0，三个安装文件均存在，安装目录已删除，数据探针保留，SHA-256 为 `2cb0707d8bab03f6f386a67811a98cb43217bf38c3c47906343d3ff7f0d7e92c`。

## 额外修复

真实验收先后发现并修复了两处升级脚本兼容性问题：历史中文品牌编码损坏，以及旧版 `（desk_发布版）` 文件名后缀未纳入匹配。两种命名均现在进行严格匹配，不接受任意未知文件名。

## 边界

本次证明 Windows NSIS 隔离跨版本升级、卸载和数据保留；不替代正式代码签名、Android 更新安装和 macOS/Linux 真实升级验收。
