# TD 工具栏响应式布局修复

日期：2026-10-01

## 问题

待办中心的筛选、分类管理、批量选择和批量操作会同时出现在同一工具栏。原布局只允许单行 flex，在桌面窄窗口和平板宽度下可能把按钮挤出内容区；错误提示也可能与其他控件争抢横向空间。

## 处理

- 工具栏改为可换行 flex，并统一控件间距。
- 标签页容器限制最大宽度并允许横向滚动，避免长本地化文本撑破页面。
- 错误提示独占整行，不再覆盖筛选或批量操作。
- 保留桌面端横向排列和移动端触控尺寸，不把 PH 或 TH 内容混入 TD。

## 验证

- 新增 TD 工具栏布局契约测试。
- 相关桌面布局测试通过。
