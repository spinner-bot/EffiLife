# 首页重复导航收敛设计

## 问题

统一应用壳已经在桌面端提供顶部主导航、移动端提供底部主导航；首页底部仍重复渲染计划、时间、待办和设置四个入口。重复入口增加视觉噪声和纵向滚动，也让首页与应用壳的导航职责不清。

## 方案

- 首页底部快捷区只保留应用壳未覆盖的“打卡”动作。
- 继续保留首页中的三域摘要卡片，它们承担状态摘要和深链接，不属于重复导航。
- 打卡按钮继续使用现有 `CheckCircle` 图标、提醒红点和 `nav.checkin` 本地化文案。
- 删除仅服务于重复入口的五列布局、计数徽章和占位样式；不改变路由和打卡业务逻辑。
- 桌面端快捷区采用靠左的紧凑动作按钮，移动端保持可触达尺寸。

## 验收标准

1. 首页不再出现指向 `/plans`、`/time`、`/tasks`、`/settings` 的重复快捷按钮。
2. 首页仍有可进入 `/checkin` 的明确入口。
3. 三域摘要卡片和应用壳主导航不受影响。
4. 构建及前端契约测试通过。
