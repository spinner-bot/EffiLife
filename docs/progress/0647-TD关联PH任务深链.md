# 1153 TD 关联 PH 任务深链

日期：2026-10-05  
类型：TH/PH/TD 协同体验优化

## 背景与问题

TD 中已经保留 PH 的计划 ID 和任务 ID，但此前只以文本展示。用户从待办回到事件计划时，需要手动进入计划中心并再次查找，三模块之间的协同路径不完整。

## 实现

- 将 TD 中的 PH 关联标识改为可访问的操作按钮。
- 点击后通过 `/plans?plan=...&task=...` 深链直接打开对应计划并定位任务。
- 仍由 PH 负责计划数据读取和编辑，TD 只持有关联引用，不合并两个模块的数据实体。
- 增加中英文操作文案与源码契约测试。

## 验证

- TD/PH 深链专项测试：8 passed。
- 项目全量测试：909 passed。
- `time-helper/desk`：`npm run build`，通过，1877 modules transformed。
