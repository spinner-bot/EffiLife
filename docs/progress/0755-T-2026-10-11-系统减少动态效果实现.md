# 系统减少动态效果实现

日期：2026-10-11

## 背景与目标

落实 `1277-T-2026-10-11-系统减少动态效果设计.md`，让系统的 `prefers-reduced-motion` 设置同时覆盖 JavaScript 和 CSS 动效。

## 实施内容

- 在 `time-helper/desk/src/App.vue` 的全局 reduced-motion 媒体查询中统一压缩 animation/transition 时长、限制重复次数，并关闭平滑滚动。
- 保留 `MotionManager` 对主题 Canvas、粒子和 JavaScript 帧循环的既有控制，不改变正常模式动画。
- 增加 CSS 动效契约测试，锁定应用壳对伪元素和后代元素的覆盖范围。

## 兼容性与边界

- 只在操作系统要求减少动态效果时生效；普通模式的主题和页面动效不变。
- 不改变 TH 丰富主题配置、数据存档或 PH/TD/TH 模块职责。
- 真实系统设置下的安装包视觉验收仍需发布候选环境完成。
