# 工作台标题栏防挤压设计

## 背景

HOTL-1 明确指出页面存在按钮、文字漂移和堆叠遮挡风险。PH 标题栏同时包含返回按钮、模块身份说明、模板入口和新建入口；TD 标题栏同时包含身份说明与统计徽标。在桌面窗口缩窄但尚未进入移动断点时，单行 flex 布局可能压缩标题或挤出操作区。

## 方案

- PH 与 TD 标题栏允许换行，标题块设置 `min-width: 0` 和可伸缩宽度。
- PH 操作按钮组允许换行并保持按钮间距。
- 保留现有移动端断点和桌面横向布局；宽屏仍保持单行，只有空间不足时才换行。
- 不改变任何业务数据、路由或 PH/TD 功能边界。

## 验收

- 标题栏具备可换行布局和可收缩标题块。
- PH 操作组具备独立的换行能力。
- 现有全量测试与桌面构建继续通过。
