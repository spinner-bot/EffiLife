# 启动器退出状态契约

日期：2026-10-02

## 背景

启动器能够记录子进程退出事件，但统一入口在子进程异常退出、启动服务不可达等场景下仍可能以成功状态结束。这样会使脚本、CI 或桌面外层无法区分“用户正常关闭”和“启动失败”。

## 本次调整

- 统一工作区入口读取 `run_module` 返回值。
- 子进程正常退出返回其退出码；退出码为 `0` 时保持正常结束。
- 保留现有诊断、浏览器打开和兼容菜单行为，不改变服务生命周期管理。
- 增加启动器单元测试，验证子进程退出码能被准确传播。

## 验证

- `python -m pytest tests/test_launcher.py -q`：66 passed。
- 本次变更未触及用户保护文件 `time-helper/desk/package-lock.json` 与 `docs/HOTL/`。

## 后续

启动器仍属于开发/测试入口；原生安装包和真实设备验证继续由发布环境负责。本次只改善测试入口的可观测性，不将其误认为正式安装器能力。
