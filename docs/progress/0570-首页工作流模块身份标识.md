# 1076 首页工作流模块身份标识

## 背景

HOTL-1 要求 TH、PH、TD 协同但保持职责清晰。首页摘要卡原本依靠图标和本地化文字区分模块，在窄屏、快速扫描或语言切换后，模块身份不够稳定，尤其 PH 与 TD 容易被看成同一类任务入口。

## 本次调整

- 首页三个统一摘要卡分别显示固定模块代码 `TH`、`PH`、`TD`。
- 保留图标、双语文本和原有跳转路径，不改变任何数据结构或业务边界。
- 代码标识使用主题变量，适配浅色、深色及 TH 主题架构；移动端与桌面端共用同一语义。
- 增加模块身份契约测试，防止后续重构误删独立标识。

## 验证

- 通过首页相关 pytest、全量 pytest 和桌面生产构建后提交。
