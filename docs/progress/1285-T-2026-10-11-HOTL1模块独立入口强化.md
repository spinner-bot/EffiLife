# HOTL-1 模块独立入口强化

## 1. 对照结论

HOTL-1 要求 PH 与 TD 保持不同定位：PH 的基本单元是完整计划，TD 的基本单元是单条快速待办；两者可以建立明确关联，但不能合并为同一工作流。

当前路由已经分别提供 `/plans`（PH）和 `/tasks`（TD），本次进一步强化页面内的可发现性。

## 2. 实现

- 在 PH 计划中心页增加 TH/PH/TD 上下文切换条，并明确 PH 当前入口。
- 在 TD 待办中心页增加同一组上下文切换条，并明确 TD 当前入口。
- 保留三个模块独立路由、独立页面、独立数据服务和独立操作逻辑。
- 不改变 PH 任务、嵌套分组、进展记录及稳定内部编号；不改变 TD 单条待办、优先级、截止日期和分类算法。
- 跨模块仍只通过显式关联和导航协同，不自动合并完成状态。
- 移动端对切换条使用横向滚动，桌面端保持紧凑横向工作台布局。

## 4. 边界

本次只强化模块入口的可发现性和上下文导航，不把 PH 与 TD 合并；HOTL-1 中关于更高层次视觉布局和其他功能问题的后续要求仍需继续按评审文件推进。
