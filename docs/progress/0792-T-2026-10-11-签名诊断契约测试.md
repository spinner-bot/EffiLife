# 签名诊断契约测试

日期：2026-10-11
类型：T（测试补强）

## 背景

启动器已经增加了发布签名环境探测，但这类探测容易因为工作站环境差异而发生误报。需要用隔离的临时目录覆盖工具齐全和工具缺失两种边界，保证“内部验收”和“正式分发”不会被混为一谈。

## 本次工作

- 增加 Android `apksigner.bat`、`zipalign.exe`、debug keystore 齐全时的就绪测试；
- 增加 Windows `signtool.exe` 可发现时的就绪测试；
- 增加 Android 与 Windows 工具均缺失时的 unsigned 边界测试；
- 使用 monkeypatch 和临时目录，不读取或生成真实发布证书，不改变当前机器环境。
