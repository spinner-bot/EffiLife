# 首页摘要刷新串行化

日期：2026-10-02

## 背景

Home 控制中心同时读取 TH 今日统计、PH 活跃计划和 TD 待办摘要。初始化、跨窗口事件和定时刷新可能重叠发起读取，慢请求返回顺序不稳定时会让旧批次覆盖较新的摘要。

## 实现

- 将三类摘要刷新统一封装为 `refreshWorkspaceSummaries`。
- 同一时刻只执行一个批次；刷新期间的新事件会排队，并在当前批次后再执行一次。
- 初始化、跨窗口刷新和每分钟刷新全部使用该协调器。

## 兼容性

不改变 TH、PH、TD 数据结构、模块边界或错误状态；各摘要原有的独立不可用提示和重试入口保持不变。
