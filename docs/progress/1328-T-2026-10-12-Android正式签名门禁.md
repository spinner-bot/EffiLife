# 1328-T：Android 正式签名门禁

## 元信息

- 日期：2026-10-12
- 类型：移动端发布 / Android
- 状态：已完成
- 关联：Android workflow、release manifest、正式发布变量

## 实施内容

1. 新增 `scripts/sign_android_artifact.py`，使用 `zipalign`、`apksigner` 完成签名和验证。
2. release keystore 通过 GitHub Secret 的 base64 内容注入临时文件，签名密码通过 `env:` 方式传给 apksigner，避免出现在命令行参数中。
3. Android workflow 仅在 `EFFILIFE_FORMAL_RELEASE_ENABLED=true` 时执行签名；未开启时保留 unsigned APK 作为内部验收产物。
4. 签名成功后移除 unsigned 输入文件，随后才执行 APK 校验、checksum 和 manifest 生成，确保清单对应最终产物。
5. 缺少 keystore、密码、别名、工具或签名验证失败时，正式流程直接失败。

## 发布边界

- 当前仓库没有配置 Android release keystore，因此本机和默认 CI 路径仍只生成 unsigned 内部 APK。
- iOS 仍按项目决定暂不构建。
- 本次不改变 PH、TD、TH 的数据职责，也不把 Android 签名凭据写入仓库。
