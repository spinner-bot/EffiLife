# 00-1028-V-2026-10-14-首页 PH 任务直达专注实现验收

## 结论

首页 PH 推荐执行任务现在可以直接进入统一专注会话，PH 与 TD 的领域边界保持不变。

## 实现

- PH 推荐任务行增加专注按钮，桌面端使用紧凑操作尺寸，移动端扩大至 40px。
- 首次进入时创建带 `related_plan_id`、`related_plan_task_id` 的 TD 待办；再次进入时复用已有关联待办。
- 专注会话仍由 `FocusSessionService` 管理，已有会话不会被覆盖。
- 失败通过现有 toast 反馈，按钮在异步创建期间防止重复触发。
- 增加中英文无障碍标签和提示文案。

## 验证

- `python -m pytest -q tests/test_focus_session_contract.py tests/test_home_todo_workspace.py tests/test_mobile_touch_targets.py`：20 passed。
- `npm run build`：通过。
- 真实 launcher + 浏览器路径：创建 PH 计划和任务 → 首页 PH 推荐任务 → 进入 TD 专注 → 活动专注条 → 停止返回 TD，输出 `home_ph_focus_verified: true`。

## 边界确认

PH 仍保存整份计划及其任务；TD 仍保存可执行待办和专注状态。本次仅新增显式关联和入口，没有把 PH 任务改造成 TD 的单一组别或合并数据实体。
