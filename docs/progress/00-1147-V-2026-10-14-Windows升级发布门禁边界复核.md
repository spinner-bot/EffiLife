# 00-1147-V-2026-10-14 Windows 升级发布门禁边界复核

## 类型与阶段

V（验证与边界复核）。当前仍为第 0 阶段；本编号只递增序列号，不增加阶段。

## 复核结论

当前 Windows 发布链路已经实际接入升级门禁，不是仅保留孤立脚本：

- `tauri-desktop-release.yml` 在 Windows NSIS 构建后执行安装包生命周期烟测。
- 手动提供 `previous_installer_url` 时，工作流下载旧版安装包，执行旧版安装、当前版本覆盖升级、卸载和隔离数据探针校验。
- `verify_release_candidate.py` 已支持重复传入 `--verify-upgrade`，可在本地候选验收中复用同一门禁。
- 旧版与当前版文件名版本不一致时，升级脚本会拒绝继续；隔离目录已存在或路径过宽时也会拒绝操作。
