# 修复 Android 云端构建 SDK 版本缺口

## 1. 问题

本地生成的 Tauri Android 工程使用 Android API 36，而 GitHub Actions 原移动端 workflow 只安装 Android 35 和 Build Tools 35.0.0；同时 workflow 没有显式安装项目本地构建所使用的 NDK 版本。这会造成本地构建正常、云端构建在 Gradle 或 Rust 链接阶段失败。

## 2. 修复

将 `.github/workflows/tauri-mobile-build.yml` 的 SDK 安装项统一为：

```text
platforms;android-36
build-tools;36.0.0
ndk;25.2.9519653
```

这与统一环境站中实际成功构建 APK 的版本保持一致。

## 3. 验证

- 使用环境站 `sdkmanager --list` 确认三个包均可用；
- 移动端 workflow、构建脚本和发布配置回归：`12 passed`；
- 未改变 iOS 边界，移动端 workflow 仍只构建 Android。

## 4. 边界

本次修复解决的是 CI 工具链版本缺口，不代表 GitHub runner 上已完成一次真实 workflow 执行；真实云端运行仍需由 GitHub Actions 触发验证。
