# HOTL 1 当前基线审计

日期：2026-10-01

## 结论

HOTL 1 号文件要求的整改范围已在当前统一工作区实现并完成本地可执行验证。PH、TH、TD 仍是三个独立业务域，由统一应用壳和首页控制台协同，不改变各自基本单元。

## 逐项证据

| 要求 | 当前实现 | 验证证据 |
| --- | --- | --- |
| PH 与 TD 定位分离 | `/plans`、`/time`、`/tasks` 为独立一级入口；首页只展示摘要 | `tests/test_home_workflow_summary.py`、`tests/test_home_navigation_deduplication.py` |
| PH 保留完整 plan 语义 | 完整计划、模块/复合编号、嵌套分组、执行记录和归档 | PH 数据/API/编辑器契约测试 |
| 首页为三模块控制台 | 首页聚合时间、计划、待办关键状态并提供深链 | Home 工作流测试 |
| 桌面端宽屏布局 | 首页、计划、时间、待办、记录、设置均有桌面布局规则 | 桌面布局测试；生产构建通过 |
| 消除错位遮挡 | 表单、工具栏、弹窗、过渡和导航已覆盖布局契约 | Python 全量测试；`vue-tsc` + Vite 构建 |
| 主题可切换且持久化 | 主题即时预览；离开主题设置时弹窗确认；确认后以同一归一化规则校验，并以持久化读取结果回灌运行态 | `tests/test_theme_persistence_contract.py`、`tests/test_settings_theme_i18n.py` |
| 现代视觉与丰富主题 | ThemeEngine 注册表、CSS 变量、ThemeCanvas 和基础/丰富主题共用应用壳 | 主题引擎与桌面构建 |
| 移除独立日历 | 主导航不提供日历入口，旧 `/calendar` 仅作兼容重定向 | 路由和导航契约测试 |

## 当前验证结果

- `python -m pytest -q`：700 passed。
- `python scripts/run_integration.py test`：55/55 passed。
- `python scripts/check_release_config.py`：通过。
- `python scripts/check_mobile_release_config.py`：通过。
- `npm run build`（`time-helper/desk`）：通过，1874 modules transformed。
- `launcher/start.py --release-check`：配置检查通过；本机仅缺少 Cargo/Rust，不能替代正式 Tauri 构件验收。

## 现行主题交互契约

主题页不提供独立保存按钮。用户修改后立即看到预览；点击返回、切换设置子页或离开设置路由时，若存在未确认修改则弹出确认框。确认后保存，取消则停留在主题编辑页。历史进展文档中关于“增加主题保存按钮”的描述属于当时阶段记录，不是当前设计。

## 未覆盖范围

正式 Tauri 安装包的真实编译、签名、安装升级迁移，以及 Android/iOS 真机验收仍需对应发布环境；本机缺少 Cargo/Rust 和移动 SDK，不能以静态契约检查替代这些验收。
