# 1162 桌面端构建分包优化

日期：2026-10-09  
类型：桌面端性能与缓存优化

## 背景与问题

统一壳和多语言目录持续增长后，Vite 构建将主入口提示为约 503 kB。虽然构建没有失败，但首屏入口过大，会降低浏览器缓存复用和桌面端更新后的加载效率。

## 实现

- 在 Vite Rollup 输出阶段按稳定依赖拆分 `vendor-vue`、`vendor-icons`、`vendor-charts`、`vendor-archive` 和 `vendor-tauri`。
- 仅对 `node_modules` 依赖执行手工分包，应用自身模块仍由 Vite 按路由和组件组织。
- 不提高 `chunkSizeWarningLimit`，保留构建体积信号。
- 增加构建配置契约测试，防止后续新增依赖时分包边界回退。

## 验证

- `npm run build`（`time-helper/desk`）：通过，1877 modules transformed；主入口约 376 kB，未再触发 500 kB 警告。
- `python -m pytest -q tests/test_vite_chunking.py tests/test_build_environment.py tests/test_ci_workflow.py`：14 passed。
- `python -m pytest -q`：923 passed。

## 提交与边界

代码与报告直接提交到 `main`，不创建分支。该优化只改变静态资源输出布局，不改变运行时模块职责、数据格式或 Tauri 配置。
