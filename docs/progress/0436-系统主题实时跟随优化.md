# 0862 系统主题实时跟随优化

## 背景

基础浅色和深色主题已经可以显式选择，但桌面用户通常还希望应用跟随操作系统的明暗模式。此前切换系统模式不会更新统一应用壳，用户只能手动重新选择主题或刷新页面。

## 本次调整

- 在 TH 主题注册表中增加 `system` 基础主题。
- ThemeEngine 根据 `prefers-color-scheme` 解析为浅色或深色设计令牌。
- 应用壳监听系统主题变化，在选择 `system` 时实时刷新统一 CSS 变量。
- 兼容不支持新式 MediaQuery 监听 API 的运行环境，并在卸载时清理监听器。
- 不新增存储字段；主题仍按现有配置和退出确认流程持久化。

- `python -m pytest -q`：提交前执行
