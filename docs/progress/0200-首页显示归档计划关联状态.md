# 0601 首页显示归档计划关联状态

## 背景

首页待办卡片已经支持跳转到关联计划，但此前只查询活动计划。计划归档后，关联待办仍然存在，却只能显示通用的“关联计划”，用户无法判断该计划是否仍处于活动状态。

## 实现

- 首页刷新时并行读取活动计划和归档计划索引。
- 计划名称索引同时覆盖活动计划与归档计划，保留待办到原计划的可追溯跳转。
- 对归档计划追加双语“已归档 / Archived”状态标识。
- 归档索引读取失败时沿用首页已有的降级策略，不阻塞待办概览。

## 验证

- 新增首页静态契约测试，确认归档索引、归档映射和双语文案均接入。
- 待运行定向测试、全量测试与桌面构建。
