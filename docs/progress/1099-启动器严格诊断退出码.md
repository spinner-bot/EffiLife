# 1099 启动器严格诊断退出码

## 背景

启动器原有 `--diagnose` 输出了完整的机器可读 JSON，但始终以成功状态退出。自动化脚本因此无法区分“诊断发现阻塞问题”和“仅有非阻塞提示”。

## 本次调整

- 新增 `python launcher/start.py --diagnose-strict`。
- 继续输出与 `--diagnose` 相同的 JSON 结构，不改变既有消费者。
- 当 `issues` 非空时返回退出码 `1`；只有 `hints` 时仍返回 `0`。
- `--diagnose` 保持原行为，适合人工采集诊断信息。
- 补充启动器帮助、README 和契约测试。

## 验证

- `python -m pytest -q tests/test_launcher.py`：应通过。
- `python launcher/start.py --diagnose-strict`：当前工作区若无阻塞问题则返回 `0`；Rust/Cargo 缺失只作为提示，不阻断开发模式。
