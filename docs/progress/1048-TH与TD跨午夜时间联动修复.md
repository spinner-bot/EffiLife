# 1048 TH 与 TD 跨午夜时间联动修复

日期：2026-10-02

## 问题

TD 的“记录时间”功能会按日期边界切分长时间段，并使用 `24:00` 表示当天结束。TH 记录编辑表单此前只允许结束小时 0–23，用户打开这类联动记录后无法重新保存；同时，时长刚好结束于午夜时会被错误格式化为 `00:00`，造成负时长。

## 实现

- TH 时间模式允许合法的 `24:00` 结束边界，但拒绝 `24:01` 等非法值。
- 时长模式精确结束于午夜时保留 `24:00` 和 1440 分钟边界。
- 继续拒绝真正跨越午夜的单条记录，要求拆分到不同日期。
- 保持 TD 记录跨日切分和 TH 单日时间轴的数据模型不变。

- Python 全量测试：`801 passed in 7.65s`。
- 桌面前端生产构建：`vue-tsc` 通过，Vite 完成 `1877 modules transformed`，构建成功。

## 影响范围

修复跨模块联动记录的可编辑性和时长计算，不改变 PH/TD 实体边界、记录 ID 或统一存档协议。
