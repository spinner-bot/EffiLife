# 1203｜统一数据目录文档与启动器契约

日期：2026-10-10  
状态：已完成

## 背景

统一运行时已经支持通过 `EFFILIFE_DATA_DIR` 指定共享数据根目录，启动器也会把该目录传给 Plan Helper。此前这项能力缺少 README 中的使用说明，容易造成开发启动、直接启动 Plan Helper 与正式数据目录之间的认知断裂。

## 本次处理

1. 在 README 增加 `EFFILIFE_DATA_DIR` 的 PowerShell 启动示例。
2. 说明启动器传参与直接执行 `plan-helper/web/server.py` 时的环境变量兼容行为。
3. 明确未设置环境变量时保留开发环境兼容路径，正式安装包应使用应用专用数据目录。
4. 增加文档契约测试，防止后续重构时删除关键说明。
5. 保留已有的 launcher 回归测试：验证配置目录会传递给 Plan Helper，未配置时不额外注入 `--data-dir`。

## 验证标准

- 文档包含环境变量、启动命令、Plan Helper 直接启动方式和未设置时的兼容说明。
- 启动器测试覆盖“已配置”和“未配置”两种路径。
- 不改变用户已有的项目级数据，不改变正式安装包的待完成状态。
