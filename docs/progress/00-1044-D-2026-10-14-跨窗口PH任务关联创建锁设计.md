# 00-1044-D-2026-10-14-跨窗口 PH 任务关联创建锁设计

## 背景

同一运行时内的关联创建已经按 `planId:taskId` 串行化，但两个独立页面各自拥有不同的 JavaScript 内存队列，仍可能同时通过“读取—创建”检查。

## 决策

- 优先使用 Web Locks API 的独占锁，锁名为 `effilife:plan-todo:<planId>:<taskId>`。
- 在不支持 Web Locks 的 WebView 或受限环境中，回退到当前运行时内存队列。
- 锁只包裹关联待办的读取—判断—创建过程，避免扩大锁范围。
- 现有已有关联待办继续复用，不改写用户数据。

## 非目标

不引入远程锁服务，不改变 PH/TD 实体边界，不改变 `.efl` 协议或移动端快照结构。
