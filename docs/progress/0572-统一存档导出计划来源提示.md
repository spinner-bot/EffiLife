# 1078 统一存档导出计划来源提示

## 背景

统一 `.efl` 存档同时承载 TH、PH、TD 数据。桌面实时服务不可用时，系统会使用缓存；移动端则使用本机 PH 快照。此前导出结果只对缓存或完全不可用状态提供提示，移动端成功导出时无法明确告知用户计划数据的来源。

## 本次调整

- 新增统一的 `planExportWarning` 来源判定函数。
- 桌面原生保存、移动系统分享和普通下载三条导出路径都使用同一提示逻辑。
- 实时服务不增加干扰提示；缓存继续显示服务不可用提示；移动本地快照明确提示可能不是最新服务数据。
- 提示支持中英文，不改变 `.efl` 协议、数据集结构、导入回滚或 PH/TD 边界。

## 验证

- 增加三条导出交付路径的来源提示契约测试。
- 通过存档专项测试、全量 pytest 和桌面生产构建后提交。
