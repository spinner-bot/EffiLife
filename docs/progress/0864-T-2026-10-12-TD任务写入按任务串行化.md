# 0864－TD 任务写入按任务串行化

类型：T（统一数据一致性）  
日期：2026-10-12  
阶段：0  
状态：已完成

## 1. 问题

TD 的更新同样采用“读取任务—计算新值—写回”的模式。快速编辑任务、切换子任务、记录用时、调整累计用时，或从另一个窗口同时操作时，后完成的旧快照可能覆盖较新的任务状态。此前 TH 记录已经在数据服务层完成按日期串行化，TD 仍缺少对应保护。

## 2. 实现

- 在 `TodoService` 增加按任务 ID 的写入队列。
- `update`、`addSubtask`、`toggleSubtask`、`removeSubtask`、`remove`、`trackTime`、`adjustTrackedTime` 统一进入任务级串行边界。
- 子任务和用时聚合的读取也移动到队列内部，避免仅串行写入但仍基于队列外旧快照计算。
- 任务删除与 TH 记录反向关联清理仍保持原有顺序和容错策略。
- 不改变 TD 数据模型、任务 ID、PH 关联字段或 TH 历史记录。
