# 1176 统一存档预览细分关联修复

日期：2026-10-09  
类型：实现报告

## 背景

统一 `.efl` 存档的导入预览此前只显示“将修复 N 条关联”，但 EffiLife 中存在两类不同职责的关联：TH 时间记录与 TD 待办的关联，以及 PH 计划任务与 TD 待办的关联。只显示总数不利于用户判断迁移风险，也没有显示存档导出的时间。

## 目标与非目标

目标是在导入确认文本中显示导出时间，并拆分两类关联修复数量。非目标是修改 `.efl` canonical dataset、校验算法、导入写入顺序或三模块实体边界。

## 影响范围

- `ArchiveService.ts`：扩展仅供预览使用的统计字段。
- `SettingsView.vue`：格式化导出时间和 TH/TD、PH/TD 修复明细。
- `i18n/index.ts`：新增中英文提示。
- `tests/test_archive_preview.py`：增加预览透明度契约。

## 实现与兼容性

预览仍从既有 `importRepairs` 统计生成，实际导入行为不变；旧版存档没有修复计数时按 0 显示。导出时间使用当前语言环境格式化，无法解析时保留原始值。此变更不改变存档协议，旧 `.efl` 文件无需迁移。
