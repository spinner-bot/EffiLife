# 1154 统一搜索提示 PH 任务索引部分失败

日期：2026-10-05  
类型：统一搜索可靠性修复

## 背景与问题

统一搜索会并行读取多个 PH 计划的任务索引。单个计划任务接口失败时，搜索仍可显示其它数据，但此前只静默丢弃该计划的任务，用户无法判断结果是否完整。

## 实现

- 检查 PH 任务索引的 `Promise.allSettled` 结果。
- 任一计划任务索引失败时保留其它可用结果，并显示现有的“部分数据不可用”提示。
- 继续提供重试入口，不改变计划、待办或时间记录的数据模型。
- 增加源码契约测试。

## 验证

- 统一搜索专项测试：20 passed。
- 项目全量测试：910 passed。
- `time-helper/desk`：`npm run build`，通过，1877 modules transformed。

## 提交与边界

代码与报告直接提交到 `main`，不创建分支。该改动只改善搜索状态透明度，不把 PH 任务转换为 TD 或 TH 实体。
