# 0784｜主题退出保存竞态修复

## 状态

已完成，2026-10-01。

## 问题

主题编辑器在退出确认后已经调用 `saveConfig`，但同一窗口的 `App.vue` 仍会响应 `settings` 工作区事件并再次读取持久化数据。该刷新与设置页退出保存、主题预览和快照同步存在竞态，可能让刚保存的主题短暂或最终回退。

## 处理

- 当前窗口收到 `settings` 事件时不再重复刷新整个工作区；设置 store 已在写入前同步更新，主题页也会维护自己的持久化快照。
- 工作区刷新增加写入版本校验：可见性刷新或跨窗口读取若早于本地配置写入开始，则整批结果丢弃并重新读取，避免旧配置覆盖新主题。
- 仍保留 locale 刷新。
- 跨窗口的 `BroadcastChannel` 消息不属于发送窗口自身，其他窗口仍会正常重新加载配置。
- 主题页继续采用“实时预览 + 退出弹窗确认保存”，不增加主题保存按钮。
