# PH 任务用时字段澄清设计

日期：2026-09-30

## 背景

PH 是事件导向的计划工具，任务的核心是事件内容；时间估计只是可选辅助信息。当前详情编辑器使用“预计分钟”标签且新增任务默认填 30，容易让用户误解为每个任务都必须输入时间。

## 决策

- 标签改为“预计用时（分钟，可选）”，英文同步表达 optional。
- 新增任务的默认用时改为 0，表示尚未估计，不要求用户填写。
- 编辑已有任务时保留其原有 `time_minutes` 值。
- 不改变 PH 原始字段、不把任务用时转换成 TH 记录，也不改变 TD 关联中的估计时间同步；用户填写后仍可被 TD 使用。

## 验收

- 中英文标签明确包含可选语义。
- 新任务编辑器默认 `0`。
- 已有任务编辑回填原值。
- 全量回归通过。
