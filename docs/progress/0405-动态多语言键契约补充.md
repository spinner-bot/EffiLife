# 动态多语言键契约补充

日期：2026-10-01

## 背景

统一工作台已有静态 `t('…')` 调用的中英文覆盖检查，但模板中还有通过变量拼接的 key：待办分类图标选择器使用 `tasks.iconTab.*`，存档统计使用 `settings.archive.planSource.*`。这类调用无法由原有静态正则自动发现。

## 处理

新增动态 key 家族契约测试，明确要求以下 key 在中英文目录中各存在一次：

- `tasks.iconTab.icons/ascii/colors`
- `settings.archive.planSource.live/cache/snapshot/unavailable`

这只强化测试约束，不改变运行时回退策略和现有语言目录结构，为后续增加语言提供更早的缺口反馈。

## 验证

- 多语言覆盖与 locale registry：6 passed。
- `git diff --check`：通过。
