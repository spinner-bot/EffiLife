# 多语言字面量键覆盖门禁

## 1. 核查

扫描 `time-helper/desk/src` 中所有 Vue/TypeScript 文件的字面量 `t('…')` 和 `translate('…')` 调用，并与共享 i18n catalog 比较。

本次扫描结果：

```text
字面量翻译调用：961 个
缺失 key：0 个
```

## 2. 实现

新增 `tests/test_i18n_literal_key_coverage.py`：

- 收集所有字面量翻译调用；
- 要求每个 key 在 catalog 中至少出现两次，分别覆盖当前的中英文 catalog；
- 动态 key 不被误判为字面量 key，继续由各模块的专门测试覆盖。
- 对 `tasks.iconTab`、`search.filter`、`plans.statusFilter`、归档来源和 `api.error` 等已知动态 key family 增加显式中英文覆盖检查。

## 3. 验证

```text
python -m pytest -q tests/test_i18n_literal_key_coverage.py tests/test_settings_theme_i18n.py tests/test_plan_center_i18n.py tests/test_task_create_form_accessibility.py
26 passed in 0.70s
```

这项门禁强化了统一应用壳、多模块页面和丰富主题文案的多语言基础，不改变 PH/TD 的功能边界。
