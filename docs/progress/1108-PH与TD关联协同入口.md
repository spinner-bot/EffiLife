# 1108 PH 与 TD 关联协同入口

## 背景

HOTL-1 要求 PH 与 TD 协同，但明确禁止把 PH 的计划任务改造成 TD 实体。此前数据模型已经预留 `related_plan_id` 与 `related_plan_task_id`，界面却没有把计划任务加入 TD 的入口，用户只能在两个模块之间重复录入。

## 本次调整

- 在 PH 计划详情摘要中增加“全部加入待办”入口；
- 仅为未完成且尚未关联的计划任务创建独立 TD 待办；
- TD 待办保存 PH 计划 ID、内部任务 ID、任务预计用时和上下文描述；
- 重复点击不会重复创建，已关联任务显示不可用状态；
- PH 任务完成时，若存在关联 TD 待办，则同步完成该 TD 待办；
- 保持 TD 页面不调用 PH 编辑接口，PH 仍是计划任务的唯一编辑者；
- 增加契约测试，明确“关联协同”与“实体合并”的边界。

## 验证

- `python -m pytest -q`
- `npm run build`（`time-helper/desk`）
