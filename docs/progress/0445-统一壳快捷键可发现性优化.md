# 0871 统一壳快捷键可发现性优化

## 背景

统一壳已经支持 `Alt+1…Alt+5` 快速切换工作区，但仅靠记忆快捷键不利于首次使用，也不利于辅助技术识别快捷键与导航入口的对应关系。

## 本次变更

- 在桌面主导航中显示每个工作区对应的 `Alt` 数字提示。
- 为五个工作区导航链接补充 `aria-keyshortcuts`。
- 平板和移动端隐藏视觉快捷键提示，避免压缩导航；快捷键逻辑和触控入口保持不变。
- 与上一轮快捷键映射保持一致：首页 1、PH 2、TH 3、TD 4、记录 5。

## 验证

- `python -m pytest -q tests/test_unified_navigation_accessibility.py`
- `python -m pytest -q`
- `npm run build`（`time-helper/desk`）
