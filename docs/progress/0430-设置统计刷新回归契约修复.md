# 0856 设置统计刷新回归契约修复

日期：2026-10-02

## 背景

将存档统计抽取为可复用的 refreshDataStats 后，原有初始化契约测试仍直接查找旧的内联赋值，导致全量测试出现 1 个静态契约失败。运行逻辑本身已有刷新函数兜底，但初始化边界需要继续显式保护。

## 实施内容

- 在设置页 onMounted 保留外层 try/catch，确保统计读取异常不会阻塞页面初始化。
- 更新契约测试，使其验证新的刷新函数调用、实际数据读取和请求结果写入，而不是绑定旧的代码布局。
