# 1066｜多语言切换广播边界修复

## 发现的问题

语言选择器原先使用 `v-model` 直接改写共享 `currentLocale`，随后再调用 `setLocale`。由于此时 locale 已经变化，`setLocale` 会误判为无变化，导致跨窗口设置事件不广播。

## 实施内容

- 语言选择器改为只读取 `:value`。
- 由 `setLocale` 统一负责校验、持久化、文档 `lang` 更新和工作区广播。
- 增加契约测试，防止选择器重新绕过语言边界。

## 验证结果

- 语言切换契约测试通过。
- 桌面生产构建验证 Vue 模板类型与编译。

## 边界说明

本次不新增语言目录或翻译内容，只修复现有中英文语言切换在多窗口场景下的同步基础。
