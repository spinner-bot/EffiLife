# 0674：设置保存异常反馈

## 背景

设置页的主题保存已有失败反馈，但普通时间显示与阈值设置直接调用配置持久化；当 IndexedDB 写入失败时，会产生未处理异常，用户也得不到明确提示。

## 实现

- 为自定义设置保存增加 `try/catch`。
- 写入失败时记录诊断信息并显示本地化失败提示。
- 保持成功提示、配置字段和主题保存流程不变。
- 增加静态回归测试，确保设置写入具备错误边界。

## 兼容性

- 不改变配置数据结构、主题架构或跨窗口设置事件。
- 不影响 PH、TD、TH 的独立数据职责。
