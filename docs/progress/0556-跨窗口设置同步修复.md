# 1062 跨窗口设置同步修复

日期：2026-10-02

## 问题

统一工作区通过 CustomEvent 和 BroadcastChannel 同步数据。为避免主题保存退出时被旧快照覆盖，App 对 `settings` 事件统一提前返回；这保护了本窗口，却使其他窗口收到主题、语言或配置变化后不刷新。

## 实现

- 为工作区事件增加每个窗口独有的 `origin` 标识。
- 同窗口事件标记为本地事件，继续跳过 App 的重复刷新，避免主题保存竞态。
- BroadcastChannel 事件标记为远程事件，App 对远程 `settings` 变化执行完整工作区刷新。
- 语言同步仍在两类事件中执行，保留跨窗口语言切换能力。

## 验证

- 工作区同步与主题持久化专项测试：`31 passed`。
- Python 全量测试：`818 passed`。
- 桌面前端生产构建：通过，`1877 modules transformed`。

## 影响范围

恢复多窗口配置/主题同步，同时保留本窗口主题保存的竞态保护；不改变 PH、TD、TH 数据职责边界。
