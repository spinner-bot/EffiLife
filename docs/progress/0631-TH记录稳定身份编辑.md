# 1137 TH 记录稳定身份编辑

日期：2026-10-05  
类型：实现报告

## 背景与目标

TH 记录页的编辑表单原先依赖记录在数组中的位置。统一工作区刷新、跨窗口修改或归档可能改变数组顺序，随后保存草稿时存在误更新另一条记录的风险。目标是让编辑操作绑定稳定记录身份。

## 实现与兼容性

- 打开编辑表单时保存记录稳定 `id`；
- 保存前根据稳定 ID 在当前工作区重新解析记录下标；
- 记录仍存在时使用最新下标更新，记录已被删除或归档时拒绝保存并提示用户重新打开；
- 新建记录仍使用原有 ID 生成逻辑，todo 关联和冲突检测保持不变；
- 不改变 TH 记录格式、PH/TD 关联字段或统一归档协议。
