# 发布产物验证

日期：2026-10-11

## 背景

HOTL-1 对齐审计中，安装包安装/升级和 Android 真机验收仍属于未完成证据。本次先验证当前工作站已经生成的桌面和 Android 发布产物，以及对应构建环境的完整性。

## 目标与非目标

目标是确认产物存在、非空、版本可识别，并确认 Android 构建工具链可用。

非目标是执行安装器写入系统、签名、发布升级或连接真实 Android 设备；这些操作需要单独的发布验收窗口。

## 影响范围

只读取 `time-helper/desk/src-tauri/target`、Android 构建输出和环境检查结果，不修改应用数据或源代码。

## 验证命令及结果

```text
python scripts/verify_release_artifacts.py \
  --directory time-helper/desk/src-tauri/target/release/bundle/nsis \
  --extension .exe \
  --version-file time-helper/VERSION
  OK: EffiLife_1.7.0_x64-setup.exe (11589066 bytes)

python scripts/verify_mobile_artifacts.py \
  --directory time-helper/desk/src-tauri/gen/android/app/build/outputs/apk \
  --target android
  OK: app-arm64-release-unsigned.apk

python scripts/check_build_environment.py --target android
  ready: true
  missing: []
```

工具链中 Node、npm、Cargo、Rust、Java、ADB 和 Android SDK 均已解析到可用路径，Android 项目目录存在。

## 兼容性与迁移说明

本次为只读验证，不改变版本号、签名配置、数据格式或构建产物。

## 提交与推送

本报告与验证结果一起提交并推送；实际提交哈希以 Git 记录为准。

## 未验证项与后续事项

- NSIS 安装器尚未执行真实安装、升级、卸载验收；
- 安装包尚未签名；
- Android APK 尚未在真实设备上安装和测试触控、返回键、数据导入导出；
- 本地验证目录尚未生成正式发布校验清单，CI 发布流程仍负责生成校验和 manifest。
