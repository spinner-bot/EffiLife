# 1207｜全局搜索模块筛选实现

日期：2026-10-10  
状态：已完成并推送

## 背景与目标

全局搜索已索引 TH 时间记录、PH 计划与计划任务/归档、TD 待办，但结果范围只能由关键词间接判断。本次实现为统一搜索增加显式模块筛选，使用户可以在控制台内快速缩小范围，同时保持三模块的数据实体、生命周期和深链接完全独立。

## 非目标

- 不把 PH 任务转换为 TD，也不改变 PH/TD 的独立生命周期。
- 不修改 `.efl` 存档协议、Plan 原始数据结构、软删除编号或日历入口。
- 不引入新的主题色；筛选控件全部使用既有主题 token。

## 影响范围

- `time-helper/desk/src/components/GlobalSearch.vue`：新增 All、TH、PH、TD 筛选状态和结果投影。
- `time-helper/desk/src/i18n/index.ts`：新增中英文筛选文案。
- `tests/test_global_search_filters.py`：锁定模块映射、双语覆盖和键盘/触控布局契约。

## 实施内容

1. 默认打开搜索时恢复 All，关闭再打开不会遗留上次筛选。
2. TH 仅显示时间记录，TD 仅显示待办，PH 显示整份计划、计划任务和归档计划。
3. 筛选不改变原有结果评分、上下键选择、Enter 深链接、Esc 关闭、加载和部分失败提示。
4. 筛选控件使用 `aria-pressed`、分组标签和水平滚动，移动端保留触控尺寸。

## 兼容性与迁移

这是纯展示层筛选，不写入数据、不改变 IndexedDB/localStorage、不改变移动端本地计划快照，也不需要迁移旧存档。All 筛选保持原有行为兼容。
