# 1219｜首页快速待办可见标签实现

日期：2026-10-10  
状态：已完成并推送

## 背景

HOTL-1 要求统一首页成为可扫描的三模块控制台，UX 规范同时要求每个输入框都有可见字段标签。首页 TD 快速新增入口此前只依赖 placeholder 和 ARIA 标签，用户在输入后无法继续看到字段语义。

## 实施内容

- 为快速新增待办输入框增加可见的“下一步行动 / Next action” label。
- 使用唯一 `id` 与 `for` 建立原生表单关联。
- 桌面端保持 label、输入框、提交按钮横向对齐；移动端改为纵向排列，避免窄屏拥挤。
- 新增中英文目录键，不改变 TD 独立数据模型和创建流程。
