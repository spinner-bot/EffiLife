# 设置页警告图标规范设计

## 背景

统一工作台的界面规范要求图标来自图标库，不使用 emoji 作为功能图标。设置页的数据重置区域仍将警告 emoji 与文案直接拼接，可能受到操作系统字体、字号和渲染差异影响，也与其他页面的 Lucide 图标体系不一致。

## 方案

- 使用 `lucide-vue-next` 的 `AlertTriangle` 组件替换 emoji。
- 警告图标与文案保持同一行，通过 `.reset-warning` 的 flex 布局对齐。
- 颜色继续使用现有语义 token `--color-warning`，不引入页面级固定色值。
- 保留原有翻译键和重置流程，不改变交互逻辑。

## 验收标准

1. 设置页重置区域不再渲染 emoji 警告图标。
2. 图标在浅色、深色及 TH 主题下继承警告色。
3. 生产构建和现有测试通过。
