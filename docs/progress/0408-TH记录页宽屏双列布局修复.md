# TH 记录页宽屏双列布局修复

日期：2026-10-01

## 问题

记录页的宽屏断点声明了双列 `grid-template-columns`，但记录列表基础样式仍是 flex 容器。CSS Grid 专属属性没有生效，桌面端仍然单列，未充分利用宽屏空间。

## 处理

- 在 `min-width: 1100px` 断点显式切换 `.records-list` 为 Grid。
- 保留移动端和窄窗口的单列 flex 结构。
- 使用 `align-items: start`，避免两列中较短的记录卡被拉伸。

## 验证

- 新增桌面记录页布局契约测试。
- 相关桌面工作区测试通过。
