# 00-1042-V-2026-10-14-Smoke 纳入跨窗口专注回归

## 结论

跨窗口专注验证已纳入可重复的 workspace smoke，不再依赖一次性手工脚本。

## 实现

- `--td-focus-flow` 现在创建第二个浏览器页面。
- 页面 A 启动专注后，页面 B 必须显示活动专注条。
- 页面 B 停止后，两个页面都必须确认活动专注条消失。
- SmokeResult 新增 `td_cross_window_focus_verified` 字段。

## 验证

- `python scripts/smoke_browser_workspace.py --url http://127.0.0.1:1420 --td-focus-flow`：通过。
- 结果包含 `td_focus_flow_verified: true`、`td_cross_window_focus_verified: true`、`th_quick_capture_shortcut_verified: true` 和 `mobile_navigation: true`。
- 验证后已清理本轮启动的 launcher、Vite 和 Plan Helper 进程。

## 边界

该 smoke 覆盖桌面 Chromium 多页面，不替代 Android WebView、原生多窗口长时间运行和真实设备验收。阶段继续固定为第 0 阶段。
