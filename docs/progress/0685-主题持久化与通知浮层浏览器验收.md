# 1191 主题持久化与通知浮层浏览器验收

日期：2026-10-09  
类型：实现与运行时验收报告

## 背景

HOTL-1 曾指出主题切换保存后退出可能恢复旧主题。此前源码、契约测试和构建均已通过，但缺少真实浏览器操作证据。本轮使用 Playwright 启动 Chromium，执行主题切换和重载流程；同时修复验收中发现的事件通知浮层长期拦截问题。

## 实现内容

- `EventPopup.vue` 为每个新事件建立 5 秒自动收起定时器，与已有进度条时长一致。
- 手动关闭会清除对应定时器；组件卸载会清理全部定时器。
- 新增事件浮层生命周期契约测试。

## 浏览器验收

使用真实 Vite 开发服务器 `http://127.0.0.1:1431` 和 Playwright Chromium：

1. 设置 `efflife_guide_completed`，进入 `/settings`。
2. 等待启动事件通知自动收起，进入主题设置。
3. 选择“深色”主题，运行时 CSS `--color-bg` 变为 `#0f172a`。
4. 点击返回，确认退出弹窗并确认保存。
5. 页面离开主题设置；重新加载页面后 CSS `--color-bg` 仍为 `#0f172a`。

结果：主题切换、退出确认、持久化重载均通过。此前阻挡设置按钮的事件通知浮层也已由自动收起修复。
