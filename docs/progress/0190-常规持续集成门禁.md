# 常规持续集成门禁

## 背景

仓库原有 Actions 主要服务移动边界和正式打包。普通 `main` 提交没有统一执行全量 Python 测试与桌面前端构建的门禁，容易让集成回归延迟到发布阶段才暴露。

## 实现

- 新增 `.github/workflows/ci.yml`，覆盖 `main` push、Pull Request 和手动触发。
- 在同一 job 中安装桌面依赖、运行全量 `pytest`、执行 `npm run build`。
- 使用并发取消旧运行，避免连续提交产生无效排队。
- 保持只读仓库权限和 15 分钟超时，避免 CI 失控。

## 验收

- 新增 CI 工作流契约测试。
- 本地全量测试与桌面端构建通过。
