# 统一工作台视觉与本地化审计

## 审计范围

检查桌面端统一入口实际使用的 Home、PlansHub、TaskCenter、Settings 视图及共享组件，关注图标来源、主题颜色和可见文案本地化。

## 结果

- 统一工作台视图未发现直接写死的中英文用户文案；`localStorage`、`IndexedDB` 属于数据技术名，保留原文以避免歧义。
- 设置页重置警告原先使用 emoji；已替换为 `lucide-vue-next` 的 `AlertTriangle`，并通过语义颜色 token 继承主题。
- Settings 中的固定颜色主要属于 TH 丰富主题架构的主题定义或颜色选择器默认值，不属于页面组件的装饰色，保留以确保主题可配置能力。
- Home 中的提醒、错误、强调色属于状态语义色；后续若统一 token 能覆盖这些状态，再单独迁移，不在本次审计中改变视觉含义。
