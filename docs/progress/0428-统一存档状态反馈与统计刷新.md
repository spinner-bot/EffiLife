# 0854 统一存档状态反馈与统计刷新

日期：2026-10-02

## 背景与目标

统一存档页负责 PH、TD、TH 数据的跨模块备份与迁移。此前数据统计只在设置页首次挂载时读取；完成导入、恢复或跨窗口变更后，重新打开存档页可能仍显示旧统计。导入导出期间按钮虽然被禁用，但缺少明确的进行中状态。

## 实施内容

- 将统计读取封装为带请求序号保护的 refreshDataStats，避免较早的异步结果覆盖较新的结果。
- 每次进入存档页时刷新当前数据统计。
- 在存档操作容器上公开 aria-busy，并增加双语 role=status 进行中提示。
- 保留现有预览、校验和失败回滚流程，不改变统一 .efl 数据协议。

## 影响范围

- 覆盖 PH 事件计划快照、TD 待办/分类、TH 时间记录及配置统计。
- 不改变数据模型、导入覆盖语义、校验摘要或恢复策略。
- 仅改善存档页的时效性和操作反馈。
