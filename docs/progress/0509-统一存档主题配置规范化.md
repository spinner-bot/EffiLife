# 1015 统一存档主题配置规范化

## 背景

统一存档已经使用 `effilife.bundle` canonical datasets 和 SHA-256 校验，但归档导入配置时曾直接保存外部 payload。启动读取会补齐主题默认段，却不能保证“导入后立即再次导出”的数据已经规范化。

## 变更

- 前端导出从底层存储读取配置后，先经过 `normalizeConfig` 再写入 `app` 数据集。
- 前端导入解析 canonical `app` 数据集时，先经过 `normalizeConfig` 再安装到运行时。
- 保持 PH、TD、TH 的数据边界不变，仅统一配置数据的存储形状。

## 兼容性与安全边界

- 完整配置会原样保留，缺失的主题段从默认配置补齐。
- 旧 `.efl` 存档仍按原有解析路径兼容；缺失配置仍允许为空并沿用现有启动默认值。
- 不改变 manifest、数据集名称、校验和算法或导入回滚流程。
