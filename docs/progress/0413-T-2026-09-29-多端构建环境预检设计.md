# 多端构建环境预检设计

## 背景

当前开发机可运行前端与 Python 契约测试，但没有 Rust/Cargo，也没有 Android/iOS 原生工具链。已有发布配置无法据此证明安装包或移动端真机验收完成。

## 方案

- 新增只读 `scripts/check_build_environment.py`。
- 支持 `desktop`、`android`、`ios` 和 `all` 目标。
- 输出 JSON，包含每项工具的路径和可读性；目标缺少必需工具时返回退出码 1。
- 不安装依赖、不修改环境、不启动服务。
- CI 可在安装工具链后复用同一检查，本地可快速定位发布前缺口。
