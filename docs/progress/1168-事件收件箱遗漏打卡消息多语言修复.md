# 事件收件箱遗漏打卡消息多语言修复

日期：2026-10-09

## 背景

事件服务已经提供中英文 catalog，但遗漏打卡提醒在构造收件箱条目时仍先写入一段硬编码中文，再在后续语句覆盖。虽然当前最终持久化内容通常已被覆盖，但该实现存在短暂错误状态，也使多语言契约不清晰。

## 目标与非目标

目标是让遗漏打卡提醒从构造开始就使用统一翻译层，并移除重复覆盖逻辑。

本次不改变事件类型、收件箱字段、打卡补记流程或既有中英文文案。

## 影响范围

- `time-helper/desk/src/audio/EventSystem.ts`：事件条目构造。
- `tests/test_frontend_i18n_coverage.py`：多语言契约。

## 实现

`addMissedCheckinReminder()` 直接使用 `settings.events.runtime.missedCheckinMessage`，传入 `date` 与 `planName`，并删除创建后重复覆盖 `title`/`message` 的语句。这样中英文环境在同一条构造路径上保持一致。

## 兼容性

保留既有 translation key、插值变量、事件 ID、`checkinPlanName` 和 `checkinDate` 字段；旧收件箱数据仍可正常读取。
