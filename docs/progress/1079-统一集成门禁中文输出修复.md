# 1079 统一集成门禁中文输出修复

## 背景

`python scripts/run_integration.py test` 的跨模块测试本身可以通过，但 Windows PowerShell 的非 UTF-8 控制台会把 `to-dos`、`plan-helper` 注册结果等中文输出显示为乱码，影响故障定位和验收记录的可读性。

## 本次调整

- 在统一集成入口启动时为 stdout/stderr 配置 UTF-8 和替换错误策略。
- 对 pytest 捕获流、嵌入式宿主等拒绝重新配置编码的对象安全回退，不阻断集成测试。
- 不改变 55 项集成测试、模块注册、数据交换或退出码行为。
- 增加编码配置契约测试，和启动器诊断保持一致的输出边界。

## 验证

- Windows 本地集成门禁输出不再出现中文乱码。
- 通过全量 pytest、统一集成测试和桌面生产构建后提交。
