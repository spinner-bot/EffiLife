# 事件规则键盘编辑

日期：2026-09-30

## 背景

事件管理页的提醒规则列表将规则主体做成了点击编辑区域，但此前仅响应鼠标点击，键盘用户无法通过 Tab 聚焦并打开编辑器。

## 实现

- 规则主体增加 `role="button"` 与 `tabindex="0"`。
- Enter/空格键调用与鼠标相同的编辑入口。
- 增加 `:focus-visible` 焦点轮廓，继续使用主题主色变量。
- 不改变规则数据、保存流程或提醒调度逻辑。
