# 首页桌面双栏工作台

## 背景

HOTL 要求统一首页承担三个模块的控制台职责，并充分利用桌面端横向空间。此前首页虽然在宽屏下放宽到 1180px，但主体仍按单列纵向排列，桌面端与移动端的布局差异不足。

## 本次调整

- 桌面端（宽度 `>= 900px`）改为双栏工作台布局。
- 左栏承载当前时间、日期和打卡提示，并在滚动时保持可见。
- 右栏按工作流顺序承载三模块摘要、PH/TH 概览、TD 快速处理和打卡入口。
- 平板与移动端不使用该双栏规则，继续沿用各自的响应式布局。
- 不修改模块数据结构、路由、存储协议或实体边界。

## 验证

- `python -m pytest -q`：预期覆盖桌面布局契约与全量回归。
- `time-helper/desk` 执行 `npm run build`：验证 Vue/CSS 生产编译。
