# 1134 首页摘要请求竞态保护

日期：2026-10-05  
类型：实现报告

## 背景与目标

首页同时受到定时刷新、跨窗口工作区事件、待办快速操作和手动重试影响。旧请求返回较晚时，可能把较新的待办或 PH 计划摘要覆盖成旧快照。目标是在不改变 TH、PH、TD 数据结构和模块边界的前提下，保证首页摘要遵循“新请求优先”。

## 实现与兼容性

- 为 TD 摘要和 PH 计划摘要分别增加单调请求序号；
- 异步读取完成后仅允许当前请求写入响应式状态，过期请求的成功或失败结果均丢弃；
- 保留既有加载、错误、重试和模块独立降级行为；
- 不改变待办、计划、时间记录数据格式，也不改变首页三模块入口。
