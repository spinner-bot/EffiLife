# 1192 主题跨窗口同步浏览器验收

日期：2026-10-10  
类型：运行时验收报告

## 背景

统一应用的主题设置不仅需要在刷新后保持，还需要在多个已打开页面之间及时同步。本轮补充真实浏览器双页面验收，覆盖设置页写入主题、首页运行时接收变更的路径。

## 验收过程

使用真实 Vite 开发服务器 `http://127.0.0.1:1432` 和 Playwright Chromium，同时打开首页与设置页：

1. 两个页面均跳过引导遮罩并完成初始化。
2. 记录首页初始 CSS 变量 `--color-bg`，结果为 `#1a2f1a`。
3. 在设置页进入主题设置，选择“深色”主题并确认退出。
4. 等待首页接收跨窗口设置更新，读取其运行时 CSS 变量。

结果：首页在约 5 秒内从 `#1a2f1a` 更新为 `#0f172a`；设置页最终值同样为 `#0f172a`。跨窗口主题同步通过。

## 验证结论

- 主题设置写入后的 BroadcastChannel / 页面同步链路有效。
- 已打开页面无需手动刷新即可应用新主题。
- 验收使用的 Vite 服务已停止，未遗留监听端口。

## 未验证边界

正式 Tauri 多窗口、Android/iOS 真机以及安装包环境仍需在对应运行环境中验收。
