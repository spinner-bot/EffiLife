# 签名工具自动发现校正

日期：2026-10-12
类型：T（环境诊断校正）

## 背景

此前只使用 PATH 检查签名工具，诊断结果显示 `signtool`、`apksigner` 和 `zipalign` 缺失。进一步检查发现本机 Windows SDK 和 Android SDK 中实际存在这些工具，只是 Windows SDK 的 `signtool.exe` 未注册到 PATH；Android 仍缺少 debug keystore。

## 实现

- 启动器在 PATH 之外自动搜索常见 Windows SDK `signtool.exe` 位置；
- 保留 Android SDK build-tools 版本目录的自动搜索；
- 增加 Windows SDK 工具发现和 unsigned 边界测试；
- 不创建密钥、不读取正式证书、不改变系统 PATH。

## 验证

本机只读检查发现：

```text
C:\Program Files (x86)\Windows Kits\10\bin\10.0.26100.0\x64\signtool.exe
F:\dev-tools\android-sdk\build-tools\35.0.0\apksigner.bat
F:\dev-tools\android-sdk\build-tools\35.0.0\zipalign.exe
C:\Users\han\.android\debug.keystore: missing
```

签名工具自动发现测试覆盖 PATH、SDK 路径和工具缺失三种情况；正式分发仍需受控证书/密钥和签名验收。
