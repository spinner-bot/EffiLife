# 0859 首页收件箱键盘交互优化

## 背景

统一首页的收件箱是三模块工作台的跨模块通知入口。此前它虽然支持鼠标打开、关闭和标记已读，但缺少完整的对话框语义；键盘用户打开后也没有稳定的焦点落点，按 Esc 不会返回收件箱触发按钮。

## 本次调整

- 为收件箱触发按钮补充 `aria-haspopup`、`aria-expanded` 和 `aria-controls`。
- 为面板补充 dialog 语义、标题关联和键盘事件边界。
- 打开面板后将焦点移到关闭按钮；按 Esc 关闭并将焦点还给触发按钮。
- 为通知条目补充可读的 aria label，不改变通知数据和三模块职责。

## 验证

- `python -m pytest -q tests/test_home_workflow_summary.py`：8 passed
- `python -m pytest -q`：将在提交前执行全量回归
- `npm run build`（`time-helper/desk`）：通过，1874 个模块转换
- `git diff --check`：通过

## 设计边界

本次仅改善统一壳中的通知入口交互，不把 PH、TD、TH 的数据实体合并，也不重新引入独立日历入口。
