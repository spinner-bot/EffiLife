# 启动器运行时状态可见性

## 背景

启动器诊断中的 `available` 表示模块具备启动条件，并不表示服务当前正在运行。此前兼容 Web 入口在未启动时仍显示 `available: true`，容易造成“可用”和“已运行”的混淆。

## 本次调整

- 为模块诊断增加 `runtime_state`：`ready`、`stopped`、`launchable`、`port-conflict`、`unavailable`。
- 为 companion 服务增加对应的运行时状态。
- doctor 人类可读输出优先展示运行时状态。
- 保留原有 `available`、端口占用和健康检查字段，兼容已有诊断消费者。
- 诊断仍为只读操作，不会自动启动、停止或修改任何模块。

## 验证

- 启动器诊断相关测试和全量 Python 回归。
- 当前本机诊断可明确区分统一工作台/Plan Helper 已运行、TD Web 已停止，以及原生工具链缺失。
