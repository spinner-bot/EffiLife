# 1070｜首页模块降级状态摘要提示

## 发现的问题

首页 TH、PH、TD 摘要在模块不可用时只显示 `—`，但小标题仍显示正常模块名称。用户必须进入卡片详情才能知道是读取失败、服务不可用还是移动端没有 PH 快照。

## 实施内容

- TH 摘要在失败时显示时间模块不可用提示。
- PH 摘要区分桌面服务不可用与移动端快照不可用。
- TD 摘要在存储不可用时显示待办不可用提示。
- 保留原有详细错误区域和重试按钮。
- 增加首页降级文案契约测试。

## 验证结果

- 针对性契约测试通过。
- 桌面生产构建与完整 Python 测试作为回归验证。

## 边界说明

本次只改善首页状态可见性，不改变三模块数据读取、重试和导航逻辑。
