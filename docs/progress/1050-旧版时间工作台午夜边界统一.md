# 1050 旧版时间工作台午夜边界统一

日期：2026-10-02

## 问题

TH 的新记录页面已经禁止单条记录跨越午夜，并支持用 `24:00` 表示当天结束；旧版 `/time` 工作台的时长模式仍可能在 23:00 之后回到 00:00，造成负时长，也无法编辑已有的 `24:00` 记录。两个入口的时间行为因此不一致。

## 实现

- 统一旧版工作台的结束时间校验：允许 `24:00`，但拒绝 `24:01` 等非法值。
- 时长模式计算结束时间时保留当天午夜边界，不再使用会将 `24:00` 折返为 `00:00` 的取模结果。
- 时长模式明确拒绝跨午夜输入，并提示用户拆分为两条记录。
- 增加旧版工作台的边界回归测试，覆盖起始时间模式与结束时间模式。

## 验证

- 时间边界及相关专项测试：`7 passed`。
- Python 全量测试：`804 passed in 7.66s`。
- 桌面前端生产构建：`vue-tsc` 通过，Vite 完成 `1877 modules transformed`，构建成功。

## 影响范围

仅统一旧版 `/time` 工作台与新记录页面的午夜边界表现，不改变 TH、TD、PH 的数据结构，也不改变跨午夜记录需要拆分的产品规则。
