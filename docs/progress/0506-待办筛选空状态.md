# 1012 待办筛选空状态

## 变更

待办中心现在区分三类空状态：完成列表为空、全部列表为空，以及当前搜索/分类筛选没有匹配项。筛选无结果时提供“清除筛选”入口，避免把筛选结果误解为数据丢失或今日没有待办。

## 设计边界

- 不改变待办数据、排序算法或筛选条件的语义。
- 仅在搜索词或分类筛选存在时显示清除按钮；状态页签保持不变。
- 中文和英文文案同步加入 i18n 资源。
