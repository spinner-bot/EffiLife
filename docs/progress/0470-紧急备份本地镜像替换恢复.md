# 0896 紧急备份本地镜像替换恢复

## 背景

紧急备份同时保存 IndexedDB 数据和 `efflife_*` 本地存储镜像。恢复时原逻辑只覆盖备份中出现的键，没有移除当前已不存在的旧键，可能让旧配置或旧模块镜像继续参与迁移/降级读取。

## 调整

- 恢复紧急备份前清理当前 `efflife_*` 运行时键。
- 保留 `efflife_emergency_backup_*` 键，避免恢复过程破坏紧急恢复源。
- 再按备份快照写回本地存储，使运行时镜像遵循替换语义。
