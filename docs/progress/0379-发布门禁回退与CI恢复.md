# 0805 发布门禁回退与 CI 恢复

## 日期

2026-10-01

## 背景

0804 尝试加强 Android SDK 根目录诊断：要求 `ANDROID_HOME` 或 `ANDROID_SDK_ROOT` 指向真实目录。该改动在当前 Windows/Python 3.13 环境下通过专项和全量测试，但推送到 GitHub Ubuntu runner 后，常规 CI 在“Run full Python test suite”步骤失败，未能获得未认证日志正文来确认具体测试项。

## 处理决策

- 先以发布稳定性为优先，回退该非核心诊断改动，不让无法解释的失败持续触发通知。
- 不修改用户保护文件，不使用强制重置覆盖工作区。
- 后续在可复现的 Linux runner 条件下重新设计该门禁，并为 runner 环境增加直接证据。

## 实际验证

- 提交 `8d401ad`：本地专项测试 `8 passed`、全量 `674 passed`，但 GitHub `EffiLife CI` 失败。
- 提交 `25b5a63`：回退 `8d401ad`；本地全量 `673 passed`，集成测试 `55/55 passed`。
- GitHub `EffiLife CI`（提交 `25b5a63`）：`success`。
- 当前工作树仅保留用户明确保护的 `time-helper/desk/package-lock.json` 与 `docs/HOTL/`。

## 未验证项

Android SDK 目录存在性门禁尚未进入正式实现；当前仍未具备 Android SDK、Cargo/Rust、Xcode 和真实设备验收环境。该项不能被静态测试或本机缺失环境替代。
