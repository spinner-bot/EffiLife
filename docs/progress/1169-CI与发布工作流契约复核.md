# CI 与发布工作流契约复核

日期：2026-10-09

## 背景

项目此前出现过 GitHub Actions 运行失败通知。为区分真实配置问题、发布环境限制和本地测试选择错误，本次复核了 CI、桌面发布、移动端边界及手动移动构建工作流。

## 目标与非目标

目标是确认版本同步、依赖安装顺序、集成测试、启动 smoke test 和桌面/移动发布门禁之间的契约一致。

本次不伪造 GitHub runner、Rust、Android SDK、Xcode 或真实安装包结果，也不把本地通过等同于平台安装验收。

## 影响范围

本次仅检查：

- `.github/workflows/ci.yml`
- `.github/workflows/tauri-desktop-release.yml`
- `.github/workflows/tauri-mobile-boundary.yml`
- `.github/workflows/tauri-mobile-build.yml`
- 相关 workflow/release 契约测试

## 复核结论

- 主 CI、移动端边界和 Android/iOS 手动构建均在 `npm ci` 前运行 `scripts/sync_desktop_version.py`。
- 主 CI 和桌面发布均执行统一跨模块集成测试与工作区启动 smoke test。
- 桌面发布等待兼容 UI 与矩阵构建完成后才发布。
- 未发现本地可安全修复的工作流顺序或契约错误。
