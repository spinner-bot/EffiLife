# 0445｜Tauri 统一数据根目录

日期：2026-09-29  
类型：T（跨运行时数据契约）  
范围：`time-helper/desk/src-tauri`

## 问题

launcher、Python DataManager 和 Plan Helper 已支持 `EFFILIFE_DATA_DIR`，但 Tauri 原生层没有读取该变量，配置文件可能写入另一份平台默认数据目录。

## 变更

- Tauri `get_data_dir()` 优先读取非空 `EFFILIFE_DATA_DIR`。
- 未设置或设置为空时保留原有平台默认路径。
- 不改变 Plan Helper 的 legacy runtime 目录结构和 sidecar 参数传递。
- 增加 Rust 源码契约测试和设计文档。

## 验证

- Tauri 数据根目录专项测试：2 passed
- 当前环境仍缺少 Rust/Cargo，未执行本机原生编译；正式编译由发布 CI 完成。
