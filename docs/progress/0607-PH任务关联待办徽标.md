# 1113 PH 任务关联待办徽标

日期：2026-10-05  
类型：实现报告

## 背景

PH 计划摘要已经显示关联 TD 总数，但在任务列表中无法判断具体哪一条任务已经加入待办中心，用户需要自行对照数量。

## 目标与非目标

目标是在 PH 任务行显示关联状态，并提供双语文案。非目标是增加 TD 编辑能力、修改 PH 编号、合并实体或改变统一存档结构。

## 实施内容

- 使用现有 `linkedTodoTaskIds` 集合为任务行显示“已关联 TD”徽标；
- 徽标同时提供 `title` 文本，支持鼠标和辅助技术获取上下文；
- 增加 `plans.linkedTodo` 的中英文目录项；
- 更新 PH/TD 关联契约测试。

## 影响范围与兼容性

只影响 PH 详情展示层，关联判断仍基于 `related_plan_id` 与 `related_plan_task_id`。旧数据无关联时不显示徽标；桌面、移动端和 `.efl` 数据集不需要迁移。
