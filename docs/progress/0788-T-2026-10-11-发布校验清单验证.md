# 发布校验清单验证

日期：2026-10-11

## 背景

发布产物本身已通过存在性和版本检查。本次进一步生成桌面安装包与 Android APK 的 SHA-256 和 release manifest，并用独立临时目录验证清单，避免本地 bundle 目录中遗留的旧品牌安装包干扰当前版本证据。

## 目标与非目标

目标是验证当前 EffiLife 1.7.0 产物可以生成并通过完整性清单校验。

非目标是签名、安装升级和设备验收。

## 影响范围

只读取现有构建产物；当前产物被复制到临时验收目录，仓库和历史构建文件未被删除或覆盖。

## 验证命令及结果

在临时目录中分别只放入当前版本产物后执行：

```text
python scripts/generate_checksums.py ... --extension .exe
python scripts/generate_release_manifest.py ... --target desktop --extension .exe
python scripts/verify_release_manifest.py ... --target desktop
  OK: EffiLife-desktop.manifest.json

python scripts/generate_checksums.py ... --extension .apk
python scripts/generate_release_manifest.py ... --target android --extension .apk
python scripts/verify_release_manifest.py ... --target android
  OK: EffiLife-android.manifest.json
```

当前版本 SHA-256：

```text
Desktop installer
ede611da402d19929c95a670947f98a072daeba0148aa474fd1fb83d98da7635

Android ARM64 unsigned APK
2031b3d81d462d0886ad21246dd659006cbb8d103da71d68dc96f1fe5b16f2d7
```

## 兼容性与迁移说明

清单采用现有 `effilife.release-manifest.v1` 格式，不改变安装包、APK、版本号或应用数据格式。旧品牌安装包仍保留在本地历史构建目录，未纳入当前版本清单。

## 提交与推送

本报告与验证结果一起提交并推送；实际提交哈希以 Git 记录为准。

## 未验证项与后续事项

- 当前 APK 仍为 unsigned，尚未进行签名和真机安装；
- 桌面安装器尚未执行真实安装、升级和卸载；
- 后续可考虑让通用清单生成器增加产品前缀过滤，进一步降低混合构建目录误收录风险。
