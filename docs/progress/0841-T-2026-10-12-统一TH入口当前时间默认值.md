# 0841｜统一 TH 入口当前时间默认值

类型：T（TH 入口一致性）  
日期：2026-10-12  
状态：[进行中]

## 1. 问题

0837 修复了 `/records` 历史记录入口的新增时间默认值，但主 TH 工作台 `/time` 使用的 `PlanView.vue` 仍固定预填 09:00–10:00，两个 TH 入口行为不一致。

## 2. 实施

- 新增 `services/recordDefaults.ts`，集中提供当前本地时间、当天剩余时长和午夜 `24:00` 截断逻辑。
- `PlanView.vue` 与 `RecordsView.vue` 共同使用该服务。
- 编辑既有记录仍保留原始时间，不使用新增记录默认值。

- `python -m pytest -q`：1063 passed in 19.29s。
- `time-helper/desk` 执行 `npm run build`：通过，1879 modules transformed。

## 4. 边界

本次只统一 TH 新增记录表单默认值，不改变记录结构、历史数据、PH 计划或 TD 待办语义。
