# 桌面安装包版本门禁

日期：2026-09-30

## 发现

桌面发布工作流原先只确认安装包存在、非空且扩展名正确。旧版本安装包可能残留在构建目录中，导致错误构件进入上传或发布阶段。

## 处理

- 扩展 `verify_release_artifacts.py`，支持从仓库 `time-helper/VERSION` 读取期望版本。
- 校验每个安装包文件名中的语义版本必须与仓库版本一致。
- 将版本不匹配转换为清晰的命令行错误，而不是 traceback。
- 桌面 release matrix 的所有平台统一启用该版本门禁。

## 验证

- release artifact、release metadata、launcher 专项测试：64 passed。
- 当前本地旧版 `1.0.11` 安装包被门禁拒绝，当前仓库版本为 `1.7.0`。
