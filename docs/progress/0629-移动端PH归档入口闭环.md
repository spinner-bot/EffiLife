# 0629-移动端 PH 归档入口闭环

## 背景

移动端 Plan Helper 已支持本地计划快照的归档与恢复，但界面仍沿用桌面服务尚未支持时的限制条件，隐藏了归档和恢复按钮，并显示“需要桌面端计划服务”的过时说明。

## 实现

- 将归档能力判定统一为可编辑数据源：移动端本地快照可用，缓存只读快照不可用。
- 移动端计划列表、归档列表和计划详情现在都能使用归档/恢复入口。
- 更新中英文说明，明确编辑、归档、恢复均直接写入本地事件计划快照。
- 保留桌面端缓存只读保护，不改变 PH 数据结构或桌面服务协议。

## 验证

- 移动端文案与入口契约测试。
- 完整 Python 测试套件。
- 桌面端 TypeScript/Vite 构建。
