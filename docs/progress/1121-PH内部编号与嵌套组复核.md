# 1121 PH 内部编号与嵌套组复核

日期：2026-10-05  
类型：架构复核报告

## 复核背景

统一工作台的 TD 关联和移动端快照都依赖 PH 的任务标识。PH 的核心语义要求软删除保留内部槽位，显示编号在展示时连续重算，且组范围允许嵌套。

## 复核结论

- Python API 的活动任务读取通过内部槽位计算显示编号，不改写历史槽位；
- 删除中间任务后，显示 ID 连续，内部 ID 和历史日志保持稳定；
- 组仍以范围保存，包含关系可以嵌套，显示范围按当前活动任务计算；
- 移动端快照使用等价的活动任务过滤和内部/显示 ID解析；
- TD 关联使用 `related_plan_task_id` 保存内部 ID，不把单个组 ID 当作任务归属；
- 本次未修改 PH 底层数据结构，避免将兼容回退语义误改为新的编号协议。
