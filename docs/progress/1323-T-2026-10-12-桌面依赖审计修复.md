# 1323-T：桌面依赖审计修复

## 元信息

- 日期：2026-10-12
- 类型：CI / 依赖治理
- 状态：已完成
- 关联：`.github/workflows/ci.yml` 的桌面构建与高危审计门禁

## 问题证据

桌面端 CI 执行 `npm audit --audit-level=high` 时报告 8 个 high 漏洞。根因不是业务运行时依赖，而是桌面端仍保留一组未使用的 Tailwind、PostCSS、Autoprefixer 和 ESLint 工具链；同时 `vue-tsc` 依赖树中的 `brace-expansion` 与 `source-map-js` 版本低于安全修复版本。

## 实施内容

1. 移除桌面端未使用的 Tailwind/PostCSS/Autoprefixer/ESLint 开发依赖。
2. 移除对应的 PostCSS、Tailwind 配置文件和 CSS 中无效的 Tailwind 指令；现有模块级 CSS 与设计令牌保持不变。
3. 在 `package.json` 中锁定 `brace-expansion@2.1.7` 与 `source-map-js@1.2.2` 的安全覆盖版本，并重新生成 `package-lock.json`。
4. 增加桌面依赖契约测试，防止无效工具链或易受影响版本再次回归。

## 验证结果

- `npm ci --ignore-scripts`：通过
- `npm audit --audit-level=high --json`：通过，high/critical 均为 0
- `npm run build`：通过，1878 个模块构建完成
- Python 全量测试将在本轮提交前再次执行

## 设计边界

- 未通过降低审计级别、忽略漏洞或删除 CI 门禁来“修复”问题。
- 未升级 Tailwind 进行无必要的主版本迁移；当前代码没有使用 Tailwind utility，移除未使用工具链风险更低。
- `to-dos/ui` 的依赖治理保持独立，桌面端变更不改变其兼容性构建边界。
