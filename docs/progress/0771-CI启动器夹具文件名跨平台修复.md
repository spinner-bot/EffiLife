# 0771 CI 启动器夹具文件名跨平台修复

## 远端复核

修复 0770 后，GitHub Actions run `36820352966` 仍在同一个 pytest 步骤失败。步骤状态确认失败发生在启动器测试，后续步骤均未执行。

## 第二个根因

测试已不再伪造 `os.name`，但自定义工具链临时目录仍固定创建 `node.exe` 和 `npm.cmd`。Linux runner 的生产逻辑按 POSIX 规则查找 `node` 和 `npm`，因此测试夹具在 Linux 上找不到文件。

## 修复

测试夹具现在使用启动器自身的 `node_tool_filename()` 创建对应平台文件名；生产代码和实际跨平台路径语义不变。

- 完整 Python 测试：651/651。
