# 0678：打卡后统计刷新异常兜底

## 背景

打卡成功后应用壳会刷新今日 TH 数据。原调用没有 Promise 异常边界，存储读取暂时失败时会产生未处理 rejection，并可能让用户误以为已完成的打卡被撤销。

## 实现

- 为打卡完成后的 `refreshTodayData()` 增加可恢复错误处理。
- 刷新失败只记录诊断 warning，不回滚已经成功的打卡动作。
- 增加回归测试锁定该应用壳边界。

## 兼容性

- 不改变打卡数据、TH 统计计算或首页刷新逻辑。
- 不改变 PH、TD 独立模块边界和统一存档协议。
