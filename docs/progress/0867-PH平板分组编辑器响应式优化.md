# 0867 PH 平板分组编辑器响应式优化

## 背景

PH 任务行已经针对平板和手机做了布局适配，但分组编辑器在窄屏统一降为单列，平板可用横向空间没有得到利用；输入控件也没有统一的收缩和盒模型约束。

## 本次变更

- 761–1099px 平板区间采用双列分组编辑器。
- 分组名称和描述跨越整行，起止任务选择器并列显示。
- 760px 以下手机端切换为单列，操作按钮占满可用宽度。
- 输入框和选择框增加 `width: 100%`、`box-sizing: border-box`，避免长内容导致横向溢出。
- 不修改分组数据、嵌套关系或编号算法，仅调整呈现层布局。

## 验证

- `python -m pytest -q tests/test_ph_responsive_layout.py`
- `python -m pytest -q`
- `npm run build`（`time-helper/desk`）
