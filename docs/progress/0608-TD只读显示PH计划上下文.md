# 1114 TD 只读显示 PH 计划上下文

日期：2026-10-05  
类型：实现报告

## 背景

PH 任务行已经显示 TD 关联状态，但用户进入 TD 工作区后无法知道某条待办是否来自 PH 计划。两个入口之间缺少可见的上下文，降低了统一工作区的可理解性。

## 目标与非目标

目标是在 TD 条目中只读显示关联的 PH 计划 ID 和 PH 内部任务 ID。非目标是让 TD 编辑 PH、打开 PH 编辑器、改变任务编号，或把两个模块的数据实体合并。

## 实施内容

- TD 条目在存在 `related_plan_id` 与 `related_plan_task_id` 时显示 PH 上下文徽标；
- 使用现有双语文案 `tasks.plan` 与 `tasks.planReference`；
- 保留 TD 原有编辑、完成、删除和时间记录逻辑；
- 更新模块边界与任务编号契约测试，明确“可见关联”不等于“反向控制”。

## 影响范围与兼容性

只影响 `TaskCenterView.vue` 展示层。旧 TD 没有关联字段时不显示徽标；桌面、移动端和统一 `.efl` 存档无需迁移。TD 仍是单条待办的独立实体，PH 仍是计划任务的唯一编辑源。
