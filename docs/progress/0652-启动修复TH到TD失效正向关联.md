# 1158 启动修复 TH 到 TD 的失效正向关联

日期：2026-10-05  
类型：统一数据边界完整性修复

## 背景与问题

工作区启动时原有修复流程会清理 TD 指向不存在 TH 记录的反向关联，但不会清理 TH 记录中指向已删除 TD 的 `todo_id`。这会造成历史记录继续显示失效待办，且导入、旧版本迁移或外部调用都可能留下该状态。

## 实现

- 启动修复同时读取有效 TD ID，并清理 TH 记录中的失效 `todo_id`。
- 按记录日期写回修复后的记录桶，继续保留时间历史本身。
- 原有 TD 反向关联清理逻辑保持不变，双向引用最终收敛到同一有效集合。
- 修复失败仍不阻断应用启动，保留现有可补偿策略。

## 验证

- `python -m pytest -q`：914 passed。

## 提交与边界

代码与报告直接提交到 `main`，不创建分支。不会删除 TH 历史记录，也不会删除 TD；仅移除已无法解析的正向关联。
