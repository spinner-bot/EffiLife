# 0606 Tauri 桌面默认宽屏工作台

## 背景

统一前端已经针对桌面宽屏提供 TH、PH、TD 的横向分区布局，但 Tauri 应用壳默认窗口仍为 `800×700`，最小宽度为 `650`。用户首次启动时容易直接进入窄布局，无法体现桌面控制台的设计目标。

## 实现

- 将桌面默认窗口调整为 `1280×820`。
- 将最小桌面窗口调整为 `960×640`，保证 PH 任务操作区、TD 详情区和 TH 时间工作区有基本横向空间。
- 未改变移动端配置；移动端仍由独立的响应式布局和移动构建配置负责。

## 兼容性与边界

这是应用壳的默认尺寸，不会强制覆盖用户后续调整的窗口大小。窄桌面和小平板仍通过前端断点折叠为适合触控的布局。

## 验证

- 新增 release metadata 契约测试，确认桌面窗口具有宽屏工作台预算。
