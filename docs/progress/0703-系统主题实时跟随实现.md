# 1209｜系统主题实时跟随实现

日期：2026-10-10  
状态：已完成并推送

## 背景与目标

统一应用壳已有系统主题基础能力，但媒体查询监听此前在应用生命周期内无条件存在，只在事件回调中判断当前主题类型。本次收敛监听生命周期，使系统主题在运行中跟随操作系统明暗变化，同时让非系统主题不保留无用监听器。

## 非目标

- 不修改用户保存的主题类型和主题预设。
- 不将系统主题持久化为浅色或深色。
- 不改变 PH、TD、TH 数据、`.efl` 协议或移动端存档结构。

## 影响范围

- `time-helper/desk/src/App.vue`：新增媒体查询监听注册/清理协调器。
- `tests/test_system_theme_runtime.py`：覆盖监听条件、现代/旧 API 和生命周期清理。
- 主题 Canvas 与 CSS 变量继续复用既有 ThemeEngine，不复制主题视觉逻辑。

## 实施内容

1. 仅在 `appStore.config.theme.type === 'system'` 时注册 `prefers-color-scheme` 监听。
2. 切换到其他主题时立即移除监听，切回系统主题时重新注册。
3. 支持 `addEventListener/removeEventListener` 与旧版 `addListener/removeListener`。
4. 在应用卸载时统一清理，避免热更新或多次挂载产生重复回调。

## 兼容性与迁移

无数据迁移。浏览器不支持 `matchMedia` 时维持既有静态主题行为；所有颜色和 Canvas 效果仍由原 ThemeEngine 提供。
