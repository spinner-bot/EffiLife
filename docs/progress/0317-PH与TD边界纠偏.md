# 0741 PH 与 TD 边界纠偏

## 背景

HOTL-1 明确指出：PH 的基本单元是一整份具有主题的计划，计划内部包含章节、计划条目、分组和执行记录；TD 的基本单元是独立的瞬时待办。此前 PH 工作区将每日 TH 计划嵌入事件计划中心，并提供将 PH 条目批量/逐条转换为 TD 的操作，造成模块定位混淆。

## 本次调整

- `/plans` 现在只进入独立 PH 事件计划工作区。
- `/time` 独立承载 TH 每日时间计划；旧 `/plan`、`/management` 地址直接重定向到 `/time`。
- 移除 PH 页面内嵌 `DailyPlanView` 的 hub/time 分支和相关死 CSS。
- 移除 PH 条目到 TD 的批量创建、逐条创建、打开 TD、TD 清理和自动同步逻辑。
- PH 条目编辑、完成、删除和计划改名现在只修改 PH 自身数据；PH 使用自身的执行记录表单记录进展。
- TD 仍通过独立 `/tasks` 入口管理，不因 PH 页面打开而改变其数据。
- 保留底层历史关联字段与兼容服务，以便后续处理旧数据；本次不再从 PH 产生新的跨模块关联。

## 验证

- `python -m pytest -q`：630 passed。
- `time-helper/desk` 执行 `npm run build`：通过，Vite 转换 1874 个模块。
- 重点契约覆盖：独立路由、PH 不嵌入 TH、PH 不创建/同步 TD、PH 自有进展日志。
