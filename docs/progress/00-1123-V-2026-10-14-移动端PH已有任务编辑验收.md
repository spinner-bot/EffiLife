# 移动端 PH 已有任务编辑验收

## 验收范围

补强统一工作台浏览器 smoke 的移动端 PH 路径，覆盖真实的：

`创建带内容的计划 → 打开已有任务编辑 → 修改长标题 → 保存 → 验证持久化 → 检查横向溢出`。

这条路径补上了此前只验证“创建计划”和“修改计划元数据”的覆盖缺口。

## 结果

执行：

```text
python scripts/smoke_browser_workspace.py --url http://127.0.0.1:4173 --mobile-ph-plan-flow
```

结果：`ok: true`，`mobile_ph_plan_flow_verified: true`。

- 移动端任务编辑入口可用；
- 长标题修改后能在当前计划中持久化显示；
- 编辑后页面没有横向滚动溢出；
- 既有移动端计划元数据编辑验收继续通过；
- 本轮未发现需要修改生产界面的缺陷，改动仅收紧真实用户路径验收。

## 边界

该证据基于 Windows Chromium 移动视口和浏览器本地运行时，不替代 Android 真机触控、屏幕阅读器和正式签名安装包验收。阶段保持第 0 阶段。
