# 核心视图多语言可见文案审查

日期：2026-10-11

## 背景与目标

统一软件已建立 `zh-CN`/`en-US` catalog 和可扩展 locale 注册机制。本轮检查应用壳、首页、PH、TD、TH、设置及公共组件，确认核心用户可见文案没有绕过 i18n 的硬编码中文。

## 审查范围

- `time-helper/desk/src/App.vue`；
- `time-helper/desk/src/views/*.vue`；
- `time-helper/desk/src/components/*.vue`。

## 审查结果

- 以用户可见元素为目标扫描标题、按钮、标签、段落、选项、占位符和 aria-label。
- 未发现核心视图中直接写入的中文用户可见文案。
- 命中的中文内容均为注释、内部兼容值或实现说明，不进入渲染文本。
- 现有 `LocaleSwitcher`、`setLocale`、持久化 locale、文案 fallback 和归档 locale 导入边界保持不变。

## 验证命令

```powershell
rg -n '<(h[1-6]|button|label|p|span|option|small)[^>]*>[^<{]*[\\u4e00-\\u9fff]' time-helper/desk/src -g '*.vue'
# 无命中

python -m pytest -q
# 997 passed
```

## 未验证项与后续事项

- 当前为源码级可见文案审查；真实 GUI 中的语言切换跨重启仍需安装包手工验收。
- 新增视图或组件必须继续使用现有 i18n catalog，不得以源码扫描通过替代运行时语言验收。
