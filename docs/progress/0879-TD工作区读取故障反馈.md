# TD 工作区读取故障反馈

## 背景

TD 任务中心在 IndexedDB 读取失败时虽然记录了错误，但主列表仍会进入“没有待办”的空状态。用户无法区分真实空列表与存储服务故障。

## 本次调整

- 增加 TD 数据读取不可用状态。
- 读取失败时展示独立的状态卡，不再展示空数据文案。
- 增加中英文“重试”入口，复用原有 `loadTodos` 流程。
- 读取成功后自动清除不可用状态。
- 不改变待办字段、优先级算法、分类、子任务或 PH 关联逻辑。

## 验证

- 定向契约与多语言测试：10 passed。
- `time-helper/desk` 生产构建成功。
- 提交前执行全量 Python 回归。
