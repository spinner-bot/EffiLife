# 0895 普通备份快照恢复一致性

## 背景

普通备份恢复用于把某个模块恢复到备份时的状态。此前 `records` 与
`manual_plans` 恢复逻辑仅逐条写入备份内容，没有清理当前同类数据，导致备份中不存在的旧日期或旧计划继续残留；当备份内容为空时，更无法恢复为空集合。

## 调整

- 恢复 `records` 前清空记录存储，再写入备份中的日期记录。
- 恢复 `manual_plans` 前清空手动计划存储，再写入备份中的日期映射。
- 保留原有的工作区变更通知，使恢复后的界面继续触发刷新。

这使两类备份都遵循“完整快照替换”语义，并与统一 `.efl` 存档恢复的空集合处理保持一致。
