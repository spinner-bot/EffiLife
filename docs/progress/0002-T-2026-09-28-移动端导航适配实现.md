# 移动端导航适配实现

## 本次变更

统一工作台在 `max-width: 680px` 时采用移动端专用导航：顶部保留品牌标识和全局搜索，主入口移动到固定底部导航栏。桌面端仍使用顶部完整导航。

## 用户体验收益

- 移动端五个主入口拥有稳定、可触控的独立区域，不再依赖拥挤的顶部横向布局。
- 图标和文字同时保留，当前页面识别更清晰。
- 底部导航使用安全区变量，适配带刘海和底部手势条的设备。
- 内容区域预留底部空间，列表末项不会被导航栏遮挡。
