# 手动切换语言跨窗口同步设计

## 问题

`LocaleSwitcher` 调用 `setLocale()` 后只更新当前窗口的响应式状态和 `localStorage`。其他窗口没有收到 `settings` 工作区事件，因此多窗口使用时语言可能不一致。

## 方案

- 将语言切换视为统一工作区设置变更，在 `setLocale()` 成功应用语言后广播 `settings` 事件。
- 应用壳已有 `settings` 事件的数据刷新路径；同时调用 `refreshLocaleFromStorage()`，让其他窗口只读取共享语言设置并更新自身文案。
- 不在 `LocaleSwitcher` 中重复广播，保持语言 API 的单一写入点。

## 验收标准

1. 手动切换语言后其他窗口收到 `settings` 事件并切换文案。
2. 当前窗口仍立即更新，不产生重复持久化。
3. 存档导入语言同步和现有设置广播不回归。
