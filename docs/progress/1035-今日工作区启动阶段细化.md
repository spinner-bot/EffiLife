# 今日工作区启动阶段细化

日期：2026-10-02

## 背景与发现

独立端口启动当前源码并用 Edge 无头模式访问 `/settings` 后，启动错误仍指向 `today workspace`。原有实现把今日记录、当天计划和实时统计合并在一个 Promise 中，无法判断究竟是哪类数据读取延迟或失败。

## 目标与非目标

- 目标：把今日工作区初始化拆成可观测、各自有界的三个步骤。
- 非目标：不改变今日统计逻辑、计划数据结构或存档协议。
- 非目标：不把启动失败静默成空数据。

## 实施内容

`useAppStore.init()` 现在调用 `initializeTodayWorkspace()`，依次以独立阶段读取：

1. `today records`
2. `today plan`
3. `today statistics`

任何阶段失败都会保留统一启动错误界面，但错误信息会指出具体数据集。正常运行时的 `refreshTodayData()` 路径保持不变。
