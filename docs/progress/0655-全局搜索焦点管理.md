# 0655｜全局搜索焦点管理

## 背景

全局搜索已经具备结果键盘导航和 dialog ARIA 语义，但关闭后焦点未必返回触发按钮，Tab 也可能穿透模态层进入背景页面。

## 实现

- 打开搜索时记录当前触发元素，关闭后恢复焦点。
- 在 dialog 内拦截 Tab/Shift+Tab，在首尾可聚焦元素之间循环。
- Escape 统一通过 dialog 键盘处理器关闭搜索。
- 增加焦点管理结构回归测试。

## 兼容性

不改变搜索索引、结果排序、路由或数据协议；仅改善键盘操作和移动端辅助技术体验。
