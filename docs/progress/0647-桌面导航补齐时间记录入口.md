# 0647｜桌面导航补齐时间记录入口

## 背景

统一壳已经提供 `/records` 时间记录页和 `nav.records` 多语言文案，但主导航没有记录入口。用户只能从首页、任务详情或 TH 页面中的历史操作进入，桌面端不易发现。

## 目标

让桌面/平板用户可以从统一主导航直接进入时间记录，同时保持移动端底部导航的五项核心结构不变。

## 实现

- 在 `App.vue` 桌面导航加入 `/records` 链接及 `History` 图标。
- 记录页和 `/day/:date` 页面共享 active/`aria-current="page"` 状态。
- 移动端不增加第六个底栏项目，继续通过首页、TH 工作区和任务关联入口访问记录。
- 更新导航可访问性回归断言。

## 兼容性

不改变路由、数据协议、记录存储或移动端布局；仅增加桌面/平板导航入口。

## 验证

- 运行导航相关回归测试。
- 检查 `git diff --check`。
- 完整前端构建由 GitHub CI 验证。
