# 发布签名环境核对

日期：2026-10-11

## 背景

当前桌面安装包和 Android APK 的内容、版本、checksum 与 manifest 均已验证，但它们还不能被称为正式发布产物：Android APK 是 unsigned，桌面安装器也尚未完成代码签名验证。

## 目标与非目标

目标是只读核对本机是否具备签名所需工具和本地测试密钥。

非目标是生成或使用正式证书、修改系统信任配置，或用临时密钥冒充正式发布签名。

## 验证结果

```text
apksigner.bat: missing
zipalign.exe: missing
%USERPROFILE%/.android/debug.keystore: missing
signtool.exe: missing
```

因此当前工作站可以完成 Android 构建和 unsigned APK 完整性验证，但不能完成 APK 签名/对齐或 Windows 安装器签名验收。

## 影响范围

这是发布环境记录，不改变源代码、构建配置、应用数据或三模块边界。

## 兼容性与迁移说明

现有 unsigned APK 和未签名安装包仍可用于内部结构测试；正式分发前必须接入受控签名环境，并在签名后重新生成 checksum 和 release manifest。

## 提交与推送

本报告与环境核对结果一起提交并推送；实际提交哈希以 Git 记录为准。

## 未验证项与后续事项

- Android 正式签名、zipalign 和真机安装未完成；
- Windows 安装器代码签名未完成；
- 需要在受控发布环境提供证书、密钥和签名工具后再进行正式发布验收。
