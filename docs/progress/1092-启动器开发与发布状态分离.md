# 1092 启动器开发与发布状态分离

## 背景

启动器的 doctor 检查关注开发工作区是否可运行；同一目录也可能存在旧版本安装包。此前最终状态只显示 `READY`，容易把“当前可以测试”误解为“可以直接分发”。

## 调整

doctor 报告增加独立的 `Distribution status`：

- `ready`：存在非空且版本匹配的安装包。
- `not ready`：没有安装包，或只有版本不匹配的旧安装包。

开发工作区的启动状态仍由原有 `Result` 表示，两个状态互不替代。

## 验证

- 新增 doctor 状态分离测试。
- 既有启动器回归测试继续覆盖端口冲突、依赖安装和服务超时。
