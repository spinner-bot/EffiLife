# [完成] Pytest 根路径一致性

## 创建信息

- 创建时间：2026-10-13
- 执行者：Codex
- 触发原因：直接执行 `pytest -q` 时，`importlib` 收集模式未自动发现仓库根目录的 `common` 包，造成与 CI 入口不同的本地收集失败。

## 本次调整

在根目录 `pytest.ini` 增加 `pythonpath = .`，使以下两种常用入口共享相同的模块解析行为：

- `pytest -q`
- `python -m pytest -q`

这只修正测试运行环境，不改变应用运行时、测试内容或 Python 包逻辑。

## 验证

- `pytest -q`：1171 passed，保留 1 个既有 ZIP 重复条目 warning。
- 之前已验证 `python -m pytest -q`：1171 passed，结果一致。

## 边界与下一步

该配置解决本地/CI 测试入口差异，不代表正式签名、Android 真机和安装升级验收完成。阶段保持第 0 阶段。
