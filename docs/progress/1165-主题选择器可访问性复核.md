# 1165 主题选择器可访问性复核

日期：2026-10-09  
类型：主题架构与无障碍交互复核

## 背景与复核

在继续排查主题持久化问题时，检查了主题卡片是否能被键盘和辅助技术操作。当前主题注册表驱动的选择器已经使用原生 `<button type="button">`，并以 `aria-pressed` 表示当前主题，避免了鼠标专用的非语义容器实现。

## 结果

- 主题卡片保留原生按钮焦点和 Enter/Space 默认交互。
- 当前选中状态由 `aria-pressed` 暴露。
- 主题名称和描述作为按钮可访问名称与内容，未发现需要重复添加键盘事件的缺口。
- 新增契约测试，防止主题列表重构时退化为不可操作元素。

## 验证

- `python -m pytest -q tests/test_settings_theme_i18n.py`：17 passed。
- `python -m pytest -q`：926 passed。

## 边界

本轮未改变主题数据、主题引擎、持久化或退出确认逻辑；真实浏览器中的视觉对比度和跨平台键盘验收仍需后续人工验证。代码与报告直接提交到 `main`，不创建分支。
