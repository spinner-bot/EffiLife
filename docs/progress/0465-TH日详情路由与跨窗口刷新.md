# TH 日详情路由与跨窗口刷新

## 背景

日详情组件在路由参数变化时会被 Vue 复用，但原实现只在首次挂载时加载数据；同时，TD 待办在其他窗口删除后，日详情页的关联索引不会自动更新。

## 调整

- 监听日期路由参数变化，切换日期时重新加载统计、计划和记录。
- 监听统一工作区的 `todos`/`archive` 事件，刷新日详情的待办引用索引。
- 组件卸载时移除工作区监听，避免重复订阅。
- 保持失效关联的非破坏策略，不因临时读取失败清理历史引用。
