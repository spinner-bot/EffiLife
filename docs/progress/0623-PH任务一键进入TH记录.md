# 0623-PH 任务一键进入 TH 记录

## 背景

PH 任务与 TH 时间记录通过 TD 关联。此前 PH 详情页只有已关联 TD 的任务才显示“记录用时”，用户必须先执行一次“加入待办”，才能进入 TH 记录表单，三模块协同路径不够直接。

## 实现

- PH 任务的“记录用时”按钮对所有可编辑任务可见。
- 若任务尚未关联 TD，点击后复用既有 `addTaskToTodos` 创建带有 `related_plan_id` 与 `related_plan_task_id` 的 TD。
- 创建/发现 TD 后跳转 `/records?todo=<id>`，由 TH 记录页预选该 TD；已有 TD 则直接跳转。
- 不改变 PH、TD、TH 的存储模型，也不把三者的数据结构合并。

## 兼容性与失败处理

- 只在可编辑计划上启用；缓存只读计划不会创建数据。
- TD 创建失败时保留既有错误提示，不进入记录页。
- 仍保留独立的“加入待办”和 TD 入口，用户可继续分别管理模块。
