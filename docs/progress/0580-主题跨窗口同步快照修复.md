# 主题跨窗口同步快照修复

## 背景

设置页监听到其他窗口的主题保存或归档导入事件时，事件本身先于异步工作区重载完成。若立即从 `appStore.config` 生成 `savedThemeSnapshot`，得到的可能是旧主题，导致设置页错误显示“有未保存修改”。

## 实现

- `SettingsView.vue` 收到 `settings` 或 `archive` 工作区事件后，先调用 `appStore.refreshWorkspaceData()`。
- 工作区重载完成后再生成主题快照。
- 重载失败时保留当前状态并输出可诊断警告，不阻断应用使用。

## 验收

- 新增主题同步契约测试，确认快照更新等待工作区 hydration。
- 运行全量 Python 测试与桌面端生产构建。
