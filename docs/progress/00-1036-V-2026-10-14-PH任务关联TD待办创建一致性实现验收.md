# 00-1036-V-2026-10-14-PH 任务关联 TD 待办创建一致性实现验收

## 结论

PH 任务进入统一专注时，首页和计划详情页已复用 TD 服务层的统一获取/创建操作，单个运行时内同一 PH 任务不会因两个入口并发而重复创建关联待办。

## 实现

- `TodoService` 新增 `getOrCreatePlanTaskTodo(planId, taskId, input)`。
- 以 `planId:taskId` 为稳定键，串行化完整读取—判断—创建过程。
- 已存在关联待办直接复用；新建时只初始化必要的标题、描述和时长字段。
- 首页 PH 推荐任务和 PH 计划详情专注入口均改用该服务。

## 验证

- PH/TD/首页领域专项测试：23 passed。
- `python -m pytest -q`：`1183 passed, 1 warning`。
- `npm run build`：通过。

## 边界

该操作只维护 PH→TD 的显式关联，不同步完成状态，不改变 PH 计划结构、TD 单条待办语义、TH 记录或 `.efl` 数据格式。阶段继续固定为第 0 阶段。
