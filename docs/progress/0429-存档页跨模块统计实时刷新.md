# 0855 存档页跨模块统计实时刷新

日期：2026-10-02

## 背景与目标

0854 已将统计刷新绑定到进入存档页，但存档页保持打开时，其他窗口或 PH、TD、TH 页面发生数据变更，统计仍可能暂时停留在旧值。

## 实施内容

- 统一工作区事件到达时，如果当前正在查看存档页，立即触发统计刷新。
- 保留设置/存档事件原有的主题与工作区重载逻辑，其他来源只更新存档统计，不干扰主题草稿。
- 使用既有请求序号保护，避免并发刷新出现旧结果覆盖新结果。

## 验证

- 存档状态契约测试覆盖进入页面刷新与跨模块事件刷新。
- 前端生产构建须在 time-helper/desk 目录执行。

本次不改变统一存档协议、数据结构或导入覆盖语义。
