# 发布版本锁文件门禁

## 1. 问题

桌面发布前已有版本同步脚本，但发布预检只比较 `VERSION`、`package.json`、Tauri 和 Cargo 元数据，没有验证 npm lock 文件的根版本。版本升级后若只更新部分文件，容易把漂移带入发布环境。

## 2. 调整

`scripts/check_release_config.py` 现在同时校验：

- `time-helper/VERSION`；
- `time-helper/desk/package.json`；
- `time-helper/desk/package-lock.json` 顶层版本；
- lock 文件 `packages[""]` 根包版本；
- Tauri 与 Cargo 版本。

版本锁文件不一致时，发布预检直接失败并报告具体范围。已有同步脚本仍负责在 CI 中先完成合法的版本同步。

## 3. 验证

```text
python -m pytest -q tests/test_release_metadata.py tests/test_release_checksums.py tests/test_workflow_version_sync.py
通过

python scripts/check_release_config.py
EffiLife desktop release configuration is ready
```
