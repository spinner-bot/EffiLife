# 1104-启动器严格发布预检

## 背景

启动器原有 `--release-check` 会同时输出配置校验和本机工具链状态，但退出码只反映配置错误。配置正确而本机缺少 Cargo、Android SDK 或 Xcode 时，命令仍然成功，容易被自动化脚本误用为“可以构建正式安装包”。

## 调整

- 新增 `python launcher/start.py --release-check-strict`。
- 保留 `--release-check` 的兼容语义：用于检查发布配置，不要求当前机器具备所有原生工具链。
- 严格模式继续输出完整 JSON，并在 `build_ready` 为 false 时返回退出码 `1`。
- 帮助文本与启动器测试同步更新。

## 验证

- `python -m pytest -q tests/test_launcher.py`
- 当前开发机的 `--release-check` 可用于配置检查；`--release-check-strict` 应因缺少本机原生工具链而阻断，避免误发布。
