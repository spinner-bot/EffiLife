# 0592｜PH 平板任务行响应式修复

## 背景

HOTL-1 要求桌面端采用横向分层布局，并指出页面存在按钮、文字挤压和遮挡风险。PH 任务行原先只在 `760px` 以下把“记录、关联待办、记录待办时间”等操作移到第二行；在平板和窄桌面（`761–900px`）中，多个操作仍可能与任务名称争夺同一行空间。

## 实施

- 将 PH 任务行的操作折叠断点前移到 `900px`。
- 保留任务编号、任务内容和耗时在首行。
- 将操作按钮放到内容列的下一行，编辑/删除按钮继续固定在首行，避免改变桌面端宽屏布局。
- 增加源码回归测试，防止后续样式整理时删除该过渡断点。

## 验证

- `python -m pytest -q tests/test_ph_responsive_layout.py`
- 后续执行全量 Python 测试与桌面端构建。
