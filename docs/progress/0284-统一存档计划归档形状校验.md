# 0686：统一存档计划归档形状校验

## 背景

## 实现

- 在 `common.data_exchange` 中补充 `plan_helper.archives` 的数组形状校验。
- 增加损坏归档形状回归测试。
- 不改变 PH 的内部数据结构，也不把 PH 与 TD 合并；只收紧统一交换容器的边界。
