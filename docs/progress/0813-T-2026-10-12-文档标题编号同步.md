# 文档标题编号同步

状态：[完成]

日期：2026-10-12

作者/执行者：Codex

## 触发原因

上一轮已统一三个文档目录的文件名序列，但部分历史文档正文首行仍保留重排前的旧编号，造成“文件名与标题编号不一致”。

## 实际完成

- 将三个文档体系中以四位编号开头的首级标题同步为当前文件名编号。
- 不修改日期、正文叙述、历史结论或文档内容语义。
- 扩展 `scripts/normalize_doc_numbering.py`，使后续迁移或检查可以重复执行标题同步。

## 验证

- 标题一致性检查结果：`heading_mismatches=0`。
- `git diff --check -- scripts docs` 通过；仅有 Windows 换行转换提示，无空白错误。
- 用户未提交的 `plan-helper/test.py`、`time-helper/desk/src-tauri/Cargo.toml` 和 `plan-helper/ph导出txt示例.txt` 未纳入本次变更。

## 边界

标题中作为历史叙述出现的普通数字不做全局替换，避免把历史事实误改为当前文件编号。后续新增文档必须让文件名编号和首级标题编号保持一致。
