# 1130 计划中心局部降级

日期：2026-10-05  
类型：实现报告

## 背景与目标

计划中心同时读取活动计划和归档计划。原实现使用 `Promise.all`，归档读取失败会连带清空活动计划，造成严重的可见性误判。目标是让核心活动计划优先可用，归档区域单独降级。

## 实现与兼容性

- `PlansHubView.loadPlans` 改用 `Promise.allSettled`；
- 活动计划读取成功时始终保留并显示活动计划；
- 归档读取失败时仅清空归档列表，由已有归档不可用状态展示局部错误；
- 只有活动计划读取失败才显示计划中心主错误；
- 不改变 PH 数据结构、归档文件、路由或主题逻辑。
