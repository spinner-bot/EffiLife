# 1041 TD 移动端分类管理布局修复

日期：2026-10-02

## 问题

TD 分类管理中的分类名称、难度、置顶、编辑和删除控件原先全部保持单行布局。窄屏下分类名称较长或操作按钮较多时，控件会互相挤压并可能超出内容区域。

## 实现

- 在 `max-width: 700px` 断点让分类行允许换行。
- 分类名称改为可伸缩列，避免固定最小宽度挤占操作区。
- 分类难度信息单独换到下一行，保留按钮区域的可点击空间。
- 桌面端布局保持不变。

## 验证

- 桌面/移动布局专项测试：`23 passed`。
- Python 全量测试：`794 passed in 7.50s`。
- 桌面前端生产构建：`vue-tsc` 通过，Vite 完成 `1877 modules transformed`，构建成功。

## 影响范围

仅调整 TD 分类管理的窄屏布局，不改变待办数据结构、优先级算法、分类逻辑或 PH 模块边界。
