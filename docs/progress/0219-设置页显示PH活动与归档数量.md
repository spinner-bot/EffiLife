# 0620｜设置页显示 PH 活动与归档数量

## 背景

统一存档已经区分活动计划与已归档计划，但设置页“当前数据”只显示活动计划数量，用户无法从日常状态确认归档数据是否存在。

## 实现

- `getDataStats()` 增加归档事件计划数量。
- 设置页将活动/归档数量并列显示，并保留数据来源状态。
- 中英文文案同步更新。
