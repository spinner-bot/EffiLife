# 1049 TH 空记录状态直接创建入口

日期：2026-10-02

## 问题

TH 当天没有时间记录时，空状态只有说明文字。用户需要回到页面顶部寻找“新增记录”按钮，移动端尤其不易发现，空状态没有形成完整的下一步引导。

## 实现

- 在空记录状态增加直接创建记录按钮。
- 复用现有 `openAddForm`，保持表单默认值、TD 关联和焦点管理逻辑一致。
- 不改变记录存储、时间冲突校验或跨模块关联行为。

## 验证

- 记录表单与联动专项测试：`9 passed`。
- Python 全量测试：`802 passed in 7.61s`。
- 桌面前端生产构建：`vue-tsc` 通过，Vite 完成 `1877 modules transformed`，构建成功。

## 影响范围

仅改善 TH 空状态的可发现性和创建路径，不改变 TH、TD、PH 数据结构或统一应用壳导航。
