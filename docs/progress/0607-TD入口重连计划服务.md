# 0607 TD 入口重连计划服务

## 背景

统一工作台允许 TD 待办独立运行，但待办编辑中的 PH 计划/任务关联需要计划服务。当 PH 服务暂时不可用或仅能读取本地快照时，TD 原先只显示不可用提示，用户必须离开 TD 入口才能尝试恢复。

## 实现

- 在 TD 计划关联状态提示旁增加“重新连接计划服务”操作。
- 重连只重新读取 PH 的计划摘要和任务，不改变 TD 自身的数据、排序、优先级或存储边界。
- 若当前正在编辑某个计划任务，重连成功后同步刷新该任务候选列表。
- 中英文文案纳入现有 i18n catalog，并沿用主题变量和窄屏自动换行布局。

## 模块边界

TD 仍是独立的单条待办管理模块；该按钮只是跨模块读取/恢复关联能力，不把 PH Plan 转换成 TD 实体，也不改变既有双向关联字段。

## 验证

- 扩展计划服务降级契约测试，覆盖重连函数、按钮和双语文案。
- 待运行定向测试、全量测试和桌面生产构建后提交。
