# 打包模式启动边界设计

## 背景

EffiLife 的统一工作台已经是主入口，兼容版 to-dos Web 仅用于迁移和调试。启动器的 `--packaged` 模式代表正式安装环境，不应因机器上存在 Node.js 就重新启动源码开发服务器。

## 方案

- `--packaged` 下，兼容版 to-dos Web 只允许使用 `to-dos/ui/dist/index.html` 的静态资源。
- 如果静态资源不存在，兼容入口标记为不可用，并不调用 npm，也不执行依赖安装。
- 开发模式保持现有行为，继续允许 npm dev server 方便测试。
- 统一工作台的 Tauri 原生二进制和预构建 dist 规则保持不变。

## 验收

- 打包模式下即使 npm 可用，也不会返回 npm 命令。
- 打包模式下存在有效 dist 时返回静态服务器命令。
- 开发模式仍返回 npm dev 命令。
- 启动器测试和全量测试通过。
