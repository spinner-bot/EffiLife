# 0755 桌面宽屏布局验收契约

## 验收重点

HOTL-1 要求桌面端和平板端充分利用横向空间，不能把桌面工作区收缩成移动端卡片式窄布局，同时移动端仍需保持可用且不发生按钮重叠。

## 现状确认

- 首页在 900px 以上进入宽屏控制台布局，内容最大宽度为 1180px，并将统计与事件区域横向组织。
- PH 工作区采用 1080px 内容预算，在 1100px 以上将计划详情拆分为摘要侧栏与内容主栏。
- TD 与时间记录工作区在 1100px 以上扩展到 1180px，并保留移动端堆叠断点。
- 平板导航保持横向排列，窄屏才切换移动导航和单列编辑布局。
- PH 任务行的移动端操作按钮具有明确网格位置，不依赖隐式网格列。

## 验证

- 新增/保留桌面布局契约测试：13 passed。
- 全量 Python 测试：638 passed。
- 本次只增强测试覆盖与记录，没有改动用户已有 lockfile 或 HOTL 文件。

## 结论

当前源代码的桌面/平板布局已经具备明确的宽屏工作区设计；下一步应在具备 Node 工具链的环境执行真实浏览器构建与多分辨率视觉验收，作为静态契约之外的补充证据。
