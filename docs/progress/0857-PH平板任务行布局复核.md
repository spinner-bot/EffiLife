# 0857 PH 平板任务行布局复核

日期：2026-10-02

## 复核范围

复核 PH 计划详情页在桌面、平板和移动端的任务行、编辑操作区和嵌套组操作区，重点关注 HOTL1 所指出的按钮挤压、文字溢出和操作区遮挡。

## 当前实现结论

- 1100px 及以上使用计划详情双栏布局。
- 761–1099px 使用紧凑横向任务网格，任务内容列保留 minmax(120px, 1fr)，操作按钮使用紧凑尺寸。
- 760px 以下将任务内容、时长和操作区拆为多行，编辑/删除按钮固定在操作列。
- 平板编辑器和分组编辑器在 1099px 以下切换为纵向排列，避免表单字段互相挤压。
- 任务文本和分组描述保留省略策略，长文本不会覆盖操作按钮。

## 决策

本次未修改 CSS。当前断点策略与 HOTL1 的桌面/移动差异要求一致，继续增加断点会扩大视觉回归范围；后续真实浏览器宽度验收时若发现具体机型问题，再以截图和复现宽度进行针对性调整。
