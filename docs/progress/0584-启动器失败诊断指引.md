# 1090 启动器失败诊断指引

## 背景

统一启动器已经能够区分健康服务复用、端口冲突、依赖安装失败和服务超时，但此前失败输出主要停留在“启动失败”或“端口占用”，用户还需要自行猜测下一步如何定位。

## 本次调整

统一启动失败提示，覆盖主工作区与 Plan Helper 伴随服务：

- `--doctor`：面向用户的可读就绪检查。
- `--diagnose`：机器可读 JSON 诊断，包含端口、依赖、服务状态和安装包状态。
- 启动日志路径：指向按用户保存的 JSONL 日志。

该提示只在已确认启动失败或端口冲突时出现，不改变服务探测、复用、终止和端口配置逻辑。

## 验证

- 新增启动器失败提示测试与端口冲突路径测试。
- 运行全量 pytest 和桌面端构建。
