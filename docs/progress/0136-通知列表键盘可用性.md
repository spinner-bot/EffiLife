# 通知列表键盘可用性

日期：2026-09-30

## 背景

首页通知下拉面板和事件管理页的通知条目原先使用可点击 `div`。鼠标操作正常，但条目无法通过 Tab 聚焦，也无法使用 Enter/空格标记已读，不符合 UX 规范中“桌面端完整键盘导航”的要求。

## 实现

- 两处通知条目增加 `role="button"`、`tabindex="0"` 和 Enter/空格键处理。
- 增加可见 `:focus-visible` 焦点轮廓，保持原有主题变量和视觉层级。
- 不改变通知存储、已读状态或签到按钮逻辑；条目内的签到按钮仍通过 `stop` 阻止重复触发。
