# 0651｜今日计划切换事件同步

## 背景

`PlanView` 通过 `appStore.changeTodayPlan()` 切换今日 TH 计划。该 store 方法此前只刷新当前窗口状态，没有广播工作区变更；其它窗口的首页和时间工作区可能继续显示旧计划。

## 实现

在 `changeTodayPlan()` 完成持久化和本地刷新后广播 `plans` 工作区事件，与日详情页和计划服务的其它写入路径保持一致。

## 兼容性

不改变今日计划的数据格式或 TH/PH/TD 边界，只补充跨窗口同步通知。
