# 0679：设置页统计初始化异常兜底

## 背景

设置页加载时会读取统一工作区的数据统计。原调用没有异常边界，IndexedDB 暂时不可用时会让 `onMounted` 提前结束，加载骨架可能一直保留，设置与存档入口因此无法正常使用。

## 实现

- 为 `getDataStats()` 增加 `try/catch`。
- 统计读取失败时记录 warning，保留默认统计值并继续关闭加载状态。
- 增加初始化回归测试，确保辅助统计失败不会阻塞整个设置页。

## 兼容性

- 不改变统一数据集、统计字段或归档协议。
- PH、TD、TH 的独立数据职责和主题架构不变。
