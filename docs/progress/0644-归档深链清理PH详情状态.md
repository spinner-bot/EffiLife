# 0644 归档深链清理 PH 详情状态

## 背景

归档 PH 搜索结果可能从活动 PH 详情、时间计划视图或计划中心内部打开。原逻辑只在归档查询存在时提前返回，没有清理已有的活动计划选择，导致归档预览可能被旧详情状态遮挡。

## 实现

- 处理 `archive` 深链时清空 `selectedPlan` 和编辑状态。
- 将视图切换到 PH 事件计划列表，确保归档只读预览可见。
- 清除旧活动任务的搜索高亮，避免跨计划残留视觉状态。
- 保持恢复操作显式触发，不因路由进入而修改数据。
