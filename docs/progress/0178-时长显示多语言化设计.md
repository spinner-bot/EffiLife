# 时长显示多语言化设计

## 背景

多语言基础已覆盖页面文案，但 `hoursToHm` 仍固定返回中文单位。英文用户在首页、时间工作台、记录页和日详情页会看到中文时长，破坏语言切换的一致性。

## 方案

- 为 `hoursToHm` 增加可选 locale 参数，保持未传参数的旧调用兼容中文输出。
- 中文保持“小时/分钟”表达；英文使用 `h` / `m` 的紧凑表达，适合统计卡片和列表空间。
- 统一入口视图从 `useI18n().locale` 传入当前语言，避免服务层直接依赖 Vue i18n。

## 验收

- zh-CN 与 en-US 时长格式均可通过纯函数验证。
- 首页、时间工作台、记录、日详情均传递当前 locale。
- i18n/前端构建及全量测试通过。
