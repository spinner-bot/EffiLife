# 1233｜TD 优先级能力核查

## 核查结论

TD 已经具备独立的优先级管理闭环，不需要再复制 PH 的计划状态筛选：

- 创建和编辑待办时可设置“紧急”“重要”和优先级排位值。
- `TaskCenterView.vue` 使用统一优先级计算服务进行排序，并随截止时间变化刷新排序时钟。
- 活跃、全部、已完成三种待办范围可切换。
- 分类导航按当前待办优先排位分排序，并支持按分类筛选。
- TD 的优先级字段和筛选状态不读取或写入 PH 计划数据。

## 与 HOTL-1 的关系

这满足 HOTL-1.2 中“TD 负责即时事项并进行优先级管理”的定位。PH 状态筛选只作用于整份计划；两者分别在各自入口处理不同维度，保持模块边界清晰。

## 证据

- `time-helper/desk/src/views/TaskCenterView.vue`：优先级字段、排序、分类筛选和待办范围切换。
- `time-helper/desk/src/services/priority.ts`：统一优先级计算。
- `tests/test_todo_priority*.py`、`tests/test_priority*.py`：优先级和排序回归覆盖。
