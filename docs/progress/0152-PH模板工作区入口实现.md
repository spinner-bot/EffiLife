# PH 模板工作区入口实现

日期：2026-09-30

## 实现结果

- 计划中心新增“从模板开始”入口，模板选择从基础创建弹窗迁移到独立工作区面板。
- 基础创建弹窗仍只包含名称和日期，继续创建空 Plan 并进入详情编辑器。
- 模板工作区提供模板选择、名称、日期、加载中和空模板状态；提交中有禁用反馈。
- 桌面端调用既有 PH 模板 API，移动端调用本地内置模板定义；两条路径都进入同一详情编辑器。
- 不新增覆盖已有 Plan 的接口，避免改变 Plan ID、日志、嵌套 group、软删除和 TD 关联语义。

## 验证

- PH 创建、模板、本地化与 i18n 定向测试：11 passed。
- 桌面生产构建：1874 modules transformed，成功。
- 全量 Python 回归将在提交前执行。

## 边界

模板工作区仍不自动生成 TD；TD 只能在详情页由用户显式关联。自定义模板仍由桌面 PH 服务管理，移动端只提供内置模板。
