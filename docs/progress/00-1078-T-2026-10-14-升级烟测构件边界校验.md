# 升级烟测构件边界校验

**报告类型**：维护报告  
**阶段**：第 0 阶段  
**日期**：2026-10-14（Asia/Shanghai）  

## 背景

Windows 升级烟测此前只校验当前安装包的 EffiLife 文件名约定，旧安装包参数本身可能指向其他品牌或不兼容构件。项目中存在历史安装器，不能将其当作 EffiLife 升级基线。

## 处理

- 升级前校验旧安装包文件名必须符合 `EffiLife_<version>_x64-setup.exe`。
- 拒绝与当前版本相同的旧安装包，避免把普通重装误报为升级验证。
- 在烟测结果中记录 `previous_version`，便于发布证据审计。
- 安全拒绝发生在启动旧安装器之前，不会触碰目标目录或用户数据。

## 验证

- 安装/升级/发布相关测试：`28 passed`。
- `python scripts/check_release_config.py`：通过。

## 结论

升级验收的输入边界已与 EffiLife 产品身份一致，历史旧品牌安装器不会再被误用于升级测试。阶段保持第 0 阶段。
