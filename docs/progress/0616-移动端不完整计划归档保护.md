# 1122 移动端不完整计划归档保护

日期：2026-10-05  
类型：实现报告

## 背景

上一轮修复了桌面端导入不完整 PH 归档时误清空计划的问题。进一步审查发现，移动端无在线 PH 服务时仍会清理本地计划快照，存在同样的数据破坏风险。

## 实现与兼容性

- 移动端导入 `planHelper.available !== true` 的归档时保留当前本地 PH 快照；
- 继续通过 `planNotRestored` 警告告知用户计划数据未被导入；
- 明确包含 `available: true` 的计划数据仍按原有快照替换逻辑处理；
- 旧归档缺失 `planHelper` 的兼容行为不变。

## 实际验证

- `python -m pytest -q tests/test_archive_plan_replacement.py tests/test_archive_primary_storage.py` → `18 passed`；
- `python -m pytest -q` → `875 passed`；
- 在 `time-helper/desk` 执行 `npm run build` → `vue-tsc` 与 Vite 构建通过。
