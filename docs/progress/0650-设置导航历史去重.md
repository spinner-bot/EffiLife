# 1156 设置导航历史去重

日期：2026-10-05  
类型：统一设置工作台交互修复

## 背景与问题

设置页使用内部视图历史栈管理主题、存档、恢复和自定义设置。重复点击当前入口会重复写入同一个视图，导致返回操作需要多次点击，破坏了设置入口的可预期性。

## 实现

- 设置导航进入同一当前视图时直接返回，不再重复压入历史栈。
- 保留主题草稿离开前的确认与自动保存流程。
- 增加设置导航历史和主题确认契约测试。
