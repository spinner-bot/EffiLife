# 0663：设置页版本历史多语言化

## 背景

设置页的版本历史原先直接渲染中文静态文本。切换到英文界面后，版本号、设置项等界面已经变化，但历史说明仍保持中文，造成语言混用。

## 目标与范围

- 保留现有中文版本历史内容，不改变发布记录的语义与顺序。
- 为设置页版本历史补充英文对应文本。
- 根据当前界面语言选择版本历史说明。
- 增加回归测试，避免后续新增版本时只补中文而遗漏英文结构。

## 实现

- 在 `time-helper/desk/src/version.ts` 增加版本历史英文映射，并提供 `getVersionChanges` 统一选择函数。
- 在 `SettingsView.vue` 的当前版本和历史版本区域调用统一选择函数。
- 在 `tests/test_version_view_text_i18n.py` 增加结构性回归检查。

## 兼容性

- 中文及默认语言仍使用原有 `VERSION_HISTORY` 数据。
- 非英文语言不会误用英文文案，继续回退到中文版本记录。
- 未改变版本号、更新日期、版本排序或发布历史内容。
- 未触碰受保护的 `docs/HOTL/` 和本地 `package-lock.json` 修改。
