# 1160 统一 API 错误多语言

日期：2026-10-05  
类型：多语言基础与跨模块 API 一致性优化

## 背景与问题

统一工作台已经具备中英文界面目录，但旧版前端 API 层仍直接返回中文错误字符串。未来模块调用这些 API 时，即使用户已切换英文，错误响应仍会回退为中文。

## 实现

- 增加 `apiFail()` 统一错误响应入口，通过现有 `translate()` 读取当前语言。
- 配置、计划、时间记录、打卡、事件、统计等 API 错误全部改用稳定的 `api.error.*` 键。
- 中英文目录同步补齐 39 个错误键。
- 保留 API 响应结构与错误语义，不改变调用方的成功/失败判断方式。
