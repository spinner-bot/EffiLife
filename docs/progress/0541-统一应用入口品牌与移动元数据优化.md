# 1047 统一应用入口品牌与移动元数据优化

日期：2026-10-02

## 问题

桌面前端入口仍引用 Vite 默认的 `vite.svg`，没有使用 EffiLife 自有标识；移动 WebView 也缺少主题色和明确的明暗配色元数据，入口层产品感不完整。

## 实现

- 新增 EffiLife E 标识 SVG favicon，并替换 Vite 默认引用。
- 增加 `theme-color`，使移动浏览器和 WebView 顶部系统区域与应用品牌色一致。
- 增加 `color-scheme: light dark`，向系统和浏览器声明支持的基础配色范围。
- 保留已有 `viewport-fit=cover`，与全面屏安全区适配配套。

## 验证

- 统一导航与前端构建契约专项测试：`10 passed`。
- Python 全量测试：`800 passed in 7.61s`。
- 桌面前端生产构建：`vue-tsc` 通过，Vite 完成 `1877 modules transformed`，构建成功。

## 影响范围

仅改善统一应用入口的品牌识别和移动系统元数据，不改变任何 PH、TD、TH 业务数据及运行逻辑。
