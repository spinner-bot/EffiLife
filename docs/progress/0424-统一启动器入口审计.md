# 0850 统一启动器入口审计

## 审计范围

复核统一应用壳的默认启动路径、旧模块兼容入口、正式打包模式和共享数据目录传递，避免三个模块在发布前重新退回分离启动。

## 当前结论

- 默认启动与 `--unified` 均进入统一 EffiLife 工作区。
- 旧模块菜单只有显式使用 `--legacy-menu` 时才启用。
- `--packaged` 模式只接受原生 Tauri 构件或已生成的静态构建，不回退到 Vite/npm 或 debug 构件。
- `EFFILIFE_DATA_DIR` 会通过启动器传递给 Plan Helper sidecar，保持统一数据根目录。
- `/plans`、`/tasks`、`/time` 仍是统一应用壳内的独立业务入口，不改变 PH、TD、TH 的基本单元。

## 验证证据

- `python scripts/run_integration.py test`：55/55 passed。
- GitHub `EffiLife CI` Run 295：completed successfully。
- 启动器契约覆盖 `tests/test_launcher.py` 的统一入口、legacy 显式入口、打包模式和数据目录传递测试。

## 未验证边界

本机仍缺少 Rust/Cargo、Android SDK/ADB、Xcode 和真实设备，因此本记录不替代正式安装包、签名、升级和真机验收。
