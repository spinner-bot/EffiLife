# 跨平台工具链发现修复

状态：[进行中]

日期：2026-10-12

作者/执行者：Codex

## 触发原因

GitHub Actions 的 `EffiLife CI` 从提交 `a50c30a` 起连续在 `Run full Python test suite` 步骤失败；此前移动边界工作流仍成功。本地 Windows 全量测试通过，说明需要重点复核该提交引入的环境站发现逻辑及其 POSIX 边界。

## 诊断证据

- 失败运行：`38211100404`、`38211838864`、`38212151102`、`38212291161`。
- 失败步骤均为 `Run full Python test suite`，版本同步、Node/npm 安装步骤均成功。
- 在 `HEAD` 隔离 worktree 中按 CI 顺序执行版本同步后，全量测试为 `1041 passed`；因此当前 Windows 本地结果不能单独证明 Ubuntu runner 已修复。
- 故障首次出现在 `a50c30a fix(env): discover managed native toolchains`，该提交把 Windows 环境站路径加入启动器和构建预检。

## 修复内容

- `launcher/start.py`：显式 `EFFILIFE_RUST_TOOLCHAIN_DIR` 在各平台可用；默认 Rust 环境站仅在 Windows 启用；POSIX 使用无扩展名工具名。
- `scripts/check_build_environment.py`：Rust、Android SDK/ADB 的显式路径按当前平台选择文件名；Windows 默认 F 盘路径不再污染 POSIX 检查。
- 保留 Windows 管理工具链契约测试，并通过启动器与构建环境定向测试。
