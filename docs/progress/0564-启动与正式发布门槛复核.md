# 启动与正式发布门槛复核

## 当前结果

- `python launcher/start.py --diagnose`：统一工作台和 Plan Helper companion 均可用，已有服务健康检查通过。
- 统一工作台开发入口使用自定义 Node/npm，未依赖 PATH 中可能失效的 npm shim。
- 桌面发布配置检查通过：`python scripts/check_release_config.py`。
- 移动发布配置检查通过：`python scripts/check_mobile_release_config.py`。

## 尚未完成的真实发布门槛

- 本机没有 Cargo/Rust，无法执行 Tauri 桌面安装包编译。
- 本机没有 Android/iOS 发布工具链，无法执行移动端真机、权限、安装升级和恢复验收。
- 工作区发现旧的 1.0.11 NSIS 安装包；当前应用版本是 1.7.0，因此该文件只能作为历史构件，不能作为当前发布物。

## 结论

启动器开发/测试路径已可诊断、可区分 companion 健康状态；正式发布仍必须在具备 Rust、平台 SDK 和签名环境的发布机或 CI 上完成，并重新生成与 1.7.0 匹配的安装包。
