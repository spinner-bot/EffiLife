# HOTL-1 当前对齐审计

日期：2026-10-11

## 审计范围

依据 `docs/HOTL/1.txt` 和 `docs/progress/0000-进展报告规范.md`，复核统一应用壳、TH/PH/TD 职责边界、首页工作台、桌面/移动布局、主题持久化、日历入口、统一存档和多语言基础。

## 逐项证据

### A1：三模块职责保持独立并协作

已验证。统一壳通过 `/time`、`/plans`、`/tasks` 保留 TH、PH、TD 独立入口；PH 仍以完整 Plan、section、任务、嵌套 group 和日志为单位，TD 仍以单条快速待办为单位。跨模块只通过显式关联字段和 TH 记录关联，不把三者写成同一种实体。

证据：`tests/test_module_boundaries.py`、`tests/test_plan_raw_archive.py`、`tests/test_plan_todo_linking.py`、`tests/test_record_todo_linking.py`。

### A2：首页同时呈现三模块关键内容

已验证。首页包含 TH 时间摘要、PH 计划进度和 TD 活跃待办，并提供对应深链、重试和快速创建入口。

证据：`time-helper/desk/src/views/HomeView.vue`、`tests/test_home_workflow_summary.py`。

### B1：桌面/平板/移动布局

配置和契约已验证。桌面使用宽工作台与横向导航，平板为双栏工作区，移动端使用触控导航和悬浮快速待办入口；PH、TD、TH 均有独立布局规则。

证据：`tests/test_desktop_workspace_layout.py`、`tests/test_ph_responsive_layout.py`、`tests/test_td_desktop_workbench_layout.py`、`tests/test_module_navigation_identity.py`。

### B2：主题切换和持久化

配置和代码路径已验证。主题由 TH 的注册表提供，支持基础主题和丰富主题；设置页离开时确认并写入 IndexedDB，随后通过启动读取路径回读校验，应用壳实时应用主题变量。

证据：`time-helper/desk/src/views/SettingsView.vue`、`time-helper/desk/src/theme/ThemeEngine.ts`、`tests/test_settings_theme_i18n.py`、`tests/test_config_normalization.py`、`tests/test_system_theme_runtime.py`。

### B3：日历入口

已验证。主导航不再提供独立日历入口，旧 `/calendar` 只保留兼容重定向；日期选择器仅用于时间记录历史定位，不构成日历模块。

证据：`time-helper/desk/src/router/index.ts`、`tests/test_frontend_guide.py`、`tests/test_module_navigation_identity.py`。

### C1：统一数据与导入导出

已验证。`.efl` 统一存档覆盖应用配置、TH 记录、TD 待办/分类和 PH 计划快照，并包含校验、恢复、回滚和旧存档兼容路径。

证据：`time-helper/desk/src/services/ArchiveService.ts`、`tests/test_unified_archive_contract.py`、`tests/test_archive_import_checkpoint.py`、`tests/test_archive_primary_storage.py`。

### C2：启动和发布链

本地已验证。启动器 doctor 为 READY，真实启动烟测中前端和 PH 健康检查通过且端口释放；桌面/移动发布配置门禁通过；CI 已加入 TD 依赖高危审计门禁。

证据：`docs/progress/1304-T-2026-10-11-启动器与兼容界面真实验证.md`、`docs/progress/1308-T-2026-10-11-CI依赖安全门禁.md`、`scripts/smoke_startup.py`。

### C3：多语言基础

配置已验证。统一工作台采用共享 locale 注册表，当前包含 `zh-CN` 与 `en-US`，主题元数据、PH、TD、TH 和壳层文案均有双语目录覆盖；本轮扫描未发现新的页面硬编码用户文案。

证据：`time-helper/desk/src/i18n/index.ts`、`tests/test_frontend_i18n_coverage.py`、`tests/test_frontend_i18n_key_coverage.py`、`tests/test_locale_registry.py`。

## 当前未完成或证据不足

- 尚未完成真实安装包安装、升级、卸载和签名验收；
- Android 已有本地构建证据，但尚未完成真机触控和数据迁移验收；
- iOS 按当前项目范围暂缓；
- GitHub Actions 远端完整流水线需要在本次 CI 门禁变更后再次观察；
- TD 兼容 Web 仍是迁移/调试入口，尚未把其旧版中文文案全部迁移到统一 locale；这不影响统一工作台的 HOTL-1 多语言边界。

## 审计结论

HOTL-1 的代码结构和本地验证证据已基本对齐，当前主要剩余项属于真实发布环境验收和后续 HOTL 阶段，而不是继续重写 PH 数据模型或合并 PH/TD 实体。下一轮应优先补充可复现的安装包/Android 验收证据，或在获得 HOTL-2 后按新要求迭代。
