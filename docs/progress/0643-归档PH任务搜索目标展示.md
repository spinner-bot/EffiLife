# 0643 归档 PH 任务搜索目标展示

## 背景

0642 已将归档 PH 任务加入全局搜索，但计划中心原有逻辑对 `archive` 查询直接停止目标解析，导致归档任务搜索只能打开归档提示，无法看到任务内容。

## 实现

- 计划中心从归档摘要的只读任务投影中渲染任务预览。
- 同时支持按内部任务 ID或显示任务 ID识别搜索目标，并对目标行进行高亮。
- 归档仍保持只读；用户必须显式点击“恢复”才会产生数据变更。
- 活动计划详情和原有归档恢复流程不变。

## 兼容性

- 旧归档没有 `tasks` 摘要时仍显示原有归档提示和恢复入口。
- 不修改归档文件、不重排任务编号、不改变 TD 关联。
- 桌面和移动端共用同一只读预览字段。

## 验证

- 新增归档任务深链契约测试。
- 全套 Python 测试将在提交前运行。
- 前端构建由 GitHub CI 验证。
