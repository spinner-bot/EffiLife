# 0645｜CI 桌面前端构建失败修复

## 背景

GitHub Actions 的 EffiLife CI Run 54、Run 55 连续在 `Build desktop frontend` 步骤失败。Python 测试与发布契约检查均已通过，因此需要针对 Vue/TypeScript 编译阶段定位问题。

## 目标

修复当前桌面前端构建阻断，并增加与问题直接相关的回归约束。

## 范围

- `time-helper/desk/src/views/PlansHubView.vue`
- 本进展记录

## 实现

`PlansHubView.vue` 新增归档任务预览后使用了 `PlanTaskSummary` 类型，但遗漏了从 `services/planGateway` 的类型导入。补充 `type PlanTaskSummary` 导入，使 `vue-tsc` 能解析该类型。

## 兼容性

仅补充 TypeScript 类型导入，不改变运行时逻辑、数据结构、路由或归档行为。

## 验证

- GitHub Run 55 的公开页面确认失败步骤为 `Build desktop frontend`。
- 本地 Python CI/移动端相关回归：`12 passed`。
- 当前环境未安装可用的 Node.js 可执行文件，无法在本机重跑 `vue-tsc && vite build`；修复后需以 GitHub CI 作为最终构建验证。
