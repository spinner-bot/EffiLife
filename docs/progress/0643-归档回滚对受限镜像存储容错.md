# 1149 归档回滚对受限镜像存储容错

日期：2026-10-05  
类型：统一归档可靠性修复

## 背景与问题

即使归档主数据已经迁移到 IndexedDB，导入前的运行时快照和失败回滚仍会访问 `localStorage`。在隐私模式、配额耗尽或 WebView 将其设为只读时，这一步可能反过来阻断归档导入或掩盖 IndexedDB 回滚结果。

## 实现

- 捕获运行时快照时，兼容镜像读取失败只记录警告，IndexedDB 快照继续建立。
- 回滚时，兼容镜像清理/恢复失败不再阻断 IndexedDB 的清理与重建。
- 保留备份快照和主存储回滚语义；受限镜像只作为尽力恢复层。
- 新增契约测试覆盖捕获和回滚两个边界。

## 验证

- 归档专项测试：3 passed。
- 项目全量测试：905 passed。
- `time-helper/desk`：`npm run build`，通过，1877 modules transformed。
