# 0602 PH 创建计划首屏录入内容

## 背景

HOTL1 指出 PH 的基本单元是完整 Plan，而不是只有名称和日期的空壳。此前统一工作台的普通“新建事件计划”虽然创建后会进入编辑页，但提交时没有传递 section/task，用户容易误以为计划已经完成创建，实际却是空计划。

## 实现

- 创建弹窗默认提供一个 section 和一个 task 输入行，并支持在提交前追加/移除 section 与 task。
- 创建前清理空白内容，只保留同时拥有名称和至少一个有效任务的 section。
- 没有有效 section/task 时拒绝提交并提示，避免继续产生空事件计划。
- 通过既有 `createEventPlan(name, date, sections)` 传递 PH 原生 section/task 数据；没有改变 A1/B1 编号、软删除、嵌套 group 或执行记录的语义。
- 创建成功后仍进入完整编辑页，后续可继续编辑 section、任务、嵌套 group、日志及 TD 关联。

## 界面与平台策略

创建内容区使用主题 CSS 变量，桌面端以紧凑多列任务行提高录入效率，窄屏端任务字段自动改为单列触控布局；移动端快照也复用相同 `InitialPlanSection` 数据边界。
