# PH 软删除显示投影防护

## 背景

PH 的底层计划保留有序槽位，删除任务采用软删除；显示编号和用户可见列表必须只基于活动任务重新计算。服务端通常已经返回活动任务，但缓存、迁移数据或兼容接口可能仍带有 `is_active: false` 的槽位。

## 调整

- 在统一工作台增加 `activePlanTasks` 显示投影。
- 任务列表、日志任务选择、分组范围选择、任务计数、完成度、TD 批量关联均只使用活动任务。
- 保留内部任务 ID、日志引用和嵌套分组的原始槽位，不改变 PH 数据结构或软删除语义。
- 增加前端契约测试，防止后续 UI 改动绕过活动任务投影。

## 验证

- 运行 PH 显示投影和桌面布局定向测试。
- 运行统一前端生产构建与完整 Python 回归测试。
