# 0594｜平板统一导航响应式收窄

## 背景

统一应用壳在 `681–820px` 宽度时仍使用完整桌面导航。此区间尚未切换到底部移动导航，但品牌、五个模块入口和全局搜索同时占用横向空间，容易导致导航压缩或溢出。

## 实施

- 保留平板的横向导航形态，符合桌面/平板工作台的分层设计。
- 在 `681–820px` 区间隐藏品牌文字，只保留品牌标记。
- 收窄模块链接间距和内边距。
- 将搜索入口收窄为图标，保留按钮和无障碍标签。
- 不改变 `≤680px` 的移动底部导航，也不改变路由和模块独立入口。

## 验证

- 新增桌面布局回归测试。
- 继续执行统一桌面端类型检查、生产构建和全量 Python 测试。
