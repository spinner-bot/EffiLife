# 0488 统一工作区运行时与发布链复核

## 复核范围

本次复核覆盖统一应用壳的测试启动、桌面正式发布配置、移动发布配置，以及启动器对已运行服务和端口冲突的处理。

## 结果

- `python scripts/check_release_config.py` 通过：版本、Tauri sidecar、桌面发布矩阵、兼容 UI 构建和产物校验链路一致。
- `python scripts/check_mobile_release_config.py` 通过：移动端构建边界和生成工程检查配置完整。
- `python launcher/start.py --release-check` 通过：启动器复用同一套桌面发布预检规则。
- `python launcher/start.py --diagnose` 显示统一工作区与 plan-helper 健康可用；启动器能够识别已占用但健康的服务，避免重复启动严格端口的开发服务器。
- 定向回归：启动器、跨运行时存档、统一计划工作区共 `56 passed`。

## 当前边界
