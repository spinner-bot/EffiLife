# 0791 主题退出保存事务提交修复

## 结论

修复主题设置“退出确认后保存、离开页面又恢复旧主题”的竞态。

## 原因

IndexedDB 通用 `set` 在 `objectStore.put` 的 `request.onsuccess` 中就结束等待。该事件只表示请求已被事务接受，并不表示事务已经提交完成。主题设置退出后，应用的可见性刷新或工作区刷新可能在事务提交前读取配置，因而读到旧主题并覆盖刚刚的预览。

## 调整

- `indexedDB.set` 改为等待 `transaction.oncomplete` 后再返回；
- 事务错误和中止均进入既有 localStorage 降级路径；
- 主题设置继续采用“修改即时预览，退出时弹窗确认后保存”，不增加主题保存按钮；
- 增加静态契约测试，防止未来重新在 request 成功事件提前结束。
