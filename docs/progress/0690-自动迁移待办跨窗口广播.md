# 0690：自动迁移待办跨窗口广播

## 背景

统一工作台启动时会把旧版 `to-dos-data` 迁移到统一 IndexedDB。手动导入已经广播 `todos` 工作区事件，但自动迁移成功后没有广播，其他已打开窗口可能继续显示旧的待办和分类摘要。

## 实现

- 自动迁移成功写入待办或分类后，广播 `todos` 工作区变更。
- 没有迁移数据时不发送无意义事件；迁移失败仍保留原始数据并允许下次重试。
- 不改变非破坏性迁移、重复 ID 跳过和 PH/TH 关联字段保留逻辑。
