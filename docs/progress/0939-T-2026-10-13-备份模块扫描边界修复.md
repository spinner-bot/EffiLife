# [完成] 备份模块扫描边界修复

## 问题

恢复面板的备份列表已经会忽略损坏的 JSON，但模块扫描仍会从损坏条目的键名推导模块名称。结果是界面可能出现一个没有可恢复条目的空模块，造成“列表与筛选模块不一致”。

## 实现

- 模块扫描统一先解析并校验备份记录。
- JSON 损坏时直接忽略，不再从键名创建空模块。
- 保留可解析的旧格式键名回退逻辑，以兼容缺少 `module` 字段的历史记录。

## 验证

- 备份/恢复专项测试：10/10 通过。
- 前端构建：Vite 1879 modules 成功。
- 全量 Python 回归：1142 passed，1 warning（既有重复 ZIP 条目测试警告）。
