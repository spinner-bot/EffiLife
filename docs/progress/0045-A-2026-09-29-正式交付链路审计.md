# 0443｜正式交付链路审计

日期：2026-09-29  
类型：A（审计）  
范围：桌面 Tauri 发布链路、统一启动边界、多端预检

## 已验证

- `python scripts/check_release_config.py`：通过，桌面发布配置完整。
- `python scripts/run_integration.py`：通过，to-dos/plan-helper 模块注册和统一系统交互入口可运行。
- `.github/workflows/tauri-desktop-release.yml` 已覆盖 Windows NSIS、Linux DEB、Linux AppImage、macOS DMG，并包含 sidecar 构建、Python 回归、安装包非空校验和 SHA-256 校验文件。
- Tauri 配置已声明 EffiLife 产品元数据、Plan Helper sidecar、桌面数据目录和正式构建命令。

## 未完成且不能误报

- 当前开发机 `check_build_environment.py --target desktop` 报告缺少 `cargo`、`rustc`，所以本机没有完成真实 Tauri 安装包构建、安装和升级验收。
- 仓库没有独立 Android/iOS 工程目录；移动端当前复用统一 Vue 前端与本地计划快照能力，尚未完成 Tauri Mobile 初始化、平台文件权限、安装升级和真机验收。
- 正式发布仍应以 CI/发布机产出的安装包和安装后数据迁移结果为准，测试 launcher 不应被当作正式产品入口。

## 结论

当前状态仍是“统一工作台开发集成版 + 已配置的桌面发布候选流水线”，不是已完成的正式跨平台发布版。后续优先级为：在发布环境完成 Rust/Tauri 安装包验收，再建立移动端工程和真机验收矩阵。
