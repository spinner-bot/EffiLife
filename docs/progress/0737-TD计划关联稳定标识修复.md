# 1255 TD–PH 计划关联稳定标识修复

## 完成内容

修复启动阶段的 TD–PH 关联修复逻辑：关联校验现在只接受 PH 活动任务的 `internal_id`，不再把软删除后可能复用的 `display_id` 当作稳定引用。

这避免了“原 A2 被删除、原 A3 显示为 A2”时，遗留 TD 关联 A2 被错误保留并指向原 A3。PH 的交互 API 仍可解析显示编号，TD 与 PH 仍保持独立入口和各自数据所有权。

## 验证

- 新增静态回归测试，明确禁止 `internal_id + display_id` 联合校验；
- 保留计划服务不可用、缓存、归档计划时不进行破坏性清理的既有保护。
