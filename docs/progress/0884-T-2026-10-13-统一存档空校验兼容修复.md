# 0884－统一存档空校验兼容修复

类型：T（统一数据与兼容性）  
日期：2026-10-13  
阶段：0  
执行者：Codex  
状态：已完成

## 1. 触发原因

统一 `.efl` 读取器允许旧包省略 `dataset_sha256`，但对显式写入 JSON `null` 的兼容包，读取数据时会直接调用 `None.get()`，产生未处理异常。该问题不影响当前导出包，却会破坏部分旧版或外部生成包的只读验证和导入。

## 2. 实施内容

- 在 Python 交换层读取入口将缺失或 `null` 的校验映射归一为空映射；
- 保留已有行为：有效校验映射继续逐数据集验证，完全没有校验字段的包仍标记为 legacy；
- 不修改 `.efl` 当前版本号、数据集名称、PH 原始结构、TH 记录或 TD 关联数据；
- 增加显式 `dataset_sha256: null` 的兼容回归测试。

## 3. 验证

- 统一数据交换定向测试：新增边界通过；
- 提交前执行全量 Python 回归；
- 本轮修复仅涉及 Python 交换层，不改变前端构建产物。

## 4. 边界与后续

该修复只处理 legacy 校验字段的容错，不放宽格式、数据集形状、文件大小或路径安全校验。未来若升级 `.efl` 协议，仍需建立显式版本迁移注册表并同步前端读取策略。阶段保持第 0 阶段。
