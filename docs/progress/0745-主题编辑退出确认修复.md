# 0745 主题编辑退出确认修复

## 问题

主题设置页此前同时使用了后台定时保存、实时预览和退出确认。编辑期间的异步保存会触发工作区刷新，退出时可能把编辑草稿与旧的持久化快照交替写回，表现为主题修改无法稳定保留。

## 调整

- 主题编辑改为独立草稿，只在界面内实时预览。
- 删除主题编辑的后台定时保存逻辑，避免编辑过程中的竞态覆盖。
- 返回、切换设置子页或离开路由时，如果草稿有变化，弹出“保存并退出”确认。
- 用户确认后执行一次持久化写入，并以持久化结果更新编辑快照。
- 移除主题页保存按钮语义，状态提示明确为“退出时确认后保存”。

## 验证

- `time-helper/desk`: `npm run build` 通过（包含 `vue-tsc` 与 Vite 生产构建）。
- `git diff --check` 通过。
