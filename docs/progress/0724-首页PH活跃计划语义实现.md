# 1236｜首页 PH 活跃计划语义实现

## 变更

修正首页 PH 摘要把全部未归档计划误称为“活跃计划”的问题：

- 有未完成任务的计划，以及没有任务的计划，归入进行中预览。
- 有任务且全部完成的计划从活跃预览中移出，并单独显示完成计划数量。
- 所有计划完成时显示明确提示，仍可进入 PH 中心复盘。
- 总任务完成比例保持按全部未归档计划计算，不改变历史统计口径。

## 边界

仅改变 Home 展示层，不修改 PH API、计划数据、嵌套组、任务编号、归档行为或 TD 关联。
