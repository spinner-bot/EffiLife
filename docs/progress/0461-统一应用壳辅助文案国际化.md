# 统一应用壳辅助文案国际化

## 背景

统一应用壳的可见导航已经使用 locale registry，但品牌导航和返回首页链接的辅助功能标签仍是直接写死的英文。此类文本虽然不影响视觉布局，却会影响屏幕阅读器和多语言完整性。

## 调整

- 将应用导航容器标签改为 `app.shellLabel`。
- 将品牌首页链接标签改为 `app.homeLink`。
- 在主目录与启动回退目录中补齐中英文文案。
- 增加双语覆盖测试；不改变路由、键盘快捷键和视觉文案。

## 验证

- 定向测试：13 passed
- 全量测试：725 passed
- 桌面端生产构建：`npm run build` 通过
- `git diff --check`：通过
