# 0613｜移动端 PH 归档恢复

## 背景

统一 `.efl` 已经携带 PH 归档快照，但移动端计划网关此前在 `listPlanArchives()` 直接返回空，并将归档/恢复操作固定发送到桌面服务，导致迁移来的归档数据无法在移动端使用。

## 目标与范围

- 移动端可查看本地归档计划。
- 移动端可将活动计划归档到本地快照，并从快照恢复为新的活动计划。
- 保持 PH 与 TD 的角色边界，不把归档计划直接转化为 TD。

## 实现

- `planGateway.ts` 增加本地归档快照读取、列表、归档和恢复逻辑。
- 恢复时分配新的计划 ID，避免覆盖现有活动计划；原归档快照保留。
- 更新中英文移动端存档能力说明。
- 增加移动端归档契约测试。

## 兼容性与架构决策

移动端仍使用 IndexedDB 的 `plan_helper_snapshot`，桌面端仍使用 PH HTTP 服务。两端交换的归档 payload 保持一致；移动端恢复不依赖桌面 sidecar。
