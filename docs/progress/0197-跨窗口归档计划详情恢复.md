# 0598｜跨窗口归档计划详情恢复

## 背景

统一工作台通过 `workspace-changed` 支持多窗口同步。若窗口 A 正在查看 PH 计划详情，窗口 B 将该计划归档或删除，窗口 A 收到 `plans`/`archive` 事件后原先会直接重新请求详情；请求失败可能留下失效页面并产生未处理异常。

## 实施

- 对 `plans` 和 `archive` 工作区事件统一捕获当前计划详情读取失败。
- 失败时清空失效详情，返回 PH 计划列表并重新加载活动计划/归档列表。
- 不修改 TD–PH 关联；关联保护仍由启动同步器和归档数据语义负责。
- 增加跨窗口回归测试，确保不会停留在不存在的详情页面。
