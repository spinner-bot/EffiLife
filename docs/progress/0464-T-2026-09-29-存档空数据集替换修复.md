# 0464-T-2026-09-29 存档空数据集替换修复

## 变更

- 前端统一存档导入新增可选数据集三态恢复函数。
- canonical 存档中的 `null` 现在会清除 IndexedDB 和 localStorage 兼容镜像中的旧值。
- 旧版 `archive.json` 缺少字段时仍保持原数据，避免破坏向后兼容。
- 导入失败继续使用既有 runtime snapshot 回滚。

## 验证

- `python -m pytest tests/test_archive_primary_storage.py tests/test_cross_runtime_archive_contract.py -q`
- 前端构建：`npm run build`

## 结果

存档恢复的替换语义与统一数据协议一致，不再因目标设备残留可选配置而出现“导入后仍保留旧状态”的隐性数据污染。
