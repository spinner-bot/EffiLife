# 1110 PH 计划关联待办可见反馈

日期：2026-10-05  
类型：实现报告

## 背景

PH 详情已经可以批量建立 TD 关联，但用户只能通过按钮文案和提示判断结果，计划摘要没有显示当前关联数量，不利于确认跨模块数据是否已经建立。

## 目标与非目标

目标是在 PH 计划摘要中持续显示已关联 TD 数量，并提供中英文文案。非目标是改变 PH/TD 数据结构、把 TD 合并进 PH，或让 TD 反向控制 PH。

## 影响范围

- `PlansHubView.vue`：增加关联数量计算和摘要项；
- `i18n/index.ts`：增加 `plans.linkedTodos` 中英文文案；
- `tests/test_plan_todo_linking.py`：增加界面和双语契约；
- 数据与平台：只读取现有关联字段，桌面、移动端和统一存档格式不变。

## 兼容性与迁移

没有数据迁移。没有关联字段的旧 TD 不计入数量，但仍保持可用；已有关联会在计划详情刷新时重新统计。PH 的完整 Plan、任务编号、嵌套 group 和软删除语义不变。

## 验证

- `python -m pytest -q tests/test_plan_todo_linking.py` → `5 passed`；
- `python -m pytest -q` → `870 passed`；
- 在 `time-helper/desk` 执行 `npm run build` → `vue-tsc` 与 Vite 构建通过；
- `git push origin main` 成功，提交 `89bb624` 已位于 `origin/main`。

## 未验证项与后续事项

- 尚未在 Android/iOS 真机验证不同屏幕宽度下摘要项的触控布局；
- 主题持久化问题仍按用户指示暂缓；
- 当前统计只反映已建立的 PH→TD 关联，不代表 TD 与 PH 实体合并。
