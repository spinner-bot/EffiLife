# 0692：迁移提示挂载时序修复

## 背景

启动迁移结果提示已经延后到统一工作区 hydration 完成后，但 `runtimeReady` 变更到 `ToastHost` 真正挂载之间仍存在 Vue 渲染间隔。若立即调用 Toast 服务，极端情况下提示会被发布到尚未存在的宿主，用户仍然看不到迁移结果。

## 实现

- 在迁移结果提示前等待 Vue `nextTick`，确保应用壳和 `ToastHost` 已完成挂载。
- 保持仅在实际迁移待办或分类时提示的行为，不改变迁移数据和跨窗口广播逻辑。
- 增加启动 hydration 回归断言，锁定提示调用必须位于 `nextTick` 之后。
