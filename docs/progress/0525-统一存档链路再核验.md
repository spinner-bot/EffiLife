# 1031 统一存档链路再核验

## 日期

2026-10-02

## 核验背景

按照统一软件目标和 HOTL-1 要求，复核 `effilife.bundle` 的跨模块导入导出边界，确认 PH、TD、TH 数据没有因服务不可用、旧格式兼容或主题配置规范化而互相覆盖。

## 核验结论

- canonical datasets 仍为 `app`、`records`、`todos`、`todo_categories`、`plan_helper`。
- canonical JSON、SHA-256 校验、缺失数据集拒绝和非法数据形状拒绝均保留。
- 导入前创建持久恢复点，写入失败时执行运行时回滚。
- 旧 `archive.json` 可兼容解析；缺失旧版 PH 数据时保留当前快照，不误清空。
- PH 服务不可用时使用快照/警告语义，不伪造 PH 已恢复；TD 与 TH 数据仍按各自 canonical dataset 恢复。
- 配置主题在导出、canonical 导入和旧档导入边界均执行规范化。

## 模块边界

PH 仍以完整计划快照为单位，TD 仍是独立待办集合，TH 仍是时间记录和日计划集合。统一存档只提供共同容器和显式引用修复，不把三者合并为同一种实体。
