# PH 空计划全屏编辑实现

日期：2026-09-30

## 实现结果

- 创建计划弹窗现在只包含名称、日期、取消和创建操作，默认日期继续填充当前本地日期。
- 创建调用 `createEventPlan(name, date)` 的空 sections 默认值，服务端和移动端都写入完整 Plan 外壳，`main` 为空。
- 创建成功后读取新 Plan，关闭弹窗并进入详情工作台；详情页可继续添加 section、task、group、log。
- 创建阶段不再隐式生成 TD；TD 关联保留在详情页的单项和批量显式操作中，避免混淆 PH 与 TD 的基本单元。
- 模板服务层和移动端本地模板定义保留，但不再塞进“从零创建”的基础弹窗。
- 清理创建弹窗对应的无效 CSS 和旧契约测试，模板本地化测试改为验证 gateway 层。
