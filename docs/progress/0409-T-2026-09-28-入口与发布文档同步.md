# 入口与发布文档同步

## 同步内容

- 记录统一启动器仅用于开发、测试、迁移和回归，正式版本使用 Tauri 安装包。
- 补充发布前只读检查命令 `python launcher/start.py --release-check`。
- 同步当前桌面发布矩阵：Windows NSIS、Linux DEB、Linux AppImage、macOS DMG。
- 明确 Plan Helper 在桌面正式包中由受控 sidecar 承载，移动端使用本地快照能力，不依赖 Python localhost 服务。

## 目的

让 README、发布流水线和启动器的产品边界保持一致，减少把兼容入口误当作日常主入口的风险。
