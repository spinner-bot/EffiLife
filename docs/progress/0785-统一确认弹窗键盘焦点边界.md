# 0785｜统一确认弹窗键盘焦点边界

## 状态

已完成，2026-10-01。

## 背景与问题

统一工作台的确认弹窗已经覆盖主题退出、归档导入、删除等高风险操作，并支持 Esc、遮罩和可见关闭按钮。但桌面键盘用户按 Tab 时可以离开弹窗，焦点可能落到背景页面，降低操作可预测性和无障碍质量。

## 目标与非目标

- 目标：在所有复用 `ConfirmHost` 的确认场景中保持 Tab/Shift+Tab 在当前弹窗内循环，并为正文提供明确的 ARIA 描述关系。
- 非目标：不改变确认服务的返回值、按钮语义、主题样式或业务流程。

## 实现与布局决策

- 在统一弹窗容器上监听 Tab，按 DOM 顺序循环可用控件。
- 保留打开时聚焦取消按钮，Esc 与遮罩关闭行为保持不变。
- 使用弹窗实例 id 生成 `aria-describedby`，避免多实例 id 冲突。
- 桌面端和移动端共享同一实现；移动端不增加额外导航层。
