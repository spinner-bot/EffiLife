# 0858 统一启动器外部前端伴随服务修复

## 背景

统一启动器在发现 1420 端口已有前端时会直接复用并返回。若这个前端是用户手动启动的，它可能没有同时启动 Plan Helper API，导致页面可以打开但计划数据不可用。另一条复用路径虽然会启动缺失的 companion，却会在打开浏览器后立即清理它，生命周期同样不正确。

## 本次调整

- 复用健康前端时，先按模块声明检查并启动缺失的 companion 服务。
- 仅当启动器实际托管了 companion 时，才等待外部前端结束；前端结束后统一回收启动器托管的 companion。
- 保留重复启动前端的保护、端口冲突处理和无 companion 时的快速复用行为。
- 增加回归测试，覆盖“外部前端 + 缺失 Plan Helper companion”的启动、浏览器打开和生命周期回收。
