# 0821 启动器原生工具链诊断提示

日期：2026-10-01

## 背景

当前开发环境可以运行统一工作区，但没有完整的 Rust、Android SDK/ADB 与 macOS/Xcode 原生构建工具链。启动器此前只提示 Rust 缺失，用户难以判断 Android 与 iOS 构建应在哪里完成。

## 本轮目标

- 为桌面、Android、iOS 原生构建前置条件提供可操作的诊断信息。
- 不改变开发模式启动、工作区可用性或 `READY` 判定。
- 用测试锁定诊断字段和提示代码，避免环境缺失被误报为应用故障。

## 实现

- 新增 `native_toolchain_status()`，报告 Android SDK 环境变量、ADB、iOS 平台和 `xcodebuild` 状态。
- `launcher/start.py --doctor` 增加三类信息提示：Rust/Cargo、Android SDK/ADB、iOS/Xcode。
- 原生工具链缺失仍属于信息级提示，不会加入阻塞问题。
- 在 `tests/test_launcher.py` 增加 Windows 无原生工具链场景的契约测试。

## 验证

已执行：

- `python -m pytest -q tests/test_launcher.py -k "doctor or release_check or verify_bundle or native_toolchain"`：7 passed
- `git diff --check`：通过
- `python launcher/start.py --doctor`：`Blocking issues: none`，`Result: READY`

当前机器的真实诊断为：开发工作区可用；Rust/Cargo、Android SDK/ADB、iOS/Xcode 未安装或不可用；原生安装包仍应在对应 release runner 上构建。

## 未验证事项

本轮没有声称完成真实 Windows 安装包构建、Android 真机安装或 macOS/iOS 签名构建；这些仍需要对应平台的 CI runner、SDK 与签名条件。
