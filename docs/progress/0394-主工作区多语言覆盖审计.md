# 0820 主工作区多语言覆盖审计

日期：2026-10-01

## 背景

EffiLife 已建立 zh-CN/en-US catalog。本轮复核统一应用壳、首页、PH、TD、主题设置和 locale registry，确认近期界面与数据整合变更没有重新引入用户可见硬编码文本。

## 审计范围

- 全局应用壳与导航；
- 首页三模块摘要和快捷操作；
- PH 计划中心；
- TD 任务中心；
- TH 主题设置和主题预设；
- locale registry、catalog key 覆盖和双语一致性。

## 验证

执行：

`python -m pytest -q tests/test_frontend_i18n.py tests/test_frontend_i18n_coverage.py tests/test_frontend_i18n_key_coverage.py tests/test_locale_registry.py tests/test_plan_center_i18n.py tests/test_todo_text_i18n.py tests/test_settings_theme_i18n.py`

结果：`25 passed`。

源码复核未发现新的主工作区用户可见硬编码文本缺口；主题、PH、TD 和统一壳均继续通过现有 catalog 契约。

## 未验证项

本轮未新增语言，也未进行真实移动设备字体、长文本和 RTL 视觉验收；后续语言扩展应继续遵循同一 registry/catalog 机制。
