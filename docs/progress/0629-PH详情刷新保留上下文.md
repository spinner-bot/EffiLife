# 1135 PH 详情刷新保留上下文

日期：2026-10-05  
类型：实现报告

## 背景与目标

PH 详情页会响应跨窗口计划、归档和网络事件。此前详情刷新失败时会立即清空当前计划并返回列表，短暂网络故障会破坏用户正在查看的计划上下文。目标是让辅助刷新失败可恢复，同时保持 PH 仍以完整 Plan 为编辑单元。

## 实现与兼容性

- 外部刷新读取 `getPlanFull` 失败时保留最后一次有效的 `selectedPlan`；
- 设置详情刷新不可用状态，在详情页显示明确错误和重试入口；
- 重试成功后清除错误状态并恢复关联待办上下文刷新；
- 不改变计划、任务、嵌套组、日志、软删除编号或 PH/TD 边界；
- 修正旧测试契约，使其验证新的保留上下文行为。
