# 0885－Windows 安装器烟测脚本化

类型：T（安装与发布可靠性）  
日期：2026-10-13  
阶段：0  
执行者：Codex  
状态：已完成

## 1. 背景

此前 Windows NSIS 安装/卸载验收依赖一次性手工命令。产品级发布流程需要可复用、有限时、隔离目标目录的验收入口，且不能误操作用户现有安装。

## 2. 实施内容

- 新增 `scripts/smoke_windows_installer.py`；
- 强制要求显式安装器和目标目录；
- 默认拒绝已存在目标目录和根目录等宽泛路径；
- 对安装器和卸载器分别设置超时；
- 校验桌面主程序、PH sidecar 和卸载器均已安装；
- 卸载后等待并确认隔离目录被移除；
- 增加脚本隔离性、超时和产物检查契约测试。
- 将 Windows 生命周期烟测接入桌面发布 workflow，位于安装器构建/签名之后、产物清单校验之前；非 Windows 构建矩阵不会执行该步骤。
- 烟测支持通过 `--version-file` 校验 NSIS 文件名版本与仓库版本一致，发布 workflow 已启用该校验。

## 3. 实际验证

- 执行：`python scripts/smoke_windows_installer.py --installer time-helper/desk/src-tauri/target/release/bundle/nsis/EffiLife_1.7.0_x64-setup.exe --target .validation/windows-installer-smoke-1.7.0`；
- 安装器退出码：`0`；
- `efflife-desk.exe`、`efflife-plan-helper.exe`、`uninstall.exe`：全部存在；
- 卸载器退出码：`0`；
- 隔离安装目录：已移除；
- 脚本契约测试：2 passed。

## 4. 验证边界

本次验证是当前版本安装/卸载烟测，不替代跨版本覆盖升级、代码签名、真实用户设备权限和 Android 真机迁移验收。脚本默认拒绝已有目标目录，不会触碰用户已有安装目录。

阶段保持第 0 阶段，iOS 继续按项目决策暂缓。
