# TD 兼容入口真实空状态实现

## 实现内容

- 删除 `to-dos/ui` store 中的示例待办和示例业务分类。
- 首次状态改为空待办集合，并保留一个系统默认分类供新建待办使用。
- 读取历史 `to-dos-data` 时继续保留用户已有待办和分类；空分类数据会补回默认分类，避免新建表单失去可用归属。
- 增加静态契约测试，防止示例数据重新进入兼容入口。

## 验证结果

- `npm run build`（`to-dos/ui`）：通过，`vue-tsc` 和 Vite 均成功，1767 个模块转换。
- 定向测试：4 passed。
- 全量 Python 测试：500 passed。

## 边界

这项修改只影响独立 TD 兼容 UI 的首次状态，不改变 TD 数据模型、导入导出格式、优先级算法，也不把 PH 的整份计划实体与 TD 合并。
