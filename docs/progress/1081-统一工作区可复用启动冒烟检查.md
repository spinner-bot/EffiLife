# 1081 统一工作区可复用启动冒烟检查

## 背景

统一工作区已经完成过一次手工冷启动验收，但手工启动、访问两个地址、停止进程的流程不适合后续发布机和升级验收重复使用，也容易误操作已有服务。

## 本次调整

- 新增 `python scripts/smoke_startup.py`。
- 启动前检查配置的前端和 plan-helper 端口，发现已有服务时直接失败，不接管外部进程。
- 使用统一启动器的 `--no-browser` 路径启动工作区。
- 分别验证 EffiLife 前端身份和 plan-helper 健康身份/状态。
- 无论成功或失败都回收本次启动的进程树，并确认两个端口释放。
- 输出机器可读 JSON，支持 `EFFILIFE_SMOKE_TIMEOUT` 配置超时时间。

## 边界

这是开发工作区的只读冒烟检查，不替代 Tauri 安装包、升级迁移、移动设备和签名验收；不会修改业务数据，也不会接管已有服务。

## 验证

- 通过脚本契约测试、真实执行、全量 pytest 和桌面生产构建后提交。
