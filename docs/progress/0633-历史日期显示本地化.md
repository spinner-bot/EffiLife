# 1139 历史日期显示本地化

日期：2026-10-05  
类型：实现报告

## 背景与目标

TH 历史详情页标题此前直接显示内部 ISO 日期字符串，显示层没有遵循当前语言和日期格式约定。统一数据仍需使用 `YYYY-MM-DD` 作为稳定键，但用户界面应显示本地化的年月日，并明确使用两位月份和两位日期。

## 实现与兼容性

- 在 `DayDetailView` 增加显示层日期计算值，使用当前语言的 `Intl.DateTimeFormat`；
- 内部路由参数、记录存储键和数据读取仍保持 ISO 日期，不改变数据协议；
- 非法日期保留原始字符串作为可诊断回退；
- 不新增日历入口，也不改变 TH/PH/TD 模块边界。
