# 0914 TD 待办本地搜索

日期：2026-10-02

## 背景

TD 的基本单元是单条快速待办，适合处理短小事项。待办数量增加后，仅按状态和分类浏览仍不够快捷，用户需要在 TD 自己的工作区中直接定位事项。

## 本次迭代

- 增加 TD 本地即时搜索框。
- 搜索标题、描述和标签。
- 保留现有状态筛选、分类筛选、优先级排序和批量操作。
- 搜索仅作用于 TD 已加载数据，不把 PH 计划任务并入 TD 列表。
- 增加中英文文案、响应式输入样式和契约测试。

## 验证

- `python -m pytest -q tests/test_td_search_contract.py`
- `npm run build`
