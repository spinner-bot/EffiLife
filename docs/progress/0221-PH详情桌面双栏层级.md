# 0622-PH 详情桌面双栏层级

## 背景

HOTL 1 号评估要求桌面端充分利用横向空间，并按层级组织页面。PH 详情页原先将计划摘要、执行日志、章节与任务全部纵向排列，长计划中定位上下文成本较高。

## 实现

- 详情页拆分为摘要/执行日志侧栏与章节任务主栏。
- 1100px 以上使用双栏布局；较窄窗口和移动端自动回到单栏，保留原有任务操作顺序。
- 未改变 PH `Plan`、章节、任务、分组或日志数据结构，仅改变布局容器。
