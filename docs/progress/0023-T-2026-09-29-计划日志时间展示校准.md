# 计划日志时间展示校准

## 背景

Plan Helper 使用 `[99, 99]` 表示日志时间没有精确记录，这是原始数据结构的一部分，不能改成普通时刻。统一工作台此前直接拼接小时和分钟，导致用户看到 `99:99`。

## 调整

- 在统一计划工作台增加展示层格式化函数。
- 遇到 `99` 标识时显示“时间未记录 / Time not recorded”。
- 正常时间仍按两位小时、两位分钟显示。
- 不改变 Plan Helper 原始存储、编号或日志数据结构。
