# 0659-首页时间概览交互语义

## 背景

首页时间概览卡片原本将整个统计区域声明为可键盘激活的按钮，但无计划时的空状态内部还包含独立操作。这样的嵌套交互会造成焦点语义冲突，也使桌面端用户难以判断真正的导航入口。

## 目标与范围

- 保留时间统计、完成度环形图、分类进度条和空状态内容。
- 将进入今日时间工作台的动作收敛到标题行按钮。
- 保持原有 `/time` 路由和首页数据逻辑不变。
- 与首页计划概览采用一致的可访问性语义。

## 实现

- 外层统计容器改为普通 `section`，移除 `role="button"`、`tabindex` 和手工键盘事件。
- 标题行改为明确的 `button`，补充方向图标及焦点样式。
- 保留无计划空状态的独立 `EmptyState` 操作，避免出现嵌套按钮。
- 更新入口契约测试，验证按钮类型、样式语义和 `/time` 导航仍然存在。

## 兼容性

不改变今日计划统计、分类进度计算、空状态文案或路由；仅调整焦点范围和导航入口的表达方式。
