# 0863－TH 记录写入按日期串行化

类型：T（统一数据一致性）  
日期：2026-10-12  
阶段：0  
状态：已完成

## 1. 问题

TH 记录采用“读取某日数组—修改—写回”的数据结构。统一工作区、历史日详情、开放 API 和 TD 用时追踪都可能进入这条路径。多个入口快速操作时，如果同时读取到同一份旧数组，后完成的写入会覆盖先完成的修改。

## 2. 实现

- 在 `DataService` 增加按日期维护的记录写入队列。
- `saveRecord`、`deleteRecord`、`deleteRecordById`、`updateRecord` 统一进入该队列。
- 同一天的读改写操作按提交顺序执行；不同日期仍可并行，避免无关日期互相阻塞。
- 队列中的失败不会阻断后续操作；当前调用方仍能收到原始错误并显示失败反馈。
- 记录删除后的 TD 反向关联清理仍在同一日期写入操作中执行，既有可恢复清理策略保持不变。
