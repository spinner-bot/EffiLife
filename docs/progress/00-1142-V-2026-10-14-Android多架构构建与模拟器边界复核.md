## 三、模拟器边界

本机 `adb devices -l` 没有连接设备。尝试使用 Android 36 x86_64 镜像创建临时 AVD 时，`avdmanager` 报告 SDK XML 版本不匹配并认为 system image package path 无效；当前 SDK 目录只有不完整的镜像元数据，未形成可启动 AVD。

因此本次完成了 x86_64 发布架构构建和 APK 级验收，但未宣称完成 Android 模拟器安装、启动和交互验收。后续需要重新安装完整 system image/匹配版本 command-line tools，或接入真实设备。
