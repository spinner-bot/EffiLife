# 存档导入跨窗口语言同步实现

## 实现内容

- i18n 新增 `refreshLocaleFromStorage()`，从共享存储读取受支持语言并更新响应式 locale 与文档语言属性。
- 应用壳在收到 `archive` 工作区事件时同步语言，再刷新共享数据。
- 窗口重新可见时也同步一次语言，覆盖广播不可用或被系统挂起的场景。
- 保留导入当前窗口的 reload 行为，保证主题、配置和 Plan Helper 状态完整重新初始化。

## 验证

- i18n 与跨窗口工作区定向测试：13 passed。
- 桌面端生产构建：通过，1874 个模块转换。
- 全量 Python 测试：504 passed。

## 边界

只同步存档已经持久化的语言设置，不自动改变用户语言，也不修改 `.efl` 格式；不支持的 locale 会被现有 `readLocale()` 逻辑安全回退。
