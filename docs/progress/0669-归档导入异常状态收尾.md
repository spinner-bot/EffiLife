# 0669：归档导入异常状态收尾

## 背景

统一归档导入涉及预览、确认、数据写入和跨模块刷新。此前浏览器文件选择路径和 Tauri 原生对话框路径在写入阶段发生未预期异常时，可能遗漏复位 `archiveBusy`，导致设置页按钮永久保持禁用状态。

## 实现

- 为 Tauri 原生导入路径增加 `try/catch/finally`。
- 为浏览器文件导入的实际写入阶段增加 `try/catch/finally`。
- 异常统一使用当前语言的导入失败提示，并确保忙碌状态一定复位。
- 增加静态回归测试覆盖两条导入路径。

## 兼容性

- 不改变归档格式、预览确认、数据校验、回滚或跨模块通知逻辑。
- 成功导入仍按原流程刷新页面；取消导入仍不产生错误提示。
