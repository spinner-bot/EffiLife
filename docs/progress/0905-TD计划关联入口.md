# TD 计划关联入口

日期：2026-10-02

## 背景

HOTL 一号规范要求 PH 与 TD 保持不同职责，但允许统一软件在模块之间建立清晰的协作入口。TD 数据已经保存计划和计划任务引用，任务列表此前没有展示或消费这些引用。

## 目标与范围

在 TD 列表中展示已有 PH 关联，并支持跳转到对应计划/任务；不把 PH 数据写入 TD，不改变 TD 的独立存储和任务算法。

## 实现

- 增加只读的“关联计划 · 任务编号”入口。
- 跳转时携带 `plan` 与可选的 `task` 查询参数，复用 PH 工作台已有深链。
- 增加中英文文案和契约测试。

## 兼容性

没有关联计划的待办保持原有显示；只有 `related_plan_id` 的旧数据也可以跳转，缺失任务引用时不构造虚假任务编号。
