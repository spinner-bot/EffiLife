# 0631-重复 PH ID 界面引用优先级

## 背景

PH 的数字 ID 可能在不同生命周期中重复。首页和 TD 中同时展示活动计划与归档计划时，原有对象合并顺序会让归档名称覆盖活动计划，并给仍然有效的 TD 错误加上“已归档”标记。

## 实现

- 计划名称索引先收集归档，再收集活动计划，使活动计划拥有同 ID 下的显示优先级。
- 归档标记排除当前仍存在的活动计划 ID。
- 首页与 TD 中心保持相同的优先级规则，避免跨页面认知不一致。
