# 0637-桌面归档 TD 关联元数据贯通

## 背景

桌面端 PH 归档发生 ID 冲突时会重新编号，但此前归档文件没有记录关联 TD，恢复后无法安全迁移 TD 关联；移动端已有同类机制。

## 实现

- 桌面端归档 API 接收并保存 TD ID/任务索引元数据。
- 归档列表暴露关联 TD ID，恢复响应返回原计划 ID和关联元数据。
- 前端恢复时仅迁移归档时记录且当前仍指向旧计划的 TD，避免误改用户后来调整的关联。
- 桌面端与移动端保持相同的“原 ID 空闲则保留、冲突则重编号并迁移明确关联”规则。

## 验证

- PH 原始归档元数据往返及 ID 冲突恢复测试。
- 移动端/桌面端归档网关契约测试。
- 完整 Python 测试套件。
- 桌面端 TypeScript/Vite 构建。
