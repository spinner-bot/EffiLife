# 0673：TD 设置加载异常兜底

## 背景

TD 任务中心进入时会读取优先级刷新设置。该读取属于可恢复的本地工作区状态，但原实现没有异常边界，IndexedDB 暂时不可用时会产生未处理 Promise rejection。

## 实现

- 为 `loadTodoSettings()` 增加 `try/catch`。
- 读取失败时保留默认设置并显示本地化错误，不阻塞 TD 页面及 PH/TH 入口。
- 增加静态回归测试，锁定初始化读取的错误边界。

## 兼容性

- 不改变 TD 设置数据结构、更新频率或跨窗口同步事件。
- 不改变 PH 与 TD 的独立数据职责；仅改善 TD 初始化失败时的恢复行为。
