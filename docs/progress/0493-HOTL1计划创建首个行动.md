# 0493 HOTL1 计划创建首个行动

## 本次变更

- 修复统一计划工作台创建空 plan 的问题。
- 新建弹窗现在收集计划名称、日期、首个分组、分组说明、首个任务和预计分钟数。
- 创建请求直接传递一个有任务的 `InitialPlanSection[]`；移动端继续沿用同一请求形状转换为原始 plan 快照。
- 创建弹窗提供默认关闭的“同时生成待办”选项，复用已有双向关联逻辑，避免产生重复待办。
- 打开或取消创建弹窗时清理草稿，日期默认重置为当前日期。
- 保留创建成功后进入详情编辑器的流程，用户仍可继续编辑嵌套分组、任务、日志和待办关联。
