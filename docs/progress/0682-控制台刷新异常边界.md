# 0682：控制台刷新异常边界

## 背景

首页每分钟刷新 TH 统计，日期详情页首次加载时间记录和日计划；原调用均可能在存储读取失败时产生未处理 Promise rejection，影响统一应用壳的稳定性。

## 实现

- 为首页定时统计刷新增加 warning 兜底。
- 为日期详情首次数据加载增加 warning 兜底。
- 不回滚已有数据或改变 PH、TD、TH 的读取和关联逻辑。
- 增加回归测试锁定两个页面的异步边界。

## 兼容性

- 不改变首页控制台摘要、日期详情和统一存档协议。
- 不改变模块独立职责或主题架构。
