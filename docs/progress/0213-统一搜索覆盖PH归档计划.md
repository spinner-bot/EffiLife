# 0614｜统一搜索覆盖 PH 归档计划

## 背景

统一搜索已经覆盖 TD、TH 记录、PH 活动计划和 PH 任务，但已归档 PH 计划只能从计划中心的归档列表进入。归档计划仍属于用户的工作资料，应该保持统一工作台中的可发现性。

## 实现

- GlobalSearch 加载 `listPlanArchives()`，新增“已归档计划”结果类型。
- 归档结果复用 `/plans?plan=<id>` 深链接，进入计划中心后显示归档目标和恢复入口。
- 移动端与桌面端均复用同一计划网关，因此本地快照归档也能被搜索。
- 增加中英文搜索标签和契约测试。

## 兼容性

活动计划、PH 任务、归档计划仍使用不同搜索结果类型和来源标签；归档计划不会被误当作活动计划，也不会改变 TD 的独立定位。
