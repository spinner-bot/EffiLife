# 路由切换主内容焦点

日期：2026-10-02

## 背景

统一应用壳已提供 Skip to main content，但通过导航切换页面后焦点仍停留在顶部导航，辅助技术用户需要再次手动寻找新页面内容。

## 实现

- 为主内容容器绑定模板引用。
- 监听 `route.path` 的实际变化，在页面渲染完成后将焦点移至主内容。
- 不监听查询参数变化，避免计划任务、归档或记录深链更新时打断当前焦点。

## 兼容性

仅影响路径导航后的键盘/辅助技术焦点；不改变路由、滚动位置、查询参数、模块数据或移动底栏行为。
