# 1173 首页不可用摘要卡原地重试

日期：2026-10-09  
类型：实现报告

## 背景

首页统一工作流摘要同时展示 TH、PH、TD 三个模块，但服务暂时不可用时，摘要卡的点击行为仍会直接跳转到模块页面。用户需要返回首页下方的详细卡片才能找到重试入口，三模块摘要的行为也不一致。

## 目标与非目标

目标是让首页摘要卡在不可用状态下直接触发对应模块的重试；数据正常时继续作为模块深链入口。非目标是修改三模块数据结构、改变 PH/TD 边界或处理主题持久化问题。

## 影响范围

- `time-helper/desk/src/views/HomeView.vue`：统一摘要卡点击行为。
- `tests/test_home_workflow_summary.py`：增加不可用状态重试契约。
- TH、PH、TD 数据集与路由协议不变。

## 实现与兼容性

新增 `openWorkflowSummary`：TH 时间统计和 TD 待办摘要不可用时在首页重试；PH 在桌面端计划服务不可用时重试，移动端仍保留进入本地计划工作区的行为。数据可用时三张卡仍分别进入 `/time`、`/plans`、`/tasks`，既有深链和旧数据无需迁移。

## 验证

- `python -m pytest -q tests/test_home_workflow_summary.py tests/test_home_module_degradation_copy.py`：17 passed。
- `npm run build`（工作目录 `time-helper/desk`）：通过；`vue-tsc` 通过，Vite 转换 1877 个模块并在 14.04s 完成构建。
