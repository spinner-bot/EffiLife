# 兼容计划入口两阶段创建

## 背景

对原始需求进行跨入口审计时发现，统一工作台已经支持空计划两阶段创建，但 `plan-helper` 兼容 Web 入口仍在创建弹窗中预置空章节和任务，且编辑器是窄弹窗，造成两个入口的行为不一致。

## 本次变更

- `plan-helper` 创建动作只初始化名称、日期和空 `sections`。
- 创建弹窗移除章节、任务和分钟输入，仅保留名称、日期及流程提示。
- 计划创建成功后继续打开现有编辑流程，用户从空计划开始添加章节与任务。
- 旧版编辑器改为占满视口的可滚动编辑工作区，保留原有 API、任务编号和嵌套组数据语义。
- 为兼容入口补充对话框语义与 Esc 关闭支持。
- 新增两阶段创建静态契约测试。
