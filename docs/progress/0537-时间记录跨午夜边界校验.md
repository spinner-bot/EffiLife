# 1043 时间记录跨午夜边界校验

日期：2026-10-02

## 问题

记录页面的“按时长添加”模式允许从接近午夜的时间开始计算，并将结束时间绕回当天 00:00 后。由于时间记录按单日时间轴保存，随后用结束分钟减开始分钟会得到负时长，造成数据错误。

## 实现

- 以单日时间轴为约束，在“参考时间为开始”和“参考时间为结束”两种模式分别校验是否跨越午夜。
- 跨午夜时阻止保存，并提示用户拆分为两条记录。
- 增加中英文本地化提示。
