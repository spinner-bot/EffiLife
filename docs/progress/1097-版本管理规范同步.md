# 1097 版本管理规范同步

## 背景

`docs/spec/版本管理规范.txt` 的当前版本和 tag 示例停留在早期版本，而模块版本文件、README 和发布配置已经推进到更高版本。规范滞后会使版本发布检查和人工操作产生错误依据。

## 调整

- 将规范中的当前版本同步为：time-helper `1.7.0`、plan-helper `0.5.1`、to-dos `0.5.0`。
- 将 tag 示例同步为对应模块版本。
- 新增版本规范契约测试，读取实际 `VERSION` 文件后校验规范内容，防止再次漂移。

## 验证

- 本次新增 `tests/test_version_spec_current.py`。
- 发布配置和模块版本文件继续作为实际版本来源；本规范不替代 CI 的 tag 校验。

## 边界

本次只同步规范和校验，不修改任何模块版本号，不创建 release tag，也不改变发布工作流。
