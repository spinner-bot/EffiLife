# 1046 PH 创建计划弹窗键盘可访问性修复

日期：2026-10-02

## 问题

PH 创建计划弹窗虽然已有打开时聚焦计划名称、Esc 关闭和关闭后恢复触发焦点，但没有限制 Tab 焦点范围。键盘用户可以从模态层跳到被遮罩的列表页面。

## 实现

- 为创建计划表单增加稳定的弹窗 ref。
- 增加 Tab/Shift+Tab 焦点循环。
- 将 Esc 处理统一收口到弹窗键盘处理函数，避免多个关闭路径行为不一致。
- 保留遮罩点击、取消按钮、创建成功后的焦点恢复逻辑。

## 验证

- PH 创建流程与桌面布局专项测试：`35 passed`。
- Python 全量测试：`800 passed in 7.68s`。
- 桌面前端生产构建：`vue-tsc` 通过，Vite 完成 `1877 modules transformed`，构建成功。

## 影响范围

仅改善 PH 创建弹窗的键盘交互，不改变计划数据结构、初始内容收集、嵌套分组或 PH/TD 模块边界。
