# PH 任务深链失效提示

日期：2026-10-09

## 背景

TD 中的待办可以通过 `related_plan_id` 与 `related_plan_task_id` 返回 PH。若目标计划任务后来被归档、软删除或旧快照不再包含，PH 仍会打开计划，但此前没有任何反馈，用户无法判断是链接失效还是页面加载失败。

## 目标与非目标

目标是保留计划工作区的可用性，同时明确提示目标任务无法定位。

本次不把 TD 任务合并进 PH，不恢复已删除任务，不修改 PH 数据，也不把提示当作错误阻断计划编辑。

## 实现

- `PlansHubView.vue` 增加 `missingTaskTargetId` 状态。
- 深链目标任务不存在时，保留已打开的计划并显示 `plans.taskTargetMissing` 非阻塞状态提示。
- 计划切换、无任务深链和归档预览会清理旧提示。
- 中文与 English catalog 均增加对应插值文案。

## 兼容性

仍兼容内部任务 ID 和显示 ID 两种深链；正常目标仍执行滚动高亮。PH/TD 职责边界不变。
