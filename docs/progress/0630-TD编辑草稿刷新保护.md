# 1136 TD 编辑草稿刷新保护

日期：2026-10-05  
类型：实现报告

## 背景与目标

TD 工作台会响应统一工作区的待办、记录、归档和网络事件。若用户正在编辑一条待办，此时外部刷新直接替换 `todos` 列表，会让未保存的编辑草稿从界面消失。目标是保护 TD 自身的编辑上下文，同时保留跨模块刷新能力。

## 实现与兼容性

- 检测 TD 行内编辑状态，在编辑期间延后工作区列表刷新；
- 使用待刷新标记合并多个外部事件，避免反复读取；
- 用户取消或保存编辑后自动执行延后的待办列表和分类刷新；
- 不改变 TD 数据结构、PH 关联字段、TH 时间记录关联或模块生命周期边界。
