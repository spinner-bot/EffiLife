# [阻塞] Android 模拟器环境修复边界

- 创建时间：2026-10-14
- 执行者：Codex
- 触发原因：x86_64 APK 已构建成功，但本机 Android 36 x86_64 system image 目录只有 `.installer` 元数据，无法创建 AVD。

## 检查结果

- `adb devices -l`：无设备
- `avdmanager create avd`：失败
- SDK manager：`12.0`，提示只能理解 SDK XML 1–3，而本机存在 XML 4；目标 system image package path 被判定为无效
- system image 目录：没有有效 `system.img` 等镜像内容，仅存在 `.installer`

## 尝试修复

尝试通过：

```text
sdkmanager --sdk_root=F:\dev-tools\android-sdk --install system-images;android-36;google_apis;x86_64
```

但命令长时间无输出，目录没有增长，输入管道已关闭，判断为当前 command-line tools 与 SDK 元数据版本不匹配或下载挂起。已停止这组精确识别的 sdkmanager 进程，未留下后台安装任务；没有删除任何已有 SDK 内容。

## 当前结论

x86_64 APK 构建和 APK 级校验已经完成，但 Android 模拟器真实安装、启动和交互仍不可验收。后续需要升级匹配版本的 Android command-line tools，并重新完整安装 system image，或接入真实 Android 设备。
