# 0817 统一应用壳边界复核

日期：2026-10-01

## 背景

HOTL-1 要求三个模块在统一应用壳内协作，但不能把 PH、TD、TH 合并成同一种实体；同时要求主界面不再提供日历功能入口。本轮针对路由、全局导航和首页深链进行了复核。

## 当前架构证据

- `/plans`：PH 完整计划工作区；
- `/tasks`：TD 单条快速待办工作区；
- `/time`：TH 时间工作区；
- 首页同时显示三个模块摘要，并分别提供深链；
- `/calendar` 仅作为旧书签兼容重定向到 `/records`，不出现在全局导航或首页主入口；
- PH/TD/TH 仍通过各自服务和数据模型协作，未合并实体语义。

## 验证

- `python -m pytest -q tests/test_home_module_identity.py tests/test_home_navigation_deduplication.py tests/test_module_boundaries.py tests/test_unified_plan_workspace.py tests/test_home_workflow_summary.py`：21 passed；
- 当前路由与 `App.vue` 全局导航源码复核通过。

## 结论与边界

统一应用壳的职责边界符合 HOTL-1。该复核不替代真实桌面/移动设备的视觉验收，也不改变旧 `/calendar` 链接的兼容行为。
