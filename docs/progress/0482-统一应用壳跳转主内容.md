# 统一应用壳跳转主内容

日期：2026-10-02

## 背景

统一应用壳在桌面端有顶部导航、移动端有固定底栏。键盘和辅助技术用户进入页面时必须重复经过导航，且页面缺少明确的主内容 landmark。

## 实现

- 增加中英文 Skip to main content 链接。
- 为路由内容增加 `main#main-content` 语义容器，并允许跳转后获得焦点。
- 使用主题变量提供可见焦点样式，不改变各模块页面结构和路由。

## 兼容性

不改变导航顺序、路由、数据模型或移动底栏布局；普通鼠标用户不会看到常驻跳转链接。
