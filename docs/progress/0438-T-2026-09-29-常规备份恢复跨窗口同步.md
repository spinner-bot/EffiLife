# 常规备份恢复跨窗口同步

## 背景

统一工作台已经为计划、待办、记录、存档和设置建立跨窗口刷新事件，但常规备份恢复路径只写 IndexedDB，不广播变化。用户在一个窗口恢复配置或记录后，其他已打开窗口可能继续显示旧状态。

## 本次变更

- 为常规备份恢复建立模块到工作区事件的映射：配置→设置，计划/规则→计划，记录→记录。
- 恢复成功后发送一次对应的 `workspace-changed` 事件，复用现有同窗口 CustomEvent 与跨窗口 BroadcastChannel。
- 未知或历史模块备份不发送错误刷新事件，保持兼容恢复行为。
- 新增静态契约测试。

## 验证

- 新增契约测试：2 passed。
- 全量 Python 测试：333 passed。
- 桌面端 `vue-tsc && vite build`：通过，1874 个模块完成构建。
