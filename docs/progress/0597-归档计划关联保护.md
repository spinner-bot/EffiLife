# 0597｜归档计划关联保护

## 背景

PH 的归档是可恢复操作：归档计划会从活动 registry 移出，但仍保存在 archive 文件中。此前启动时的 TD–PH 关联修复器会把“计划不在活动摘要列表”转换为空任务集合，继而解除所有关联。这会让归档计划恢复后无法自动恢复其待办关联，也可能把服务暂时不完整的索引误判为删除。

## 实施

- 活动计划摘要中找不到计划时，不再做破坏性清理。
- 只有成功读取到具体计划的任务列表后，才根据任务 ID 判断关联是否确实失效。
- 保留离线 cache 保护：缓存不完整时完全跳过修复。
- 增加回归断言，禁止恢复“缺失计划即空任务集合”的逻辑。

## 数据语义

这是“宁可暂时保留待确认关系，也不主动丢失可恢复关系”的策略。计划真正恢复并可读取任务后，修复器仍能清理明确不存在的任务关联；用户也可以在 TD 中手动解除保留的关联。
