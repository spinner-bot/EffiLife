# 1178 TH 新记录同步 TD 累计用时

日期：2026-10-09  
类型：实现报告

## 背景

TH 的记录表单可以关联 TD 待办，但此前只写入 `related_time_record_ids`，没有像 TD 的“记录用时”入口一样累计 `time_spent`。因此同一待办从两个入口记录相同时间时，列表中的累计用时不一致。

## 目标与非目标

目标是让 TH 新建记录与 TD 的累计用时保持一致，并避免编辑同一条记录重复累计。非目标是改变删除记录保留历史累计的既有语义、合并 TH/TD 实体或修改 PH 关系字段。

## 实现

- 新建记录或把已有记录改为关联新 TD 时，调用 `TodoService.trackTime`，以记录时长换算的正整数分钟和记录 ID入参。
- 编辑仍关联同一 TD 的记录时，只补齐缺失的反向记录 ID，不重复增加 `time_spent`。
- 更换 TD 时保留旧 TD 的历史累计，并为新 TD 建立一次幂等累计。
- 失败仍沿用现有保存成功、关联同步失败的反馈，不回滚已保存的 TH 记录。

## 兼容性

使用既有 `trackTime` 服务和记录 ID 去重逻辑，不增加数据字段，不改变 `.efl` 存档协议；旧记录在下次编辑/重新关联时按新规则处理。
