# 00-1183-T-2026-10-14 PH 模板创建草稿放弃保护

## 类型与阶段

## 背景

PH 的“新建计划”已经具备未保存草稿保护，但“从模板创建”同样包含计划名称、日期和模板选择。关闭该工作区时若直接丢弃填写内容，会形成同类入口交互不一致并造成数据丢失风险。

## 实现内容

- 为模板创建草稿增加脏状态判断：名称、日期或模板选择发生变化时视为已编辑。
- 单模板自动选择作为初始状态，不会在用户尚未编辑时误弹确认。
- 通过取消按钮关闭时复用统一的放弃确认弹窗。
- 创建成功后使用强制关闭路径，避免重复确认并清理草稿状态。
- 保持既有计划数据结构、模板创建 API 和路由行为不变。
