# 1074 启动器诊断中文路径输出修复

日期：2026-10-02

## 问题

`launcher/start.py --doctor` 可以正确报告统一工作区、Plan Helper 和安装包状态，但 Windows 控制台使用非 UTF-8 默认编码时，包含中文目录的安装包路径会显示为乱码，降低诊断信息的可复制性。

## 实现

- 启动器启动时尝试将标准输出和标准错误流切换为 UTF-8。
- 仅对支持 `reconfigure` 的流执行切换；嵌入式宿主和测试捕获流不支持时安全保留原编码。
- 输出内容、退出码和诊断 JSON 协议不变。

## 验证

- 增加 `test_launcher_console_encoding.py` 契约测试。
- 后续执行全量测试与桌面构建。
