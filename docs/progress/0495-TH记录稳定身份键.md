# 0921 TH 记录稳定身份键

日期：2026-10-02

## 背景

TH 记录列表此前使用数组下标作为渲染 key。跨窗口刷新、存档导入或记录增删导致排序变化时，Vue 可能复用错误的列表行 DOM，造成编辑状态、焦点或高亮错位。

## 本次迭代

- 记录存在稳定 `id` 时优先使用该 ID。
- 兼容历史无 ID 数据，使用日期、起止时间和下标组成回退 key。
- 不改变记录存储结构和既有删除/编辑语义。
- 增加稳定身份键契约测试和进展文档。
