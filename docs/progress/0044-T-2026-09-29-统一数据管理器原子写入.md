# 0442｜统一数据管理器原子写入

日期：2026-09-29  
类型：T（数据可靠性）  
范围：`common/data_manager.py`

## 背景

统一 `.efl` 存档协议已经采用临时文件和原子替换，但 DataManager 写入跨模块引用、全局备份和模块目录注册时仍直接覆盖 JSON 文件。三大模块的关联索引属于统一数据边界，不能因为中断写入而留下半截文件。

## 本次变更

1. 新增同目录临时文件写入工具，写入后 `flush`、`fsync`，再通过 `os.replace` 原子替换目标。
2. `references.json`、全局备份和 `module_dirs.json` 统一使用该工具。
3. 异常时清理临时文件，不改变既有目录、字段和引用语义。
4. 增加写入契约与引用重载回归测试。
