# 1157 TH 删除记录清理 TD 反向关联

日期：2026-10-05  
类型：统一数据边界完整性修复

## 背景与问题

页面删除 TH 记录时已有 TD 反向关联清理，但底层 `DataService.deleteRecord` 和 `deleteRecordById` 也可被 API、回滚流程或其它入口直接调用。直接调用时可能删除了 TH 记录，却留下 TD 的孤立 `related_time_record_ids`。

## 实现

- 在数据服务边界增加 TH 记录删除后的 TD 反向引用清理。
- 同时覆盖按索引和按稳定记录 ID 删除路径。
- 清理失败只记录警告，不阻断 TH 记录的权威删除；后续工作区修复流程仍可补偿。
- 保留页面层清理逻辑，兼容已有调用路径。

## 提交与边界

代码与报告直接提交到 `main`，不创建分支。TH 历史记录仍按用户操作删除，TD 独立待办不会被删除，只清除失效的反向记录 ID。
