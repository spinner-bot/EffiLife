# [完成] 统一工作台全路径浏览器验收

- 创建时间：2026-10-14
- 执行者：Codex
- 触发原因：启动链路烟测通过后，继续验证真实浏览器中的核心产品路径和错误恢复能力。

## 一、验证范围

在启动器提供的统一工作台和 Plan Helper 服务上，使用 Playwright 执行桌面与移动视口组合烟测，覆盖：

- TH、PH、TD 的独立入口与工作台摘要
- TH 快速记录、记录持久化和焦点快捷键
- PH 创建带内容计划、编辑计划、PH-TD 联动和完成状态同步
- TD 快速创建、完成、焦点会话和跨窗口状态
- 主题选择、25 个主题矩阵、多语言持久化
- `.efl` 存档导出/导入往返、移动分享路径
- 无效存档恢复、存档写入失败恢复、IndexedDB 启动失败恢复
- 首次引导流程与移动端引导流程
- 全局搜索和移动端搜索深链
- 桌面核心路由与移动导航、确认弹窗键盘可访问性

## 二、验证结果

完整组合命令：

```text
python scripts/smoke_browser_workspace.py --url http://127.0.0.1:1420 \
  --archive-roundtrip --ph-plan-flow --mobile-ph-plan-flow \
  --td-task-flow --td-focus-flow --th-record-flow \
  --mobile-archive-share-flow --onboarding-flow \
  --mobile-onboarding-flow --startup-recovery-flow \
  --archive-invalid-flow --archive-write-failure-flow \
  --global-search-flow --mobile-search-flow --theme-matrix-flow
```

结果：`ok: true`。所有启用的功能路径均为 `true`，主题矩阵发现 25 个主题；桌面统一前端、`/time`、`/plans`、`/tasks`、`/records`、`/settings` 均正常渲染。

单独执行存储写入故障注入：

```text
python scripts/smoke_browser_workspace.py --url http://127.0.0.1:1420 --inject-write-failure
```

结果：`ok: true`，`storage_write_failure_handled: true`。

## 三、环境清理

测试结束后发现启动器父进程退出时仍有两个 EffiLife 子进程监听 1420 和 8765。根据命令行确认其分别属于项目 Vite 与 Plan Helper 服务后，按 PID 精确回收；最终两个端口均已释放。

这不影响本次功能路径结果，但说明启动器的 Windows 进程树回收仍有进一步加固空间，应作为后续发布可靠性工作处理。

## 四、结论与边界

当前统一工作台的核心桌面/移动用户路径、模块联动、存档和主要错误恢复已经获得真实浏览器证据。Android 真机交互、正式签名安装包和跨版本升级仍属于未完成边界。
