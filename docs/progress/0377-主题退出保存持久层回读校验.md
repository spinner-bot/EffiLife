# 0802 主题退出保存持久层回读校验

## 变更

主题设置继续采用“编辑时预览、离开时确认保存”的交互，不增加主题保存按钮。保存流程现在在写入 IndexedDB/localStorage 完成后，立即通过启动时使用的 `DataService.loadConfig()` 回读并比对主题对象。

## 目的

避免内存预览已经更新、但退出或重新加载时仍读取旧主题快照的情况。若回读结果不一致，保存流程失败，编辑页保持当前状态，用户不会在未确认的情况下退出并丢失主题修改。

## 验证

- `tests/test_theme_persistence_contract.py` 增加持久层回读校验契约。
- 主题页仍不存在 `@click="saveTheme"` 保存按钮。
