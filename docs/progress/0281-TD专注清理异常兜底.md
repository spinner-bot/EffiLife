# 0683：TD 专注清理异常兜底

## 背景

离开 TD 任务中心时，应用会自动停止当前专注计时并写入关联时间记录。原卸载清理调用没有异常边界，写入失败时会产生未处理 Promise rejection。

## 实现

- 为卸载阶段的 `stopFocus()` 增加 catch 兜底。
- 写入失败只记录 warning，不阻塞页面切换或影响已存在的待办状态。
- 增加回归测试锁定任务中心清理边界。

## 兼容性

- 不改变专注计时、TD 数据模型或 TH 时间记录关联字段。
- 不改变 PH/TD/TH 独立职责。
