# 00-1159-T-2026-10-14 首页 TD 联动失败可重试

## 类型与阶段

T（技术实现）。当前仍为第 0 阶段；本报告只递增序列号，不增加阶段。

## 问题

首页直接完成一个与 PH 任务关联的 TD 时，系统先完成 PH，再写入 TD。若 TD 写入失败，PH 已完成但首页原先只显示同步错误，没有保留 TD 重试入口，用户需要转到其他页面恢复状态。

## 实现

- 首页记录 TD→PH 联动失败的待办上下文。
- 显示明确状态：“TD 已完成，但关联 PH 同步失败”或对应英文提示，避免误解同步结果。
- 在首页原位置提供重试按钮。
- 重试只补写失败的 TD/投影阶段，不重复执行已经成功的 PH 完成操作。
- 重试成功后刷新 PH 与 TD 摘要；失败时保留入口。
- 原有普通 TD 完成、空状态和加载状态逻辑保持不变。

## 边界

本轮修复首页交互逻辑，与 PH→TD 的已有重试入口形成双向一致的错误恢复体验；不改变 TH、PH、TD 的领域边界，也不把跨存储操作伪装成事务性写入。
