# [完成] TD 批量解绑补偿

## 背景

删除 TD 前会批量清除多个日期的 TH 记录 `todo_id`。此前批量写入按日期逐项提交，中途失败可能只解绑部分记录，使 TD、TH 关系进入半完成状态。

## 实现

- 预先建立所有受影响日期的 TH 快照。
- 所有日期的解绑写入成功后，才更新兼容镜像。
- 任一 IndexedDB 写入失败时，恢复本轮已经处理的全部日期，并向 TD 删除服务抛出异常。
- 保持历史 TH 记录不被删除，TD 删除仍由上层在解绑成功后执行。

## 验证

- TD/TH 批量解绑与删除专项：`14 passed`。
- 桌面端生产构建：Vite `1879 modules`，成功。
- 全量 Python 回归将在提交前执行。

## 边界

该路径仍是跨日期、多对象存储的补偿式操作，不宣称为 IndexedDB 多 store 原生原子事务；补偿失败会保留错误并交由恢复与启动修复机制处理。
