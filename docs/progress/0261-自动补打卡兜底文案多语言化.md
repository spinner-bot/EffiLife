# 0662-自动补打卡兜底文案多语言化

## 日期

2026-10-01

## 背景

统一工作台已支持中英文切换，但自动补打卡服务在缺少计划名称时仍直接写入中文兜底值。该值会进入打卡记录和事件上下文，在英文模式下造成用户可见的语言泄漏。

## 实现

- `CheckinSystem` 引入共享 `translate`，自动补打卡默认计划名改用现有双语事件标题。
- 新增 `settings.events.runtime.unknownPlan` 中英文目录键，未知计划兜底值随当前语言生成。
- 增加检查打卡兜底文案和双语目录完整性的契约测试。

## 兼容性

不改变打卡记录结构、日期计算、连续天数或自动补卡逻辑；已有显式计划名称原样保留，仅替换缺省文本。
