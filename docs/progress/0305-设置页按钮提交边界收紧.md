# 设置页按钮提交边界收紧

## 背景

设置页包含多个子页面、存档操作、重置操作和反馈操作。虽然这些控件当前大多不直接位于表单中，但未声明按钮类型会让后续布局复用或表单嵌入产生隐式提交风险，也会使交互语义不稳定。

## 本次处理

- 为设置页全部点击按钮显式声明 `type="button"`。
- 覆盖设置导航、主题操作、存档导入导出、重置、反馈和帮助入口。
- 保留自定义设置表单唯一的 `type="submit"` 保存动作。
- 增加跨行模板静态契约测试，确保后续新增点击按钮不会遗漏类型声明。

## 结论

设置页的导航和动作按钮不再依赖浏览器默认按钮类型，降低了页面组合时的意外提交风险，不改变任何业务流程。
