# 统一应用壳图标按钮可访问性

日期：2026-09-30

## 发现

统一工作台的主要导航已有 `aria-current` 语义，但部分通知、收件箱、音效和记录弹窗中的纯图标按钮只有视觉图标，屏幕阅读器无法识别其用途。

## 处理

- 为通知弹窗关闭按钮复用本地化通知关闭文案。
- 为首页收件箱打开/关闭按钮增加双语标签。
- 为音效试听、自定义音乐添加和移除按钮增加双语标签。
- 为记录编辑弹窗关闭按钮增加可读标签。
- 增加专项可访问性契约测试。

## 验证

- 可访问性专项测试：7 passed。
- 前端生产构建：`vue-tsc && vite build`，1874 个模块通过。
