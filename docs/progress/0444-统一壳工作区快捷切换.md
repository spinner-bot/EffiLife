# 0870 统一壳工作区快捷切换

## 背景

统一应用壳已经提供桌面主导航和全局搜索，但在桌面键盘工作流中，用户仍需回到导航栏点击才能在 TH、PH、TD 和记录工作区之间切换。

## 本次变更

- 增加桌面端 `Alt+1` 至 `Alt+5` 工作区快捷切换：
  - `Alt+1` 首页
  - `Alt+2` PH 事件计划
  - `Alt+3` TH 时间工作台
  - `Alt+4` TD 快速待办
  - `Alt+5` 时间记录
- 快捷键处理避开输入框、文本域、选择框和可编辑元素，不抢占用户输入。
- 移动端不依赖快捷键，保持现有触控导航。
- 只改变应用壳导航，不改变三个领域的数据结构、入口边界或同步规则。
