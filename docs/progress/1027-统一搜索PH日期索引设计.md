# 1027 统一搜索 PH 日期索引设计

## 日期

2026-10-02

## 背景

统一搜索已经覆盖 TH 记录、PH 活动/归档计划、PH 计划任务和 TD 待办，但活动 PH 计划及其任务的 `searchText` 没有包含计划日期。用户在计划中心可以按日期筛选，却无法在全局搜索中使用同一日期定位计划。

## 目标与非目标

- 目标：把活动计划和活动计划任务的计划日期加入全局搜索索引；归档计划继续保留文件名、编号和日期索引。
- 目标：保持结果类型、独立入口和深链接不变。
- 非目标：不将 PH 任务转换为 TD，不改变搜索排序算法或任何底层计划结构。

## 设计决策

使用现有计划日期元组的连字符形式（`YYYY-MM-DD`）加入 `searchText`。这样无需新增翻译键，且与计划中心的日期筛选输入保持一致；显示文案仍由各自模块负责。
