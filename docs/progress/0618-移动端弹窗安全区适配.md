# 1124 移动端弹窗安全区适配

日期：2026-10-05  
类型：实现报告

## 背景

统一工作台已提供移动端底部导航，但 TH 记录编辑、PH 计划编辑和计划中心创建弹窗的底部操作区没有统一使用系统安全区。在带 Home Indicator 的设备上，按钮可能贴近或被系统手势区域遮挡。

## 实现与兼容性

- TH `RecordsView` 的记录弹窗 footer 增加底部安全区；
- TH `PlanView` 的统一编辑弹窗 footer 增加底部安全区；
- PH `PlansHubView` 创建计划弹窗增加底部安全区；
- 使用 `max(原有间距, env(safe-area-inset-bottom))`，桌面端和无安全区设备保持原有间距；
- 不改变模块数据、路由和主题持久化逻辑。

## 实际验证

- `python -m pytest -q tests/test_mobile_modal_safe_area.py tests/test_ph_responsive_layout.py tests/test_records_desktop_layout.py tests/test_td_desktop_workbench_layout.py` → `9 passed`；
- `python -m pytest -q` → `877 passed`；
