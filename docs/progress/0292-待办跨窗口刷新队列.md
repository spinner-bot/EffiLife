# 0694：待办跨窗口刷新队列

## 背景

TD 入口原来为每个工作区事件立即启动一次异步刷新。批量导入、PH 联动和多个窗口连续编辑时，刷新请求可能并发完成，较早的读取结果有机会晚于较新的结果写回界面，造成待办中心短暂显示旧状态。

## 实现

- 为待办中心增加工作区事件队列，合并相同来源并按顺序刷新。
- 单次刷新失败只记录警告，队列继续处理后续来源，不阻断 TD 页面。
- 保持 TD 作为单条待办核心的独立模块定位，不改变 PH 计划任务模型或关联字段。
