# 1018 启动器缺失命令退出码

## 问题

统一启动器在模块命令不存在时能够打印错误并记录日志，但 `run_module` 原先隐式返回 `None`。主入口会把该结果当作成功退出，脚本和 CI 无法通过返回码识别启动失败。

## 修复

捕获 `FileNotFoundError` 后显式返回 `1`，保持已有提示、日志和 companion 清理行为不变。

## 验证

- `python -m pytest tests/test_launcher.py -q`
- `python -m pytest -q`

## 后续边界

本次只修复测试/开发启动器的退出码语义；正式 Tauri 安装包和多端真机生命周期仍需在对应发布环境验收。
