# 仓库结构整理

## 背景

仓库根目录同时放置了集成 CLI 和本机生成的桌面 EXE，源码、工具脚本与发布产物边界不清晰。随着三个模块逐步整合，这种结构会增加新成员寻找入口和 CI 维护的成本。

## 本次整理

- 将 `run_integration.py` 归档到 `scripts/run_integration.py`，并修正脚本从新位置运行时的项目根路径计算。
- 将本机桌面发布 EXE 移入 `artifacts/releases/`，保留本地文件但不再让二进制产物散落在根目录。
- 为本地发布产物目录增加说明和精确的二进制忽略规则，不影响 CI 发布产物校验。
- 更新 README 的项目结构和集成 CLI 命令。
- 未移动 `time-helper/android/gen-android` 等已纳入版本控制的模块工程，避免破坏 Android 构建路径。

## 验证

- `python -m py_compile scripts/run_integration.py`：通过。
- `git diff --check`：通过。
- 全量 Python 测试：330 passed。
