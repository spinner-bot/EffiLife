# 00-1169-T-2026-10-14 移动导航可读性优化

## 类型与阶段

T（技术实现）。当前仍为第 0 阶段；本报告只递增序列号，不增加阶段。

## 问题

移动端底部导航采用固定定位。原有半透明背景在导航覆盖页面内容时会让下方 TH/PH/TD 内容透出，降低导航标签和图标的可读性。

## 实现

- 将移动底部导航背景不透明度从 88% 提升至 96%。
- 增加 `backdrop-filter` 与 WebKit 前缀，保持现代玻璃层效果，同时避免内容穿透干扰。
- 保留既有固定导航、横向模块入口和安全区域间距，不改变 TH、PH、TD 的导航边界。

- 前端生产构建：1881 modules transformed。
- 真实浏览器组合烟测通过：TD 创建/完成/编辑、首页快捷待办、移动搜索、移动导航均通过。
