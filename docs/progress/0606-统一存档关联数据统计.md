# 1112 统一存档关联数据统计

日期：2026-10-05  
类型：实现报告

## 背景

统一存档设置页已经展示 TH、PH、TD 的数据数量，但没有展示 PH 与 TD 之间已建立的关联数量。用户无法在数据管理界面快速确认跨模块关联是否被保留。

## 目标与非目标

目标是从统一 TD 数据集统计同时存在 `related_plan_id` 与 `related_plan_task_id` 的待办，并在存档设置页显示。非目标是校验或改写关联、自动修复数据、合并 PH/TD 实体，或改变 `.efl` 存档格式。

## 实施内容

- `ArchiveService.getDataStats()` 增加 `linkedPlanTodoCount`；
- Settings 存档统计区增加关联待办统计卡片；
- 增加中英文文案；
- 增加归档统计契约测试。

## 影响范围与兼容性

这是只读统计，不新增存储字段，不改变 canonical datasets（`app`、`records`、`todos`、`todo_categories`、`plan_helper`）。旧待办没有关联字段时计数为零且保持原样；桌面、移动端和旧 `.efl` 存档无需迁移。
