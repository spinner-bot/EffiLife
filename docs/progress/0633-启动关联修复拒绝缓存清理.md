# 0633-启动关联修复拒绝缓存清理

## 背景

应用启动时会检查 TD 与 PH 任务的关联。桌面服务短暂不可用时，计划任务读取会回退到本地缓存；缓存可能过期或不完整，不能据此执行解除关联这种破坏性修复。

## 实现

- 在每次 `getPlanTasks` 后重新检查 `planDataSource`。
- 只要任务读取发生缓存回退，立即放弃本轮自动清理并保留所有 TD 关联。
- 保留已有规则：归档计划、缺失摘要和暂时不可读取的计划都不被推断为已删除。
