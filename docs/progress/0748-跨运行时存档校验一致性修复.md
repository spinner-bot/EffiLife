# 0748 跨运行时存档校验一致性修复

## 发现

Python 公共交换层要求 manifest 中的 SHA-256 值必须是 64 位小写十六进制字符串；前端此前只检查字段是否为字符串，协议边界不完全一致。

## 修复

- 前端 `effilife.bundle` 解析器现在使用与 Python 交换层一致的 SHA-256 格式校验。
- 保持现有校验和比对、旧版无摘要存档兼容读取和导入前预览行为不变。
- 增加跨运行时契约测试，防止两端校验规则再次漂移。

- Python 全量测试：632 passed。
- `time-helper/desk`：`npm run build` 通过。
