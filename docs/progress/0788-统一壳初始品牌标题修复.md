# 0788｜统一壳初始品牌标题修复

## 状态

已完成，2026-10-01。

## 背景与问题

统一工作台运行时会按路由和语言设置 `document.title`，但 `index.html` 的初始 `<title>` 仍是旧 time-helper 品牌文案。在 Vue 初始化前、启动失败页或极短暂加载阶段，浏览器标签页和桌面 WebView 标题会显示旧产品名，破坏三模块统一产品边界。

## 实现与兼容性

- 将 HTML 启动标题改为 `EffiLife`，作为语言初始化前的中性品牌兜底。
- 保留 App 壳运行时的本地化页面标题，不改变路由标题、主题或数据逻辑。
- 不删除旧模块代码或迁移入口，仅修复统一壳的初始品牌显示。

## 验证

- `tests/test_unified_navigation_contract.py` 增加启动标题契约。
- 需运行完整 pytest 与前端生产构建。
