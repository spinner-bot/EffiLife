# 0818 统一壳真实渲染冒烟验证

日期：2026-10-01

## 背景

静态测试和 production build 不能证明统一应用壳在实际浏览器中能够加载。本轮使用本机已有的开发实例进行真实 HTTP 和无头浏览器渲染检查。

## 实际验证

- `Invoke-WebRequest http://127.0.0.1:1420/`：HTTP 200，入口 HTML 498 bytes；
- Microsoft Edge headless `--dump-dom http://127.0.0.1:1420/settings`：实际渲染 DOM 约 78 KB；
- 渲染 DOM 包含 `EffiLife`、设置路由内容和中文界面文本；
- 当前实例由启动器占用 1420 端口，本轮未重复启动或覆盖已有服务。

## 结论

统一壳在当前开发运行实例中可以被真实浏览器加载，未出现启动级白屏或 HTTP 错误。

## 未验证项

本机未安装 Playwright/Puppeteer，未进行自动化点击，因此本报告不宣称已经完成“选择主题—退出确认—刷新—主题仍保持”的完整交互回归；该项仍需浏览器自动化依赖或人工验收。原生安装包和移动设备验收同样未覆盖。
