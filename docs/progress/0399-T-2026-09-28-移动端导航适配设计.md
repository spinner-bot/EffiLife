# 移动端导航适配设计

## 背景

统一工作台当前通过媒体查询压缩桌面顶部导航。五个入口在窄屏中同时展示时，文字被隐藏后仍然占用横向空间，触控目标和当前页面识别都不够友好。

## 方案

- 桌面端保留顶部胶囊式导航，适合鼠标与宽屏多入口切换。
- 移动端顶部只保留品牌标识与全局搜索，主导航移动到屏幕底部。
- 移动端底部导航继续使用同一套路由和 active 判定，不复制业务状态。
- 底部导航采用 44px 以上触控区域，并通过 `env(safe-area-inset-bottom)` 适配全面屏安全区。
- 移动端内容增加底部留白，避免最后一项被底部导航遮挡。
- 不改变数据结构、桌面端样式、路由地址或权限逻辑。

## 验收

- 桌面宽度显示顶部导航，底部导航不可见。
- 移动宽度显示顶部品牌/搜索和底部五项主导航，顶部桌面导航不可见。
- 当前路由在两种导航中都能正确高亮。
- 前端生产构建通过，已有 Python 测试不回归。
