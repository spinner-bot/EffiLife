# 统一搜索待办深链筛选

日期：2026-10-02

## 问题

全局搜索索引包含已完成、已归档和已取消的 TD，但任务中心默认筛选为“进行中”。从搜索结果打开这类待办时，页面虽然跳转成功，目标却不在当前列表中，用户会误以为链接失效。

## 调整

任务中心在处理 `?todo=` 深链时，根据目标状态自动选择对应筛选：

- `completed` → 已完成
- `archived` / `cancelled` → 全部
- 其他状态 → 进行中

这只调整当前视图筛选，不改变待办状态，也不改变 PH/TD 的模块边界。

## 验证

- 搜索、边界和新增契约测试：24 passed。
- `npm run build`：通过。
