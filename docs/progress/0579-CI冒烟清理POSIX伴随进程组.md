# 1085 CI 冒烟清理 POSIX 伴随进程组

## 现象

`cca8e99` 已修复格式化 JSON 的健康检查，但 GitHub Ubuntu CI 仍在启动冒烟步骤失败；完整 Python 测试与跨模块集成测试均通过。

## 根因

启动器在 POSIX 系统中默认让每个子服务进入独立进程组。冒烟脚本结束时只回收启动器主进程组，计划助手伴随服务可能继续占用 `8765`，导致端口释放检查失败。Windows 的 `taskkill /T` 会递归回收子进程，因此本地 Windows 检查无法复现。

## 修复

- 启动冒烟检查时设置内部环境标记，让启动器的子服务继承冒烟所属进程组。
- 正常交互启动仍保留原有独立进程组策略。
- 增加契约断言，防止后续移除该清理保障。

## 验证

- 针对性测试
- Windows 本地启动冒烟
- 完整 Python 回归
- 推送后复核 Ubuntu CI
