# 统一工作区事件订阅幂等性

## 背景

统一应用壳使用 CustomEvent 和 BroadcastChannel 同步 TH、PH、TD 及存档变化。组件生命周期清理可能在复杂路由切换或异常恢复路径中被重复调用；原订阅解除函数会重复递减订阅计数，极端情况下可能提前关闭仍被其他页面使用的 BroadcastChannel。

## 调整

- 为 `onWorkspaceChanged` 返回的解除函数增加幂等保护。
- 同一订阅重复解除时不再重复移除监听器、递减计数或关闭通道。
- 保持同窗口事件、跨窗口 BroadcastChannel 和最后订阅者关闭通道的既有语义。
- 增加事件总线契约测试。
