# 存档导入后即时刷新当前工作区

日期：2026-10-02

## 背景

统一 `.efl` 存档导入已经持久化 TH、TD、PH 快照，但用户可以选择暂不重载页面。此时设置页和 Pinia 中的当前工作区可能仍显示导入前的摘要。

## 实现

- 导入成功后先刷新当前工作区和存档统计。
- 保留原有的成功提示及“是否立即重载”确认，不强制用户重载。
- 原生文件选择器和浏览器文件选择器共用同一刷新协调函数。

## 兼容性

不改变 `.efl` 格式、导入回滚、重载确认或 PH/TD/TH 数据边界；刷新失败不会撤销已成功持久化的导入，后续仍可通过重载或设置页重试恢复显示。
