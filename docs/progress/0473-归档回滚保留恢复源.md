# 0899 归档回滚保留恢复源

## 背景

统一 `.efl` 导入会先创建 `archive_import` 检查点。此前归档检查点恢复和导入失败时的内存回滚都会清空全部 `localStorage`，可能连同当前普通备份、紧急备份以及正在使用的导入检查点一起删除，降低恢复链路的可用性。

## 调整

- `archive_import` 恢复只清理运行时应用键。
- 导入过程的内存回滚采用相同规则。
- 保留 `efflife_backup_*` 与 `efflife_emergency_backup_*` 恢复源，再覆盖快照中的运行时数据。

这样既维持应用数据的快照替换语义，又不会因为恢复动作破坏后续恢复能力。

## 验证

- 新增归档检查点与内存回滚契约测试。
- 完整测试与桌面构建将在提交前执行。
