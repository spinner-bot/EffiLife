# 移动端边界持续集成

日期：2026-09-30

## 完成内容

新增 `.github/workflows/tauri-mobile-boundary.yml`。当统一前端、移动 Tauri 配置、移动构建脚本或相关测试发生变化时，CI 会执行：

1. Node/Python 环境准备和前端依赖安装。
2. 移动端不携带桌面 sidecar 的配置检查。
3. Android/iOS 构建命令契约测试。
4. 统一 Vue 前端生产构建。

## 边界

该 workflow 是移动边界持续检查，不上传安装包，也不声称完成 Android/iOS 原生构建。真实移动构建仍由具备 SDK、签名和平台工程的发布环境执行；这样可以在当前阶段持续保护跨端共享代码和配置边界。
