# 1223｜统一搜索可见输入标签实现

日期：2026-10-10  
状态：已完成并推送

## 背景

统一搜索是 TH、PH、TD 的共同入口，但搜索框此前只有 placeholder 和 ARIA 标签，没有始终可见的字段名称，不符合统一表单体验规范。

## 实施内容

- 增加中英文“搜索内容 / Search content”可见 label。
- 通过唯一 `global-search-input` id 建立原生 `label[for]` 关联。
- 保留 Ctrl/Cmd+K、Esc、方向键导航、TH/PH/TD 筛选和结果深链行为。
- 新增搜索输入语义契约测试。

## 验证

- 搜索、筛选、导航定向测试：`10 passed`。
- 前端生产构建通过，Vite 转换 `1877` 个模块。
- 全量 Python 测试：`968 passed`。
