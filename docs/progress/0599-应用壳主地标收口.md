# 1105-应用壳主地标收口

## 问题

统一应用壳已经通过 `#main-content` 提供主内容地标，但各个路由 View 内部仍使用 `<main>` 作为布局容器，形成嵌套主地标。视觉布局不受影响，但会干扰屏幕阅读器的地标导航，也不符合统一应用壳的语义结构。

## 调整

- 保留 App.vue 中唯一的 `<main id="main-content">`。
- 将 Home、PH、TD、TH、记录、设置及其他路由 View 的内部主容器改为 `<div>`。
- 保留原有 class、CSS、焦点目标和交互，不改变页面行为。
- 增加契约测试，防止后续路由再次引入嵌套 `<main>`。

## 验证

- `python -m pytest -q tests/test_app_shell_landmarks.py`
- 完整 Python 测试集应继续通过。
- 前端生产构建应继续通过。
