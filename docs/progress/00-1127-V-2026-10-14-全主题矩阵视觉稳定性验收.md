# 全主题矩阵视觉稳定性验收

## 目标

HOTL-1 要求支持基础主题和 TH 的丰富主题架构。此前浏览器 smoke 只验证主题卡片数量、单次切换和持久化；本次增加逐项矩阵验收，避免某个主题单独切换时产生状态或布局回归。

## 验收内容

```text
python scripts/smoke_browser_workspace.py --url http://127.0.0.1:4173 --theme-matrix-flow
```

在隔离浏览器环境中依次选择全部主题，并对每个主题验证：

- 选中卡片数量始终为 1；
- 设置页没有横向布局溢出；
- 主题切换过程可持续完成，不依赖手工刷新；
- 原有主题退出确认和持久化验收仍继续执行。

## 结果

结果：`ok: true`，`theme_cards: 25`，`theme_matrix_visual_verified: true`，`theme_save_buttons: 0`，`theme_persistence_verified: true`。

本次是 Windows Chromium 隔离视口的自动化视觉稳定性门禁，不替代真实 Android WebView、系统读屏和人工逐主题审美验收。阶段保持第 0 阶段。
