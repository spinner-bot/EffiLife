# 1174 宽屏桌面侧栏工作台布局

日期：2026-10-09  
类型：设计与实现报告

## 背景

HOTL-1 要求桌面端充分利用宽屏，并明确桌面/平板不应简单复用移动端纵向体验。统一壳当前在所有桌面宽度使用顶部横向导航，模块入口虽完整，但主工作区仍被迫采用移动式顶部导航结构。

## 目标与非目标

目标是在宽屏桌面提供固定侧栏工作台：品牌、PH、TH、TD、记录和设置入口垂直组织，搜索入口固定在侧栏底部；平板继续使用横向顶部导航，移动端继续使用底部导航。非目标是修改路由、数据协议、模块职责或主题变量。

## 影响范围

- `time-helper/desk/src/App.vue`：增加 `min-width: 1200px` 的侧栏布局媒体查询。
- 现有导航 DOM、快捷键、ARIA 状态和移动底栏保持不变。

## 实现与兼容性

宽屏下将 `.global-nav` 变为左侧纵向 rail，并为 `.app-content` 预留 260px 内容区；1200px 以下仍沿用原有顶部导航，680px 以下仍沿用移动底栏。侧栏仅使用现有导航链接，不引入额外状态或数据迁移，因此不影响历史深链和主题系统。

## 验证

- `python -m pytest -q tests/test_unified_navigation_accessibility.py tests/test_unified_navigation_order.py`：提交前执行并记录实际结果。
- `npm run build`（工作目录 `time-helper/desk`）：提交前执行并记录实际结果。
- 静态契约将确认宽屏断点、内容预留和移动/平板导航未被删除。

## 提交与推送

本报告与实现保持同一变更批次；提交哈希和远端状态在验证后补录。

## 未验证边界

尚未在真实 1200px、平板和手机设备上进行视觉回归；本轮不处理主题选择退出后的持久化受阻问题，也不宣称正式安装包或真机验收完成。
