# 00-1165-T-2026-10-14 历史安装包品牌匹配修复

## 类型与阶段

T（技术实现）。当前仍为第 0 阶段；本报告只递增序列号，不增加阶段。

## 问题

Windows 升级烟测脚本声明支持旧中文产品名安装包，但正则表达式中的中文品牌字符串出现编码损坏，导致真实的 `浪兮效率时钟_1.0.11_x64-setup.exe` 被错误拒绝。

## 修复

- 恢复历史品牌 `浪兮效率时钟` 的精确安装包文件名匹配。
- 增加直接契约测试，验证历史品牌与版本号均能正确解析。
- 不放宽版本校验，不改变安装、升级、卸载逻辑，不触碰用户数据目录。

## 验证边界

修复后继续执行隔离 Windows 旧版→当前版升级，并验证数据探针字节级保留；测试目录使用项目 `artifacts` 下明确命名的临时路径。
