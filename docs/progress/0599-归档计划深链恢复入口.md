# 0599｜归档计划深链恢复入口

## 背景

TD–PH 关联在计划归档后应保留，但从 TD 点击关联计划会以 `?plan=` 深链进入 PH。活动计划列表不包含归档计划，原先用户只会看到普通计划列表，无法判断为什么目标不存在，也没有直接恢复入口。

## 实施

- PH Hub 根据 `plan_id` 将深链匹配到归档项。
- 在 Hub 与事件计划视图显示双语“计划已归档”提示。
- 提供直接恢复按钮；恢复后重新加载活动计划并重新消费原深链，进入对应计划/任务。
- 不改变 TD–PH 关联数据，也不把归档计划误当作失效关系。

## 验证

- 新增归档深链回归测试。
- 继续执行全量 Python 测试与桌面端生产构建。
