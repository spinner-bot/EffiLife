# 0619｜归档历史文件名防覆盖

## 背景

PH 归档文件此前只使用秒级时间戳命名。同一计划在短时间内归档、恢复再归档时，文件名可能相同并覆盖历史归档；移动端快照也存在同类风险。

## 实现

- 桌面 PH 归档文件名增加微秒精度。
- 移动端归档文件名使用毫秒级时间戳。
- 增加归档—恢复—再次归档测试，验证两个历史文件同时保留。
