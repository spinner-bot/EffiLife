## 构建过程

- 直接执行 `npm run mobile:android:build` 时，Rust/NDK 编译成功，但 Tauri 默认流程在 Windows 创建 `.so` 符号链接时失败；原因是当前工作站未启用开发者模式或符号链接权限。
