# 首页模块独立加载

**报告类型**：实现报告  
**阶段**：第 0 阶段  
**日期**：2026-10-14（Asia/Shanghai）

## 问题

首页原先使用统一的 `workspaceSummaryReady` 控制 TH、PH、TD 的展示。PH 服务响应慢或不可用时，会连带阻塞 TH 与 TD 的首页内容，破坏三个模块各自可用、并置协同的产品定位。

## 调整

- TD 使用独立的 `todoSummaryReady`。
- TH 使用独立的 `timeSummaryReady`。
- TH/TD 的加载状态不再依赖 PH 或其他模块的完成状态。
- PH 继续使用自身的 `eventPlanState` 管理加载、可用和失败重试。

## 边界

本次只调整首页展示状态，不改变 TH、PH、TD 数据结构、模块入口或跨模块关联数据；阶段保持第 0 阶段。

## 验证

- 新增 TH 独立加载契约测试。
- 保留首页 TD 创建、完成、成功反馈真实烟测。
- 桌面端构建成功；全量 Python 回归 `1213 passed, 1 warning`。
- 首页 TD 真实浏览器烟测成功，TH/TD 独立展示改动未破坏既有路径。
