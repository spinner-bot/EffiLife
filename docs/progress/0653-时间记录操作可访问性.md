# 0653｜时间记录操作可访问性

## 背景

TH 的记录列表和日详情页包含编辑、删除、关闭等图标型操作。部分控件只有视觉图标与 `title`，缺少稳定的辅助技术名称；部分按钮也没有显式 `type`。

## 实现

- 为记录列表编辑/删除按钮增加双语 `aria-label` 与 `type="button"`。
- 为日详情删除、关闭按钮增加双语 `aria-label`。
- 为日详情取消按钮显式声明 `type="button"`。
- 增加回归测试，覆盖控件名称、类型和双语文案。

## 兼容性

不改变时间记录数据、删除逻辑、路由或跨模块同步，仅改善键盘和辅助技术使用体验。

## 验证

- 时间记录相关回归测试。
- 完整 Python 测试。
- 前端构建由 GitHub CI 验证。
