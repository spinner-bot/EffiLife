# 0844 动态音频名称多语言门禁

## 发现

音频设置页的内置 BGM 名称通过 `builtInBgmNameKeys` 动态映射到翻译目录。普通静态 `t('...')` 扫描无法发现新增 BGM 后忘记补齐中英文文案的情况。

## 调整

- 从 `AudioManager.ts` 读取全部内置 BGM ID。
- 与 `AudioSettingsView.vue` 的动态映射集合进行一致性比较。
- 要求每个 `settings.audio.bgmName.*` key 在中英文目录各出现一次。

这只加强多语言门禁，不改变音频数据结构；自定义 BGM 仍显示用户导入的文件名。
