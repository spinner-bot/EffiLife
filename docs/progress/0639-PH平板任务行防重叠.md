# 0639 PH 平板任务行防重叠

## 背景

HOTL 1 要求桌面/平板使用横向层级，并修复按钮、文字错位和互相遮挡。PH 详情页的任务行在 901–1099px 仍使用包含多个固定操作列的桌面网格；此宽度尚未进入双栏详情工作区，任务标题可被操作按钮挤压。

## 实现

- 将 PH 详情页紧凑任务布局断点从 `max-width: 900px` 提前到 `max-width: 1099px`。
- 该断点下任务行统一使用 `24px minmax(0, 1fr) auto`，日志、TD 关联、TH 记录按钮流式换行到任务内容列。
- 保留 `min-width: 1100px` 的桌面双栏详情布局，不改变任务数据结构、PH/TD 职责或交互语义。
- 更新原有响应式布局契约，并新增独立源代码契约测试，防止断点回退。

## 兼容性

- 移动端既有单列布局不变。
- 桌面端双栏工作区仍从 1100px 启用。
- 仅改变 CSS 响应式边界，不改变 Plan、任务编号、嵌套组或 TD 关联数据。

- 全 Python 测试：562 passed。
