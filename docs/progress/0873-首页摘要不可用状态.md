# 首页摘要不可用状态

## 背景

统一首页顶部的三项工作流摘要分别读取 TH、PH、TD 数据。此前任一模块读取失败时，摘要仍可能显示 `0` 或 `0/0`，用户无法区分“确实没有数据”和“数据暂时不可用”。

## 本次调整

- TH 今日记录读取失败时，时间摘要显示中性占位符 `—`。
- PH 计划摘要进入 `unavailable` 状态时显示 `—`，不伪造 `0/0`。
- TD 摘要读取失败时显示 `—`，不伪造待办数量为零。
- 不可用摘要使用虚线边框弱化为状态提示，但仍保留原模块跳转入口。
- 下方各模块已有的错误提示和重试操作保持不变；本次只统一顶部反馈层。

## 验证

- `python -m pytest -q`：717 passed。
- `time-helper/desk` 执行 `npm run build`：成功。

## 边界

本次不修改 PH、TD、TH 的数据结构、存储协议或模块间实体关系，仅改善统一首页对不可用数据的表达。
