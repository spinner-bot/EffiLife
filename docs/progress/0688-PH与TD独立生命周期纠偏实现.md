# 1194 PH 与 TD 独立生命周期纠偏实现

日期：2026-10-10  
类型：实现与回归报告

## 实现内容

- 移除 PH 改名对关联 TD 描述的自动改写。
- 移除 PH 任务编辑对关联 TD 标题和预计时长的自动改写。
- 移除 PH 任务完成对关联 TD 的自动完成。
- 删除 PH 任务或章节时，仍清理 TD 上已经失效的计划引用，但不删除 TD 数据。
- 保留 PH 中用户主动执行的“创建关联待办”入口，以及查看关联待办时间记录的入口。
- 删除不再使用的双向生命周期同步函数，并将相关错误文案调整为“关联引用处理失败”。

## 验证

- 定向 PH/TD 契约测试：25 passed。
- `time-helper/desk` 执行 `npm run build`：通过，Vite 转换 1877 个模块。
- 全量 Python 测试：943 passed。

## 结论

PH 与 TD 现在是两个独立实体：可以通过用户主动操作建立引用和协同，但双方的编辑、完成、改名不会互相改变生命周期。这与 HOTL-1 对两模块定位的要求一致。
