# 1155 首页平板断点与统一壳对齐

日期：2026-10-05  
类型：统一应用壳响应式布局修复

## 背景与问题

统一应用壳在 681px 起保留桌面/平板横向导航，但首页工作台此前从 761px 才切换为横向布局。681–760px 宽度因此出现导航与内容布局模式不一致，屏幕空间利用率偏低。

## 实现

- 将首页平板横向工作台断点从 761px 调整为 681px，与统一应用壳断点对齐。
- 保留 680px 及以下的移动端单列内容和底部导航。
- 继续使用主题变量与现有安全区规则，不改变三模块数据和路由边界。
- 更新首页响应式契约测试。

## 验证

- 首页响应式专项测试：16 passed。
- 项目全量测试：910 passed。
- `time-helper/desk`：`npm run build`，通过，1877 modules transformed。

## 提交与边界

代码与报告直接提交到 `main`，不创建分支。本次只调整首页布局断点，不改变 PH、TH、TD 功能语义。
