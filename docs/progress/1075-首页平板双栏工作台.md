# 1075 首页平板双栏工作台

## 背景

HOTL-1 要求桌面和平板充分利用横向空间，首页应作为三个模块的控制台。此前首页在 `761–899px` 区间虽然放宽了最大宽度，但仍沿用纵向单列布局，导致平板仍需要较多滚动，且时钟与工作区没有形成稳定的层级关系。

## 本次调整

- 平板首页改为双栏工作台：左侧固定时钟、日期和打卡状态，右侧依次放置 TH 统计、PH 概览、TD 今日待办和快捷操作。
- 左侧时钟在滚动时保持可见，方便用户在浏览工作区时持续获得当前时间上下文。
- 保持 `<=760px` 的移动端单列布局，以及 `>=900px` 的桌面宽屏布局不变。
- PH、TD 仍保持独立入口和独立数据边界；本次仅调整首页展示层级。

## 验证

- 新增首页平板布局契约测试，检查双栏网格、时钟跨行和四个右侧工作区槽位。
- 通过首页相关 pytest、全量 pytest 和桌面生产构建后提交。
