## 当前仍未完成或不能仅靠本地测试证明的事项

- 主题退出保存问题需要真实用户复现后继续处理；当前代码已有持久化校验和无独立保存按钮的退出保存流程，但不能据此宣称用户问题已完全解决。
- Windows、Linux、macOS 正式安装包需要在 GitHub Actions 的对应 runner 上实际构建并验证；本地前端构建不等价于安装包验收。
- Android/iOS 需要真实设备或发布前预检验证原生分享、文件选择器、safe-area 和触摸交互；移动端契约测试不替代设备验收。
- GitHub Actions 远端运行结果需要从 GitHub 状态页核实；本地测试通过不等价于远端 workflow 全部成功。
