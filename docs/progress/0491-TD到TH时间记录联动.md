# 0917 TD 到 TH 时间记录联动

日期：2026-10-02

## 背景

TD 的专注计时/记录时间功能会在统一存储中创建 TH 时间记录，但此前只广播 TD 的 `todos` 变更。已打开的 TH 记录页无法及时感知这次跨模块写入。

## 本次迭代

- TD 记录时间成功后同时广播 `records` 工作区事件。
- TH 记录页通过统一应用壳刷新当前日期数据。
- TH 历史日期详情页对 `records`、`plans` 和 `network` 事件重新读取统计与记录。
- 保持 TD 和 TH 各自数据模型，仅通过既有记录关联与事件总线协同。
- 增加跨模块契约测试和进展文档。
