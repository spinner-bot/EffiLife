# 0861 主题基础浅深色注册优化

## 背景

主题引擎已经保留 TH 的丰富主题架构，但设置页此前只有“纯色”基础主题；浅色和深色仅作为纯色编辑器中的预设，不能作为明确、稳定的主题选项使用。

## 本次调整

- 在统一主题注册表中增加独立的 `light` 和 `dark` 基础主题。
- 两个主题由 ThemeEngine 提供完整设计令牌，PH、TD 和 TH 继续共享同一 CSS 变量层。
- 增加中英文主题名称和说明；现有 `solid` 及历史丰富主题数据保持兼容。
- 不引入新的存储迁移，主题仍沿用现有退出确认和持久化回读流程。

## 验证

- `python -m pytest -q tests/test_settings_theme_i18n.py`：提交前执行
- `python -m pytest -q`：提交前执行
- `npm run build`（`time-helper/desk`）：提交前执行
