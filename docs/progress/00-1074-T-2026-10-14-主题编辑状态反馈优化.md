# 主题编辑状态反馈优化

**报告类型**：迭代报告  
**阶段**：第 0 阶段  
**日期**：2026-10-14（Asia/Shanghai）  

## 背景

主题设置采用实时预览、退出时确认保存的交互，不提供独立主题保存按钮。原状态文案始终提示“退出时确认后保存”，即使当前没有修改，也容易让用户误以为存在未保存内容。

## 实现

- 主题设置页无修改时显示“当前主题已应用”。
- 主题草稿发生变化时显示“有待保存的主题修改，退出时确认保存”。
- 待保存状态使用主题强调色和更高字重，提升视觉可辨识度。
- 保持原有实时预览、退出确认、持久化校验和失败恢复逻辑不变。
- 中英文文案同步更新。

## 验证

- `pytest -q tests/test_theme_persistence_contract.py`：18 passed。
- `npm run build`：生产构建成功。

## 结论

主题编辑状态更清晰，用户能够立即判断当前是否存在待保存修改；未改变主题数据结构及保存语义。阶段保持第 0 阶段。
