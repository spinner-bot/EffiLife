# 1011 待办批量选择作用域

## 结论

待办中心的批量选择现在明确属于当前筛选视图。切换状态页签、分类或搜索关键词时，旧选择会清空，避免用户在看不到目标时继续执行批量完成或删除。

同时，待办列表重新加载或单项删除后会校验已选 ID，只保留仍存在的数据，避免跨窗口同步或删除后出现失效选择。

## 实现边界

- 不修改 `UnifiedTodo` 数据结构，也不改变批量操作 API。
- “全选当前可见项”仍只作用于 `visibleTodos`。
- 选择状态仍为页面临时状态，不写入统一存档。
