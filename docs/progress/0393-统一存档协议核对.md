# 0819 统一存档协议核对

日期：2026-10-01

## 背景

项目同时出现物理文件扩展名 `.efl` 与协议格式名 `effilife.bundle`。本轮核对两者是否被误认为不一致，并确认统一存档链路仍符合 HOTL-1。

## 当前协议结论

- `.efl` 是用户可见的 ZIP 存档物理扩展名；
- ZIP manifest 的协议名为 `effilife.bundle`，版本 `1.0.0`；
- canonical datasets 为 `app`、`records`、`todos`、`todo_categories`、`plan_helper`；
- 前端和 Python 公共交换层使用相同数据集、规范化 JSON 和 SHA-256 校验规则；
- 导入包含预览、形状校验、关联修复、原子回滚和旧 `archive.json` 兼容读取。

因此当前不应把导出文件扩展名改为 `.bundle`；那会破坏既有用户文件和兼容入口。
