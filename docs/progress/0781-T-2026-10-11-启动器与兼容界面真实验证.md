# 启动器与兼容界面真实验证

日期：2026-10-11

## 背景

统一启动器、跨模块集成层和 TD 兼容 Web 界面此前主要由契约测试覆盖。本次对当前工作站环境执行接近 CI 的真实命令，确认继续整合工作的运行基础没有被静态测试掩盖。

## 目标与非目标

目标是验证统一启动链、PH 配套服务、统一集成层以及 TD 兼容界面能够在当前环境完成启动或构建。

非目标是发布签名、真实安装升级和移动设备验收；iOS 仍按项目范围暂缓。

## 影响范围

- `launcher/`：统一开发启动与诊断；
- `plan-helper/`：PH HTTP 配套服务；
- `time-helper/desk/`：统一工作台前端；
- `to-dos/ui/`：TD 兼容 Web 界面；
- `scripts/` 与跨模块测试：集成及发布门禁。

## 兼容性与迁移说明

本次只执行读取、启动、测试和构建，没有改变 PH 数据结构、统一 `.efl` 存档格式或任何用户数据。启动烟测结束后前端端口和 PH 端口均已释放。
