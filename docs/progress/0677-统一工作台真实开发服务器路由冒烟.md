# 1183 统一工作台真实开发服务器路由冒烟

日期：2026-10-09  
类型：验证报告

## 背景

源码契约和生产构建均已通过，但仅凭静态检查不能证明统一应用壳的各个入口能被开发服务器实际返回。本次启动真实 Vite 开发服务器，对当前统一工作台路由做最小运行时冒烟。

## 验证方式

在 `time-helper/desk` 使用项目 Node 环境启动：

```text
npm run dev -- --host 127.0.0.1 --port 1430 --strictPort
```

Vite 输出 `ready`，随后使用 PowerShell `Invoke-WebRequest` 请求以下路径并检查 HTTP 状态和应用壳标识：

```text
/          200  EffiLife=true
/plans     200  EffiLife=true
/tasks     200  EffiLife=true
/records   200  EffiLife=true
/settings  200  EffiLife=true
/calendar  200  EffiLife=true
```

## 结论

- 统一应用壳的首页、PH、TD、TH、设置入口均可由真实开发服务器访问。
- `/calendar` 仍可访问是为了兼容旧书签；当前路由逻辑将其重定向到记录模块，不恢复独立日历功能。
- 本次为 HTTP/入口级冒烟，不替代真实浏览器交互、主题切换、跨窗口同步和原生安装包验收。

## 提交

本报告随当前工作推进提交到 `main` 并推送 `origin/main`；未创建分支，未执行快进合并。
