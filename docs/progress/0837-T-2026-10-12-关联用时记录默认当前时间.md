# 0837｜关联用时记录默认当前时间

类型：T（TH/PH/TD 跨模块交互）  
日期：2026-10-12  
状态：[进行中]

## 1. 问题

从 PH 任务或 TD 待办进入 TH 的“记录用时”入口时，记录表单固定预填 09:00–10:00，不符合当前操作语境，也容易造成用户忘记修改时间而保存错误记录。

## 2. 实施

- `RecordsView.vue` 新增当前本地时间默认值计算。
- 时间模式的开始时间、结束时间和时长模式参考时间均随打开新增表单时计算。
- 默认结束时间最多到当天 `24:00`，避免跨日改变现有 TH 单日记录语义。
- 保留编辑既有记录时的原始时间，不覆盖用户历史数据。

## 3. 验证

- `python -m pytest -q tests/test_records_current_time_defaults.py tests/test_record_todo_linking.py tests/test_plan_workspace_record_entry.py tests/test_todo_time_link_integrity.py`：14 passed。
- `time-helper/desk` 执行 `npm run build`：通过，1878 modules transformed。

## 4. 兼容性

本次只改变新增记录表单的默认值，不改变 `TimeRecord` 数据结构、PH 任务编号、TD 独立实体或跨模块关联字段。午夜边界继续由现有表单校验负责。
