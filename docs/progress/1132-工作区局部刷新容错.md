# 1132 工作区局部刷新容错

日期：2026-10-05  
类型：实现报告

## 背景与目标

跨窗口或归档导入后，应用会刷新配置、TH 计划、日程规则、今日记录、今日计划和统计。原实现的批量读取会因任一数据集失败而放弃整批刷新，容易让一个局部存储故障影响整个工作区。

## 实现与兼容性

- `app` store 的跨窗口刷新改用 `Promise.allSettled`；
- 成功读取的数据集立即更新，失败的数据集保留上一份有效内存值；
- 局部失败会输出诊断警告，全部数据集失败时仍抛出错误，保留上层重试/提示行为；
- 保留写入版本检查和刷新串行机制，不改变 TH 数据结构或统一归档协议。
