# 1204｜统一前端构建入口

日期：2026-10-10  
状态：已完成

## 背景

统一启动器已经能够识别项目约定的 Node.js 目录，并为 Vite 开发服务注入对应的 `PATH`。直接在仓库根目录执行普通 `npm run build` 时，如果系统 PATH 没有 Node，则 Windows 的 `npm.cmd` 可能找不到同目录的 `node`，导致构建命令失败。这是工具链入口不一致，不是前端代码错误。

## 本次处理

- 新增 `scripts/build_frontend.py`，复用 `launcher.start.find_npm()` 和 `launcher.start.node_environment()`。
- 构建工作目录固定为 `time-helper/desk`，与项目实际前端边界一致。
- 缺少 Node.js 时输出可执行的 `EFFILIFE_NODE_DIR` / PATH 提示。
- README 增加统一构建命令，并增加静态契约测试。

## 验证

- 通过统一入口实际执行 `vue-tsc && vite build`。
- Vite 成功转换 1877 个模块并生成生产构建。
- 构建产物位于被忽略的 `time-helper/desk/dist/`，未进入版本控制。
