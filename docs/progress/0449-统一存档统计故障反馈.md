# 统一存档统计故障反馈

## 背景

统一存档页会读取 TH、PH、TD 的当前数据统计。此前统计读取失败时，页面仍显示初始化的零值，容易把存储故障误解成空数据。

## 本次调整

- 为存档统计增加独立的不可用状态。
- 读取成功后清除不可用状态；读取失败时不再展示伪造的零值。
- 增加可访问的状态提示和就地“重试”入口。
- 导入、导出和旧版待办迁移操作不受统计读取失败影响。
- 为中英文界面补充对应文案。

## 边界

本次只调整设置页反馈层，不改变 `.efl` 存档协议、数据集、导入回滚机制或 PH/TD/TH 数据实体。

## 验证

- `python -m pytest -q`：全量回归。
- `time-helper/desk` 执行 `npm run build`：生产构建。
