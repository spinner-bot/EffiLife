# 1055 统一存档范围可视化说明

日期：2026-10-02

## 问题

统一 `.efl` 存档协议已经覆盖 `app`、`records`、`todos`、`todo_categories` 和 `plan_helper` 数据集，但设置页主要通过统计数字间接说明范围。用户首次使用导入/导出时，难以确认 TH、PH、TD 是否都包含在同一个存档中。

## 实现

- 在存档管理页增加统一工作区范围说明区。
- 明确展示三个独立域：`TH` 为每日时间记录、`PH` 为整份事件计划、`TD` 为单条待办事项。
- 桌面端使用三列域标签，窄屏自动堆叠为单列。
- 仅增加界面说明和双语文案，不改变 `.efl` 协议、导入校验、检查点或回滚逻辑。

## 验证

- 存档范围、存档预览、主存储和主题配置专项测试：`26 passed`。
- Python 全量测试：`811 passed in 7.73s`。
- 桌面前端生产构建：`vue-tsc` 通过，Vite 完成 `1877 modules transformed`，构建成功。

## 影响范围

提升统一数据管理的可理解性，同时明确 PH、TD、TH 仍是三个不同职责的数据域。
