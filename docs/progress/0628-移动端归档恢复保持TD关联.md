# 0628-移动端归档恢复保持 TD 关联

## 背景

移动端使用本地 Plan Helper 快照时，归档恢复会保留原计划 ID；若该 ID 已被其他计划占用，则恢复计划必须重新编号。计划 ID 是 TD 与 PH 之间的关联键，单独改计划 ID 会使任务中心中的关联任务继续指向旧计划。

## 实现

- 移动端归档计划时，将当时关联到该计划的 TD ID 与任务编号写入归档元数据。
- 恢复时若发生计划 ID 冲突，只迁移归档时记录的 TD，且再次确认 TD 当前仍指向旧计划，避免覆盖用户后来手动修改的关联。
- 没有新元数据的旧归档仍可正常恢复，但不做无法可靠推断的关联迁移。
- 不改变 PH 原始 `head/main/log` 数据结构，不改变 TD 独立存储，也不改变桌面端服务协议。

## 兼容性

归档元数据为可选字段；既有移动端归档和桌面端归档均可继续读取。
