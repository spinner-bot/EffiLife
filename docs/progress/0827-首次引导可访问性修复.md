# 0827 首次引导可访问性修复

日期：2026-10-01

## 发现

真实主题交互验收中发现首次引导浮层会按设计拦截高亮区域外的点击；用户若想暂时离开引导，原关闭按钮只有图标，没有可见或辅助技术标签，容易误以为设置页面不可操作。

## 修复

- 为引导关闭按钮补充双语 `aria-label` 与 `title`。
- 保留关闭前的确认流程，不改变引导状态和数据备份逻辑。
- 增加双语目录与可访问性契约测试。

## 验证

- `python -m pytest -q tests/test_guide_accessibility.py tests/test_frontend_guide.py`：本轮执行
- 全量回归与前端构建：本轮执行
