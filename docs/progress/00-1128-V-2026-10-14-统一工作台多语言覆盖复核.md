# 统一工作台多语言覆盖复核

## 复核目标

在主题矩阵验收之后，复核统一工作台新增或高频用户路径是否绕过 locale 目录写入硬编码可见文案，避免未来增加语言时出现中英文混杂。

## 复核范围与结果

执行：

```text
python -m pytest -q tests/test_frontend_i18n_coverage.py \
  tests/test_plan_center_i18n.py tests/test_todo_text_i18n.py \
  tests/test_settings_theme_i18n.py tests/test_mobile_touch_targets.py \
  tests/test_plan_accessibility_contract.py
```

结果：`31 passed`。

复核确认：

- PH 计划中心和计划操作文案继续通过双语覆盖；
- TD 待办字段、状态、优先级和无障碍文案继续通过覆盖；
- 设置与 25 个主题目录文案继续通过覆盖；
- 触控目标和 PH 图标操作标签没有出现新的多语言回退缺口；
- 音频内置名称由设置页按 locale key 显示，用户可见目录未直接暴露内部中文名称。

## 决策与边界

本轮没有发现需要修改生产代码的问题，因此不进行无效的批量迁移。兼容模块中的低频历史文案仍单独属于迁移/调试入口范围，不改变统一工作台的 HOTL-1 多语言结论。阶段保持第 0 阶段。
