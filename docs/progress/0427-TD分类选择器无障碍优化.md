# 0853 TD 分类选择器无障碍优化

日期：2026-10-02

## 背景与目标

TD 的分类编辑器使用图标和色块按钮。此前这些控件主要依赖 title，读屏用户无法稳定获得控件含义，图标搜索框也只有 placeholder 提示。本次优化补齐语义，不改变待办分类数据结构或保存流程。

## 实施内容

- 为图标选择按钮增加双语 aria-label 和 aria-pressed。
- 为颜色选择按钮增加双语颜色标签和 aria-pressed。
- 为图标搜索框增加显式 aria-label。
- 增加契约测试，防止后续重构移除这些语义。

## 影响范围

- 仅影响 TD 分类编辑器的键盘/辅助技术体验。
- PH 计划数据、TH 时间记录、统一存档协议和主题持久化逻辑不变。
- 鼠标、触摸和原有视觉交互保持不变。

## 验证

- python -m pytest -q tests/test_category_icon_display.py tests/test_global_search.py
- npm run build（在 time-helper/desk 目录执行）
