# 主题保存入口恢复

日期：2026-09-30

## 背景

HOTL-1 指出主题切换在退出后无法保留。审计发现，主题页仍有预览与退出确认逻辑，但此前的交互修复误删了显式“保存”按钮，用户无法主动提交当前主题配置。

## 实现

- 恢复主题设置页的显式保存按钮。
- 仅在主题配置发生变化时启用按钮，避免无变化重复写入。
- 保存仍统一经过 `appStore.saveConfig`，并更新已保存快照；退出时的未保存确认逻辑保持不变。
- 增加前端契约测试，固定保存入口必须存在。

## 兼容性与边界

不改变主题注册表、主题引擎、配置结构、预览机制或跨端数据格式；本次只修复桌面设置页的持久化入口。
