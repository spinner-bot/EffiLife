# 0616｜归档 PH 关联修复不变量

## 背景

启动时会维护 TD 与 PH 任务的关联。活动计划列表不包含已归档计划，因此不能把“活动列表中不存在”直接当作“计划已删除”；否则归档计划恢复后，TD 关联会被永久清除。

## 实现与确认

审查并固化 `repairTodoPlanTaskLinks()` 的不变量：

- 只有能够取得活动计划且成功读取其任务列表时，才会判定具体任务引用失效。
- 活动计划列表中不存在的计划直接保留关联，覆盖已归档计划和服务暂时不完整两种情况。
- 计划服务处于 cache/mobile 不确定状态时不执行破坏性修复。

本次增加专门契约测试，防止后续重构将归档计划误判为删除。
