# 0440｜统一引导目标语义化

日期：2026-09-29  
类型：T（体验与维护性迭代）  
范围：`time-helper/desk`

## 背景

统一应用壳同时提供桌面导航和移动底部导航。新手引导此前通过 `.global-nav-link:nth-child(n)` 按位置寻找入口，导航顺序变化或切换平台后容易高亮错误目标。独立日历入口已经退役，引导也不应再把它作为产品概念。

## 本次变更

1. 桌面和移动导航为计划、待办、记录、设置添加同名 `data-guide` 语义标识。
2. 当前有效引导步骤改用语义选择器，不再依赖导航项序号。
3. 增加回归测试，确保两端标识数量一致，且引导不回退到序号选择器。
4. 将设计决策和验收标准记录在 `docs/设计方案/0403-统一引导目标语义化方案.md`。

## 验证

- 引导相关测试：5 passed
- 桌面生产构建：通过，1874 modules transformed

## 后续观察

当前 `GuideManager.ts` 文件仍保留早期引导定义作为历史迁移痕迹，但运行时以统一应用壳步骤为准；后续可在确认无需兼容旧引导状态后再做单独清理提交。
