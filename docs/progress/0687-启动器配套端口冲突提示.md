# 0687：启动器配套端口冲突提示

## 背景

统一开发启动器在 plan-helper 端口已被其他服务占用、但健康检查不匹配时，过去会继续创建子进程并等待超时。用户只能看到笼统的启动失败，难以判断是端口冲突还是服务本身异常。

## 实现

- 在启动 plan-helper 等配套服务前检查其本地端口。
- 发现端口被不兼容服务占用时立即停止本次启动，并提示用户停止冲突进程或确认已有服务身份。
- 记录 `companion_port_conflict` 诊断事件。
- 不改变健康检查通过时复用现有服务的行为，也不改变正式 Tauri sidecar 路径。

- 启动器测试：55 passed。
- `python -m pytest -q`：595 passed。
- `git diff --check`：通过。
