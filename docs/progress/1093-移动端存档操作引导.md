# 1093 移动端存档操作引导

## 背景

统一存档已经支持移动端的文件导入和导出：导出优先使用 Web Share API 分享文件，无法分享时回退为下载；导入使用 WebView 的文件选择器。此前设置页只说明了移动端 PH 计划快照来源，没有说明这两个实际交互入口，用户可能将系统分享面板或文件选择器误认为按钮没有反应。

## 调整

- 在移动端存档管理页增加独立的操作提示。
- 明确说明导出优先打开系统分享面板，不支持时下载文件。
- 明确说明导入打开设备文件选择器，并要求使用 `.efl` 文件。
- 中文和英文文案同步加入现有 i18n 资源，不改变存档协议和桌面端行为。

## 验证

- 新增 `tests/test_mobile_archive_guidance.py`，验证移动端入口和中英文文案均存在。
- 待执行：相关 pytest、完整 pytest、桌面端生产构建。

## 边界

本次不改变移动端 PH 快照策略、Web Share 回退逻辑或统一存档格式；真实 Android/iOS 系统分享面板仍需在对应设备或发布前预检中验证。
