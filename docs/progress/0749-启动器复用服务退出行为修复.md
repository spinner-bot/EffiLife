# 0749 启动器复用服务退出行为修复

## 问题

统一工作区已经由其他进程启动时，launcher 会打开健康服务，但随后持续轮询外部服务，导致启动命令无法自然返回，看起来像启动卡住。

## 修复

- 检测到健康的既有统一工作区后，launcher 打开浏览器并立即返回。
- 仅清理本次调用实际启动的 companion 进程，不触碰外部已运行的主服务。
- launcher 自己启动的主服务仍按原有方式前台托管，生命周期不变。

## 验证

- launcher 回归测试：59 passed。
- Python 全量测试：633 passed。
- `python launcher/start.py --diagnose` 与 `--doctor` 已确认当前统一工作区和 plan-helper companion 可用。
