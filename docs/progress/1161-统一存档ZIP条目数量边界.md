# 1161 统一存档 ZIP 条目数量边界

日期：2026-10-09  
类型：统一数据交换安全与可靠性优化

## 背景与问题

`.efl` 导入已经限制归档文件大小、数据集数量和解压后数据量，但 ZIP 中的额外文件条目仍没有上限。大量无关条目会增加预览和解析开销，也会让 Python 与前端的安全边界不一致。

## 实现

- Python 与桌面前端统一限制 ZIP 条目总数为 64。
- 普通导入、Tauri 文件导入和设置页预览均执行条目数量检查。
- 保留 manifest、数据集摘要和形状校验；超限归档在模块数据写入前拒绝。
- 增加中英文错误提示、Python 交换层测试和前端契约测试。

## 验证

- `python -m pytest -q`：921 passed。
- `npm run build`（`time-helper/desk`）：通过，1877 modules transformed；Vite 主包约 503 kB 的提示仍为性能建议。
