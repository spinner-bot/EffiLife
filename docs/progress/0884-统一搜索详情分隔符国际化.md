# 统一搜索详情分隔符国际化

## 背景

统一搜索已经支持中文和英文目录，但结果详情中的分隔符仍由组件直接写入。随着主题、模块和搜索结果继续扩展，展示格式应由当前语言目录统一管理。

## 调整

- 将计划任务、时间记录和搜索结果副标题中的详情分隔符改为 i18n key。
- 在中文、英文目录中补齐 `search.detailSeparator`。
- 保持搜索排序、索引来源和路由行为不变，仅调整显示层文本。
- 增加回归测试，确保两个语言目录均有该 key，且组件通过翻译函数消费它。
