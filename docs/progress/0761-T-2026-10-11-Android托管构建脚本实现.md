# Android 托管构建脚本实现

## 1. 实现

新增 `scripts/build_android_managed.ps1`，并在桌面端 `package.json` 增加：

```text
npm run mobile:android:build:managed
```

脚本统一使用环境站中的 Node、Rust、Android SDK/NDK、Java/Gradle 缓存，执行以下链路：

1. 调用 Tauri Android 构建完成前端和 Android Rust release 编译。
2. 在 Windows 无符号链接权限时，确认 Rust 动态库确实是本次新生成，再转入生成 Android 工程。
3. 将动态库复制到 `jniLibs/arm64-v8a`，同步前端 assets。
4. 自动启用中文项目路径所需的 `android.overridePathCheck=true`。
5. 使用 Gradle 组装 ARM64 release APK。

脚本提供 `-Action check` 环境检查模式，不要求修改系统级环境变量。
