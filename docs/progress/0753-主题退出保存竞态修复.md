# 0753 主题退出保存竞态修复

## 背景

主题编辑页不提供独立的“保存”按钮，用户修改后应在退出时通过确认弹窗完成保存。此前退出保存成功后还会等待一次全局工作区刷新；刷新期间设置页的旧主题快照仍可能参与预览同步，导致用户看到主题恢复为修改前的状态。

## 本次处理

- 保留主题编辑页的实时预览与退出确认流程。
- `saveConfig` 成功返回后，立即以当前脱离式草稿更新已保存快照。
- 立即同步编辑控件，避免退出流程继续被旧快照判定为未保存。
- 移除主题退出保存路径中额外的工作区刷新等待；持久化服务成功即代表本次写入完成，其他窗口刷新仍由工作区事件处理。
- 保留保存成功与失败提示；失败时不清除脏状态，用户可以重试。

## 影响范围

仅涉及 TH 设置页主题退出保存流程及其契约测试，不改变主题数据结构、丰富主题注册表或其他模块的数据逻辑。
