# 移动底栏导航顺序一致性

日期：2026-10-02

## 背景

统一应用壳的桌面导航已将 TD 待办放在 TH 时间记录之前，与 Alt+4/Alt+5 快捷键一致；移动底栏仍保持相反顺序，造成同一软件在不同端的认知顺序不一致。

## 实现

- 将移动底栏调整为 Home、Plans、Time、Tasks、Records、Settings。
- 增加导航契约测试，锁定 Tasks 位于 Records 之前。

## 兼容性

只调整入口顺序，不改变路由、数据结构、页面内容或移动端触摸尺寸。
