# 0916 TD 统一存档刷新

日期：2026-10-02

## 背景

统一 `.efl` 存档导入后会广播 `archive` 工作区事件，但 TD 页面此前只处理待办、时间记录和设置事件。用户在 TD 页面停留时，导入的数据可能直到手动刷新或重新进入页面才出现。

## 本次迭代

- TD 工作区新增对 `archive` 事件的响应，重新加载待办和分类。
- TD 工作区同时响应统一 `network` 恢复事件，保证跨窗口/离线恢复后的列表一致。
- 不改变 TD 数据结构，也不把 PH 计划任务并入 TD。
- 增加跨模块刷新契约测试和进展文档。

## 验证

- `python -m pytest -q tests/test_td_workspace_refresh_contract.py`
- `npm run build`
