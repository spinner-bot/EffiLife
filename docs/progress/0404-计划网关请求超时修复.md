# 计划网关请求超时修复

日期：2026-10-01

## 问题

统一工作台的存档请求已经有超时控制，但普通 `planGateway` 请求没有超时。Plan Helper 连接建立后如果不返回响应，主页计划摘要、计划中心或启动后的待办-计划关联维护可能长期停留在加载状态。

## 处理

- 为每次 Plan Helper 请求增加 8 秒超时，并通过 `AbortController` 中止无响应请求。
- 保留调用方 `AbortSignal` 的取消语义，路由离开或组件主动取消不会被网关吞掉。
- 在成功、失败和重试路径统一清理定时器及外部取消监听器。
- 超时仍沿用现有有限重试和本地快照降级策略，不改变 PH 数据结构或 PH/TD 模块边界。

## 验证

- `tests/test_plan_gateway_timeout.py`：2 passed。
- 计划缓存与跨模块关联回归：9 passed。
- 桌面端 `npm run build`：通过。

## 影响范围

该修复只改变不可响应服务的失败时限，不改变正常响应、移动端本地快照路径或导入导出协议。
