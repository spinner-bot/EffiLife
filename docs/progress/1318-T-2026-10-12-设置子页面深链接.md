# 设置子页面深链接

日期：2026-10-12
类型：T（交互改进）

## 背景

设置页的主题、存档、恢复等页面原先只由组件内部状态控制。按钮点击可以进入，但刷新、外部链接或统一应用壳需要定位到存档时没有稳定地址，降低了设置与存档入口的可发现性和可恢复性。

## 实现

- 使用 `/settings?view=<view>` 表示设置子页面；
- 允许的 view 使用显式白名单，未知值安全回退到 `main`；
- 内部导航通过 `router.replace` 同步查询参数，不制造重复浏览器历史；
- 从外部查询参数进入时重建设置页返回栈；
- 进入恢复页时继续触发备份状态加载；
- 保留主题未保存离开确认逻辑。

## 边界

本次只改变设置子页面的导航状态，不改变主题持久化、存档协议或三模块数据边界。
