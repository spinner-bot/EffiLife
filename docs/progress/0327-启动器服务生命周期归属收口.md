# 0751 启动器服务生命周期归属收口

## 决策

统一工作区的主前端和 plan-helper companion 必须由同一启动流程负责生命周期，launcher 不对外部已运行的主工作区进行半托管。

## 实现

- 在启动 companion 前先检测健康的主工作区。
- 检测到外部主工作区时，仅打开其 URL 并返回，不启动或停止 companion。
- 只有 launcher 自己确认需要启动主工作区时，才创建并管理 companion；启动竞态仍由原有端口冲突处理兜底。

## 验证

- launcher 测试：59 passed。
- 既有统一工作区和 companion 的 `--diagnose` / `--doctor` 行为保持 READY。
