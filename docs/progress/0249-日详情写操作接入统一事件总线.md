# 0650｜日详情写操作接入统一事件总线

## 背景

`DayDetailView.vue` 是 TH 历史记录入口。其删除时间记录和切换指定日期计划的操作直接调用 `DataService`，没有广播统一工作区事件，导致其它窗口或首页控制台无法及时感知变化。

## 实现

- 删除历史记录并刷新本页后广播 `records`。
- 切换指定日期计划并刷新本页后广播 `plans`。
- 增加回归断言，确保日详情写操作不会绕过工作区同步协议。

## 兼容性

不改变历史记录、日期计划或 PH/TD 数据结构；仅补充跨页面、跨窗口刷新通知。

## 验证

- 记录删除与任务-记录导航相关测试。
- 完整 Python 测试。
