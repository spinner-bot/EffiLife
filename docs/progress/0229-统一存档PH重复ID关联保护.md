# 0630-统一存档 PH 重复 ID 关联保护

## 背景

PH 使用数字计划 ID，而历史归档会长期保留旧计划。不同生命周期的计划可能出现相同 ID；统一存档导入时如果让归档快照覆盖活动计划的任务索引，TD 关联修复会误判并解除有效链接。

## 实现

- 导入统一存档时，对同一 PH ID 的活动计划与归档计划任务索引取并集。
- 继续清理确实不存在于任何对应快照的 TD 关联。
- 不改变 PH 原始数据结构、ID 生成规则或 TD 的独立数据模型。
