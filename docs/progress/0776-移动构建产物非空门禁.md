# 0776 移动构建产物非空门禁

## 问题

移动构建 workflow 之前直接把 APK、app bundle 或 IPA 的 glob 上传为 artifact。若构建输出路径变化、产物为空或只生成了空目录，失败会延迟到上传步骤，诊断信息不够明确。

## 处理

- 新增 `scripts/verify_mobile_artifacts.py`。
- Android 构建后要求至少存在一个非空 `.apk` 文件。
- iOS 构建后要求存在包含非空文件的 `.app` bundle 或非空 `.ipa` 文件。
- 两个平台均在上传 artifact 前执行校验，并增加单元与 workflow 契约测试。

## 边界

该门禁只验证构建产物存在且非空，不等价于签名、安装、升级或真实设备验收。
