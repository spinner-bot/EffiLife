# 1030 PH 与 TD 自动联动显式启用实现

## 日期

2026-10-02

## 实施内容

- `register_all_handlers` 默认不注册 `PlanTodoLinker`。
- `EffiLifeIntegration` 暴露 `enable_plan_todo_automation=False`，只有显式传入 `True` 才开启兼容自动联动。
- 保留 TD 完成后记录 TH 时间的既有联动，以及统一数据层的显式关联和查询能力。
- 增加默认关闭与显式开启两条注册路径的测试。

## 兼容性与边界

默认启动行为不再因 PH 事件自动创建或完成 TD；历史关联字段、查询 API、存档迁移和兼容 handler 本身仍保留。既有需要旧自动化的集成调用方必须明确传入 opt-in 开关。
