# 0640 TD 筛选标签可访问性

## 背景

TD 任务中心原本使用了 `role="tablist"`，但三个筛选按钮没有声明 `role="tab"`、当前选中状态或与任务列表的关联。键盘用户和辅助技术无法可靠识别当前筛选条件。

## 实现

- 为“活动/全部/已完成”三个筛选按钮增加 tab 角色、唯一 ID、`aria-selected` 和非活动项焦点管理。
- 为任务列表增加 `tabpanel` 角色、稳定 ID、实时更新提示，并通过 `aria-labelledby` 关联当前筛选标签。
- 保持既有 `filter` 状态和排序、优先级逻辑不变。

## 兼容性

- 不改变 TD 数据结构、优先级算法、PH 关联或移动端布局。
- 只增强统一应用壳中的无障碍语义。
