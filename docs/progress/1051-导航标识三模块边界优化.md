# 1051 导航标识三模块边界优化

日期：2026-10-02

## 背景

HOTL-1 要求 PH 与 TD 保持独立定位。当前实现已经有独立路由、页面和数据服务，但全局桌面导航只显示“计划中心”“时间工作台”“待办”，用户不容易快速确认三者的职责边界。

## 实现

- 在桌面全局导航中为三个工作模块增加稳定的模块标识：`PH`、`TH`、`TD`。
- 为 PH、TH、TD 入口增加职责提示：PH 使用整份计划组织事件进展，TH 展示当日时间记录，TD 处理可快速完成的单条事项。
- 保持 PH、TH、TD 的路由、数据存储、页面和快捷键完全独立，不引入功能合并。
- 增加导航身份与职责提示的回归测试。

## 验证

- 导航身份、现有导航语义和模块边界专项测试：`16 passed`。
- Python 全量测试：`806 passed in 7.70s`。
- 桌面前端生产构建：`vue-tsc` 通过，Vite 完成 `1877 modules transformed`，构建成功。

## 影响范围

这是导航层的可识别性优化，直接回应 HOTL-1 的 PH/TD 定位要求；不改变数据结构、同步逻辑或业务行为。
