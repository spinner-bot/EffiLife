# 0821｜to-dos 兼容入口多语言迁移

类型：T（兼容入口多语言）  
日期：2026-10-13  
状态：[进行中]

## 1. 目的

将 to-dos 旧兼容入口纳入统一的可扩展多语言基础，避免主工作台已经切换语言后，用户打开兼容入口仍看到大量固定中文。此次保持 to-dos 的独立职责和原有数据逻辑，不把它与 PH 合并。

## 2. 本阶段实现

- 新增 `to-dos/ui/src/i18n.ts`，支持 `zh-CN` / `en-US`，读取统一 `efflife_locale` 存储键。
- 迁移筛选栏、分类侧栏、主工作区工具栏、导入弹窗、批量操作、空状态、待办列表、待办卡片、创建/编辑表单、设置面板和图标选择器。
- 保留优先级、截止日期、重复规则、分类、标签、备注、排序和持久化实现，仅替换用户可见文案。
- 增加 `tests/test_todos_legacy_i18n.py` 契约测试，防止新迁移区域重新写入固定文案。

## 3. 验证

- `python scripts/build_todos_ui.py`：通过，Vue/Vite 构建转换 1768 个模块。
- to-dos 兼容 i18n 定向测试：通过。
- 多次模块提交已分别推送到 `main`，最近包括 `ab463ac`、`e4b77c9`。

## 4. 边界

- 兼容入口仍有少量历史注释和未迁移的低频文案，后续继续按组件批次处理。
- 统一桌面主工作台的 i18n、TH 丰富主题、PH/TD 独立入口和统一存档协议不受本阶段改动影响。
