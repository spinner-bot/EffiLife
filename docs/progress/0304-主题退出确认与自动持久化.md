# 主题退出确认与自动持久化

## 问题

主题编辑页已经取消独立的保存按钮，但之前离开页面时会直接静默写入。这样用户无法确认当前预览是否应该持久化，也不符合“退出时处理”的交互约定；同时已有的未保存提示文案没有接入流程。

## 处理

- 主题编辑仍然实时预览，不增加保存按钮。
- 主题存在改动时，点击返回或发生路由离开会弹出确认框。
- 确认后持久化主题并退出；取消后停留在主题编辑页。
- 保存失败时继续阻止离开，保留当前草稿以便重试。
- 主题选择、颜色操作和预设按钮统一声明 `type="button"`。

## 验证

- 增加主题退出确认与无保存按钮的静态契约测试。
- 保留原有主题注册表、多语言和持久化失败回滚测试。

## 结论

主题编辑交互现在是“即时预览 + 退出确认 + 确认后保存”，不会再出现保存后退出状态被悄悄覆盖的问题。
