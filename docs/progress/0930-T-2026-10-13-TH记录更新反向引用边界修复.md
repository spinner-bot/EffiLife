# [完成] TH 记录更新反向引用边界修复

## 基本信息

- 创建时间：2026-10-13
- 执行者：Codex
- 触发原因：TH 时间记录关联 TD 待办的清理逻辑主要位于界面层，直接调用数据服务更新记录时可能遗留旧待办的反向记录引用。

- 将旧记录反向引用清理下沉到 `DataService.updateRecord` 存储边界。
- 当记录 ID 或 `todo_id` 发生变化时，清理旧记录 ID 在 TD 中的反向引用。
- 不改变记录内容、时间或待办正向累计用时的业务语义。
- 保持现有 RecordsView、PlanView 的显式联动逻辑兼容；重复清理是幂等的。

## 变更范围

- `time-helper/desk/src/services/dataService.ts`
  - 更新记录后检测旧记录身份/关联变化并清理反向引用。
- `tests/test_record_delete_cleans_links.py`
  - 增加数据服务直接更新路径的回归约束。
