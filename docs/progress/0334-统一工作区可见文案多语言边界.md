# 0758 统一工作区可见文案多语言边界

## 发现

统一应用壳已经建立 `zh-CN`/`en-US` 语言目录、locale registry 和翻译键覆盖测试，但仅检查 `t()` 调用不能阻止开发者在模板中直接写入中文可见文案。

## 处理

- 对当前启用的首页、PH、TD、TH 记录和设置模板增加可见文案扫描。
- 扫描只检查 `<template>` 可见文本，排除注释、脚本和样式，避免把兼容数据判断误报为用户文案。
- 保留现有双语键覆盖检查，形成“调用键存在 + 模板无硬编码可见中文”的双重边界。

## 验证

- `python -m pytest -q tests/test_frontend_i18n_coverage.py`：3 passed。
- 全量 Python 测试：639 passed。
- 当前工作区模板扫描未发现硬编码中文可见文本。

## 后续

新增语言时仍需同时扩展 `LOCALE_DEFINITIONS`、语言目录和键覆盖测试；真实桌面构建待 Node/npm 工具链恢复后执行。
