# 1246｜跨运行时旧计划别名迁移实现

创建时间：2026-10-10  
执行者：Codex  
状态：[完成]

## 触发原因

前端存档解析已支持 `planHelper` 旧数据集名称，Python 统一交换层此前只支持 `plans`。同一份旧存档在两个运行时可能得到不同结果，违反统一 `.efl` 协议的兼容性预期。

## 实际完成

- Python 侧旧别名表改为一个 canonical 名称对应有序别名集合。
- `plan_helper` 迁移顺序为 `plans` → `planHelper`。
- 已有 canonical `plan_helper` 时保持 canonical 优先，避免旧数据覆盖新数据。
- 旧值仍要求数组，迁移后包装为统一计划快照容器。
- 新增 camelCase 别名迁移和双旧别名并存时 canonical 优先测试。

## 未改变的逻辑

- 不修改 PH 计划实体、A/B/C 模块、任务编号、嵌套组、软删除编号或执行日志。
- 不改变导入的整体覆盖、备份和回滚行为。
- 不改变前端既有别名解析。
