# 1040 计划创建弹窗错误反馈修复

日期：2026-10-02

## 问题

PH 创建计划时，校验失败或服务端创建失败会写入统一的 `errorMessage`。此前错误提示只位于计划列表区域；创建弹窗打开时，列表被模态遮罩覆盖，用户看不到错误，表现为提交按钮无响应。

## 实现

- 在创建计划弹窗标题和表单字段之间增加独立错误提示。
- 使用 `role="alert"`，让屏幕阅读器和视觉用户都能立即获得反馈。
- 保留列表页原有错误提示，兼容弹窗关闭后的服务错误状态。

## 验证

- 新增回归测试：确认创建弹窗内包含错误提示、`plans-error` 样式和 `role="alert"`。
- PH 创建与桌面布局专项测试：`33 passed`。
- Python 全量测试：`793 passed in 7.64s`。
- 桌面前端生产构建：`vue-tsc` 通过，Vite 完成 `1877 modules transformed`，构建成功。

## 影响范围

仅改善 PH 创建流程的错误可见性，不改变计划数据结构、任务编号、分组嵌套或 PH/TD 模块边界。
