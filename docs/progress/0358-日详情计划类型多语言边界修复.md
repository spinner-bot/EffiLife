# 0783 日详情计划类型多语言边界修复

## 问题

统一记录链路的 `PlanView` 已将历史计划类型值在显示边界本地化，但 `DayDetailView` 仍直接渲染 `dayPlanType` 与 `plan.plan_type`。英文 locale 下会泄漏历史中文领域值。

## 修复

- 在日详情页增加与时间工作台一致的 `planTypeLabel` 映射。
- 今日计划信息和计划切换弹窗均只渲染本地化标签，存储值和比较逻辑不变。
- 增加日详情专用 i18n 回归测试。

## 验证边界

本次只改变用户可见文本，不改变历史计划类型数据结构；真实英文浏览器视觉换行仍需人工验收。
