# 1096 启动器原生打包环境提示

## 背景

本机启动器可以运行统一开发工作区，但当前 Windows 环境没有 `cargo` 和 `rustc`，无法直接执行 Tauri 原生安装包构建。此前 `--diagnose` 会返回 Rust 工具链状态，`--doctor` 只通过提示间接说明，用户需要进一步阅读机器诊断才能理解本地不能打包的原因。

## 调整

- `launcher/start.py --doctor` 直接显示 `cargo`、`rustc` 路径。
- 增加 `Native build: ready/not ready` 状态。
- 缺少工具链时明确提示安装 Rust 或使用 CI/release machine，不影响开发工作区启动判断。
- 增加 doctor 输出契约测试。

## 验证

- 本地 `python scripts/check_build_environment.py --target desktop`：结果为 `ready: false`，缺少 `cargo`、`rustc`。
- `python scripts/check_release_config.py`：通过。
- 相关启动器测试将在提交前执行。

## 边界

本次不伪造安装包，也不把开发工作区 READY 视为可发布；真实安装包仍需在安装 Rust 的发布机或 GitHub Actions runner 上构建并验证。
