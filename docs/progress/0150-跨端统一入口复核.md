# 跨端统一入口复核

日期：2026-09-30

## 复核结论

统一应用壳在桌面和移动布局中都保留三域独立入口：

- `/plans`：PH 事件计划与 TH 时间工作台的统一计划中心入口。
- `/time`：TH 时间记录入口。
- `/tasks`：TD 待办入口。
- `/settings`：统一配置、主题、语言和存档入口。

桌面使用顶部横向导航，移动端使用带安全区的底部导航；两套导航均使用同一组语义路由、主题变量和 `aria-current` 状态，不依赖导航顺序定位。独立日历入口没有回流，旧 `/calendar` 仅作为兼容重定向。
