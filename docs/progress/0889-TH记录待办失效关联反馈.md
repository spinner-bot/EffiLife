# TH 记录待办失效关联反馈

## 背景

时间记录可以选择关联 TD 待办。当待办已经被删除或归档数据无法找到时，记录页原先仍显示原始 ID，并提供一个无法定位目标的跳转按钮，容易让用户误以为关联仍然有效。

## 调整

- 成功读取待办列表后，识别记录中的失效待办引用。
- 失效引用显示明确的不可用文案，并禁用无效跳转。
- 待办存储读取失败时不改变或清理原有关联，只保留原引用，避免把暂时不可用误判为已删除。
- 增加中英文文案和关联边界测试。
- 不改变 TH 记录数据、不自动删除 TD 数据，也不改变 PH/TD 实体边界。
