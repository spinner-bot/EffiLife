# 0901 记录保存弹窗关闭时序修复

- 创建时间：2026-10-13
- 作者/执行者：Codex
- 状态：[完成]
- 阶段：第 0 阶段

## 触发原因

真实行为审计发现，0899 引入的 `closeRecordForm` 同时承担用户取消和保存完成后的收尾。保存流程中 `isSavingRecord` 仍为 `true` 时调用该函数，会被“保存中不可关闭”保护拦截，导致成功保存后弹窗不关闭；编辑目标失效时也存在同样问题。

## 完成情况

- `closeRecordForm()` 默认仍阻止保存中的用户主动关闭。
- 保存成功和失效记录清理路径使用 `closeRecordForm(true)` 强制完成关闭与焦点恢复。
- 增加回归契约，锁定保护条件和强制关闭路径。
- 未改变记录写入、TD 关联同步和错误反馈逻辑。

- `time-helper/desk/src/views/PlanView.vue`
- `tests/test_plan_record_modal_accessibility.py`

## 验证

执行 TH 弹窗专项、全量 Python 回归和前端生产构建；重点确认保存路径不再因时序保护留下弹窗。

## 风险与下一步

风险为低，修复仅调整弹窗收尾时序。后续继续关注异步保存流程中的“用户取消”和“成功收尾”状态边界。
