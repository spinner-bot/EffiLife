# 全局搜索快捷键提示修复

日期：2026-10-02

## 背景

统一应用壳已支持 macOS 使用 Command+K、Windows/Linux 使用 Ctrl+K 打开全局搜索，但 macOS 提示文本缺少可读间距，影响快捷键识别。

## 目标与范围

仅调整桌面壳层的快捷键提示文本，并增加回归检查；不改变快捷键处理逻辑、不涉及主题持久化或原生打包边界。

## 实现

- 将 macOS/iOS 平台提示统一为可读的 `⌘ K`。
- 保留 Windows/Linux 的 `Ctrl K` 提示及现有 `aria-keyshortcuts` 语义。
- 在全局搜索契约测试中锁定该显示文本，防止回归。

## 兼容性

不改变路由、数据结构、跨窗口事件或模块边界；仅影响桌面端搜索按钮的显示文案。
