# 1197 PH 整份计划语义文案统一

日期：2026-10-10  
类型：产品语义与多语言文案修正

## 背景

HOTL-1 将 PH 定义为围绕明确主题组织的“整份计划”，而不是 TH 的日计划。界面和存档说明仍大量使用“事件计划 / event plan”旧术语，容易使用户误解 PH 与时间计划的关系。

## 修正范围

- PH 页面标题、创建、空态、任务统计和移动端快照文案。
- 首页 PH 概览、搜索结果和模块说明。
- 设置中的存档范围、快照状态、帮助和引导文案。
- 中文与英文资源同步校准为“整份计划 / plan document”语义。

代码内部的 `eventPlan` 变量和兼容 key 暂不改名，避免破坏数据协议和已有深链；它们不再作为用户可见术语出现。

## 验证

- 模块身份、移动端计划文案和多语言覆盖定向测试：15 passed。
- 可见资源中不再出现 `事件计划`、`Event plan` 或 `event-plan` 文案。
- `time-helper/desk` 执行 `npm run build`：通过，Vite 转换 1877 个模块。
