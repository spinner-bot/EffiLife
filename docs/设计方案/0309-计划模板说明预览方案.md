# 计划模板说明预览方案

## 背景

统一创建弹窗已接入 Plan Helper 模板，但下拉框只显示模板名称。用户在提交前无法判断模板的用途，容易选择错误模板或反复创建后修改。

## 方案

- 根据 `selectedTemplateId` 从已加载的 `PlanTemplateSummary[]` 查找当前模板。
- 选择模板后显示模板描述和类型；未选择模板时不显示模板说明。
- 继续使用现有模板元数据，不把模板内容复制到前端，也不改变创建 API。
- 移动端模板列表为空时不显示模板相关 UI，保持首个行动创建路径。

## 验收

- 桌面模板选择后可见描述和类型。
- 中英文模板说明文案使用模板返回内容，不引入硬编码模板名称。
- 模板创建、手工创建、移动端回退行为不变。
