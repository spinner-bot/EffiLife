# 帮助中心组件化与多语言收敛

## 背景

设置页帮助中心的历史模板包含大量硬编码文案，且与当前统一工作台的计划中心、待办中心和时间记录入口不完全一致。

## 方案

- 新增独立 `HelpCenterPanel` 组件，所有用户可见文案通过 i18n 获取。
- 内容围绕当前统一工作台：快速开始、计划与待办协作、时间记录、主题与存档。
- 通过设置页现有 `currentView === 'help'` 入口展示新组件；旧模板暂不删除，便于回退和后续逐步清理。
- 使用事件回调返回设置页，不引入新的路由或数据存储。

## 验收

- 中文和英文环境下帮助中心无新增硬编码中文。
- 帮助中心可通过 Esc/返回按钮退出。
- 不影响主题、存档、恢复和反馈页面。
