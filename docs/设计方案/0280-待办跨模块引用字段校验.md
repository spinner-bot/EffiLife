# 0280 待办跨模块引用字段校验

## 背景

统一待办会引用计划任务和时间记录。导入归档时，标题等基础字段已有校验，但跨模块引用字段曾通过 TypeScript 类型断言直接保留，异常数据可能进入运行时。

## 方案

在共享 `normalizeImportedTodo` 中校验：计划 ID、计划任务 ID 必须是字符串；时间记录 ID 必须是字符串数组。任一字段形状错误即拒绝该待办，由归档导入流程整体报告无效任务。

## 边界

- 不在此处判断引用对象是否存在；存在性依赖同一归档内的其他数据集，交由启动自愈流程处理。
- 未提供字段仍保持兼容，允许历史待办无关联。
- 不修改合法引用内容，不改变 ID 语义。
