# 0361 待办用时同步反馈方案

## 背景

待办中心的手动记录用时和专注计时会写入统一时间记录，并更新待办的累计用时与关联记录 ID。此前操作成功后只有列表数据变化，没有明确的成功反馈，跨模块同步结果不够可见。

## 决策

1. 两种入口继续共用 `persistTodoTime`，不复制记录和回滚逻辑。
2. 只有时间记录写入和待办累计更新都成功后，才显示成功 Toast。
3. Toast 使用统一 i18n，明确提示分钟数和已同步到时间记录。
4. 失败路径继续沿用原有错误提示与已生成记录回滚，不显示成功反馈。

## 验证标准

- 成功记录用时后出现中英文一致的反馈。
- 时间记录与待办关联行为不变。
- 失败时仍能进入原有错误处理，不产生成功 Toast。
