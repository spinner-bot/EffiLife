# 0388 统一工作台确认对话框方案

## 背景

统一工作台的计划、待办、记录页面仍使用浏览器原生 `confirm`。原生对话框无法适配 EffiLife 主题，键盘焦点和中英文文案也不受统一壳控制。

## 决策

1. 在应用壳挂载单例 `ConfirmHost`，由 `requestConfirm()` 返回 Promise，调用方按异步结果继续或取消操作。
2. 对话框使用主题变量、全局中英文目录、Esc 和点击遮罩取消，并默认把焦点放在取消按钮，避免误触危险操作。
3. 危险操作使用 `danger` tone；确认服务不负责业务数据写入，只负责用户决策。
4. 本次迁移计划中心、待办中心、今日记录和历史记录四个统一页面；旧版兼容页面保留原有同步确认，避免扩大迁移范围。

## 结果

删除、归档和清理关联等统一操作拥有一致的视觉与可访问性基础，后续设置页和兼容页面可以逐步迁移而不改变业务 API。
