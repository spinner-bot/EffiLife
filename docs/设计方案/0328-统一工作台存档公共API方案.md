# 统一工作台存档公共 API 方案

## 目标

让 Python 侧的迁移、备份和启动器工具直接使用与前端 `.efl` 相同的统一工作台数据集协议，避免调用方自行拼接 ZIP 或依赖模块私有目录。

## API

- `common.export_workspace_bundle(...)`：导出 `app`、`records`、`todos`、`todo_categories`、`plan_helper` 五个 canonical 数据集。
- `common.read_workspace_bundle(...)`：读取并校验五个数据集完整存在。
- `DataManager.export_workspace_bundle(...)` 与 `DataManager.read_workspace_bundle(...)`：为已有统一数据管理入口提供同等能力。

## 约束

公共 API 只负责协议、文件安全和完整性校验，不解释各模块内部字段。模块字段迁移仍由各自适配器负责；缺少任一 canonical 数据集时必须拒绝作为完整工作台存档读取。
