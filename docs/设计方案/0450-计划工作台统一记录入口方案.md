# 计划工作台统一记录入口方案

## 背景

计划工作台已经同时承载日计划与今日时间记录，但主导航和首页快捷入口仍把“时间记录”作为独立一级入口，用户会感知为两个平行模块。

## 方案

- 桌面与移动主导航只保留“计划”作为时间规划与记录的一级入口；
- 首页的“今日已记录”和“记录时间”快捷入口改为进入 `/plans?mode=time`；
- 在计划工作台内提供“历史记录”次级入口，继续保留完整历史记录管理和深链接兼容；
- 保留 `/records` 路由，避免旧书签、待办关联和外部链接失效；
- 不删除 `RecordsView`，因为今日记录与历史记录的操作密度不同，移动端也更适合分层进入。

## 验收

- 增加入口契约测试，确认主导航和首页时间入口指向统一计划工作台；
- 确认计划工作台仍提供历史记录入口；
- 运行前端生产构建与全量 Python 测试；
- 保持用户已有 `time-helper/desk/package-lock.json` 不变。
