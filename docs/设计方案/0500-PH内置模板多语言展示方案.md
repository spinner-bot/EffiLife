# 0500 PH 内置模板多语言展示方案

## 问题

统一创建弹窗已经接通 Plan Helper 模板接口，但接口中的内置模板名称和说明是中文领域数据。英文用户会在模板选择器中看到中文，破坏统一工作台的语言切换体验。

## 决策

- 仅按稳定的内置模板 `type`（`workday`、`weekend`、`exam`）映射前端 i18n 文案。
- 未知类型或自定义模板继续显示服务端返回的 `name`、`description`，不把用户内容当作翻译键。
- 不修改 Plan Helper API、模板存储或 `.efl` 数据；语言只影响展示。
- 名称和说明均使用静态 i18n key，纳入现有双语 key 覆盖门禁。

## 验收

- 中文和 English 目录均包含三种内置模板的名称、说明。
- 模板下拉选项调用本地化展示函数；自定义类型保留原文。
- 全量测试和前端生产构建通过。
