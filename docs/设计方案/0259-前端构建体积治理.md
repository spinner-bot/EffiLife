# 0259 前端构建体积治理

## 目标

在不改变分类图标功能的前提下，降低首次进入任务中心的脚本体积，并避免图标组件拖大业务页面分包。

## 方案

- 抽取有限的分类图标清单到 `categoryIcons.ts`，预览组件只从该清单查找图标，不再引入 `lucide-vue-next` 的全量 `icons` 命名空间。
- 任务中心中的图标选择器和预览器使用异步组件，只有进入分类编辑场景时才加载编辑器代码。
- 为上述边界增加源码契约测试，防止后续重新引入全量图标命名空间或静态加载可选编辑器。

## 验收标准

- `npm run build` 通过。
- 构建输出不再出现分类图标分包超过 500 KB 的警告。
- 分类图标选择、预览和默认圆形图标行为保持不变。
