# 统一启动器默认入口方案

## 决策

`launcher/start.py` 直接运行时默认进入统一工作台（time-helper 桌面壳及其 plan-helper 配套服务），与 `start.bat`、`start.sh` 的行为保持一致。

旧的三模块兼容菜单不删除，改为仅在显式传入 `--legacy-menu` 时使用。这样迁移和调试仍有入口，但正常用户不会因为启动方式不同而进入旧产品界面。

## 参数约定

- `--unified`：显式进入统一工作台，保持兼容。
- 无 `--legacy-menu`：默认进入统一工作台。
- `--legacy-menu`：进入旧兼容菜单。
- `--no-browser`：统一工作台启动时不自动打开浏览器。
