# 首页打卡提醒行动入口方案

## 背景

首页在当天计划完成后显示“可打卡”提醒。现有实现使用带有指针样式的 `div`，但没有点击行为、键盘焦点或语义角色，用户只能看到提示，不能从提示直接进入打卡页。

## 设计决定

- 将提醒改为原生 `button`，保留现有条件：当天尚未打卡且今日计划完成度达到 100% 时显示。
- 点击或按 Enter/Space 后进入 `/checkin`，与首页底部的打卡行动按钮使用同一路由。
- 保留现有提醒视觉语言和动效，不增加新的弹窗或重复业务逻辑。
- 添加可见的焦点样式，确保键盘用户可以识别当前控件；触控尺寸保持不小于 44px。
- 不改变 TH 的数据模型、打卡判定、事件提醒或导航结构。

## 验收标准

1. 提醒以 `button` 语义渲染，并可通过键盘聚焦。
2. 点击提醒进入 `/checkin`。
3. 提醒显示条件和底部打卡入口保持一致。
4. 中英文构建、静态契约测试和已有首页真实浏览器路径通过。

本方案仍属于第 0 阶段，不递增阶段编号。
