# 0069 发布版本标识统一

## 决策

EffiLife 的桌面发布版本以 `time-helper/desk/package.json` 为主版本源。Tauri 配置和 Rust crate 的版本必须与前端包版本保持一致。

本次将桌面应用发布版本统一为 `1.6.0`，避免前端、安装包元数据和内部 crate 继续显示不同版本。

## 约束

- 不修改用户未提交的依赖锁文件变更。
- CI 发布仍由 Tauri 配置控制目标平台和安装包类型。
- 后续升级版本时，同一提交内同步更新 `package.json`、`tauri.conf.json` 和 `Cargo.toml`。
