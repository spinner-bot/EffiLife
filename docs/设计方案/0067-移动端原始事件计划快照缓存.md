# 移动端原始事件计划快照缓存

## 目标

为移动端统一存档提供事件计划的安全承载，先支持原始 plan 快照的导入、导出和只读查看，为后续兼容运行时铺路。

## 数据边界

- 新增独立 IndexedDB store：`plan_helper_snapshot`，只保存 plan-helper `/api/data/export` 返回的原始 `plans` 数组。
- 不复用 time-helper 的 `plans` store，不改变待办、记录或原始 plan 对象。
- 快照中的 section、任务槽位、软删除标识、嵌套 group 和日志全部原样保留。

## 移动端能力

- 可从 `.efl` 导入原始事件计划快照。
- 可从本地快照导出 `.efl`，并在统一工作台只读展示计划摘要和任务。
- 创建、编辑、完成、删除、分组、日志等写操作继续明确不可用，避免产生与 plan-helper 不兼容的第二套模型。

## 迁移与恢复

IndexedDB 版本从 2 升至 3，仅新增 store，不迁移或删除已有 store。导入采用 replace 语义；没有可用事件计划快照时清空该 store，避免残留旧数据混入新存档。

## 验收

- 旧 IndexedDB 数据可正常升级。
- 桌面端 HTTP plan-helper 行为不变。
- 移动端导入后可再次导出同一原始快照。
- 移动端写操作仍返回明确不可用状态。
