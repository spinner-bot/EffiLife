# 0378 计划任务待办关联状态方案

## 问题

计划详情页此前对已关联待办的任务仍显示“加入待办”。用户再次点击后才收到重复关联错误，关联状态没有成为界面的一部分。

## 决策

1. 进入计划详情时读取统一待办集合，按 `related_plan_id` 和 `related_plan_task_id` 建立轻量索引。
2. 已关联任务显示“已关联待办”、使用成功色，并禁用重复操作。
3. 新关联成功后立即更新索引，不等待整页重新加载。
4. 待读取待办存储失败时索引回到空集合，原有手动关联功能仍可用；真正写入失败继续显示错误。
5. 同时识别任务内部编号和显示编号，兼容软删除后产生的双编号引用。
