# 统一工作台运行时端点方案

## 背景

统一前端需要访问 Plan Helper API。此前计划网关和存档服务分别写入固定地址，端口或部署地址变化时容易出现只有部分功能可用的配置分叉。

## 方案

- 由 `src/services/runtimeConfig.ts` 集中提供 `PLAN_HELPER_ORIGIN`。
- 通过 Vite 环境变量 `VITE_PLAN_HELPER_ORIGIN` 覆盖地址。
- 未配置时继续使用本地启动器的默认地址 `http://127.0.0.1:8765`。
- 计划查询、计划写入以及 `.efl` 存档导入导出全部使用同一端点。
- 端点只规范化尾部斜杠，不改变协议、主机或端口，避免拼接出双斜杠。

这样既保持现有启动器零配置可用，也为局域网部署、测试环境和桌面打包提供统一切换点。
