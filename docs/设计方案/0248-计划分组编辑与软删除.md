# 0248 计划分组编辑与软删除

## 背景

plan-helper 原始 API 已支持 section 元数据更新和软删除，但统一工作台此前只有新增入口，导致已创建计划的结构无法完整维护。

## 决策

- “编辑分组”只更新名称和说明，不重建 section，不触碰其中任务槽位。
- “清空分组”调用 plan-helper 的 `del_section` 语义：将任务槽位恢复为 `[None]`，保留 section 索引，避免历史编号整体重排。
- 清空前逐项解除统一待办中的计划任务引用；待办本身保留，避免出现指向已失效任务的链接。
- 移动端快照复用同一语义，直接修改本地 raw plan；离线缓存仍保持只读。

## 验收

- 已有分组可编辑、清空、取消编辑。
- 嵌套 group 和历史索引不被前端重新编号。
- 计划服务与移动快照路径均有实现，文案在中英文资源中成对存在。
