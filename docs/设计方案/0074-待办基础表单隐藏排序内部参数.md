# 待办基础表单隐藏排序内部参数

## 依据

用户要求排序分值位于待办条目右端，待办内容是核心，基础创建表单不应把内部排序参数置于内容输入旁边。

## 方案

- 从创建和编辑基础表单移除 `priority_rank` 输入控件。
- 条目右侧继续展示计算后的排序分值。
- 创建任务使用默认排序值 0；编辑已有任务时保留原有 `priority_rank` 并继续提交，避免数据丢失。
- 紧急、重要、截止时间等用户可理解的排序因素保留在基础流程中。

## 验收

- 创建/编辑表单不再要求用户理解排序分值。
- 待办条目右侧仍可查看排序结果。
- 旧数据的 `priority_rank` 不被迁移或清空。
