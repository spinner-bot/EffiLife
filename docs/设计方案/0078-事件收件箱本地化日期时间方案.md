# 事件收件箱本地化日期时间方案

## 背景

事件收件箱的触发时间此前由字符串拼接生成 `MM-DD HH:mm`。这绕过了统一语言设置，在中文、英文及其它未来语言环境中都可能产生不一致的日期阅读顺序。

## 方案

- 复用统一 i18n 当前语言 `locale`。
- 使用 `Intl.DateTimeFormat` 生成月、日、小时和分钟。
- 保留两位数字字段，确保收件箱列表对齐稳定。
- 对损坏或不可解析的历史时间保留原始字符串，避免历史通知因显示失败而消失。

## 边界

- 不修改事件存储格式，`triggeredAt` 仍保存原始时间字符串。
- 不改变排序、已读状态、提醒补打卡和事件过滤逻辑。
- 这是显示层修复，不影响 TH、PH、TD 的领域边界。

## 验证

- 静态契约测试确认使用当前语言环境与 `Intl.DateTimeFormat`。
- 前端类型检查和生产构建必须通过。
