# 统一工作台启动错误可诊断方案

## 背景

统一壳在本地存储、音频、打卡或计划模块初始化失败时需要停止渲染业务页面，但仅显示“启动失败”无法帮助用户判断重试是否有效。

## 方案

- 捕获初始化异常的 `Error.message`，只在启动错误态展示；
- 错误标题、说明和详情标签全部使用 i18n；
- 详情使用等宽字体、可换行布局，避免长路径或 WebView 错误撑破窗口；
- 重试仍通过整页 reload 执行，不改变既有恢复行为；
- 详情不进入正常业务页面、日志收集或存档，避免扩大数据暴露范围。

## 兼容性

非 `Error` 异常统一转为字符串；空错误信息时隐藏详情块。正常初始化路径不创建额外网络请求或持久化数据。
