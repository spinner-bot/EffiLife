# 公共适配层字段兼容方案

**文档性质**：实施设计方案  
**创建时间**：2026-09-25（Asia/Shanghai）  
**适用范围**：common 统一模型与三个模块的字段适配

## 1. 问题

统一前端时间记录使用英文业务字段，历史 time-helper 适配器使用中文字段；待办分类的 `difficulty` 也没有进入公共分类模型。直接跨层转换会出现空日期、零时长或分类配置丢失。

## 2. 决策

- `TimeAdapter.to_unified_record` 同时识别统一前端字段和历史中文字段，优先使用统一字段。
- 统一时间记录的关联优先读取 `todo_id`，并兼容公共层已有的 `related_todo_id`。
- `UnifiedCategory` 增加 `difficulty`，默认值为 5，保持旧分类输入可读取。
- 不改变旧模块的原始存储格式；兼容逻辑集中在 common 适配层，避免污染领域模型。
