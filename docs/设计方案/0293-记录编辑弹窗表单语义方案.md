# 记录编辑弹窗表单语义方案

## 背景

统一记录页的新增/编辑弹窗当前由多个普通容器组成，保存动作只绑定在按钮点击上。输入时间、时长或内容后，桌面键盘和移动端软键盘不能稳定地通过表单提交完成保存，模式切换按钮也没有明确的按钮类型。

## 决策

- 用一个原生 `<form>` 包裹弹窗标题、输入区和底部操作区；
- 使用 `@submit.prevent="saveRecord"` 作为唯一保存入口；
- 模式切换、关闭和取消按钮显式声明 `type="button"`；
- 保存按钮显式声明 `type="submit"`；
- 增加表单容器的 flex 与最小高度规则，保持原弹窗的滚动区域、底部操作区和移动端布局；
- 不改变时间记录校验、存储和待办关联逻辑。

## 验证

- 增加静态契约，确认表单提交入口和按钮类型；
- 执行 Python 全量测试；
- 执行桌面端 Vite 生产构建。
