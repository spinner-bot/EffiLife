# 启动器存档验证命令方案

## 用途

为测试、迁移和支持场景提供不启动前端、不启动 plan-helper 的 `.efl` 健康检查入口。

## 命令

```text
python launcher/start.py --verify-bundle path/to/workspace.efl
python launcher/start.py --verify-bundle=path/to/workspace.efl
```

成功时输出 `ok: true` 及统一验证报告；文件缺失、协议不支持、数据集缺失或摘要不匹配时输出 `ok: false` 并以非零状态退出。命令复用 `common.verify_workspace_bundle`，不另建一套校验逻辑。
