# 0235 启动器静态构建回退

## 问题

测试启动器原先只支持 Node/npm 开发服务器或已编译 Tauri 可执行文件。机器没有 Node/npm、但仓库已有 `dist` 构建产物时，统一工作台仍被判定为不可用。

## 方案

启动顺序保持为：开发服务器 → Tauri 可执行文件 → 静态 `dist`。静态回退使用 Python 内置 `http.server`，只服务本地构建产物，不改变正式 Tauri 安装包入口。to-dos 兼容 Web 入口采用相同策略。

## 边界

静态回退用于测试、迁移和本地演示；正式版本仍通过 Tauri 安装包交付。若没有 Node、Tauri 可执行文件和 `dist`，启动器继续明确报告不可用原因。
