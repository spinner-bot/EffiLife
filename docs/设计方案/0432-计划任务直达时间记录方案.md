# 计划任务直达时间记录方案

- 状态：[完成]
- 创建时间：2026-09-29
- 执行者：Codex
- 关联目标：统一计划、待办与时间记录工作流

## 1. 背景

计划详情当前可以记录 Plan Helper 的文字进展，也可以打开关联待办；但“实际花了多久”仍需要用户先离开计划详情，再从待办中心或时间记录页重新寻找任务。这样会割裂计划执行流程。

## 2. 方案

在计划任务行中，为已经关联统一待办的任务增加“记录用时”入口。入口只携带已有待办 ID 跳转到统一记录页，由记录页负责打开表单并预选待办。

```text
计划任务
  ├─ 未关联待办：保留“加入待办”
  └─ 已关联待办：查看待办 + 记录用时
                         │
                         └─ /records?todo=<existing-id>
```

## 3. 约束与取舍

- 不修改原始 plan 数据结构，也不为任务复制新的关联字段；继续使用现有 `linkedTodoIdsByTask` 映射。
- 不自动创建待办、不自动创建时间记录；只有用户明确点击后才进入记录表单。
- 已完成任务仍可记录实际用时，因此入口不依赖 `!task.finish`；这符合复盘和补记场景。
- 未关联任务不显示入口，避免隐式创建待办或产生无法追溯的记录。
- 记录页已有 query 预选和校验逻辑，本次只复用现有导航契约。

## 4. 验收标准

- [x] 已关联任务显示记录用时按钮。
- [x] 点击按钮跳转 `/records?todo=<已有待办 ID>`。
- [x] 未关联任务不显示记录用时按钮。
- [x] 中英文文案均已补齐。
- [x] 桌面和窄屏布局均保留可点击入口。
