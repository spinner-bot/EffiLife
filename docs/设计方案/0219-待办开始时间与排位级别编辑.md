# 0219 待办开始时间与排位级别编辑

## 背景

统一待办数据模型已经包含 `start_time` 和 `priority_rank`，优先级算法也会使用它们；但任务中心只展示紧急/重要选项，创建和编辑表单无法修改这两个核心输入。

## 方案

- 创建表单增加开始时间和排位级别输入，开始时间默认当前本地时间。
- 编辑表单读取并保存已有开始时间与排位级别。
- `datetime-local` 仅作为界面格式，保存时转换为 ISO 时间；不改变统一数据结构。
- 排位分继续作为条目右侧紧凑指标展示，编辑字段只出现在详情编辑态。

## 验收

- 新建待办可设置开始时间和非负整数排位级别。
- 编辑已有待办可保留并修改这两个字段。
- 中英文标签齐全，前端 TypeScript 解析和回归测试通过。
