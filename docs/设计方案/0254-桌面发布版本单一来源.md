# 0254 桌面发布版本单一来源

## 问题

仓库版本文件与桌面 package、Tauri、Cargo 元数据可能不同步，导致前端版本显示、安装包版本和升级识别不一致。

## 决策

- `time-helper/VERSION` 是发布版本的唯一来源。
- 发布 CI 在 `npm ci` 完成后、测试和 Tauri 打包前运行 `scripts/sync_desktop_version.py`。
- 脚本同步 `package.json`、`tauri.conf.json` 和 `Cargo.toml`，不改写 `package-lock.json`。
- 本地开发仍使用提交中的稳定依赖锁文件；正式构建阶段再注入发布版本。
