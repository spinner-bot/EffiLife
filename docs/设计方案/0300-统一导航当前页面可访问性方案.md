# 统一导航当前页面可访问性方案

## 背景

统一应用壳的桌面导航和移动底部导航通过 CSS 高亮当前路由，但没有向辅助技术声明当前页面；搜索按钮也没有暴露已支持的快捷键。

## 决策

- 为桌面和移动导航中的当前 `RouterLink` 添加 `aria-current="page"`，非当前链接不输出该属性；
- 为全局搜索入口添加 `aria-keyshortcuts="Control+K Meta+K"`；
- 保持现有路由、视觉样式和快捷键焦点边界不变。

## 验证

- 增加统一壳静态契约，覆盖两套导航和搜索快捷键声明；
- 执行 Python 全量测试；
- 执行桌面端 Vite 生产构建。
