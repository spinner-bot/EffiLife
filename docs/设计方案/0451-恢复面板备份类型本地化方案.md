# 恢复面板备份类型本地化方案

## 背景

恢复面板直接显示 `BackupData.module` 内部标识。统一存档导入新增的 `archive_import` 检查点会因此以实现细节呈现，英文用户也会看到 Python/IndexedDB 侧的模块名。

## 方案

- 在恢复面板建立已知备份类型到 i18n key 的映射；
- 覆盖统一存档检查点、配置、计划、时间记录、日程规则、手动计划和迁移检查点；
- 未知模块继续显示原始名称，保证旧备份可见且不因新版本映射缺失而消失；
- 不修改备份协议中的 `module` 值，保持恢复逻辑和兼容性不变。

## 验收

- 增加组件契约测试，确认映射和未知回退存在；
- 运行前端生产构建与全量 Python 测试；
- 保持用户已有 `time-helper/desk/package-lock.json` 不变。
