# 创建计划同时生成待办方案

## 背景

统一计划详情已有“全部加入待办”能力，创建弹窗也已有对应 i18n 文案，但创建计划时必须再进入详情页手动触发，计划到待办的整合链路仍然断开。

## 方案

- 创建弹窗增加默认关闭的“同时生成待办”复选框，适用于手工计划和模板计划。
- 创建成功后复用现有批量关联逻辑：只为未完成且没有活动关联的计划任务创建待办。
- 待办沿用 `related_plan_id`、`related_plan_task_id`、计划名称描述和预计用时字段。
- 单项创建失败不回滚计划；通过现有成功/失败提示告知用户，用户可在详情页再次补齐。
- 默认不勾选，保持创建计划的最小副作用和用户可预测性。

## 不变约束

- 不改变计划创建 API、任务编号、嵌套组、软删除或待办存储结构。
- 不产生重复活动待办；同时识别内部任务 ID和显示任务 ID。
- 不把模板内容复制进待办以外的数据结构，继续由计划关联字段追踪来源。
