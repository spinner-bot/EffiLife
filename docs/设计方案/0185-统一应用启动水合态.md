# 0185 统一应用启动水合态

## 设计决策

- 美学方向：Linear 风格的“工作台启动帧”，使用现有主题 token，不新增独立视觉体系。
- 布局：启动阶段保持全屏背景与居中单行状态，不挂载业务导航，避免用户看到尚未同步的数据。
- 状态：仅覆盖启动加载态；失败仍由既有服务回退机制处理，不增加打断式弹窗。
- 动效：使用短促的透明度/位移动画，并在 `prefers-reduced-motion: reduce` 下关闭过渡。
- 组件边界：应用壳等待音频、事件、打卡三项主存储水合，再挂载 RouterView、EventPopup、CheckinPopup 和 GuideOverlay。
- 可访问性：启动状态使用 `role="status"` 和 `aria-live="polite"`，不依赖颜色传达状态。

## 影响范围

只调整 `App.vue` 的启动门控和加载状态，不改变页面业务 API、路由地址或存储结构。
