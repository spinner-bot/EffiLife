# 0369 启动器统一数据根目录传递

## 决策

启动器通过可选环境变量 `EFFILIFE_DATA_DIR` 向 plan-helper sidecar 传递统一数据根目录，转换为其现有的 `--data-dir` 参数。这样打包版本可以把 sidecar 数据放入平台应用数据目录，开发环境在未设置变量时仍保持原有仓库内数据行为。

## 边界

- 本次不迁移已有仓库数据，也不静默覆盖用户数据；
- 未配置变量时命令行完全保持兼容；
- `--diagnose` 输出实际配置的数据根目录，便于定位数据写入位置；
- 后续正式安装包应在启动进程前设置平台对应的 `EFFILIFE_DATA_DIR`。
