# 0296-统一搜索时间记录索引

## 背景

统一搜索覆盖待办、事件计划、计划任务和时间记录。但 IndexedDB 的时间记录 store 使用通用 `set()` 保存，底层记录带有 `{ key, value }` 包装；搜索组件直接读取 `getRawAll()` 后再 `flat()`，得到的不是 `TimeRecord`，因此内容和标签无法可靠命中。

## 方案

改用存储层的 `getAll<TimeRecord[]>()`：该接口负责移除底层包装并返回按日期分组的记录数组，搜索组件继续展平数组后建立记录结果。待办等原生 keyPath 数据不受影响。

## 验收

- 搜索时间记录内容或标签可以得到结果。
- 计划、计划任务和待办搜索行为保持不变。
- 不改变 IndexedDB schema 或历史数据。
