# 任务分类置顶交互方案

**文档性质**：实施设计方案  
**创建时间**：2026-09-25（Asia/Shanghai）  
**适用范围**：统一任务中心分类导航

## 1. 背景

分类排序已经支持读取 `pinned` 字段，但没有统一界面入口，用户无法主动控制重要分类的展示顺序。

## 2. 决策

- 在分类管理列表提供置顶/取消置顶按钮，直接更新分类自身的 `pinned` 字段。
- 分类导航继续按“置顶优先、分类分数降序、名称升序”排序；置顶不改变任务优先排位分，也不把单任务分数置顶显示。
- 更新通过 `TodoCategoryService` 写入现有分类存储，导入导出沿用既有分类归一化协议。
- 默认分类也允许置顶，但不能删除。
