# 自定义设置表单语义方案

## 背景

设置页的自定义时间显示区域包含阈值和显示选项，但保存仅绑定在普通按钮点击上。随着统一工作台支持桌面和移动端，这一入口应与待办、记录、计划编辑器使用一致的表单提交语义。

## 决策

- 将自定义设置区域包裹为原生 `<form>`，使用 `@submit.prevent="saveCustomSettings"`；
- 阈值加减按钮显式使用 `type="button"`，避免未来被表单默认提交；
- 返回按钮使用 `type="button"`，保存按钮使用 `type="submit"`；
- 不改变设置状态、阈值边界、存储键和保存提示逻辑。

## 验证

- 增加静态契约，确认唯一提交入口与按钮类型；
- 执行 Python 全量测试；
- 执行桌面端 Vite 生产构建。
