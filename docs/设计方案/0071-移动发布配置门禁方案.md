# 移动发布配置门禁方案

## 状态

- 状态：已落地配置门禁，待原生工具链验收
- 日期：2026-09-29
- 范围：Tauri Mobile 构建配置和桌面发布 CI

## 背景

EffiLife 的移动运行时不依赖 Python Plan Helper sidecar。此前已有移动附加配置，但只有针对性测试，发布脚本没有一个独立的、可在无 Android/iOS SDK 环境执行的配置门禁。

## 决策

- 新增 `scripts/check_mobile_release_config.py`，只检查配置边界，不探测或安装 SDK；
- 检查桌面配置仍声明 sidecar；
- 检查移动配置只执行前端构建并清空 `externalBin`；
- 将门禁接入桌面发布 workflow，使每个平台发布矩阵都先验证移动配置未被误改；
- Android/iOS SDK、签名、模拟器和真机验收仍由后续专门 job 或发布机完成，不在本门禁中伪造完成状态。
