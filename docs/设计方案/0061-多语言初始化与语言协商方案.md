# 多语言初始化与语言协商方案

## 状态

- 状态：已落地
- 日期：2026-09-29
- 范围：统一应用壳的 locale 初始化与持久化

## 问题

语言模块在导入阶段直接访问 `localStorage`，受限 WebView 或隐私模式可能因此阻断应用启动；没有用户选择时也固定使用中文，无法尊重浏览器语言；动态切换后 `document.documentElement.lang` 不同步，不利于辅助技术和后续多语言扩展。

## 决策

- 统一维护 `SUPPORTED_LOCALES`，语言选项从常量导出，新增语言只需扩展目录和类型；
- 解析顺序为：已保存的精确语言 → 浏览器 `navigator.languages`/`navigator.language` 的语言前缀 → 中文默认值；
- 所有存储读写使用容错处理，localStorage 不可用时仍可运行；
- `setLocale` 同步更新 `document.documentElement.lang`；
- 未支持的语言安全回退到中文，不把任意浏览器字符串写入运行时状态。
