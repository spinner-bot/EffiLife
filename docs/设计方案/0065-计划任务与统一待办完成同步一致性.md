# 计划任务与统一待办完成同步一致性

## 问题

统一待办可以引用 plan-helper 的 `related_plan_id` 和 `related_plan_task_id`。完成待办时需要同时完成计划任务；两个存储边界之间不存在事务，必须明确失败时的优先顺序。

## 决策

- 对有计划引用的待办，先调用 plan-helper 完成原始计划任务。
- 计划任务调用失败时，不更新本地待办状态，保留待办为未完成并显示同步错误。
- 计划任务成功后，再更新统一待办；若本地写入失败，计划任务已完成，界面报告错误，后续可通过计划中心的反向同步修复关联待办。
- 无计划引用的待办保持原有本地完成流程。

该方案不改变 plan-helper 的原始任务 ID、显示编号或嵌套组模型。

## 验收

- plan-helper 不可用时，关联待办不会被标记为完成。
- plan-helper 成功时，计划任务和待办按既定顺序更新。
- 非关联待办行为不变。
