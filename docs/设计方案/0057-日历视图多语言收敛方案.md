# 日历视图多语言收敛方案

## 范围

本方案只处理 time-helper 的历史时间记录日历视图及其日期详情弹窗，不为 plan-helper 增加日历功能。plan-helper 的事件计划仍使用统一计划中心和日期字段。

## 决策

- 日历标题、月份导航、星期、统计概览、图例、详情弹窗和空状态接入现有 `useI18n()`。
- 日期、月份、记录数量和完成度仍由现有计算逻辑生成；翻译键只负责周边文案。
- 星期显示使用响应式翻译值，语言切换后不改变日期索引和数据查询。
- 保持日历到日详情页的路由、弹窗关闭、热力图和快速翻页行为。
