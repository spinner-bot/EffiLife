# 0387 历史记录待办导航一致性方案

## 背景

统一记录页已经支持关联待办导航，但历史日期详情页只有在通过待办深链进入时才显示导航按钮。用户从记录历史自然浏览时无法回到关联待办，造成同一数据关系在两个记录入口表现不一致。

## 决策

1. 历史日期详情页只要记录存在 `todo_id`，就显示“打开关联待办”按钮。
2. 继续使用 `/tasks?todo=<id>` 深链和待办中心已有的定位逻辑，不复制待办加载或修复逻辑。
3. `todo` 查询参数仍只负责高亮关联记录；普通历史浏览不再影响按钮是否出现。
4. 不改变时间记录、待办累计用时或存档数据结构。

## 验收

- 通过待办深链进入历史记录时仍高亮目标记录。
- 普通进入历史日期详情时，所有有关联待办的记录均可打开待办中心。
- 中文和英文继续复用已有文案。
