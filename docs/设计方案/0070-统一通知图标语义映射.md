# 0070 统一通知图标语义映射

## 背景

统一工作台的通知数据仍可能携带历史 emoji 图标。直接把字符串渲染到首页、事件管理和弹出通知中，会绕过主题颜色、尺寸和无障碍语义，也不符合 `docs/spec/UI 设计理念.md` 中“图标使用专业图标库”的约束。

## 方案

- 通知展示层根据事件类型选择 Lucide 图标组件。
- 保留原始通知数据中的 `icon` 字段，避免破坏存档和旧数据；展示时不再把任意字符串当作 UI 图标。
- 未识别类型使用 `Bell` 作为稳定回退图标。
- 图标颜色继续由现有主题 CSS 控制，尺寸由所在组件统一传入。

## 语义映射

| 事件类型 | 图标 |
| --- | --- |
| achievement / checkin | `Trophy` |
| event | `CalendarClock` |
| warning / reminder | `BellRing` |
| 其它 | `Inbox` |

## 兼容性

本次只调整展示层，不修改事件对象、存档格式或跨模块引用；旧通知仍可正常读取，未来新增事件类型只需扩展映射表。
