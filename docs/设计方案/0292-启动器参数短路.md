# 0292-启动器参数短路

## 背景

`--version` 属于只读的脚本接口，不应为了输出一个版本字符串而探测 Node/npm、前端依赖和模块可用性。

## 方案

在 `launcher/start.py` 的 `main()` 中优先处理 `--version`，仅读取 `time-helper/VERSION` 并输出结果；只有需要诊断、统一启动或交互菜单时才构建模块配置。

## 验收

- `python launcher/start.py --version` 只输出版本号。
- 单元测试确认版本参数不会调用 `build_modules()`。
- 不改变 `--diagnose`、`--unified` 和兼容菜单行为。
