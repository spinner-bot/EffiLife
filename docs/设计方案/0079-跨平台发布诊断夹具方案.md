# 跨平台发布诊断夹具方案

## 背景

启动器的发布诊断需要识别 Windows 与 POSIX 两种 Android SDK 工具命名。原测试夹具固定创建 Windows 文件名，导致 Windows 本地测试通过而 Ubuntu CI 失败，无法证明诊断逻辑跨平台可靠。

## 方案

- 测试夹具根据当前运行平台创建对应的工具文件名：
  - Windows：`apksigner.bat`、`zipalign.exe`；
  - POSIX：`apksigner`、`zipalign`。
- 断言复用夹具实际生成的名称，不在测试中硬编码另一平台的后缀。
- 保持生产代码对真实 Android SDK 的平台命名判断不变。

## 边界

- 不修改签名工具查找策略或正式发布凭据策略。
- 不把缺少签名凭据误判为 CI 失败；本次只修复测试环境与平台命名不一致。
- 不改变桌面、Android 构建和 iOS 延后边界。

## 验证

- Windows 本地完整回归。
- POSIX 命名模拟下的完整回归。
- CI 推送后的真实 Ubuntu `EffiLife CI` 运行。
