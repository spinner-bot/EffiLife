## 1. 触发原因

参考 `F:/资源夹/赛事/HydroAI Flow/README.md` 的做法，将 EffiLife 根 README 从“项目说明文档”提升为可快速识别产品定位的封面式入口。

## 2. 目标

1. README 首屏直接展示统一时间管理工作台的产品身份。
2. 使用仓库内 SVG 实现轻量、可审阅、可版本控制的动画封面，不引入二进制图片依赖。
3. 覆盖时间记录、计划编排、待办协同三条核心工作流，并说明桌面正式发布与开发启动器的边界。
4. 尊重 `prefers-reduced-motion`，同时提供 SVG 的 `title` 与 `desc`，保证静态阅读和辅助技术可用。
5. 保留面向开发者的运行、数据、文档和路线入口，避免封面化后丢失工程信息。

## 3. 方案与取舍

### 采用：SVG 动画封面 + 分层产品 README

- 动画元素采用时间环、任务卡片、进度流线和网格，分别映射记录、计划、待办与持续推进。
- 动效只使用 SVG/CSS 内置动画，不依赖 JavaScript、构建步骤或在线服务。
- README 以“产品定位 → 三步工作流 → 启动边界 → 工程入口 → 当前状态”为阅读顺序。

### 否决：视频/GIF 封面

视频或 GIF 会增加仓库体积、降低可审阅性，且无法自然响应减少动画偏好；本项目的 SVG 方案更适合长期维护和多端文档预览。

### 否决：仅保留一行图片 README

只有封面会牺牲安装、开发和数据迁移信息，不利于贡献者和测试人员复现，因此保留结构化正文。

- [x] 封面包含产品名、英文定位、三项核心能力和统一工作流视觉隐喻。
- [x] SVG 包含无障碍元数据和减少动画媒体查询。
- [x] README 明确 launcher 仅用于开发/测试，正式版本使用 Tauri 安装包。
- [x] 有静态测试防止封面入口、无障碍元数据和关键产品信息回退。
