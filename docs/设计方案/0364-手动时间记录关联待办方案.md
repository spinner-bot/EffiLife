# 0364 手动时间记录关联待办方案

## 背景

待办中心的专注计时可以自动生成时间记录，但记录页手动新增的记录此前没有待办关联入口，导致用户从记录开始工作时无法把三类数据连起来。

## 决策

1. 记录表单增加可选的待办下拉框，默认“不关联待办”。
2. 保存新记录时生成稳定记录 ID，并把 ID 写入选中待办的 `related_time_record_ids`。
3. 编辑记录更换待办时，清理旧待办关联，再写入新待办关联。
4. 删除记录继续复用 `unlinkTodoFromTimeRecord`，不删除待办历史累计用时。
5. 关联同步失败时，记录本身仍保留，但显示明确错误 Toast，避免伪装成完全成功。
6. 旧记录没有 ID 时仅在编辑保存时补齐，不改变旧数据读取兼容性。

## 验证标准

- 新增和编辑表单能选择待办。
- 保存后时间记录和待办拥有可追溯的双向关联。
- 归档/取消的待办不出现在普通选择列表中，但正在编辑的历史关联仍可显示。
- 中英文文案和契约测试完整。
