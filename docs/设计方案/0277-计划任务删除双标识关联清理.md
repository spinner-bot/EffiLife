# 0277 计划任务删除双标识关联清理

## 背景

计划任务同时存在稳定的内部标识和面向用户显示的编号。当前新建待办使用内部标识，但旧数据或外部导入可能使用显示编号。单任务删除如果只清理内部标识，会留下无法再定位的待办关联。

## 方案

删除单个任务时同时清理 `internal_id` 与 `display_id` 两种关联；两者相同时只执行一次。删除动作本身仍由 plan-helper 网关完成，待办清理属于次级同步，失败时保留已有错误提示。

## 约束

- 不改变 plan.py 的任务编号和软删除语义。
- 不删除待办，只解除失效的计划任务引用。
- 与整组/整节删除保持一致。
