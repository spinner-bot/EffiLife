# 0409｜认证数据原子写入方案

## 背景

统一数据层、to-dos 存储和统一存档已经避免直接覆盖 JSON，但认证用户列表和当前会话仍可能在进程中断时留下截断文件。

## 设计决策

- `users.json` 与 `current_user.json` 使用同目录临时文件、`flush`、`fsync` 和 `os.replace` 写入。
- 登出仍通过删除会话文件实现，不改变会话语义。
- 不改变用户模型、密码哈希、目录优先级或认证 API。

## 验收标准

1. 用户列表和会话写入均使用原子工具。
2. 注册、登录、登出、偏好更新和用户删除行为保持兼容。
3. 统一根目录和历史默认目录均可正常重载。
