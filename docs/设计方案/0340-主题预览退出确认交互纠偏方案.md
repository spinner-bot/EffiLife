# 主题预览退出确认交互纠偏方案

## 背景

`docs/req/6[th]-测试结论.txt` 明确要求：选择主题后立即预应用，离开设置时若有变化再询问是否保存。上一轮为解决“主题保存不明显”增加了显式保存按钮，但这改变了既定交互契约。

## 方案

- 保留主题选择和参数调整的即时预览；
- 主题页不提供独立保存按钮；
- 点击返回离开主题页时，若 `themeDirty`，弹出统一确认框；
- 选择保存时调用现有 `saveTheme()`，选择放弃时恢复 `savedThemeSnapshot`；
- 保存后继续通过 `DataService.saveConfig()`、IndexedDB/localStorage 双写和工作区通知持久化；
- 不拦截浏览器刷新或返回，避免制造不可关闭的拦截式交互。

## 验收

- 当前主题页没有显式保存按钮；
- 主题切换能立即预览；
- 返回时只在发生变化时询问保存；
- 保存和放弃后均不再重复询问；
- 主题持久化契约、前端构建和全量测试通过。
