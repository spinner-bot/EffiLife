# 0377 计划创建待办联动方案

## 背景

统一工作台已经能在计划详情中手动把单个计划任务加入待办，但新建计划时仍需逐个操作，计划和待办的融合不够连续。

## 决策

1. 在新建计划弹层提供可选的“同时生成待办”开关，默认关闭，不改变已有用户的创建行为。
2. 开关开启后，创建完成的每个未完成任务生成一个统一待办，并写入 `related_plan_id` 与 `related_plan_task_id` 双向引用。
3. 模板创建和手动创建共用同一同步函数，避免两条路径产生不同字段形状。
4. 计划创建成功优先于待办同步；个别待办失败时保留计划，并通过非阻塞错误提示报告，不回滚已经创建的计划。
5. 预计时长同时写入 `time_estimate` 和 `estimated_time`，保持旧待办字段兼容。

## 边界

移动端本地计划创建仍可使用该开关，待办写入本地统一 IndexedDB；跨模块状态同步继续由现有 workspace sync 负责。
