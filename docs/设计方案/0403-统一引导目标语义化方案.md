# 0403｜统一引导目标语义化方案

## 设计决策

- 新手引导不再使用 `.global-nav-link:nth-child(n)` 这类依赖视觉顺序的选择器。
- 桌面导航和移动底部导航对同一业务入口使用相同的 `data-guide` 语义标识，入口顺序可以独立调整。
- 当前引导只介绍统一应用壳的计划、待办、记录和设置，不重新引入已退役的独立日历概念。
- 遮罩定位从同名候选项中优先选择当前可见元素，避免桌面导航和移动导航同时存在时命中隐藏节点。
- 继续使用现有引导遮罩与主题 token，不改变引导存储、跳过和完成状态。

## 验收标准

1. 计划、待办、记录、设置四个步骤均通过 `data-guide` 定位。
2. 桌面与移动导航均提供对应标识。
3. 引导源码不依赖导航项的 `nth-child` 序号。
4. 中英文引导文案与当前统一工作台入口保持一致。
