# Tauri 移动端存档导入交互方案

## 状态

- 状态：已落地
- 日期：2026-09-29
- 范围：统一应用壳的 `.efl` 存档导入入口

## 问题

桌面 Tauri 可以使用系统文件对话框，浏览器和 Tauri Mobile 则应使用 WebView 提供的 HTML 文件选择器。原逻辑只按“是否为 Tauri”分支，导致移动端调用了被移动运行时主动拒绝的桌面导入 API，用户无法真正选取存档。

## 决策

导入入口按能力而非运行时名称分流：

- `isTauriRuntime() && !isMobilePlatform()`：调用桌面原生文件对话框；
- 浏览器或 Tauri Mobile：触发隐藏的 `<input type="file" accept=".efl">`，复用同一套预览、确认、校验和写入流程。

移动端仍然使用统一 `.efl` 协议，不降低校验和数据集要求；仅替换文件获取方式。
