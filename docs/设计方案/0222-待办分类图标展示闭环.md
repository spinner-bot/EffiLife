# 0222 待办分类图标展示闭环

## 背景

分类编辑器已经支持 Lucide 图标、ASCII 图标和颜色，但任务列表与分类管理列表只显示颜色色点，用户选择的图标不会出现在日常使用场景。

## 方案

- 新增轻量共享分类图标预览组件。
- 使用 lucide 的图标注册表解析保存的 kebab-case 图标名，ASCII 图标优先显示字符。
- 在分类管理行和待办分类标签中展示图标，同时保留原有颜色标识。
- 未识别的历史图标回退为圆形图标，不影响旧数据。

## 验收

- 分类列表和待办条目都能看到所选图标。
- ASCII 图标可直接显示。
- 旧分类数据安全回退，现有分类编辑行为不变。
