# 0385 首页待办时间入口方案

## 背景

首页已经聚合计划进度和待办，但待办行只能完成或打开待办中心。用户想记录一个刚开始处理的待办时，必须先进入待办中心再切换到记录页，统一工作台的跨领域路径仍然偏长。

## 决策

1. 每个首页待办行增加轻量的时间记录入口，导航到 `/records?todo=<id>`。
2. 记录页复用已有查询参数处理，自动打开新增记录表单并预选目标待办，不在首页复制记录表单或时间校验逻辑。
3. 待办行同时显示已用时/预估时长；没有任何时长数据时不显示空占位。
4. 保持完成按钮、待办详情导航、计划同步和现有优先级排序不变。

## 结果

首页形成“查看待办 → 记录用时 → 返回统一数据”的短路径，记录仍由统一时间记录服务保存，并通过既有双向关联维护待办累计用时。
