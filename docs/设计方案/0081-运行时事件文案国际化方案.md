# 运行时事件文案国际化方案

## 背景

统一工作台的事件弹窗和收件箱已经使用 `i18n` catalog，但遗漏打卡提醒是在事件服务内部直接拼接中文。用户切换为 English 后，新产生的提醒会与界面语言混杂。

## 决策

- 事件服务只负责传入动态参数（日期、计划名），不直接持有用户可见自然语言。
- 新增 `settings.events.runtime.missedCheckinTitle` 与 `settings.events.runtime.missedCheckinMessage`，同时维护 `zh-CN` 与 `en-US`。
- 仍保留事件数据中的纯日期、计划名和可补打卡字段，旧存档中的历史中文提醒不做破坏性重写。
- 继续沿用现有 `translate()`，确保事件生成时使用当前语言，而不是启动时固定语言。

## 验收标准

1. 遗漏打卡提醒不再出现硬编码中文标题或消息。
2. 两个 locale 都包含新增 key。
3. 动态日期与计划名继续进入提醒文本。
4. 全量 Python 回归和前端构建通过。
