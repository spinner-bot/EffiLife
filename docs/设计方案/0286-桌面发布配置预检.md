# 0286 桌面发布配置预检

## 背景

桌面发布涉及版本文件、Tauri 配置、Cargo 清单、Plan Helper sidecar 和三平台 workflow。分散的测试能够覆盖部分契约，但开发者缺少一个可直接运行的发布前检查命令。

## 方案

新增 `scripts/check_release_config.py`，只读检查版本一致性、sidecar 构建钩子、三平台 workflow 矩阵、测试步骤和安装包校验和步骤。CI 在发布测试前执行同一脚本，保证本地和远程门禁一致。

## 使用

```text
python scripts/check_release_config.py
```
