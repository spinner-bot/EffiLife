# 任务排序设置统一存档方案

**文档性质**：实施设计方案  
**创建时间**：2026-09-25（Asia/Shanghai）  
**适用范围**：统一任务中心优先排位设置

## 1. 背景

优先排位需要定期刷新，分类导航也需要“前 N 个展开”的用户偏好。若仅写入页面局部状态，重启、导入存档或更换设备后会丢失配置，形成新的数据孤岛。

## 2. 决策

- 使用现有 IndexedDB `config` 对象存储中的 `todo_settings` 键保存设置，不增加独立数据库或模块私有文件。
- `.efl` 的 `data/app.json` 携带 `todoSettings`，旧存档缺失时使用默认值；导入时通过同一归一化入口写回。
- 刷新频率限制为 5/10/15/30/60 秒，分类展开数量限制为 1 至 20，避免误填造成高频计算或过长侧栏。
- 页面切换只重启计时器，不把实时分数写入任务数据；重置配置时一并清除排序设置。

## 3. 兼容性

旧版 `.efl`、旧版 IndexedDB 和没有设置字段的任务均可读取；缺失字段不会阻断待办或分类导入。
