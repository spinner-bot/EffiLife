# 日期字符串本地解析

## 背景

`YYYY-MM-DD` 是 EffiLife 的业务日期格式，不是一个带时区的时间戳。JavaScript 对 ISO 日期字符串调用 `new Date(value)` 时会按 UTC 解释，在负时区可能导致显示日期回退一天。

## 方案

在统一数据服务中提供 `parseLocalDate`：对标准 `YYYY-MM-DD` 使用本地年月日构造 `Date`，其他输入保留运行时解析作为兼容回退。日期范围查询、周报和日期加减全部复用该入口。

## 约束

- 业务日期的格式化继续使用本地 `getFullYear/getMonth/getDate`。
- 日期范围的逐日遍历只在本地日历上推进。
- 不改变对外 API 的日期字符串格式和返回结构。
