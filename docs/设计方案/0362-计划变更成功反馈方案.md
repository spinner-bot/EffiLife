# 0362 计划变更成功反馈方案

## 背景

统一计划工作台已经把计划、任务组、任务、日志和待办关联放在同一编辑流中，但保存后主要依赖内容刷新来表示成功。跨模块操作缺少明确反馈时，用户容易重复点击或误以为关联没有生效。

## 决策

1. 在计划工作台集中提供 `showPlanSaved` 反馈函数。
2. 计划元数据、分组、任务、日志、任务组、完成任务和删除任务组/任务等成功写入后显示统一成功 Toast。
3. 成功反馈只在主操作和视图刷新完成后触发；异常继续走原有错误提示。
4. Toast 文案通过中英文目录管理，保留已有具体的待办关联反馈。

## 验证标准

- 计划主要写入动作都调用统一反馈函数。
- 中英文目录各有一条 `plans.saved`。
- 不改变 Plan Helper 数据结构、嵌套任务组或待办关联逻辑。
