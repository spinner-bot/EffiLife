# 0394 跨运行时存档协议契约方案

## 背景

Python 公共层与 time-helper 前端已经共同使用 `effilife.bundle` 1.0.0 和五个 canonical dataset，但两端常量分散维护。单侧测试无法阻止未来新增、删除或重命名数据集造成跨运行时存档不可读。

## 决策

- 在 Python 测试层读取前端 `ArchiveService.ts` 的协议常量，校验格式名、版本号和 canonical dataset 集合一致。
- 继续允许前端保留 `archive.json` 旧版导入路径，但新导出只允许 manifest/data 协议。
- 将协议一致性作为全量回归的一部分，不在运行时引入 Python 依赖或改变领域存储。
