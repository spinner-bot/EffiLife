# 统一搜索深链接路由响应方案

## 状态

- 状态：已落地
- 日期：2026-09-29
- 范围：统一应用壳全局搜索到计划和待办工作台的跳转

## 问题

全局搜索通过 query 参数定位计划、计划任务和待办。Vue Router 在同一页面组件已挂载时会复用组件，不会再次触发 `onMounted`；因此从当前工作台再次搜索时，URL 会变化，但目标条目不会自动展开或滚动到可见位置。

## 决策

- 计划工作台监听 `plan` 和 `task` query；目标计划变化时加载详情，目标任务变化时滚动并短暂高亮；
- 待办工作台监听 `todo` query；目标待办变化时滚动并短暂高亮；
- 保留首次挂载时的定位逻辑，避免破坏直接打开深链接的行为；
- 查询变化只影响定位，不改变原有数据权威来源和跨模块关联结构。
