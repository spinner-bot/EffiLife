# 0276 统一时间记录删除关联清理

## 背景

桌面端有“记录中心”和“日详情”两个删除时间记录入口。记录中心已经在删除后清理待办侧的 `related_time_record_ids`，日详情此前只删除记录本身，造成入口行为不一致。

## 方案

日详情删除前先保存当前记录对象，删除成功后复用 `workspaceSync.unlinkTodoFromTimeRecord` 清理待办侧关联。清理失败只记录警告，不阻止已经完成的记录删除；这样不会影响用户的主要操作，也不会修改待办的历史统计。

## 约束

- 记录删除仍由 `DataService` 负责。
- 清理只移除记录 ID，不删除待办。
- 无 `todo_id` 或记录不存在时安全跳过。
- 各删除入口必须保持相同的关联清理语义。
