# 0218 计划日期本地化显示

## 背景

计划中心当前用固定的 `YYYY/MM/DD` 拼接日期。这样虽然能显示日，但英文环境仍沿用中文/内部格式，且无法使用系统语言的日期习惯。

## 方案

- 使用现有 i18n 的当前 locale 通过 `Intl.DateTimeFormat` 格式化计划日期。
- 显式指定年、月、日，保证日期不会退化为只显示年月。
- 保留底层计划日期三元组和编辑输入格式，不改变数据结构与保存逻辑。

## 验收

- 中文与英文环境都显示完整的年、月、日。
- 编辑器仍使用原生 `date` 输入并保持当前日期默认值。
- 通过专项静态测试和前端 TypeScript 解析。
