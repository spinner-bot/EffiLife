# 统一应用壳单次初始化方案

## 状态

- 状态：已落地
- 日期：2026-09-29
- 范围：time-helper 前端 Pinia 应用 store 的启动初始化

## 问题

应用壳已经在 `App.vue` 中等待 `appStore.init()` 完成后才渲染工作台，但首页还会再次调用初始化。重复调用可能并发执行数据迁移、示例数据生成和今日统计加载，增加启动竞态和不必要的 IO。

## 决策

- `appStore.init()` 在同一生命周期内复用正在进行的 Promise；
- 初始化失败时清空 Promise，允许启动错误页重试；
- 统一应用壳负责首次初始化，首页只负责自己的待办和事件摘要；
- 保留 store 公共 `init()` API，避免破坏独立测试或未来入口。
