# 0294-待办快速创建区

## 背景

待办创建区同时展示描述、标签、开始时间、排序级别、优先级、预计时长、分类、截止日期、重复规则和计划关联，首次使用时信息密度过高，核心动作“写下要做什么”不够突出。

## 方案

- 默认只显示待办标题输入和新增按钮。
- 将保留的可选字段放入原生 `details` 折叠区，使用“更多设置”明确其可选性质。
- 展开后使用网格布局，桌面端利用横向空间，移动端继续由既有响应式规则自然换行。
- 不改变字段、数据结构或创建逻辑，已有高级能力仍可直接使用。

## 设计依据

符合统一 UX 规范中的“核心内容优先”“减少认知负担”和“长表单分层”原则。
