# 前端多语言基础接入方案

**文档性质**：前端基础能力设计方案（实施前置）
**创建时间**：2026-09-25（Asia/Shanghai）
**适用范围**：time-helper 统一工作台首批页面

## 1. 目标

将多语言从公共 Python 层扩展到桌面工作台，先建立无第三方依赖的轻量 catalog 层，避免在三模块完全融合前引入额外框架耦合。

## 2. 方案

- 支持 `zh-CN` 与 `en-US`，locale 持久化到 `efflife_locale`。
- 翻译键使用点号路径，例如 `tasks.title`、`tasks.priority.normal`。
- 缺少目标语言键时回退到 zh-CN，再回退到键名；插值使用 `{name}`。
- `Intl.DateTimeFormat` 使用当前 locale，不在业务页面硬编码 `zh-CN`。
- 页面通过响应式 `t()` 读取文案，切换 locale 后无需刷新页面。

## 3. 接入范围

本阶段接入统一待办中心和首页主导航，作为后续计划、设置、存档页面迁移模板。旧页面暂不大规模重写，避免把翻译迁移与业务修复混在一起。

## 4. 状态与可用性

- locale 选择器具有默认、聚焦和切换状态。
- 不支持的 locale 自动回退到 `zh-CN`。
- 翻译缺失不阻断功能，不显示空白。

## 5. 验收条件

- 切换中英文后待办中心核心文案和首页待办入口即时变化。
- locale 刷新后保持。
- 日期格式随 locale 改变。
- 构建和类型检查通过。
