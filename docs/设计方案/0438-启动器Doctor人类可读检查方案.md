# 启动器 Doctor 人类可读检查方案

- 状态：[完成]
- 创建时间：2026-09-29
- 执行者：Codex
- 关联方案：0437-启动器诊断建议层方案.md

## 1. 背景

`--diagnose` 的 JSON 输出适合脚本和 CI，但不适合作为普通用户排查 launcher 启动问题的第一入口。需要一个不要求用户理解 JSON 的检查命令。

## 2. 方案

新增 `python launcher/start.py --doctor`：

- 复用现有只读诊断结果；
- 以 ASCII 安全文本展示版本、模式、工作台状态、阻塞问题和建议；
- 存在 `issues` 时返回退出码 1，只有提示或无问题时返回 0；
- 不启动服务、不打开浏览器、不写入数据。

`--diagnose` 保持原有 JSON 契约，不改变脚本和 CI 用法。

## 3. 验收标准

- [x] `--doctor` 输出人类可读检查结果。
- [x] 有阻塞问题时返回非零退出码。
- [x] 无阻塞问题但有发布提醒时返回 0。
- [x] 诊断仍然只读，并复用同一份事实来源。
