# 0233 事件计划服务离线只读降级

## 问题

统一工作台的事件计划来自 plan-helper 服务。桌面服务短暂不可用时，即使本地存在最近一次快照，页面也会直接进入错误状态，用户无法查看已有计划。

## 方案

- `planGateway` 在查询计划摘要、任务和完整计划失败时读取本地原始快照。
- 暴露 `planDataSource`，区分实时服务、移动端本地编辑和桌面离线缓存。
- 桌面离线缓存只读展示，并显示明确提示；所有计划写入入口隐藏，待服务恢复后重新加载。
- 待办中心在缓存模式下不允许建立新的计划任务关联，避免生成无法同步的引用。

## 边界

不把桌面缓存升级为第二个可写服务，不改变 plan-helper 原始数据结构、编号、软删除和归档语义。移动端原有本地编辑路径保持不变。
