# 0194 首页今日待办工作台

## 目标

首页除了显示待办数量，还应直接呈现用户下一步可执行的任务，减少在计划、时间记录和待办中心之间来回切换。

## 方案

- 从统一 `TodoService` 读取未完成待办。
- 按置顶、截止日期、优先级和创建时间进行稳定排序，展示前 3 项。
- 每项支持直接跳转待办中心；卡片提供查看全部入口。
- 保持待办中心作为唯一编辑入口，首页只承担摘要与导航职责。
- 空状态提供创建/进入待办中心的行动按钮。

## 验收

- 首页显示待办摘要、截止日期和剩余数量。
- 中英文界面文案完整。
- 待办数据刷新与现有首页定时刷新一致，不新增独立存储。
