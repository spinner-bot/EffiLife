# PH 日志日期跨运行时保真方案

## 问题

PH 原始日志允许保存可选的真实日历日期 `date`，与用于计划内排序/偏移的 `day` 不同。归档和原始 JSON 已保留该字段，但统一 API 和移动端投影曾将其丢弃。

## 决策

- Python API 的日志序列化只在字段存在时透传 `date`，不改变旧日志结构。
- 前端 `PlanLog` 与移动端 `RawPlan` 类型增加可选 `date`，从服务和快照两条路径保真读取。
- 不用 `day` 覆盖 `date`；`day` 继续表示 PH 的计划日语义。
- 本次不强制改变 UI 文案，先保证数据链路完整，后续可在日志卡片中按当前语言格式化真实日期。
