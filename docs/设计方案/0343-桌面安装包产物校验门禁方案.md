# 桌面安装包产物校验门禁方案

## 问题

仅依赖上传步骤发现安装包缺失，失败位置靠后且信息不明确。不同平台的 Tauri bundle 目录还需要验证平台对应的扩展名，避免误把缓存文件或错误产物当作发布包。

## 方案

发布矩阵显式声明目标扩展名：Windows NSIS 为 `.exe`、Linux deb 为 `.deb`、macOS DMG 为 `.dmg`。Tauri 构建完成后、生成 SHA-256 校验和前执行 `verify_release_artifacts.py`：

- bundle 目录必须存在；
- 至少存在一个匹配扩展名的普通文件；
- 文件大小必须大于 0；
- 失败立即停止当前平台 job。

校验脚本不修改产物，后续 checksum 和上传步骤保持不变。
