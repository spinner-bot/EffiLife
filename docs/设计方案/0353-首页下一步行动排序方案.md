# 首页下一步行动排序方案

日期：2026-09-30

## 背景

统一首页同时展示 PH 计划进度、TH 时间记录和 TD 待办。首页的“今日待办”卡片实际承担的是用户下一步行动入口，因此排序应首先反映时间紧迫度，而不能只按置顶或优先级排列。

## 决策

对活跃待办采用以下稳定排序：

1. 已逾期。
2. 今天到期。
3. 未来有截止时间，越近越前。
4. 没有截止时间。

同一紧迫度内继续使用原有的置顶、算法优先级和更新时间排序。这样不会改变待办数据结构、状态或 PH/TD 关联，只调整首页摘要的展示顺序。

## 边界

- 仍然展示最多 3 条下一步行动，完整清单继续由 TD 入口提供。
- 截止日期按本地日期解析，不把日期字符串转换为 UTC 日历日，避免跨时区前后偏移。
- 首页的活跃数量仍统计所有未完成、未归档、未取消待办，不改动统计口径。
