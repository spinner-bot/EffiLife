# 热力图术语替代旧日历文案方案

## 背景

独立日历入口、页面和引导已经退役，但打卡页仍把反馈区标题称为“打卡日历”，热力图组件也继续依赖 `calendar.weekday.*` 翻译键。这样会让用户和维护者误以为产品仍提供独立日历功能。

## 方案

- 将打卡页的用户可见标题改为“打卡热力图 / Check-in heatmap”；
- 为热力图星期标签增加 `heatmap.weekday.*` 翻译键，组件改用新键；
- 版本历史中的旧功能描述改为“活跃度热力图 / 打卡热力图”，保留历史版本条目和事实，不删除历史记录；
- 保留未被当前页面使用的 `calendar.*`、`nav.calendar` 等旧翻译键，以及 `/calendar` 兼容重定向，作为旧版本数据和书签的兼容边界；
- 不删除打卡热力图，不改变日期计算、统计数据或点击行为。

## 验收

- 当前界面源码不再使用 `checkin.calendar` 或 `calendar.weekday.*`；
- 中文、英文翻译键完整对应；
- 前端生产构建通过；
- 全量 Python 测试通过；
- 保持用户已有 `time-helper/desk/package-lock.json` 不变。
