# 0316-启动器服务就绪诊断方案

## 背景

启动器原有诊断只报告端口是否被占用。端口被其他程序占用时，用户无法直接判断是已有 EffiLife 实例、残留开发服务，还是端口冲突。

## 方案

`--diagnose` 对每个带 URL 的模块同时报告 `port_occupied` 与 `service_ready`：

- `port_occupied` 表示本机端口是否接受 TCP 连接；
- `service_ready` 表示该 URL 是否返回可用的 HTTP 响应；
- 两者均为 `false` 表示服务尚未启动；
- 仅 `port_occupied` 为 `true` 表示存在端口冲突或非目标服务；
- 两者均为 `true` 表示可复用已运行服务。

该诊断只读，不启动、停止或修改任何进程。
