# 0220 统一工作台全局搜索

## 背景

三个模块已经共享数据层，但用户仍需要分别打开计划、待办和记录页面寻找内容，统一应用壳缺少跨模块入口。

## 方案

- 在应用壳增加全局搜索按钮和 `Ctrl/Cmd+K` 快捷键。
- 搜索计划摘要、统一待办和时间记录，结果按模块分组展示。
- 结果点击后跳转到对应工作区：计划中心、待办中心或对应日期记录。
- 搜索组件只读访问统一 IndexedDB 数据，不引入新的持久化结构。
- 通过现有 i18n 提供中英文界面文案。

## 验收

- 搜索弹层可打开、关闭、输入和键盘选择。
- 三类统一数据可被检索，空结果和加载状态可解释。
- 应用壳与搜索组件 TypeScript 解析通过，现有回归不受影响。
