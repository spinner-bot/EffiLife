# 1231｜PH 计划状态筛选方案

## 设计决策

### 美学方向

沿用 Linear 的工作区筛选语言：搜索框负责查找内容，紧邻的低对比度胶囊筛选器负责切换集合范围。筛选器不使用颜色区分状态，选中态通过边框、背景和 `aria-pressed` 同时表达。

### 字体、色彩与间距

- 沿用现有 PH 工作区的字体层级与设计 token，不新增硬编码色值。
- 过滤器与搜索框保持同一工具栏节奏，间距使用现有 `gap: 6px/10px` 体系。
- 桌面端筛选器与搜索框横向排列，移动端允许换行，避免压缩输入框。

### 行为

- 提供“全部”“进行中”“已完成”三个互斥筛选器，默认“全部”，不改变现有入口行为。
- “已完成”定义为 `completed_tasks >= total_tasks` 且计划至少有一个任务；空计划仍归入“进行中”，避免被误判为已完成。
- 筛选与全文搜索叠加，结果为空时复用现有空状态提示。
- 仅改变列表视图，不修改 PH 数据、编号、组嵌套、日志或 TD 链接。

### 状态覆盖

- 默认、悬停、键盘聚焦、选中、禁用/加载状态沿用现有按钮状态；加载期间筛选器禁用。
- 筛选按钮使用可见文本、`aria-pressed` 和统一焦点样式；不依赖颜色传达状态。
- 不新增弹窗，不拦截返回，不引入额外保存步骤。
