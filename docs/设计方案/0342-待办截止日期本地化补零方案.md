# 待办截止日期本地化补零方案

## 背景

`ph` 计划日期已经使用 `Intl.DateTimeFormat` 的二位月份和日期，但 `td` 待办截止日期仍直接调用 `toLocaleDateString()`。不同浏览器和语言环境下可能出现 `yyyy/m/d`，无法满足产品要求中的 `yyyy/mm/dd` 视觉一致性。

## 方案

- 保留截止日期作为可选字段，不自动为待办填充今天；
- 使用当前应用 locale 和 `Intl.DateTimeFormat` 显式指定 `year/month/day`；
- `month`、`day` 使用 `2-digit`，确保日期显示补零；
- 不改变存储中的 ISO 时间戳、截止状态判断或优先级算法；
- 计划创建日期继续沿用已有的本地日期格式化逻辑。

## 验收

- `td` 截止日期不再调用裸 `toLocaleDateString()`；
- 中文显示包含补零的月、日，英文仍遵循 locale 顺序；
- 截止日期为空时仍不显示；
- 日期显示契约、前端构建和全量测试通过。
