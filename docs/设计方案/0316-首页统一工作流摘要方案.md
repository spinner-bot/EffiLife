# 首页统一工作流摘要方案

- 状态：[完成]
- 创建时间：2026-09-29
- 执行者：Codex
- 关联目标：统一应用壳与统一工作流入口

## 1. 背景

首页已有日计划进度、事件计划汇总和待办列表，但三者分布在不同卡片中；时间记录的当日实际总时长没有与另外两类状态并列展示。用户需要进入记录页才能完成当天状态判断。

## 2. 方案

在首页时钟区下方增加“工作流摘要”三项指标：

1. 今日记录：来自 `appStore.todayRecords`，点击进入时间记录；
2. 事件计划：使用已有事件计划完成数/任务数，点击进入计划中心；
3. 活跃待办：使用已有 `activeTodoCount`，点击进入待办中心。

摘要只做导航和状态概览，不复制任何数据，不引入新的存储字段或新的领域模型。

## 3. 约束与取舍

- 时间统一使用现有 `hoursToHm` 格式，避免首页和记录页出现不同单位。
- 事件计划服务不可用时仍显示 `0/0`，不阻塞日计划和待办入口。
- 使用按钮而不是纯装饰卡片，保证键盘、触摸和辅助技术可操作。
- 保留 th 的主题变量，摘要只使用现有颜色、边框和间距 token。

## 4. 验收标准

- [x] 首页并列显示记录时长、事件计划进度和活跃待办数。
- [x] 三项摘要分别跳转到记录、计划和待办页面。
- [x] 中文和 English 文案齐全。
- [x] 不新增跨模块数据字段，不改变既有数据源。
- [x] 窄屏下摘要可换行显示。
