# 事件计划任务时间输入简化

## 依据

用户优化要求指出，创建计划和添加任务时不应让用户面对“给单个框输入时间”的困惑。经核对原始 `plan.py`，任务时间只是 `t_m` 的内部估算值；日志中的 `99` 是时间精度标识，不应套用到任务时长。

## 决策

- 事件计划任务编辑器移除单任务预计分钟输入框。
- 新增任务继续使用现有默认 30 分钟，编辑任务保留其已有 `t_m` 值。
- 计划统计和 API 数据结构不变，任务列表仍可展示已有预计时长。
- 后续如需要精细估算，放入不阻断主流程的高级设置，不回到必填输入框模式。

## 验收

- 用户添加任务只需输入任务内容。
- 原始 plan 数据、内部编号、软删除和嵌套组语义不变。
- 统计接口继续正常返回预计分钟。
