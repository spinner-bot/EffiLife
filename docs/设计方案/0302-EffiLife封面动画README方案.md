# EffiLife 封面动画 README 方案

## 目标

将根 README 从“模块说明汇总”提升为项目首页：首屏通过可访问的 SVG 动画表达产品定位，随后给出统一工作台入口、能力边界和开发者入口。

## 设计原则

- 沿用现有 `assets/hero.svg`，避免重复维护两套品牌视觉。
- README 首屏只承担品牌识别、产品定位和快速入口；详细架构继续放在正文。
- 动画必须提供 `prefers-reduced-motion` 降级，SVG 也要有 `title` 与 `desc`。
- 所有启动说明明确区分开发启动器与正式 Tauri 安装包，避免误导用户。

## 验收标准

- 根 README 首行展示动画封面，并使用相对路径，适配 GitHub 仓库渲染。
- 首屏包含中英文产品定位、核心能力入口和当前发布边界。
- 封面 SVG 保留无障碍描述和减弱动画规则。
- 增加自动化契约测试，防止后续整理仓库时破坏封面入口。
