# 0196 计划任务加入待办

## 目标

让计划详情中的具体任务可以直接进入统一待办队列，补齐计划到执行层的联动路径。

## 方案

- 在计划任务行增加“加入待办”操作。
- 使用 `TodoService.create` 写入统一待办存储，并保存 `related_plan_id`、`related_plan_task_id`、预计时长等关联信息。
- 创建前扫描现有待办，若同一计划任务已有未归档关联，则拒绝重复创建。
- 计划任务完成后继续复用现有 `completeLinkedTodos`，同步完成关联待办。
- 不修改 plan-helper 原始数据结构，不改变任务编号、嵌套组或日志逻辑。

## 验收

- 计划任务可一键加入待办。
- 重复点击不会产生重复待办。
- 新待办在待办中心可见，并保留计划引用。
- 中英文文案与成功/重复提示完整。
