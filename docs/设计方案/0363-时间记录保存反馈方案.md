# 0363 时间记录保存反馈方案

## 背景

记录页已接入统一时间数据层和待办关联清理，但保存成功后缺少明确反馈，和计划、待办页面的交互表现不一致。

## 决策

1. 新增和编辑时间记录共用 `records.saved` 成功 Toast。
2. Toast 只放在 `appStore` 写入成功之后，冲突、格式和存储异常继续使用原有错误路径。
3. 不改变记录日期、时间冲突算法、待办关联 ID 或导入导出协议。
4. 文案纳入中英文目录，作为未来更多语言扩展的稳定键。

## 验证标准

- 新增和编辑成功后均显示保存反馈。
- 中英文目录各存在一条 `records.saved`。
- 保存失败时不显示成功反馈。
