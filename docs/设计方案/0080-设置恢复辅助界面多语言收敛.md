# 0080 设置恢复辅助界面多语言收敛

## 背景

统一工作台已经提供 `zh-CN` / `en-US` 字典，但设置页仍保留一组旧版恢复、重置和反馈辅助界面的硬编码中文。用户切换语言后，这些界面会出现中英文混用。

## 决策

1. 仅迁移旧版辅助界面的用户可见文案；不调整恢复、重置、备份和导出行为。
2. 新增 `settings.legacyRecovery.*`、`settings.reset.*`、`settings.feedback.*` 命名空间，避免与现代 `settings.restore.*` 语义混淆。
3. 状态值（空/有数据）也使用字典，不通过 CSS 或代码推断语言。
4. 本轮不迁移主题预设名称、帮助中心长文档和版本历史；这些属于后续低频文案收敛范围。

## 验收

- 中文和英文 locale 均包含新增 key。
- 旧版恢复与重置界面不再直接渲染硬编码用户文案。
- `vue-tsc` 与生产构建通过。
