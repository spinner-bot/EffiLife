# 0298-计划任务双编号同步

## 背景

plan-helper 同时存在内部任务编号和面向用户的显示编号。历史待办关联可能保存任一编号。计划任务编辑流程此前只用内部编号查找关联待办，导致保存显示编号的旧关联不会同步标题和预计时长。

## 方案

进入计划任务编辑时同时保存 `internal_id` 与 `display_id`。保存编辑结果时将两个编号传给统一同步协调器，由协调器去重匹配关联待办；不修改待办中已有的编号，也不改变 plan-helper 的底层编号规则。

## 验收

- 内部编号关联可以同步。
- 显示编号关联可以同步。
- 两个编号相同或同时命中同一待办时不会重复更新。
