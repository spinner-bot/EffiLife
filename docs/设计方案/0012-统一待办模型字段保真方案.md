# 统一待办模型字段保真方案

**文档性质**：跨模块数据模型决策  
**创建时间**：2026-09-25（Asia/Shanghai）  
**适用范围**：`common.schemas.UnifiedTodo` 与 `TodoAdapter`

## 1. 问题

to-dos 原模型包含优先级排位、紧急/重要标志、开始时间、估算时间和时间记录关联等字段。现有公共适配器只转换基础字段，跨模块经过统一模型后会丢失这些信息。

## 2. 决策

- 将上述字段加入 `UnifiedTodo`，字段名与 to-dos 原模型保持一致。
- `TodoAdapter.to_unified_todo()` 与 `from_unified_todo()` 双向保留这些字段。
- 缺失字段继续使用原模型的兼容默认值，不对旧数据做破坏性迁移。
- 子任务、计划任务引用和时间记录引用都视为稳定 ID/数组，不在适配层重建。

## 3. 影响

- 统一存档和跨模块事件可以携带完整待办优先级语义。
- 现有调用方只使用基础字段时无需改变。
- 后续 TaskCenter 可以逐步开放高级优先级和时间追踪编辑，而不再需要改变统一模型。

## 4. 验收

- 完整 to-dos 样本经过适配器往返后字段值保持一致。
- 旧版缺少新增字段的样本仍能成功转换。
