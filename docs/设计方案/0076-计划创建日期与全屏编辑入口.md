# 计划创建日期与全屏编辑入口

## 目标

让事件计划创建流程符合 `docs/req/7[ph][td]-优化.txt`：创建弹窗只收集计划名称和日期；创建成功后进入统一工作台中的全屏计划编辑页，避免在小弹窗内编辑复杂的 section、task、group 和 log 数据。

## 交互决策

- 创建入口打开时，计划日期始终初始化为本地当前日期，不复用上一次未提交或已提交计划的日期。
- 弹窗只保留名称和日期两个字段，提交后先创建空计划。
- 创建成功后立即加载完整计划并切换到详情编辑视图；详情视图负责从零添加内容，也负责已有计划的修改。
- 取消或按 Esc 关闭时不清空用户正在编辑的字段，避免误操作造成输入丢失；下次重新打开创建入口时再初始化为当天。

## 验收标准

- 首次打开和再次打开创建入口，日期均为当天。
- 创建请求仍只传名称和日期，计划内容结构不被简化或重写。
- 创建成功后不留在小弹窗，直接进入完整编辑工作区。
