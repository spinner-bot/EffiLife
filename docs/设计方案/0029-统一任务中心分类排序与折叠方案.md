# 统一任务中心分类排序与折叠方案

**文档性质**：实施设计方案  
**创建时间**：2026-09-25（Asia/Shanghai）  
**适用范围**：统一任务中心分类导航

## 1. 背景

原 to-dos 的分类分数用于组织待办，但统一任务中心只有按名称排列的筛选下拉框，用户无法快速识别当前最需要处理的分类。

## 2. 决策

- 分类分数沿用单任务分数：活动任务分数之和除以该分类活动任务数的平方根。
- 分类导航默认展示分数最高的前 5 个活动分类；其余活动分类和空分类分别折叠，避免大量分类挤压核心任务内容。
- 分类条目只负责筛选，不改变任务的归属或复制任务数据；当前筛选项可一键清除。
- 分类排序优先考虑已有 `pinned` 元数据，其次按分类分数降序、名称升序；没有活动任务的分类独立放在空分类区域。
- 分类分数和单任务分数均为运行时计算，不写回存档。

## 3. 响应式约束

分类导航使用自适应网格，在窄屏下自动减少列数；任务正文仍保持左对齐，分数位于条目右侧，不把排位数字置于任务内容上方。

## 4. 后续

可在设置中开放“前 N 个分类”和刷新频率配置，但必须继续以稳定字段而非本地化显示文本作为排序和筛选依据。
