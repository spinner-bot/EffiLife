# 计划日期搜索令牌方案

## 目标

让计划中心与全局搜索对计划日期采用一致、与界面展示格式无关的匹配规则。用户输入 `2026-10-10`、`2026/10/10`、`2026.10.10` 或不补零的 `2026-10-1` 时，都应能找到同一计划。

## 设计决策

- 只在前端生成搜索文本，不修改 PH 原始数据结构，也不改变日期存储格式 `[year, month, day]`。
- 将日期数组规范化为 ISO、斜杠、点号和不补零的连字符四类令牌；搜索仍使用现有不区分大小写的包含匹配。
- 计划中心与全局搜索共用同一纯函数，避免两个入口出现不同结果。
- 日期缺失、长度不足或包含非有限数字时不生成令牌，不能因为坏数据阻断整个列表。

## 验证

- 静态契约测试确认两个入口均调用共享日期令牌函数。
- 运行全量 Python 测试与前端生产构建。
