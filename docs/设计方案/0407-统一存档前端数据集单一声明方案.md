# 0407｜统一存档前端数据集单一声明方案

## 背景

Python 与前端已经通过契约测试校验统一 `.efl` 的五个 canonical 数据集，但前端的导出函数仍重复手写数据集名称列表。重复声明会让新增或移除数据集时出现导出与导入校验不一致。

## 设计决策

- `CANONICAL_ARCHIVE_DATASETS` 是前端唯一的数据集名称声明。
- 导出函数通过展开该常量生成可迭代列表，不再手写第二份列表。
- Python `CANONICAL_WORKSPACE_DATASETS` 继续作为跨运行时对应声明，并由契约测试比较顺序和内容。
- 不改变存档格式、字段、排序或兼容导入行为。

## 验收标准

1. 导出函数直接复用 canonical 常量。
2. 跨运行时数据集顺序和名称继续一致。
3. 现有 `.efl` 导入、导出和旧格式兼容测试保持通过。
