# 0358 独立日历组件退役方案

## 背景

统一工作区已经将时间记录、任务和计划分为三个互相联动的入口，产品要求不再提供独立日历功能。此前仅移除了导航入口，但旧的 `CalendarView.vue` 仍留在源码中，容易造成维护误判和后续误引用。

## 决策

1. 删除未被路由或组件引用的独立 `CalendarView.vue`。
2. 保留 `/calendar -> /records` 兼容跳转，避免旧书签和历史链接失效。
3. 日期详情页返回“记录”入口，不再返回已退役的日历页面。
4. 保留记录页和签到页中的日期筛选、贡献热力图等信息架构，它们是记录与习惯功能的一部分，不构成独立日历入口。
5. 旧引导配置中的历史文本暂不删除，以避免无关的引导数据迁移；运行时使用的引导步骤已经是统一工作区版本。

## 验证标准

- 构建阶段不再编译独立日历组件。
- 用户界面没有独立日历导航入口。
- 旧 `/calendar` 地址仍能进入记录页。
- 本地日期解析契约覆盖记录详情、签到和热力图。
