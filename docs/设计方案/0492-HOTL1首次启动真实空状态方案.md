# 0492 HOTL1 首次启动真实空状态方案

## 背景

当前应用在首次启动且没有时间记录时自动生成示例计划、日程规则和历史记录。首页是跨模块控制台，展示这些内容会让用户误判为真实数据，削弱 HOTL1 要求的清晰产品边界和可信状态反馈。

## 方案

保留 `DataService.generateSampleData()` 作为演示/测试能力，但只有在构建变量 `VITE_EFFILIFE_DEMO_DATA=true` 时才由应用启动流程调用。默认构建不生成任何虚假业务数据，用户从真实空状态开始；已有数据和迁移流程不受影响。

## 验收

- 默认启动路径不调用示例数据生成。
- 显式开启 `VITE_EFFILIFE_DEMO_DATA=true` 时保留原演示数据能力。
- 不改变真实数据加载、迁移、主题初始化和统一首页摘要逻辑。
- 为开关增加静态契约测试和进展记录。
