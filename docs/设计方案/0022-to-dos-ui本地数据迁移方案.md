# to-dos/ui 本地数据迁移方案

**文档性质**：实施设计方案  
**创建时间**：2026-09-25（Asia/Shanghai）  
**适用范围**：旧版 `to-dos/ui` localStorage 到统一任务中心

## 1. 背景

旧版 to-dos Web UI 使用 `to-dos-data` localStorage 保存任务、分类、筛选器和设置。统一工作台使用 IndexedDB；如果没有启动迁移，升级用户会看到空任务中心。

## 2. 决策

- 统一应用首次访问待办域时检查 `to-dos-data`，将其中 `todos` 和 `categories` 迁移到统一 IndexedDB。
- 使用统一任务/分类归一化器，非法条目跳过并保留有效条目。
- 迁移采用按 ID 合并：统一库已有同 ID 任务时保留统一库版本，不覆盖用户当前数据。
- 原始 `to-dos-data` 永不删除，另用独立迁移标记保证幂等；用户可通过旧数据导出或手工恢复。
- 迁移只触发一次并返回统计结果，不能阻塞应用启动；失败时记录警告，后续仍可重试。
