# 计划嵌套组显示方案

**文档性质**：实施设计方案  
**创建时间**：2026-09-25（Asia/Shanghai）  
**适用范围**：统一计划工作台的 plan-helper group 展示

## 1. 背景

plan-helper 使用 section 内的区间键（如 `0_5`）表达任务组，允许完全包含的嵌套组，禁止交叉组。统一工作台原先只把 group 显示为平铺标签，虽然数据未丢失，但用户无法理解层级关系。

## 2. 决策

- 仅在前端根据区间键计算显示深度：先按起始索引升序、结束索引降序排列，再统计完全包含当前区间的父组数量。
- 原始区间键、标题、描述原样保留；不把组转换成单个任务组 ID，也不修改 plan-helper 数据。
- 无法解析的异常键不阻断整个计划，只从层级展示中过滤，并继续由服务端数据校验负责发现问题。
- 使用缩进、区间标识和描述表达层级，移动端保持可滚动和文本截断。

## 3. 后续

后续若开放 group 编辑，必须复用 plan-helper 的交叉检测规则，并使用原始区间索引操作，不能按显示编号直接改写存储。
