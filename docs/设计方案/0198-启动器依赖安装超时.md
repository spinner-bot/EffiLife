# 0198 启动器依赖安装超时

## 目标

避免首次启动执行 `npm install` 时因网络、代理或包管理器异常无限阻塞统一启动器。

## 方案

- 增加 `EFFILIFE_SETUP_TIMEOUT` 环境变量，默认 300 秒，限制在 30 至 900 秒。
- 使用 `subprocess.run(..., timeout=...)` 执行依赖安装。
- 超时或启动异常时输出明确的手动恢复指引，并返回菜单，不启动后续服务。
- 保持依赖检测、统一入口、服务就绪探测和子进程清理逻辑不变。

## 验收

- 默认和自定义超时均有边界。
- 安装超时不会继续执行主服务启动。
- 既有启动器回归测试全部通过。
