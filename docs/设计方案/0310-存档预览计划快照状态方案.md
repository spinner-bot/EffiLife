# 存档预览计划快照状态方案

## 背景

统一 `.efl` 预览当前只统计事件计划数量。导出可能使用实时 Plan Helper、陈旧缓存快照，或因服务不可用而没有计划数据；仅显示数量会让用户无法判断数据是否完整。

## 方案

- 在 `ArchivePreview` 增加 `planStatus`：`available`、`stale`、`unavailable`。
- 从现有 `planHelper.available` 与 `planHelper.stale` 推导状态，不修改 `.efl` 协议和存储字段。
- 导入确认摘要显示本地化状态：实时快照、缓存快照或未包含事件计划。
- 旧版 `archive.json` 缺少计划字段时按 `unavailable` 处理，保持兼容且不伪造完整备份。
- 具体服务错误仍保留在导出 warning/导入结果中，预览只显示用户可理解的状态。

## 验收

- 三种状态均能进入确认摘要。
- 计划数量为 0 时仍能区分“空计划”和“未包含计划”。
- 不改变导入写入、回滚、校验和移动端存档边界。
