# 统一工作台存档验证报告方案

## 目标

为启动器、迁移工具和未来设置页提供统一的只读存档健康检查，不要求调用方读取或展示业务数据内容。

## 报告字段

- `format` / `format_version`：协议身份。
- `integrity`：`verified` 或 `legacy`。
- `datasets`：已验证的 canonical 数据集名称。
- `top_level_counts`：各数据集顶层对象或数组的数量；标量返回 `null`。

报告建立在 `read_workspace_bundle` 的完整性与数据集校验之上，任何缺失、损坏或摘要不匹配都会抛出异常，且不会产生写入。
