# 工作区变更事件跨窗口传输方案

## 背景

工作区变更事件的本地 `CustomEvent` 只能通知同一页面上下文。统一软件支持桌面窗口和浏览器多标签后，不同窗口中的搜索索引可能短暂不一致。

## 实现

在既有事件 API 后增加可选 `BroadcastChannel` 传输：

- 当前窗口继续通过 `CustomEvent` 同步，保证即时响应；
- 有 `BroadcastChannel` 时，向 `effilife-workspace` 通道广播同一变更来源；
- 其他窗口收到消息后复用同一个订阅回调；
- 没有该 API 的环境只使用本地事件，不影响旧浏览器或受限 WebView；
- 最后一个订阅者解绑后关闭通道，避免后台资源泄漏。

事件只携带变更来源，不携带业务数据。接收方收到后重新读取自己的统一存储，从而避免跨窗口传递过期对象或破坏模块边界。
