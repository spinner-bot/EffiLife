# 0367 旧管理组件退役方案

## 背景

`/management` 已在 0366 中改为统一计划工作台的兼容跳转。旧 `ManagementView.vue` 不再有路由或组件引用，继续保留会让维护者误以为它仍是有效产品页面。

## 决策

1. 删除无运行时引用的 `ManagementView.vue`。
2. 保留 `/management` 路由重定向，确保旧书签可用。
3. 保留历史 `management.*` i18n 键，避免旧配置或迁移文本解析出现无关破坏；后续统一文案清理单独处理。
4. 统一计划工作台中的 `PlanView.vue` 继续承担时间计划功能，不受本次退役影响。

## 验证标准

- 源码中不存在对 `ManagementView.vue` 的运行时引用。
- 前端构建不再编译该组件。
- 导航与 Toast 契约测试改为覆盖仍在产品入口中的视图。
