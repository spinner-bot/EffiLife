# 自定义背景音乐删除回退方案

## 问题

删除当前选中的自定义背景音乐后，音频服务把 `currentBgm` 写成 `default`，但内置音源列表没有这个 ID，后续启动或切换时无法找到可播放的背景音乐。

## 决策

- 删除当前音源后回退到 `DEFAULT_AUDIO_SETTINGS.currentBgm`，由默认设置作为唯一事实来源。
- 不新增名为 `default` 的隐式音源，避免存储中出现无法在列表中选择的 ID。
- 继续立即调用 `updateBgm()`，让用户删除后获得可感知的有效播放状态。

## 验收标准

1. 删除当前自定义音源后，`currentBgm` 是内置列表中的合法 ID。
2. 删除非当前自定义音源不改变当前播放项。
3. 既有自定义音源存档可以正常读取。
