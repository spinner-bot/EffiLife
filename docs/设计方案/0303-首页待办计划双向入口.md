# 首页待办计划双向入口

## 背景

统一首页已经可以展示待办、快速完成和记录用时，但计划关联只存在于待办中心。用户从首页看到一项由计划拆出的行动时，无法判断其来源，也不能直接回到对应计划任务。

## 方案

- 复用首页已加载的 `PlanSummary[]`，按 `related_plan_id` 建立计划名称索引。
- 对具有关联计划的首页待办显示计划引用按钮；点击后跳转 `/plans?plan=<id>&task=<task-id>`。
- 保留待办主体点击进入待办中心、时钟按钮进入时间记录的原有行为，避免改变既有操作语义。
- 计划服务不可用时仍允许使用引用按钮，名称使用本地化的“关联计划”回退文本；计划页自行处理缓存或不可用状态。
- 采用独立按钮和明确 aria-label，避免在一个按钮内部嵌套另一个交互元素。

## 不变约束

- 不修改 `UnifiedTodo` 的持久化字段。
- 不改变 plan-helper 的嵌套组、双编号或软删除语义。
- 不把计划关联降级为单一组 ID；仍保留计划 ID 与任务 ID 两级引用。
