# 移动端事件计划本地编辑适配

## 目标

将移动端事件计划从“只读快照”推进到“本地可编辑”，同时不引入第二套计划模型，也不破坏 plan-helper 的原始数据语义。

## 边界

- 仅在移动端对 `PLAN_HELPER_SNAPSHOT` 中的原始 `head/main/log` 快照做读写。
- 桌面端仍通过 plan-helper HTTP API，现有 API 行为不变。
- 计划任务删除继续写入 `is_active = false`，不压缩原始数组；显示编号由活跃任务扫描生成。
- 任务组仍以原始 `start_end` 字符串键存储，允许嵌套关系并保持日志引用稳定。
- 新增、编辑、完成任务和记录日志支持本地写回；归档恢复属于桌面文件服务能力，移动端继续隐藏。
- 每次成功变更整体写回快照，避免只写派生视图导致原始数据丢失。

## 验收

- 移动端创建/编辑计划后，重新读取仍能看到名称、日期、分组、任务、软删除状态、完成状态、嵌套组和日志。
- 跨模块待办同步在移动端不可用时不报错阻塞计划本地保存。
- 桌面端构建、Python 回归测试和数据结构专项测试通过。
