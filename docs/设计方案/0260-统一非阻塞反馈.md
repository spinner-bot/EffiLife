# 0260 统一非阻塞反馈

## 美学方向

采用 Linear 风格的轻量状态提示：提示位于工作区右下角，不遮挡主要内容；成功、错误和普通信息使用有限的语义色与图标层级，不使用浏览器原生弹窗打断工作流。

## 交互决策

- 提示默认显示 3.8 秒，用户可点击关闭。
- 提示使用 `role="status"` 和 `aria-live="polite"`；错误使用 `role="alert"`。
- 同一时刻允许多个提示，按出现顺序堆叠，避免新提示覆盖旧提示。
- 提示消息由调用方传入已本地化文本，Toast 服务不持有业务文案。
- 遵循 `prefers-reduced-motion`，减少动画时不使用位移过渡。

## 字体、色彩与布局

- 继承现有主题字体与 `--color-*`、`--shadow-*` token。
- 成功使用 `--color-success`，错误使用 `--color-error`，信息使用 `--color-primary`。
- 桌面端距离视口右下 20px；窄屏幕左右保留 14px 并允许文本换行。

## 范围

先替换设置页的导入、导出、恢复和反馈结果；其余页面逐步迁移，保持本轮风险可控。
