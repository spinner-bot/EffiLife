# 可扩展语言注册表方案

- 状态：[完成]
- 创建时间：2026-09-29
- 执行者：Codex
- 关联目标：统一应用壳的多语言基础

## 1. 背景

当前前端已经支持简体中文和 English，并有双语键集合测试；但语言选择器只消费字符串数组，语言代码、显示文案和回退策略没有统一描述。后续增加语言时容易出现选择器和运行时支持范围不一致。

## 2. 方案

增加 `LOCALE_DEFINITIONS` 注册表，每个语言条目包含：

- `code`：运行时语言代码；
- `labelKey`：该语言在界面中的显示文案键；
- `fallback`：该语言目录缺失时使用的回退语言。

`SUPPORTED_LOCALES` 从注册表派生，`useI18n()` 同时暴露定义列表，语言选择器只依赖注册表。

## 3. 约束与取舍

- 本次不新增第三种语言，只整理扩展点，避免伪造未完成翻译。
- 保留现有 `Locale` 类型和 `zh-CN` / `en-US` 目录，确保行为和存储格式兼容。
- 现有翻译查找顺序保持不变；注册表用于选择和规范化，不改变文案回退语义。

## 4. 验收标准

- [x] 支持范围由单一注册表派生。
- [x] 语言选择器使用注册表条目，而不是重复维护语言代码。
- [x] 浏览器语言检测和非法输入仍回退到中文。
- [x] 保留现有双语目录键集合校验，并增加 registry 契约测试。
