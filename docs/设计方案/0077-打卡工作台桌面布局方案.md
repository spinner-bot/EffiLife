# 打卡工作台桌面布局方案

## 背景

打卡页当前使用 `max-width: 600px` 的单列布局，状态、统计、近七天可视化、热力图和历史记录在桌面端连续纵向排列。该布局更接近移动端，不符合桌面端应利用横向空间、建立信息层级的设计要求。

## 设计决定

- 断点设为 `900px`，与统一工作台现有桌面布局断点一致。
- 桌面端使用两列工作区：左列承载当前打卡状态和近七天摘要，右列承载统计和历史记录。
- 热力图横跨两列，保持完整可读宽度。
- 移动端不改变现有单列顺序、触控尺寸和交互路径。
- 仅调整布局和容器宽度，不改变打卡数据、路由、热力图点击或多语言逻辑。

## 验收标准

1. 桌面断点存在明确的双列布局和热力图全宽规则。
2. 移动端仍为单列，不出现横向溢出。
3. 现有 Checkin 访问性、日期本地化和生产构建测试通过。
4. 阶段保持第 0 阶段。
