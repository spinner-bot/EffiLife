# 主题原生控件色彩方案

- 状态：[完成]
- 创建时间：2026-09-29
- 执行者：Codex
- 关联目标：保留并适配 th 丰富主题架构

## 1. 背景

统一应用壳已经将 th 的主题预设转换为 CSS 设计令牌，但浏览器原生 `input`、`select` 和滚动条等控件仍可能使用系统默认浅色方案。深色、霓虹和午夜类主题下，控件与工作台视觉不一致。

## 2. 方案

在 `getThemeCssVariables()` 中根据主题背景色推导 `color-scheme`，将其写入根元素已有的主题变量应用流程：

- 背景亮度低于阈值：`dark`；
- 其他主题：`light`；
- 无法解析的自定义颜色：使用 `light` 安全回退。

不改动各主题原有颜色、粒子和 Canvas 动效，只增加浏览器控件的环境提示。

## 3. 约束与取舍

- 使用主题背景色而不是文字色判断，避免特殊主题文字颜色与背景不匹配时误判。
- 仅处理可解析的 3/6 位十六进制颜色；渐变仍使用其起始色判断。
- 不强制覆盖组件自身已经定义的背景和文字颜色。

## 4. 验收标准

- [x] 主题 CSS token 包含 `color-scheme`。
- [x] 深色和浅色主题分别得到 dark/light 结果。
- [x] 无效颜色安全回退，不抛出异常。
- [x] 统一应用壳继续通过现有主题变量入口应用该 token。
