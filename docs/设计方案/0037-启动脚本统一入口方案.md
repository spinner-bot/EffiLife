# 启动脚本统一入口方案

**文档性质**：实施设计方案  
**创建时间**：2026-09-25（Asia/Shanghai）  
**适用范围**：`launcher/start.bat`、`launcher/start.sh`

## 决策

Windows 与 POSIX 启动脚本都直接进入统一工作台模式，并由 `launcher/start.py` 负责启动统一前端及 plan-helper companion。

这样可以避免不同操作系统的默认入口分别落到旧模块菜单或兼容模块，降低“同一软件在不同平台打开后功能不同”的风险。需要调试旧模块时，仍可直接运行 Python 启动器进入菜单模式。
