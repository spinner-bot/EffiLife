# 存档统计实时计划来源方案

## 背景

设置页的数据统计只读取 `PLAN_HELPER_SNAPSHOT` 缓存，而统一工作台在线时可能拥有更新的 Plan Helper 数据。缓存写入失败会使统计显示 0，和用户当前看到的计划不一致。

## 方案

- `getDataStats()` 复用 `collectPlanHelperDataWithCache()` 的实时→缓存→不可用降级链路。
- 除计划数量外返回来源：实时服务、缓存快照、移动端本地快照或不可用。
- 设置页在计划快照统计旁显示来源，明确数据是否可能陈旧。
- 不改变 `.efl` 协议、缓存写入、移动端计划边界和导入恢复语义。

## 验收

- 在线服务可用时统计使用实时计划数量。
- 服务不可用但有缓存时显示缓存来源和缓存数量。
- 移动端显示本地快照来源；无快照显示不可用。
