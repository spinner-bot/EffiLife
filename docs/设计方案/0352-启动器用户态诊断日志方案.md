# 0352 启动器用户态诊断日志方案

## 目标

当统一工作台因端口冲突、依赖安装、伴随服务健康检查或子进程提前退出而无法启动时，用户能够提供一份稳定、可复制的诊断上下文。

## 方案

- 启动器以 JSONL 追加记录关键生命周期事件。
- 默认写入当前用户数据目录：Windows 为 `%LOCALAPPDATA%/EffiLife/logs/launcher.log`，类 Unix 为 `$XDG_STATE_HOME/EffiLife/logs/launcher.log`。
- `EFFILIFE_LOG_DIR` 可覆盖日志目录，便于便携版、测试和问题复现。
- 单文件超过 1 MiB 时滚动为 `launcher.log.1`。
- 日志写入失败不得阻塞启动；不记录任务内容或用户业务数据。

## 记录事件

包括模块启动、复用已有服务、端口冲突、依赖安装失败/超时、服务健康检查失败、命令不存在和模块退出码。
