# 1218｜首页快速待办可见标签方案

日期：2026-10-10

## 美学方向

采用 Linear 风格的工作流输入区：信息密度克制、操作入口明确，将“下一步行动”作为输入区的视觉锚点；保留 TH/PH/TD 三模块身份，不把 TD 伪装成 PH 任务。

## 字体与层级

- 复用应用现有字体与字号 token。
- 新增的可见 label 使用现有 eyebrow 级别，正文输入保持原有 12px 控件层级。
- placeholder 只提供示例，不再承担字段名称职责。

## 色彩与布局

- 只使用现有 `--color-*` token，不引入新色值。
- 桌面端 label、输入框和提交按钮保持同一横向工作流行。
- 移动端改为 label 在上、输入控件在下，避免窄屏挤压。

## 状态与交互

- 保留提交中禁用、空值禁用和表单 Enter 提交。
- label 与输入框通过 `for`/`id` 建立语义关联。
- 不改变快速待办的数据模型、独立生命周期或排序逻辑。
- 尊重现有 reduced-motion 规则。

## 验收

- DOM 中存在可见 label，且关联到唯一输入框。
- 中英文目录均提供 label 文案。
- 生产构建与全量 Python 契约测试通过。
