# 统一计划模板创建方案

## 背景

Plan Helper 已有工作日、休息日等模板 API，统一工作台却没有模板入口。用户只能手工填写首个分组和任务，历史模板能力仍被隔离在兼容界面。

## 方案

- 创建弹窗增加可选模板下拉框，模板列表由现有 `GET /api/templates` 提供。
- 选择模板时，调用现有 `POST /api/plans/from-template`，模板负责生成完整 section/task 结构；用户仍需填写计划名称和日期。
- 未选择模板时沿用首个分组 + 首个任务的本地创建请求，确保服务不可用或没有模板时仍能创建可执行计划。
- 模板加载失败不阻断创建弹窗，隐藏模板选项并保留手工创建路径。
- 移动端不伪造模板可用性；模板服务不可用时使用本地首个行动路径。

## 不变约束

- 不复制模板数据到前端，不改变 plan-helper 模板定义和原始 plan 数据结构。
- 不改变任务编号、嵌套组、软删除和待办关联语义。
- 统一创建成功后继续进入同一计划详情编辑器。
