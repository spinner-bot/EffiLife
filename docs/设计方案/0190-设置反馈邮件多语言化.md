# 0190 设置反馈邮件多语言化

## 目标

让设置页的反馈邮件入口遵循当前界面语言，并自动带入当前应用版本，避免英文界面仍生成中文主题或旧版本号。

## 方案

- 在统一 i18n 资源中增加反馈邮件主题和正文模板。
- 使用现有 `{version}` 参数插值能力注入 `APP_VERSION`。
- `SettingsView` 仅负责组装 `mailto`，不再保存面向用户的文案。
- 邮件地址保持现有配置不变；复制邮箱、打开失败等反馈继续使用既有翻译键。

## 验收

- 中英文资源均存在主题和正文键。
- 主题、正文随语言切换变化，并包含当前版本。
- TypeScript 语法解析和 Python 回归测试通过。
