# 主题分类由注册表派生方案

- 状态：[设计完成，待实现]
- 创建时间：2026-09-29
- 执行者：Codex
- 关联目标：让主题注册表成为设置页主题列表的唯一来源

## 1. 背景

主题名称、描述和分类元数据已经集中到 `ThemeEngine`，但 `SettingsView.vue` 仍将基础、艺术、自然和科技四个分类分别写成四段模板。新增分类时仍需同步修改页面，注册表尚未完全承担主题目录职责。

## 2. 方案

- 在 `ThemeEngine` 中根据注册表条目首次出现的顺序派生分类列表。
- 导出 `getAvailableThemeCategories()`，返回去重后的分类 key。
- 设置页使用分类列表循环渲染分组，每组继续通过 `categoryKey` 筛选主题。
- 分类标题继续通过现有 i18n key 渲染，不在模板内硬编码可见文案。
- 保留现有主题分组顺序和主题卡片交互，不改变主题类型、配置或保存逻辑。

## 3. 约束

- 不改变 `ThemeDefinition` 的兼容字段。
- 不改变主题注册表条目的顺序；分类顺序由条目首次出现顺序决定。
- 不允许空分类渲染，避免新增或移除主题后出现空分组。
- 未提供翻译的分类 key 仍交由 i18n 的现有 fallback 机制处理。

## 4. 验收

- 设置页不再出现四段重复主题卡片模板。
- 所有现有主题仍可见且分组顺序不变。
- 注册表新增一个已有分类的主题无需修改设置页。
- 回归测试覆盖分类派生和动态模板消费。
