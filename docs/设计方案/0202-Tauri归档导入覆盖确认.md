# 0202 Tauri 归档导入覆盖确认

## 目标

统一浏览器和桌面端的归档导入安全行为，避免 Tauri 原生文件选择器路径跳过覆盖确认直接写入数据。

## 方案

- `importArchiveWithDialog` 接收可选的确认回调。
- 先选择并读取归档、完成 ZIP 读取，再调用确认回调；用户取消时返回 `cancelled`，不执行数据写入。
- Settings 页复用既有 `settings.archive.importConfirm` 文案，不改变导入格式和处理流程。
- 未提供回调时保持服务层现有直接处理行为，兼容其他调用方。

## 验收

- Tauri 导入路径传入覆盖确认回调。
- 取消确认不会调用归档写入处理。
- 浏览器导入行为保持不变。
- 现有归档与 Python 回归测试通过。
