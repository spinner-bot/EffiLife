# 统一数据交换导入原子回滚

## 问题

`common.data_exchange.import_bundle()` 已经先完成 manifest、数据集和目标冲突预检，也使用 staging 生成文件；但覆盖导入时仍逐个替换目标文件。如果替换序列中途发生 I/O 异常，目标目录可能只包含部分新数据。

## 方案

- 导入前将覆盖模式下的既有目标文件移动到同目录临时备份目录。
- 按现有数据集顺序将 staging 文件替换到目标目录。
- 全部成功后删除临时备份目录。
- 任一步失败时，删除本次已安装的新文件，并将已备份的旧文件原位恢复；非覆盖模式下只删除本次已安装文件。
- staging、临时备份和异常路径都在 `finally` 中清理。

## 约束

- 不改变 `.effilife.bundle 1.0.0` 协议。
- 不改变默认禁止覆盖的行为。
- 不引入跨目录 rename；临时目录始终创建在目标目录内，保持同文件系统原子替换语义。
