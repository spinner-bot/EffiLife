# 旧版待办分类 canonical 迁移方案

## 背景

Python 侧旧版 to-dos 迁移器此前原样返回分类列表，而前端迁移器会过滤缺少 `id`、`name` 或颜色的分类，两个入口可能产生不同的统一数据集。

## 方案

- 使用共享 `CategoryAdapter` 输出统一分类字段；
- 分类至少需要有效 `id` 和 `name`，颜色、图标、难度等使用统一默认值；
- 严格模式将分类错误与待办错误一起报告并拒绝迁移；
- 宽松模式跳过无效分类并将警告写入同一 `warnings` 列表；
- 不改变迁移器无副作用的性质，也不直接写入任何存储。

这样 CLI/服务端迁移结果与统一工作台前端导入路径遵循相同的基本数据边界。
