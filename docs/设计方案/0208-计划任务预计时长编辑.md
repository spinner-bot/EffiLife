# 0208 计划任务预计时长编辑

## 目标

让计划任务编辑器真正暴露预计时长字段，使计划数据能够为待办排序和时间投入提供可靠的预估基础。

## 方案

- 在计划任务新增/编辑表单中增加数字输入框。
- 复用现有 `taskMinutes` 状态与 `addPlanTask` / `updatePlanTask` API 参数。
- 允许 0 分钟，限制为非负整数；保存前继续由现有逻辑归一化。
- 新增/编辑完成后沿用现有表单重置和计划刷新流程。

## 验收

- 新增任务可以输入预计分钟数。
- 编辑已有任务会回填并保存原预计时长。
- 该值在任务行、关联待办和后续时间记录流程中保持一致。
