# 0285 启动脚本参数透传

## 背景

统一入口脚本默认使用 `--unified`，但 Windows 和 POSIX 包装脚本没有透传调用者参数，导致 `--no-browser` 等模式只能直接调用 Python 文件。

## 方案

- Windows `start.bat` 使用 `%*` 透传额外参数。
- POSIX `start.sh` 使用 `"$@"` 透传额外参数。
- 保留脚本自身的统一入口参数，调用 `start.bat --no-browser` 或 `./start.sh --no-browser` 即可使用无浏览器模式。

## 约束

- 不改变默认双击/直接执行行为。
- 不将参数拼接成单个字符串，保留参数边界和空格安全。
