# 0351 移除独立日历导航方案

## 背景

EffiLife 的统一工作台已经以“计划、任务、记录”为核心工作流。独立日历入口会把用户引导到一条与当前工作流割裂的历史浏览路径，也与产品要求中的“不要日历功能”冲突。

## 决策

- 从桌面端一级导航和首页快捷操作中移除独立日历入口。
- `/calendar` 保留为兼容重定向，旧书签进入记录页，不再加载日历页面。
- 日详情页继续保留，因为打卡、全局搜索和任务关联仍需要查看某一天的记录；其返回语义改为“返回记录”。
- 打卡页的热力图属于打卡反馈，不作为独立日历功能入口，暂不移除。

## 影响范围

本调整只改变导航和路由入口，不改变时间记录、打卡、任务关联及统一存档数据结构。
