# 统一首页跨域概览方案

**文档性质**：统一应用壳信息架构方案  
**创建时间**：2026-09-25（Asia/Shanghai）  
**适用范围**：time-helper 首页与 plan-helper 事件计划摘要

## 1. 目标

首页同时呈现时间计划和事件计划的最小可行动摘要，让用户从统一壳感知三个模块已经协同工作；详情仍回到各自领域工作台，避免首页变成第二个管理页面。

## 2. 交互决策

- 保留原有“今日进度”主卡，新增事件计划摘要卡。
- 事件卡只显示活跃计划数、计划任务总数、已完成任务数，并整体进入 `/plans`。
- plan-helper 不可用时显示服务状态文案，不阻塞时间计划、待办和其它首页功能。
- 首页不提供事件计划编辑、日历和复杂筛选，保持概览职责。

## 3. 主题与多语言

- 卡片使用统一主题令牌和现有首页布局节奏。
- 摘要标题、状态和统计标签进入 i18n catalog。
- 不使用硬编码颜色，不用颜色作为唯一状态表达。

## 4. 验收

- plan-helper 可用时首页显示事件计划统计，点击可进入统一计划中心。
- 服务不可用时有可理解降级状态，首页其它区域仍可用。
- Vite 构建和现有 Python 测试保持通过。
