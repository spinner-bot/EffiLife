# 0266 统一计划工作台入口

## 目标

消除主页 `/plan` 与顶部导航 `/plans` 造成的双入口，让用户从同一个“计划”工作台访问 time-helper 的日计划和 plan-helper 的事件计划。

## 方案

- `/plans` 成为唯一用户入口，保留现有事件计划中心。
- 在同一页面上下文中嵌入已有 `PlanView`，作为日计划工作区，不重写其数据逻辑。
- 使用 `/plans?mode=time` 表达日计划视图；事件计划继续使用 `/plans`。
- `/plan` 保留为兼容地址并重定向到 `/plans?mode=time`，既不破坏旧书签，也不继续制造第二个入口。
- 日计划页返回时回到统一计划中心，而不是跳出到主页。

## 不变项

- 不修改 plan-helper 原始数据模型。
- 不改变 time-helper 的记录、计划管理和调度规则逻辑。
- 不删除日历、打卡或事件系统；它们仍由各自的统一工作台入口负责。
