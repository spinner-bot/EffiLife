# 旧版计划工作台多语言收敛

## 背景

统一应用壳已经提供 `zh-CN` / `en-US` 切换，但历史 `PlanView` 仍直接输出大量中文，导致用户切换语言后计划管理、日程规则和记录表单仍混杂中文。

## 方案

- 在现有统一 i18n catalog 中增加 `legacyPlan.*` 命名空间，不新建第二套翻译系统。
- 先覆盖用户可见的导航、计划管理、日程规则、临时计划、记录表单和校验提示；代码注释及底层兼容数据值（如 `切分制`、`分配制`）保持不变。
- 仅替换显示文案和提示文本，不改变 `PlanView` 的数据结构、计划算法、时间冲突判断及存储接口。
- 动态内容通过现有 `t()` 插值或字符串拼接保留，确保英文目录下不出现结构性中文文案。

## 验收

- PlanView 使用统一 `useI18n()`，切换语言后主要用户可见区域同步切换。
- 旧计划类型和底层数据值仍保持兼容。
- 前端类型检查和生产构建通过。
