# 0252 旧版待办文件迁移入口

## 背景

Python `common.migrations` 已支持 to-dos 旧版 JSON 迁移，但统一桌面工作台没有用户入口，迁移能力无法被普通用户使用。

## 方案

- 设置 → 存档管理增加“导入旧版待办 JSON”。
- 接受 to-dos 的包装格式 `{version, todos, categories}`，也接受裸待办数组。
- 导入采用合并语义，不清空当前统一数据；稳定 ID 已存在时跳过。
- 待办先归一化，非法条目计入 warnings；分类和默认分类同步进入统一 IndexedDB。
- 导入前确认，完成后刷新工作台，使任务、分类和统计立即一致。

## 边界

该入口只迁移 to-dos 数据，不迁移时间记录或 plan-helper 原始计划；三模块完整迁移仍使用 `.efl` 统一存档。
