# 音频自定义条目交互结构方案

## 背景

音频设置页的自定义背景音乐条目目前使用外层 `<button>`，内部又嵌套删除 `<button>`。HTML 交互元素不能这样嵌套，容易造成删除同时触发选择、键盘焦点混乱以及移动端辅助技术语义错误。

## 决策

- 自定义条目改为 `div[role=button][tabindex=0]`，只负责选择音源。
- Enter 和 Space 触发与点击相同的选择行为，并阻止 Space 的页面滚动。
- 删除按钮保留独立的 `button` 语义，通过 `stop` 阻止冒泡，不改变已有删除逻辑。
- 内置音源继续使用原生 `<button>`，因为其没有嵌套交互控件。

## 验收标准

1. 自定义音源条目不再嵌套 button。
2. 鼠标、Enter、Space 均可选择自定义音源。
3. 删除按钮仍独立可用，不会触发音源选择。
4. 前端构建和静态交互契约测试通过。
