# 待办截止状态展示方案

## 背景

统一待办中心已经按截止时间计算优先级，但卡片只显示日期。用户无法快速区分已经逾期、今天到期和未来截止的任务，过期信息也只通过分数颜色间接表达。

## 方案

- 在待办卡片的截止日期旁增加明确的状态标签：已逾期、今天到期、即将到期。
- 状态由现有 `deadline` 字段按本地时间计算，不写回数据，也不改变优先级算法。
- 保留完整本地化日期；状态文字作为额外语义，不依赖颜色单独传达。
- 使用主题 token 和独立 class 表达危险、强调、普通三种状态，适配现有基础主题和 TH 主题。
- 无效或缺失截止日期继续沿用现有展示逻辑，不阻断任务卡片。

## 验收

- 中英文均有状态文案。
- 过期任务有可读文字和 aria 可见文本，而不只依赖分数颜色。
- 截止状态展示不改变任务排序、存储结构、计划关联或记录关联。
