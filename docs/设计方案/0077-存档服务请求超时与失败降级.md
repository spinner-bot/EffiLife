# 存档服务请求超时与失败降级

## 问题

统一 `.efl` 存档会读取和恢复 plan-helper 快照。桌面 companion 进程异常或端口半开放时，裸 HTTP 请求可能长时间等待，用户无法得到明确反馈。

## 方案

- 所有 ArchiveService 对 plan-helper 的请求经过统一超时封装。
- 默认超时为 4 秒；超时后沿用现有降级策略：导出标记快照不可用，导入/重置保留其他本地数据并显示警告。
- 移动端仍在请求前直接跳过，不请求 localhost。
- 不改变 `.efl` manifest、dataset 字段或原始 plan 数据结构。

## 验收

- plan-helper 无响应时归档操作在有限时间内结束。
- 正常响应的导入导出行为不变。
- 失败不会阻塞待办、记录和设置数据处理。
