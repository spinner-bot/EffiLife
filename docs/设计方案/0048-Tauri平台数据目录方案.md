# Tauri 平台数据目录方案

## 问题

开发环境常把当前工作目录当作数据目录，但安装包启动位置、快捷方式工作目录和移动端沙盒都不稳定。正式版本不能依赖项目目录写入配置或运行数据。

## 方案

Tauri Rust 层按以下顺序选择目录：

1. 平台本地应用数据目录（`dirs::data_local_dir()`）。
2. 平台通用应用数据目录（`dirs::data_dir()`）。
3. 当前目录作为开发环境的最后回退。

最终使用 `<平台应用数据目录>/EffiLife/data`，确保正式安装包具备稳定且可写的数据位置，同时为当前无完整 Tauri 运行上下文的开发环境保留回退能力。

前端 IndexedDB 与 Tauri 文件备份功能后续应继续统一到同一应用数据生命周期，并在正式打包验收时验证迁移和权限。
