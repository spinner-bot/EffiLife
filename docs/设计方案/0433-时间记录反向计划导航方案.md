# 时间记录反向计划导航方案

- 状态：[完成]
- 创建时间：2026-09-29
- 执行者：Codex
- 关联目标：统一计划、待办与时间记录工作流

## 1. 背景

时间记录目前可以显示并打开关联待办，但待办还可能属于某个计划任务。记录列表没有继续回到计划的入口，导致“记录实际用时 → 检查计划上下文”的复盘路径中断。

## 2. 方案

在带有 `todo_id` 且该待办包含 `related_plan_id` 的记录项上增加“关联计划”按钮。点击后跳转现有计划路由：

```text
/plans?plan=<related_plan_id>&task=<related_plan_task_id>
```

计划中心已经负责加载计划并高亮目标任务，因此记录页只负责解析已有待办关系和导航。

## 3. 约束与取舍

- 不给时间记录复制 `plan_id` 或 `plan_task_id`，继续以统一待办作为跨域关联边界。
- 待办没有计划关系时不显示按钮，避免伪造计划上下文。
- 缺少任务 ID 时仍可打开计划级别详情；有任务 ID 时同时定位并高亮任务。
- 不改变记录的保存、删除和关联同步逻辑。

## 4. 验收标准

- [x] 计划关联待办的时间记录显示计划入口。
- [x] 导航携带计划 ID，并在可用时携带任务 ID。
- [x] 没有关联计划的记录不显示入口。
- [x] 中英文文案和静态契约测试齐全。
