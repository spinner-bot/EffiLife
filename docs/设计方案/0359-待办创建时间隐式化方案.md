# 0359 待办创建时间隐式化方案

## 背景

待办中心的首要任务是快速记录待办内容。此前新建和编辑表单暴露 `datetime-local` 开始时间输入，用户必须先理解一个与待办正文无直接关系的时间字段；这会削弱内容输入的主路径。

## 决策

1. 新建和编辑待办界面不再显示开始时间输入框。
2. `UnifiedTodo.start_time` 仍保留为内部数据字段，由 `todoService.normalize` 在创建时使用创建时间补齐。
3. 优先级评分继续读取 `start_time`，因此本次仅改变交互层，不改变排序算法、导入导出协议或历史数据。
4. 排序调整继续位于待办条目右侧操作区；待办标题、描述和关联信息保持左对齐并作为主要视觉内容。
5. 截止日期、预计时长、紧急/重要标记等明确的业务字段仍保留在高级选项中。

## 验证标准

- TaskCenter 不包含 `datetime-local` 输入。
- 待办底层模型仍能为新建数据补齐 `start_time`。
- 排序控件仍提供上调和下调操作。
- 中英文现有文案目录和统一导入导出测试不受影响。
