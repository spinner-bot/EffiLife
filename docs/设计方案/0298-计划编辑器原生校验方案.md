# 计划编辑器原生校验方案

## 背景

计划详情页的元数据、分区、任务和嵌套组编辑器已经统一为原生表单，但必填约束仍主要依赖提交函数中的静默 guard。用户在移动端或键盘操作时无法在提交前得到明确的浏览器校验反馈。

## 决策

为编辑器输入增加原生约束：

- 计划名称和日期：`required`；
- 分区名称：`required`；
- 任务内容：`required`；
- 嵌套组标题：`required`；
- 保留现有提交函数校验，作为数据层边界的第二道防线；
- 不改变任务分钟数、组范围、编号、嵌套关系和存储逻辑。

## 验证

- 增加静态契约，确认必填字段覆盖所有计划编辑器；
- 执行 Python 全量测试；
- 执行桌面端 Vite 生产构建。
