# 0487 统一引导时间工作区目标纠偏方案

## 背景

统一应用外壳已经把“计划中心”和“时间工作区”拆成两个明确入口，但主引导中的 `time-workspace` 步骤仍复用了计划入口选择器。这样会造成引导文案与实际操作不一致，也无法让用户发现独立的时间记录工作区。

## 方案

将主引导的时间步骤改为使用 `data-guide="time"` 语义目标，并同步修改 `actionTarget`。继续保留桌面端和移动端各一个同名目标，由引导浮层选择当前可见目标；不依赖导航按钮顺序或 CSS `nth-child`。

## 验收

- 主引导同时覆盖 plans、tasks、time、settings 四个统一导航入口。
- `time-workspace` 的 target 与 actionTarget 均指向 `[data-guide="time"]`。
- 中英文引导文案键完整存在。
- 现有引导浮层的可见目标选择逻辑和其他步骤不变。
