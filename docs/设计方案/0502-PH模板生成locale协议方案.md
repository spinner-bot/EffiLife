# 0502 PH 模板生成 locale 协议方案

## 背景

此前只本地化了模板选择器的名称和说明；模板实际生成的分组、任务和组说明仍是中文。英文用户创建新计划后会再次看到中文内容，统一多语言体验不完整。

## 决策

- `POST /api/plans/from-template` 新增可选 `locale` 字段，旧调用不传时保持中文原始模板行为。
- Plan Helper 只对内置模板按稳定类型提供英文内容副本；自定义模板不做自动翻译，避免改写用户数据。
- locale 只影响新建计划写入的初始内容，不影响已有计划、模板注册表或存档导出格式。
- 前端创建模板计划时传递当前应用 locale；移动端不调用模板接口，继续使用手工创建路径。

## 兼容与安全

- 未知语言回退到中文模板。
- 不在原始模板常量上原地修改，使用深拷贝，避免一次英文创建污染后续中文创建。
- API 仍兼容旧版客户端的三字段请求。

## 验收

- Python 测试验证英文内置模板的分组和任务内容，并验证中文默认与自定义模板不变。
- 前端契约测试验证创建请求传递当前 locale。
- 全量测试和生产构建通过。
