# 0247 全局搜索无障碍语义

## 目标

让统一搜索的键盘选中状态能够被辅助技术正确识别，同时保持现有鼠标、键盘导航和深链接行为不变。

## 方案

- 搜索输入框使用 `combobox` 角色，并通过 `aria-activedescendant` 指向当前结果。
- 结果容器使用 `listbox` 角色，每条结果使用 `option` 角色。
- 结果 DOM id 从稳定的结果 id 生成，过滤特殊字符，避免依赖数组下标。
- 查询为空或没有结果时不设置活动结果，避免无效的 ARIA 引用。

## 验收

- ArrowUp/ArrowDown 与 Enter 行为保持不变。
- 鼠标点击结果与原有深链接保持不变。
- 输入框、结果列表和当前选项具备完整的关联语义。
