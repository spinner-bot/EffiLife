# 0366 旧管理路由统一跳转方案

## 背景

统一壳已经通过 `PlansHubView` 承载时间计划和事件计划，但旧 `/management` 路由仍会直接加载历史 `ManagementView.vue`。用户从旧书签进入时会重新看到独立旧界面，破坏统一导航和状态体验。

## 决策

1. `/management` 保留为兼容路由。
2. 路由改为跳转 `/plans?mode=time`，不再加载旧管理组件。
3. `PlanView.vue` 继续作为统一计划工作台的时间计划子视图，不在本轮删除。
4. 不改变旧数据、API 或导入导出协议。

## 验证标准

- 旧 `/management` 书签进入统一计划工作台。
- 路由配置不再将 `ManagementView.vue` 作为用户入口组件。
- `/plan`、`/calendar` 等已有兼容跳转继续有效。
