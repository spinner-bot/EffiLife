# 统一任务中心截止与重复方案

**文档性质**：统一任务域交互方案  
**创建时间**：2026-09-25（Asia/Shanghai）  
**适用范围**：time-helper 统一 TaskCenter 与 to-dos 任务元数据

## 1. 目标

在统一任务中心提供截止日期与重复规则的基础编辑能力，使原 to-dos 的时间语义不会因融合而退化；该功能只管理任务元数据，不增加独立日历视图。

## 2. 交互决策

- 新建任务表单提供可选截止日期和重复规则，默认“无重复”。
- 编辑任务可修改或清空截止日期及重复规则。
- 任务卡显示截止日期与重复状态，日期使用当前语言环境格式化。
- 重复规则使用明确文字选项：无、每天、每周、每月、自定义；自定义规则的详细配置继续由原始 to-dos 数据和后续专门编辑器承载。
- 保存期间保持输入内容并禁用提交按钮，失败显示错误反馈。

## 3. 数据约束

- 截止日期继续保存为 ISO 日期/时间字符串，空值写为 `undefined`。
- 重复值只使用现有 `TodoRecurrence` 枚举，不创建新的枚举分支。
- 不自动生成下一条重复任务，不改变 to-dos 原有事件和存档语义。

## 4. 验收

- 新建、编辑、刷新后截止日期和重复规则保持。
- 中英文界面均有可理解的选项文案。
- 统一 `.efl` 导出不丢失这些字段。
