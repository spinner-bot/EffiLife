# 集成层认证数据根目录收口方案

- 状态：[已实现并验证]
- 创建时间：2026-09-29
- 执行者：Codex
- 关联目标：统一 launcher、sidecar 与 Python 集成层的数据目录

## 1. 问题

`DataManager` 会根据显式参数或 `EFFILIFE_DATA_DIR` 选择统一数据根目录，但 `EffiLifeIntegration` 只有在显式传入 `data_root` 时才把认证目录传给 `AuthManager`。当运行时只通过环境变量配置根目录时，认证数据可能仍写入仓库内默认目录。

## 2. 方案

- 以 `DataManager.data_root` 作为集成层唯一解析后的数据根目录。
- 始终将 `DataManager.user_dir` 传给 `AuthManager`。
- 保留显式 `data_root` 和环境变量两种入口，统一经过 `DataManager` 解析。
- 增加环境变量场景回归测试，验证认证数据与模块数据位于同一根目录。

## 3. 约束

- 不改变认证文件格式、用户模型或会话行为。
- 不改变开发环境无配置时的历史默认目录。
- 不移动已有用户数据；目录选择修复由发布运行时的数据迁移策略负责。

## 4. 验收

- 显式根目录时认证目录为 `<root>/user`。
- 仅设置 `EFFILIFE_DATA_DIR` 时认证目录仍为 `<env-root>/user`。
- 集成层注册的模块目录与认证目录共享同一个解析后的根目录。
