# 0376 事件计划模板融合方案

## 背景

plan-helper 已有工作日、周末和备考等模板及任务组定义，但统一工作台只暴露手动创建接口，旧模块的成熟能力没有进入统一应用壳。

## 决策

1. 新建事件计划弹层提供可选模板；未选择模板时继续使用章节/任务手动录入。
2. 选择模板后，提交调用既有 `POST /api/plans/from-template`，由 plan-helper 保留模板中的章节、任务和嵌套任务组语义。
3. 模板是可选增强，不阻塞服务不可用时的手动创建；移动端不伪造模板列表，继续遵守原始 plan 快照边界。
4. 创建后统一进入计划详情页，名称、日期、任务和任务组仍可继续编辑。

## 兼容性

本次不复制模板数据到前端，也不改变 plan-helper 模板协议。这样能避免模板内容、分组范围和底层任务编号在两套实现之间漂移。
