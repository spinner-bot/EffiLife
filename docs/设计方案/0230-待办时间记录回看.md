# 0230 待办时间记录回看

## 背景

统一待办中心已经可以通过计时器写入 `TimeRecord`，并在待办中保存 `related_time_record_ids`。此前这些数据只有统计意义，用户无法从待办回到实际时间记录。

## 方案

1. 在 `DataService` 增加按 `todo_id` 扫描记录存储键的查询方法，返回存在关联记录的日期并保持日期排序。
2. 待办卡片在存在关联记录时显示“查看时间记录”入口，默认打开最近一个关联日期。
3. 通过 `todo` 查询参数传递关联待办，日详情页对匹配 `todo_id` 的记录增加高亮和“关联待办”标识。
4. 查询失败或数据已被清理时仍可回到普通记录页，不阻塞待办操作。

## 取舍

本次使用现有记录存储扫描，避免改动 `TimeRecord` 数据结构和历史归档格式；代价是打开入口时需要一次轻量扫描，符合当前数据规模下“用时间换空间”的原则。
