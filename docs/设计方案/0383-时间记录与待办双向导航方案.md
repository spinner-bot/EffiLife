# 0383 时间记录与待办双向导航方案

## 背景

统一工作台已经保存时间记录与待办之间的关联，并支持从待办打开其历史记录。记录列表仍只有文本形式的关联标识；当待办没有历史记录时，记录入口也没有把待办带入新增记录表单。

## 决策

1. 记录列表中的关联待办改为可访问按钮，点击后进入 `/tasks?todo=<id>`，复用待办中心已有的定位与高亮行为。
2. `/records?todo=<id>` 在待办存在于当前统一存储时自动打开新增记录表单，并预选该待办。
3. 不改变记录数据结构、记录日期范围或关联清理逻辑；该迭代只补齐导航和创建上下文。
4. 关联待办不存在时仍显示原始 ID，避免历史数据因显示层异常而丢失可识别信息。

## 验收

- 记录列表关联待办可进入待办中心。
- 待办没有记录时，从待办进入记录入口会预选该待办。
- 中文、英文均有对应标签。
- Python 契约测试与桌面前端构建通过。
