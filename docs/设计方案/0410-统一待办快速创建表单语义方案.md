# 统一待办快速创建表单语义方案

## 背景

统一工作台的待办快速创建区目前通过标题输入框的 `keyup.enter` 和按钮点击分别触发创建。该方式虽然能够完成创建，但没有形成浏览器原生表单语义：移动端软键盘的提交动作、辅助技术的表单识别，以及未来新增输入字段后的回车行为都不够稳定。

## 决策

将快速创建区改为原生 `<form>`：

- 使用 `@submit.prevent` 作为唯一创建入口；
- 创建按钮显式使用 `type="submit"`；
- 移除标题输入框的手动回车监听，避免重复提交路径；
- 保留现有 `addTodo()` 校验、异步状态、音效和字段清空逻辑；
- 不调整 Todo 数据结构、存储服务或计划关联逻辑。

## 兼容性与边界

高级字段继续作为同一表单的一部分，桌面端回车和移动端软键盘提交均进入同一入口。编辑任务、子任务创建等其他表单不在本次范围内。

## 验证

- 增加静态契约，确认快速创建表单具备 submit 事件、提交按钮和唯一创建入口；
- 执行 Python 全量测试；
- 执行桌面端 Vite 构建。
