# th 工作区语义色令牌收口方案

## 背景

`time-helper` 的每日时间工作区已经接入统一主题引擎，但工作台底部快捷卡片仍以内联样式写入紫色、绿色、橙色和蓝色的固定 rgba/hex 值。切换水墨、深色或其他丰富主题时，这些局部颜色不会随主题变化，削弱了统一视觉和可读性。

## 方案

- 为计划管理、规则、临时变更、历史记录四类快捷卡片分别使用语义类名；
- 背景使用 `--color-primary-muted`、`--color-success-bg`、`--color-warning-bg`、`--color-info-bg`；
- 图标颜色使用 `--color-primary`、`--color-success`、`--color-warning`、`--color-info`；
- 删除组件模板中的固定 rgba/hex 内联颜色；
- 保持卡片的入口、文案、图标和路由不变；
- 让 CSS token 在所有已有主题中自动继承，不为单个主题增加特例。

## 验收

- `PlanView.vue` 当前模板不再包含四组快捷卡片的固定颜色内联样式；
- 四类语义颜色均通过 CSS 变量提供；
- 前端构建和全量 Python 测试通过；
- 不修改 `ph`、`td` 数据结构及用户已有 `package-lock.json`。
