# 0192 恢复反馈多语言化

## 目标

统一数据恢复页面的反馈语言。恢复服务目前直接返回中文提示，导致英文界面在备份恢复、无备份和异常场景中出现混合语言。

## 方案

- 由恢复服务使用统一 `translate` 资源生成用户可见提示。
- 日期格式跟随当前语言环境，不固定为 `zh-CN`。
- 错误详情继续保留，作为插值参数嵌入本地化模板。
- 不改变恢复流程、备份格式和返回接口结构。

## 验收

- 恢复建议、最近备份恢复、指定备份恢复和紧急恢复均使用 i18n。
- 中英文资源均覆盖成功、失败、无备份和建议提示。
- 通过静态测试、TypeScript 解析和完整回归。
