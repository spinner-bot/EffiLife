# 任务中心时间追踪融合方案

**文档性质**：实施设计方案  
**创建时间**：2026-09-25（Asia/Shanghai）  
**适用范围**：统一任务中心、time-helper 时间记录、to-dos `track_time` 语义

## 1. 目标

让用户在待办详情中直接记录本次投入分钟数，同时保留 time-helper 原有按日期查看时间记录的能力。记录动作必须同时更新任务累计用时和时间记录明细。

## 2. 数据决策

- `TimeRecord` 增加可选稳定 `id` 与 `todo_id`，旧记录没有这两个字段时仍可正常显示和编辑。
- 时间记录的 `duration` 继续使用小时，待办的 `time_spent` 继续使用分钟，写入边界明确换算。
- 记录内容使用任务标题，标签使用任务分类；不改变用户已有手工记录的内容和标签。
- 新增记录 ID 回写到待办的 `related_time_record_ids`，删除待办不会反向删除历史时间记录。

## 3. 交互

- 任务详情提供分钟输入和“记录用时”按钮，默认不自动计时，避免后台偷偷记录。
- 输入必须是 1–1440 的整数；保存中按钮禁用并显示反馈。
- 成功后立即显示累计用时，失败保留输入并在任务中心显示原因。
