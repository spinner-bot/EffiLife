# 0279 归档记录结构校验

## 背景

`.efl` 是统一数据交换格式。导入流程在写入 IndexedDB 和兼容性镜像前，需要确保时间记录仍是“日期键 -> 数组”的结构。此前异常对象可能通过类型断言绕过校验并污染运行时数据。

## 方案

在解析 manifest 新格式和旧版 `archive.json` 时统一调用 `normalizeImportedRecords`：缺失记录视为空对象；顶层必须是非数组对象；每个日期键的值必须是数组。校验失败直接终止解析，因此不会进入存储写入阶段。

## 兼容性

- 合法旧版和新版归档结构不变。
- 不强制日期键格式，兼容历史数据中的自定义日期键。
- 不校验记录对象内部字段，继续由既有数据层兼容历史字段。
