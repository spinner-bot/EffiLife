# 启动器正式包运行模式方案

## 状态

- 状态：已落地
- 日期：2026-09-29
- 范围：`launcher/start.py` 的桌面启动选择

## 问题

测试启动器需要优先使用 Node 开发服务器以便快速迭代，但正式安装目录可能同时存在 Node、源码或旧的 `node_modules`。如果仍按测试优先级选择，安装包会意外启动开发服务器，而不是已构建的 Tauri 应用。

## 决策

新增显式 `--packaged` 模式：

- 优先启动 `time-helper/desk/src-tauri/target/{release,debug}/efflife-desk.exe`；
- 没有原生可执行文件时，允许使用已有 `time-helper/desk/dist` 静态构建；
- 不执行 npm 检测、安装或开发服务器回退；
- 没有可运行构件时明确报告模块不可用；
- 默认模式继续保留 Node 开发优先行为，兼容当前测试流程。

正式安装器应将启动快捷方式指向 `launcher/start.py --packaged`（或等价包装命令），测试启动仍使用默认模式。
