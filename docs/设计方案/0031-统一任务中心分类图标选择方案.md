# 统一任务中心分类图标选择方案

**文档性质**：实施设计方案  
**创建时间**：2026-09-25（Asia/Shanghai）  
**适用范围**：统一任务中心分类管理

## 1. 背景

旧 to-dos UI 已实现 100+ Lucide 图标、62 个 ASCII 字符和预设颜色，但这些能力没有进入统一任务中心，分类数据虽能保存图标字段，用户却无法编辑。

## 2. 决策

- 将选择器抽成统一前端可复用组件，不引入旧 to-dos 页面、状态管理或路由。
- 选择器分为图标、ASCII、颜色三个页签；图标支持搜索，ASCII 保留大小写字母和数字，颜色支持预设与自定义色。
- 分类只保存稳定的 `icon`、`ascii_icon` 和 `color` 字段；选择器的视觉组件不写入任务数据。
- 编辑分类时保留未修改的字段，空 ASCII 选择回退为未设置；旧分类缺失字段继续使用 `circle` 和默认颜色。

## 3. 兼容性

组件只依赖统一前端已有的 Lucide 图标包和 i18n；分类字段已纳入现有归一化和 `.efl` 存档流程，不改变历史分类编号。
