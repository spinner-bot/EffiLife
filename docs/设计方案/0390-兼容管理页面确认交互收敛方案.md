# 0390 兼容管理页面确认交互收敛方案

## 背景

统一工作台已经使用主题化确认服务，但设置中的动态效果、事件管理和旧计划管理页面仍属于可达路由。若这些页面保留浏览器原生确认框，主题、多语言和键盘交互仍会出现断层。

## 决策

- 所有可达管理页面统一调用 `requestConfirm()`，由应用壳中的 `ConfirmHost` 渲染。
- 清除、删除、重置和自动清理等不可逆操作使用危险样式；计划时间自动平衡提示使用普通确认。
- 仅替换确认交互，不改变旧页面的数据结构、业务 API 或兼容路由，保证逐步退役过程中的行为稳定。
- 用静态契约测试约束这些页面不重新引入原生 `confirm()`。
