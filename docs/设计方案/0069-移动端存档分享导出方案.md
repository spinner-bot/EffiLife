# 移动端存档分享导出方案

## 状态

- 状态：已落地
- 日期：2026-09-29
- 范围：统一 `.efl` 存档在移动浏览器/WebView 中的导出

## 问题

移动 WebView 对浏览器下载的落盘位置和可访问性并不一致，单纯调用 `saveAs` 可能让用户找不到导出的存档，削弱统一数据迁移能力。

## 决策

- 移动环境优先构造带 `.efl` 文件的 Web Share 请求；
- 通过 `navigator.canShare({ files })` 检查当前平台是否支持文件分享；
- 分享成功后不再重复下载；
- 用户取消分享视为一次明确取消，不自动触发下载；
- 系统不支持文件分享或分享调用失败时，回退到现有 `saveAs` 下载；
- 桌面 Tauri 原生保存对话框和普通浏览器下载路径保持不变。
