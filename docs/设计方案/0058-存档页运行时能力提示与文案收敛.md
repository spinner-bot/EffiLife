# 存档页运行时能力提示与文案收敛

## 范围

本次只收敛设置页“存档管理”中的核心操作文案，并增加移动端 plan-helper 能力提示。主题编辑器、帮助中心和反馈页的历史文案另行处理。

## 交互原则

- 导出、导入仍使用统一 `.efl` 流程，不增加第二套数据格式。
- 移动端仍可导出和导入记录、待办及应用设置；事件计划数据若无法接入本地 plan-helper，必须明确提示，不伪造为空计划。
- 提示使用当前语言目录，避免页面固定中文导致中英文混用。
- 提示不阻断普通存档操作，采用说明卡片而非模态弹窗。

## 验收

- 中文和英文环境下，存档页标题、统计标签、导入导出按钮和说明可切换。
- 移动端显示事件计划能力说明，桌面端不显示移动端警告。
- 构建、Python 测试和差异检查通过。
