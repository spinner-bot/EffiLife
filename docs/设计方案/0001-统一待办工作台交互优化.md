# 统一待办工作台交互优化方案

**文档性质**：前端设计方案（实施前置）
**创建时间**：2026-09-25（Asia/Shanghai）
**适用范围**：time-helper 统一待办中心首轮优化

## 1. 美学方向

采用 Linear 风格的“低噪声工作台”方向：以内容列表为主要视觉结构，使用细边框、窄间距和克制的主题强调色区分状态；不使用大面积渐变卡片或居中式任务组件。页面要让用户一眼看到“下一件要做什么”，而不是先阅读装饰信息。

## 2. 字体与层级

- 沿用 time-helper 当前主题字体栈，避免引入额外字体资源造成桌面包体和中文回退问题。
- 任务标题使用 15px、600 字重；描述和辅助信息使用 13px；页面标题使用 25px。
- 任务正文左对齐，优先级属于辅助元信息，固定在条目右侧，不抢占标题起始位置。

## 3. 色彩与主题

- 所有颜色只使用统一主题 CSS 令牌，例如 `--color-text-primary`、`--color-border`、`--color-primary-muted`。
- 优先级不依赖颜色单独传达，保留文字标签；主题只负责提供强调色。
- 编辑态使用主题边框和背景，不引入独立的模块配色。

## 4. 布局与交互

- 创建表单增加可见字段标签，满足键盘导航和可理解性要求。
- 待办条目保持“左：完成控件与内容；右：优先级、编辑、删除操作”的信息架构。
- 编辑操作在原条目内展开，保存和取消均可见，避免跳转和弹窗打断上下文。
- 完成任务后保留条目并进入已完成筛选，不自动删除用户可见数据。
- 空状态、加载态、错误态继续保留；提交期间禁用保存按钮，避免重复写入。

## 5. 动效策略

- 编辑区域使用短距离淡入和高度过渡，时长不超过 180ms。
- 遵循 `prefers-reduced-motion`，减少动画时不执行位移和缩放。
- 不增加自动弹窗或干扰性提示。

## 6. 验收条件

- 优先级位于待办条目右端，标题和描述左对齐。
- 创建和编辑表单字段具有可见标签。
- 待办可从列表进入编辑、保存或取消，且模型扩展字段不会因编辑丢失。
- Vite 构建通过，`vue-tsc` 不产生待办相关新增诊断。
