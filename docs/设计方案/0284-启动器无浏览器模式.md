# 0284 启动器无浏览器模式

## 背景

统一启动器默认会在服务就绪后打开浏览器，但测试、远程开发、CI 和未来安装包的后台启动场景不需要或无法打开浏览器。强制打开会造成额外窗口和自动化环境噪声。

## 方案

统一模式支持 `--no-browser` 参数。服务、健康检查、端口冲突处理和子进程生命周期保持原有逻辑，仅跳过浏览器打开，并继续输出服务地址。未指定参数时保持原有默认行为。

## 示例

```text
python launcher/start.py --unified --no-browser
```

## 兼容性

- 仅影响 `--unified` 启动路径。
- 交互式兼容菜单仍保持默认打开浏览器行为。
- 不改变服务端口和进程清理策略。
