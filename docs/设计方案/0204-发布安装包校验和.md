# 0204 发布安装包校验和

## 目标

为 Windows、Linux、macOS 发布产物生成 SHA-256 校验文件，便于用户和发布流程验证安装包完整性。

## 方案

- 新增跨平台 Python 校验和脚本，递归读取当前矩阵任务生成的 bundle 目录。
- 每个 CI 矩阵任务生成独立的 `<platform>.sha256` 文件。
- 安装包与校验文件作为同一 artifact 上传。
- 不改变 Tauri 构建参数、sidecar 构建和安装包格式。

## 验收

- 空目录和多文件目录行为明确。
- 校验文件包含相对文件名和 64 位 SHA-256 摘要。
- 发布 workflow 在构建成功后生成并上传校验文件。
- 通过脚本单元测试和完整回归。
