# 统一存档记录主数据源方案

## 背景

时间记录为兼容旧版本会同时写入 IndexedDB 与 localStorage。两者可能因浏览器清理、迁移或异常恢复而暂时不一致。

## 约定

- `.efl` 导出以 IndexedDB `records` store 为主数据源。
- localStorage 记录先作为兼容快照读取；IndexedDB 中存在同一日期时覆盖快照。
- IndexedDB 不可用时，导出回退到 localStorage，而不是让导出整体失败。
- 旧版统计接口保持同步行为，继续读取 localStorage；后续可再改为异步统一统计服务。

这样可以避免“应用还能显示记录，但导出文件丢记录”的静默数据损失，同时兼容历史数据。
