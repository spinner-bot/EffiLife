# 任务中心分类管理交互方案

**文档性质**：实施设计方案  
**创建时间**：2026-09-25（Asia/Shanghai）  
**适用范围**：统一任务中心待办分类管理

## 1. 入口与布局

- 分类管理放在任务中心工具栏，以“管理分类”按钮打开可收起面板。
- 面板与任务创建区同属待办域，不进入全局主题/存档设置，减少跨页面跳转。
- 面板使用现有主题变量、表单状态和键盘焦点规则，支持 Esc 收起。

## 2. 操作语义

- 新建分类要求非空名称和合法颜色，难度限制在 0–10。
- 编辑分类只更新分类本身，不重写任务历史。
- 默认分类不可删除。
- 删除其他分类前，必须把使用该分类的任务迁移到默认分类，再删除分类；迁移失败则保留分类并提示错误。
- 保存成功后立即刷新任务列表和筛选器，当前筛选若指向已删除分类则回退到全部。

## 3. 数据与反馈

- 分类操作通过 `TodoCategoryService` 写入统一 IndexedDB，任务通过 `TodoService.update` 保持单一写入路径。
- 表单保留用户输入，错误显示在面板内，不使用无法定位原因的全局弹窗。
- 颜色只作为视觉辅助，名称仍是分类的唯一可读标识。
