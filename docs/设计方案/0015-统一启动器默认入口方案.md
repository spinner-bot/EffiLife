# 统一启动器默认入口方案

**文档性质**：启动体验方案  
**创建时间**：2026-09-25（Asia/Shanghai）  
**适用范围**：`launcher/start.py` 与 Windows `start.bat`

## 1. 问题

统一工作台虽然位于启动器第一项，但用户双击启动器后仍需先面对兼容模块菜单，日常入口与产品定位不一致。

## 2. 决策

- `start.bat` 默认使用 `--unified` 直接启动 EffiLife 统一工作台。
- `launcher/start.py` 不带参数时保留交互菜单，供迁移、调试和回归测试使用。
- `--menu` 显式进入兼容菜单，`--unified` 显式启动统一工作台。
- 两种模式共享同一服务健康检查、配套服务托管和终止策略。

## 3. 兼容性

- 不删除 plan-helper、to-dos 的兼容入口。
- 不改变已有模块命令和端口。
- 无 Node/Python 依赖时继续沿用原有可用性提示。

## 4. 验收

- 双击 `start.bat` 不需要菜单选择即可进入统一工作台。
- `python launcher/start.py --menu` 仍显示原兼容菜单。
- `python launcher/start.py --unified` 能复用统一入口配置。
