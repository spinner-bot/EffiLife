# 0073 打卡弹窗多语言文案方案

## 背景

统一工作台已有 `zh-CN` / `en-US` 基础，但打卡弹窗仍直接写入中文标题、说明、按钮和动画状态，导致切换语言后页面部分内容不变。

## 方案

- 在现有 i18n 命名空间下增加打卡弹窗文案键。
- 连续天数、计划名称和增量等动态值使用插值参数，不拼接语言相关句子。
- `CheckinPopup` 只消费 `useI18n()`，不改变打卡逻辑、事件触发或动画时序。
- 保留现有 `CheckinView` 文案键，不重复创建同义键。

## 验收

切换 `zh-CN` / `en-US` 后，准备、进行中、完成、连续天数和按钮文案均随语言更新；前端构建与全量测试通过。
