# 0236 静态构建 SPA 路由回退

## 问题

无 Node 环境下的静态构建回退可以打开首页，但浏览器刷新 `/tasks`、`/plans` 等 history 路由会被普通静态服务器当作文件请求并返回 404。

## 方案

增加轻量 `launcher/static_server.py`：真实静态资源按文件服务；不存在且不带文件扩展名的路径统一回退到 `index.html`，交由 Vue Router 处理。脚本仅用于测试/演示回退，不替代正式 Tauri 服务器。

## 安全边界

带扩展名的资源不存在时仍返回正常 404，不把资源拼写错误静默回退为 HTML；服务器只绑定 `127.0.0.1`。
