# 公共分类适配器方案

**文档性质**：实施设计方案  
**创建时间**：2026-09-25（Asia/Shanghai）  
**适用范围**：to-dos 分类与 common API Gateway

## 1. 目标

让分类数据与任务、时间记录一样具备明确的公共适配入口，避免调用方自行拼接分类字段。

## 2. 决策

- 新增 `CategoryAdapter`，提供 to-dos 分类到 `UnifiedCategory` 及反向转换。
- 保留 `difficulty`、颜色、图标、描述和创建时间；模块来源固定为 `to-dos`。
- 不在适配器中执行分类去重或删除迁移；这些属于存储/业务层职责。
