# 首页内容卡悬停反馈方案

**文档性质**：前端交互细节方案  
**创建时间**：2026-09-25（Asia/Shanghai）  
**适用范围**：统一首页时间计划与事件计划摘要卡

## 1. 问题

首页中心卡片承载的是阅读型统计内容，但现有悬停状态改变整块背景，降低文字对比和阅读稳定性。

## 2. 决策

- 悬停时保持卡片原有背景色。
- 使用主题边框高亮和轻微外轮廓表达可点击性。
- 不增加位移、不改变文字颜色，不让内容看起来像普通导航按钮。
- `prefers-reduced-motion` 下不执行过渡动画。

## 3. 验收

- 鼠标移入首页时间计划和事件计划摘要卡时，正文仍保持原背景和可读性。
- 边缘轮廓可明显识别卡片的可点击状态。
