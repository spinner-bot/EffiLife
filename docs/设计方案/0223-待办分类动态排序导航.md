# 0223 待办分类动态排序导航

## 背景

待办分类数据已经支持置顶、难度和优先排位分，但统一任务中心只有下拉筛选，无法体现类别排序和高频类别优先的设计要求。

## 方案

- 根据当前有效待办的优先排位分计算类别分数：分类内分数总和除以有效待办数平方根。
- 置顶类别优先，其余类别按类别分数降序排列；无有效待办的类别放在末尾。
- 使用 `TodoSettings.expandCount` 展示前 N 个高频/高分类别，其他类别默认收纳，可手动展开。
- 点击分类导航直接复用现有 `categoryFilter`，不引入第二套筛选状态。

## 验收

- 类别分数随待办优先级时钟更新。
- 置顶、展开/收纳、全部分类和分类筛选可用。
- 移动端保持横向滚动或自动换行，不破坏现有任务列表。
