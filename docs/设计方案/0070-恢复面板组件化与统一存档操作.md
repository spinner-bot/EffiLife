# 恢复面板组件化与统一存档操作

## 目标

将设置页的数据恢复入口与统一 `.efl` 存档、自动备份机制放在同一套可理解的多语言界面中，同时复用现有恢复服务。

## 方案

- 新增 `RecoveryPanel` 展示 localStorage、IndexedDB 和备份状态。
- 紧急 JSON 导出、备份恢复和返回操作通过事件交给设置页现有处理函数。
- 组件只负责展示与事件派发，不直接操作存储，保持恢复流程的单一入口。
- 旧模板保留为 `legacy-recovery` 回退分支，待后续视觉清理时删除。

## 验收

- 中英文环境下恢复面板可用。
- 备份列表为空、加载中和有备份三种状态均有明确表达。
- 恢复服务与确认流程不改变。
