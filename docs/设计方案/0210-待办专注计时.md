# 0210 待办专注计时

## 目标

让待办中心能够直接开始一次专注工作，并将实际投入写入统一时间记录，而不是要求用户事后估算分钟数。

## 方案

- 每次只允许一个待办处于专注计时状态。
- 使用浏览器时间戳计算经过秒数，界面显示当前会话时长。
- 停止时按分钟向上取整，复用现有时间记录分段逻辑，跨午夜时按日期拆分。
- 记录写入成功后调用 `TodoService.trackTime`，保存累计用时和关联记录 ID。
- 保留原有手动记录用时入口；组件卸载时停止界面计时，不自动丢弃已记录数据。

## 验收

- 待办可开始/停止专注计时。
- 停止后生成时间记录并更新待办累计用时。
- 跨午夜记录仍分配到正确日期。
- 中英文操作文案完整，原有手动记录和回滚逻辑不受影响。
