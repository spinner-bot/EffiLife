# td 待办条目右侧优先级布局方案

## 背景

`td` 的核心内容是单条待办文本，优先级排位属于辅助控制。当前条目使用可换行的 flex 布局，正文变长时右侧控制区会随行高居中，视觉上容易被误认为内容的一部分，也不利于快速扫描。

## 方案

- 待办正文区域保持左对齐并占据主要剩余宽度；
- 排位、分数、子任务、置顶、编辑和删除统一放在条目最右侧的操作区；
- 条目改为顶部对齐，使右侧操作区固定在条目上沿；
- 移动端继续允许操作区换行到下一行，并保持触控目标尺寸；
- 不改变优先级计算、排位调整或待办数据结构。

## 验收

- `.task-main` 明确左对齐；
- `.task-item-actions` 使用 `margin-left: auto` 位于右侧；
- 排位控件位于操作区而非待办标题上方；
- 桌面和移动端构建、测试通过。
