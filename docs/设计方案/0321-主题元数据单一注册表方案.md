# 主题元数据单一注册表方案

- 状态：[完成]
- 创建时间：2026-09-29
- 执行者：Codex
- 关联目标：保留并适配 th 丰富主题架构

## 1. 背景

主题视觉预设由 `ThemeEngine` 注册，但设置页另有一份主题分类和翻译键映射。新增主题时可能出现预设存在、设置页却落入错误分类或显示原始 key 的情况。

## 2. 方案

扩展 `ThemeDefinition`，由主题引擎同时登记：

- 类型和预览信息；
- 显示名称与描述的 i18n key；
- 设置页分类 key。

设置页直接消费定义，不再维护 `themeMeta` 映射。保留 `name/description/preview` 字段，兼容已有调用者。

## 3. 约束与取舍

- 不改变主题类型、主题配置数据或视觉渲染函数。
- 不把翻译文本重新硬编码到设置页；名称和描述仍由 i18n 目录提供。
- 新主题若未登记元数据仍可通过引擎渲染，但注册表测试会阻止其无分类进入设置页。

## 4. 验收标准

- [x] 主题类型、分类和翻译键在单一注册表定义。
- [x] 设置页移除重复主题元数据映射。
- [x] 保留已有返回字段兼容性。
- [x] 全部现有主题仍可分类展示并通过构建测试。
