# 0495 统一待办本地日期解析方案

## 问题

待办截止日期以 `YYYY-MM-DD` 保存时，它表示用户所在时区的日历日期，而不是 UTC 时间戳。首页和待办中心直接调用 `new Date(deadline)`，在部分时区会把日期转换到前一天，造成显示和“今天到期”判断不一致。

## 决策

- 对纯 `YYYY-MM-DD` 值统一使用 `dataService.parseLocalDate`。
- 仍保留带时间和时区的 ISO 时间戳使用原生 `Date` 解析。
- 首页摘要、待办列表显示和截止状态判断共用同一解析规则。
- 不修改存档字段、待办数据结构或导入导出协议。

## 验收

- 静态契约测试确认两个入口都使用本地日期解析。
- Python 全量测试和前端生产构建通过。
