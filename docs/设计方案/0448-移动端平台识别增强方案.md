# 移动端平台识别增强方案

## 背景

`runtimeCapabilities.ts` 原先主要依据 `navigator.userAgent` 判断移动端。部分 Chromium/WebView 可能启用用户代理精简，单靠字符串会把移动设备误判为桌面，进而尝试调用桌面 Plan Helper sidecar。

## 方案

- 优先采纳标准 `navigator.userAgentData.mobile` 的明确移动端信号；
- 保留 UA 字符串识别，兼容 Safari、旧版 WebView 和非 Chromium 环境；
- 保留触控 iPad 的 `MacIntel + maxTouchPoints` 兜底；
- 不改变桌面 Tauri、浏览器服务和移动端本地计划快照的既有行为；
- 不引入平台专用插件，避免影响未来多端构建。

## 验收

- 增加静态契约测试，确保三类识别信号均存在；
- 运行移动端存档相关测试；
- 运行前端生产构建；
- 全量 Python 测试；
- 不修改用户已有的 `time-helper/desk/package-lock.json`。
