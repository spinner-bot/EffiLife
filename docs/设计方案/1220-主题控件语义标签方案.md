# 1220｜主题控件语义标签方案

日期：2026-10-10

## 美学方向

延续现有 TH 主题设置的“预览优先、控件克制”方向，不增加视觉组件；只把已有的可见字段名称升级为原生表单语义，让主题编辑保持轻量且可键盘操作。

## 实施范围

- 纯色主题的窗口背景、按钮背景、按钮文字。
- 渐变主题的起止颜色与方向。
- 玻璃主题的背景、透明度、模糊度。
- 霓虹主题的背景、霓虹色、强调色、发光强度。

## 交互与兼容

- 每个可见字段文字通过 `label[for]` 关联唯一控件 `id`。
- 不改变现有 `v-model`、预览即时更新、退出自动持久化和主题注册表。
- 颜色输入、滑块和选择框继续使用现有主题 token 与原生控件状态。

## 验收

- 主题控件均具备原生 label 关联。
- 现有主题持久化/i18n 契约与生产构建通过。
