# 统一存档数据完整性校验方案

## 目标

识别存档中“仍是合法 JSON、但内容已被替换或损坏”的情况，避免用户在导入后才发现数据不一致。

## 协议

- manifest 可包含 `dataset_sha256`，键为数据集名，值为对应 `data/*.json` 原始 UTF-8 字节的 SHA-256 小写十六进制摘要。
- 新版 Python 与前端导出器都会写入摘要。
- Python `read_bundle` 和前端 `parseArchiveData` 在存在摘要时校验；缺少该字段的历史 `.efl` 仍可读取。
- 摘要只负责物理内容完整性，不解释业务字段，也不替代导入归一化和关联修复。
