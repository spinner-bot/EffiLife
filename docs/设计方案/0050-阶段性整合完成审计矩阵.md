# 阶段性整合完成审计矩阵

## 当前状态

| 目标 | 当前结论 | 证据 | 后续缺口 |
|---|---|---|---|
| 统一应用壳 | 已具备开发集成版 | `time-helper/desk` 路由、全局导航、统一 launcher 冒烟测试 | 正式安装包入口仍需替代测试 launcher |
| 统一数据 | 已具备主要链路并补齐计划服务落盘与导入回滚 | `.efl` bundle、IndexedDB 主存储、Plan Helper 导入导出、待办/计划完成同步、原始快照写回、Python bundle 原子回滚测试 | 需要正式安装包环境下的迁移验收 |
| 丰富主题 | 已接入统一壳 | `ThemeEngine` 高级主题预设与 CSS token | 需要逐平台视觉验收与性能基线 |
| 多语言基础 | 已具备基础架构并持续收敛 | `zh-CN` / `en-US` locale、导航、待办、记录、设置、声音、动效、事件管理页及旧版 PlanView 主要文案 | 旧版页面仍可能存在低频注释/辅助文案 |
| 正式桌面交付 | 已具备 sidecar 构建链，尚未完成安装包验收 | Tauri `externalBin`、PyInstaller 构建脚本、release sidecar 启动代码、Windows sidecar HTTP smoke | 当前机器缺少 Rust/Cargo；需在发布环境完成 Rust 编译、NSIS、签名和安装后数据迁移验收 |
| 多端交付 | 已具备移动端本地计划编辑候选链路，尚未完成平台验收 | Tauri mobile entry point、IndexedDB 原始计划快照、本地计划编辑写回、移动端导入导出边界 | 需要 Android/iOS WebView 真机验收，以及移动端文件/权限/安装升级验证 |

## 审计结论

当前可以称为“统一工作台开发集成版，并已具备正式桌面 sidecar 构建候选方案”，不能称为已完成的正式跨平台产品。下一阶段应优先在发布环境完成 Tauri/Rust/NSIS 验收，并继续收敛历史页面多语言和移动端运行时，而不是扩大测试 launcher 的产品职责。
