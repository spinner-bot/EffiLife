# 打卡未就绪状态行动入口方案

## 背景

打卡页在今日计划未完成时会显示说明和禁用按钮，但用户需要自行返回其它页面寻找今日计划，未就绪状态没有提供下一步行动。

## 设计决定

- 保留禁用状态作为规则说明，明确“完成计划后可打卡”。
- 在其下方增加“打开今日计划”按钮，点击进入现有 `/time` 工作台。
- 不放宽打卡条件，不允许绕过 TH 完成度校验。
- 使用现有应用壳导航和 i18n，不增加重复的计划管理逻辑。
- 保持移动端与桌面端相同的路由语义，由各端布局自行适配。

## 验收标准

1. 未就绪状态提供可聚焦、可点击的今日计划入口。
2. 入口进入 `/time`，不会直接执行打卡。
3. 中文和英文均有对应文案。
4. 打卡页静态契约、前端构建和基础真实浏览器路径通过。

本方案仍属于第 0 阶段，不递增阶段编号。
