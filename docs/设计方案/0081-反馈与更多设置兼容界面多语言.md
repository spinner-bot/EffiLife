# 0081 反馈与更多设置兼容界面多语言

## 范围

设置页的反馈页和“更多设置”兼容入口仍直接写入中文，英文 locale 下会出现明显混用。本次只迁移这些界面中的用户可见文案。

## 决策

- 使用 `settings.feedback.*` 和 `settings.more.*` 命名空间。
- 邮箱地址、复制状态和邮件发送行为保持现有实现。
- “更多设置”中的导航项只替换显示文案，不改变 `currentView` 或路由行为。
- 不迁移版本历史内容和旧版帮助中心长文档，避免本次变更扩大到内容重写。

## 验收

- 中文、英文字典均包含反馈页与更多设置所需 key。
- 反馈页和更多设置模板不再直接渲染对应中文文案。
- 前端类型检查与生产构建通过。
