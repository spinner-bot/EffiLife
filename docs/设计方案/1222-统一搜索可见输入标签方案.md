# 1222｜统一搜索可见输入标签方案

日期：2026-10-10

## 设计方向

沿用统一工作台的命令面板风格：标题说明入口，字段标签说明当前输入目标，placeholder 只提供内容范围示例。标签使用紧凑的辅助层级，不改变搜索弹窗的视觉密度。

## 实施内容

- 为跨 TH/PH/TD 的搜索输入增加中英文可见 label。
- 使用唯一 `id`/`for` 关联 combobox 输入框。
- 保留 Ctrl/Cmd+K、Esc、方向键、模块筛选和结果深链行为。

## 验收

- 搜索输入具备原生 label 语义和可见文字。
- 中英文目录各有对应文案。
- 现有搜索契约与生产构建通过。
