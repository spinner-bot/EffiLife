# 0278 计划任务关联启动自愈

## 背景

统一待办可以引用计划任务。任务软删除、旧版本导入或计划恢复后，待办可能保留无法解析的计划任务 ID。此前启动流程只修复时间记录关联。

## 方案

启动时读取计划摘要和存在关联的计划任务列表，构造内部 ID/显示 ID 双标识集合。仅当计划列表读取成功且任务列表明确返回时，才解除无法匹配的待办引用；任一读取失败则跳过该计划，避免离线状态造成误清理。

## 数据语义

- 只清理 `related_plan_id` 与 `related_plan_task_id`，不删除待办。
- 任务已软删除且不再出现在活动任务列表时视为失效引用。
- 计划不存在时视为失效引用。
- 服务暂不可用时保留原数据，等待下次启动自愈。
