# 丰富主题多语言元数据方案

**文档性质**：实施设计方案  
**创建时间**：2026-09-25（Asia/Shanghai）  
**适用范围**：time-helper 丰富主题选择器

## 1. 问题

主题引擎和主题类型已经统一，但设置页直接把主题名称、描述和分组写成中文。切换语言后，用户仍会看到中文主题目录，削弱多语言基础的一致性。

## 2. 决策

- 主题预设只保存稳定的 `nameKey`、`descriptionKey` 和 `categoryKey`，不改变 `ThemeType` 和引擎配置。
- 设置页通过 locale catalog 渲染名称、描述和分组；筛选使用稳定 category key，不比较显示文本。
- 中英文 catalog 同时覆盖基础主题与 th 的丰富主题，后续新增语言只扩展 catalog。
- 主题预览色值和 Canvas 效果保持现有实现，不将视觉配置与文案耦合。
