# 0360 正式发布预检入口方案

## 背景

EffiLife 的 Tauri 发布配置已经包含版本一致性、Plan Helper sidecar、三平台矩阵、测试和安装包校验，但开发者此前必须从仓库根目录手动调用 Python 脚本。前端项目入口没有体现这条正式发布链，容易误把 `npm run build` 当成完整发布验证。

## 决策

在 `time-helper/desk/package.json` 增加：

```text
npm run release:check
```

该命令只执行发布配置预检，不启动服务、不构建安装包，也不修改版本或用户数据。真实安装包仍由具备 Rust/Cargo 的发布 runner 执行 Tauri 构建。

## 验证标准

- 命令从 desk 目录可直接执行。
- 预检继续验证统一版本、sidecar、三平台 workflow、回归测试和安装包校验步骤。
- 契约测试保证命令不会被移除或指向错误脚本。
- 没有 Rust/Cargo 的开发机可以明确得到配置预检结果，而不会被误导为已完成安装包构建。
