# 计划控制台桌面双工作区方案

## 背景

`th` 的每日时间记录和 `ph` 的主题计划已经在同一个 `PlansHubView` 中协作，但桌面端仍按两个纵向 section 排列，用户需要滚动才能看到另一种工作内容。这与“记录与日计划管理合并为计划控制台”的要求不完全一致。

## 方案

- 默认计划中心在宽屏下采用双工作区网格：左侧为今日时间与每日记录，右侧为主题计划列表、创建入口和归档；
- 两侧仍使用各自的服务、数据结构和编辑器，只共享工作区容器、主题和导航上下文；
- 主题计划详情继续切换为全宽编辑状态，避免在窄栏中编辑复杂的模块、任务和嵌套分组；
- 移动端保持单列顺序，先看今日时间，再看主题计划；
- `?mode=time`、`/time` 和旧书签兼容逻辑不变。

## 验收

- 桌面默认计划页同时显示两个工作区，不需要在两个页面间跳转；
- `ph` 与 `th` 的数据 API 不互相替换；
- 计划详情仍可全屏编辑；
- 移动端不出现横向溢出；
- 增加布局契约测试并通过前端构建、全量测试。
