# 移动端事件计划只读工作区

## 背景

移动端已能读取原始 plan 快照，但尚未提供兼容原始模型的本地写运行时。若继续显示编辑按钮，会造成用户误操作和数据不同步。

## 方案

- 计划中心在移动端快照模式显示只读提示。
- 隐藏创建、编辑元数据、归档、添加 section/task/group、完成任务、记录日志和删除等写入口。
- 保留计划摘要、任务内容、完成状态、预计时长、日志、嵌套组和软删除后的有效显示编号。
- 桌面端和浏览器 HTTP 服务行为不变。

## 验收

- 移动端能查看导入的原始计划内容。
- 移动端不展示会触发写操作的按钮。
- 中英文只读提示明确说明后续兼容运行时状态。
