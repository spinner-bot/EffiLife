# 统一应用壳主导航方案

**文档性质**：实施设计方案  
**创建时间**：2026-09-25（Asia/Shanghai）  
**适用范围**：`time-helper/desk/src/App.vue`

## 1. 背景

融合前端虽然已经通过路由提供首页、计划、待办和时间记录，但各页面仍然各自承担入口导航，用户容易把它们理解为三个拼接的模块。

## 2. 决策

- 在应用壳中提供持久主导航：今日、计划中心、待办、时间记录、设置。
- 使用统一的主题变量、激活态和响应式布局，不改变各页面已有的业务编辑入口。
- 日历、打卡、音频等功能保留为次级功能，不占用核心时间管理导航位。
- 导航文案纳入现有中英文 i18n 基础，后续可继续扩展语言而不改路由结构。

## 3. 交互约束

- 当前路由对应导航项必须有明确激活态。
- 移动宽度下保留图标导航和可访问标签，避免横向溢出。
- 主题切换后导航自动沿用主题颜色、边框和阴影。
