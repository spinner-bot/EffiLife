# 系统减弱动效与主题画布协同方案

## 状态

- 状态：已落地
- 日期：2026-09-29
- 范围：统一应用壳的 JavaScript 动效、主题画布和粒子系统

## 问题

CSS 的 `prefers-reduced-motion` 只能压缩 CSS 动画和过渡，无法停止 `requestAnimationFrame` 驱动的主题画布与粒子系统。系统已要求减少动效时，后台仍可能持续进行绘制，既不符合无障碍预期，也会增加移动设备功耗。

## 决策

- `MotionManager` 读取 `window.matchMedia('(prefers-reduced-motion: reduce)')`；
- 系统偏好变化时更新响应式状态并通知 `ThemeCanvas` 重建；
- 系统要求减少动效时，主题画布、粒子和过渡能力统一视为关闭；
- 用户保存的动效设置不被覆盖，系统偏好只作为更高优先级的运行时安全约束；
- 无 `window.matchMedia` 的测试或非浏览器环境保持原有用户设置行为。
