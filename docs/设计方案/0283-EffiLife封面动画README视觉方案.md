# EffiLife 封面动画 README 视觉方案

## 目标

为仓库 README 提供一个无需外部服务、可在 GitHub 直接渲染的封面动画，快速传达 EffiLife 已从三个历史模块演进为统一个人时间管理工作台。

## 视觉方向

- **风格**：参考 Linear 的深色产品封面与精致数据可视化，使用深靛蓝背景、青绿色强调色和克制的蓝紫辅助色。
- **左侧信息**：产品名、英文定位和“记录 / 计划 / 待办”能力标签，保持 README 首屏信息清晰。
- **右侧图形**：以时间刻度环为核心，外环缓慢旋转；任务卡片沿时间线轻微浮动；底部进度流线表达记录、计划和待办的连续闭环。
- **动效**：只使用旋转、呼吸、平移和轻微浮动，动画速度分级；系统启用减少动画时停止所有动画但保留完整构图。
- **技术边界**：使用仓库内原生 SVG 和 CSS，不依赖 JavaScript、外部字体、远程图片或视频；所有颜色集中在 SVG token 中。

## README 接入

- 文件位置：`assets/hero.svg`。
- README 以宽度自适应的 `<img>` 作为首屏封面，正文仍保留完整启动、架构、数据和发布边界说明。
- 封面文案只描述当前真实能力，不把未完成的正式安装包和真机验收写成已交付能力。
