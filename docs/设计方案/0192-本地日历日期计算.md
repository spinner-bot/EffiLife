# 0302-本地日历日期计算

## 背景

时间记录、计划和打卡按用户所在地区的日历日工作。核心日期工具此前通过 UTC ISO 字符串截取日期，在本地午夜附近可能把记录归入前一天或后一天，跨平台时尤为明显。

## 方案

- `getTodayDate()` 使用本地 `年/月/日` 组件。
- `formatDate()` 使用本地日历组件生成 `YYYY-MM-DD`。
- `addDays()` 先按日期组件构造本地日期，再进行日历运算。
- API 层的范围查询、周报和 `addDays` 复用统一本地日期工具。

不改变存储格式，历史日期字符串仍为 `YYYY-MM-DD`。
