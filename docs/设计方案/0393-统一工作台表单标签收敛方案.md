# 0393 统一工作台表单标签收敛方案

## 背景

UX 规范要求每个输入框都有可见标签。统一计划详情的进度输入、Section 编辑输入，以及待办分类管理中的部分编辑字段仍主要依赖 placeholder 或无关联文本，键盘和读屏用户难以确认字段含义。

## 决策

- 为缺少可见标签的输入补充统一的 `label` 文本，保留 placeholder 作为示例或补充说明。
- 使用稳定 `id`/`for` 关联标签与输入，不改变字段绑定、校验和提交逻辑。
- 对重复渲染的待办分类编辑行使用分类 ID 生成唯一字段 ID。
- 继续使用现有主题令牌和页面布局，不引入新的表单组件层。
