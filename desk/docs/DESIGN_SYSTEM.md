# EffiLife Desktop 设计方案

> 本文档为桌面版 UI/UX 设计规范，遵循"先设计，再编码"原则。

---

## 1. 美学方向

**参考品牌：Linear + Vercel + Notion**

- **Linear**：精致的深色/浅色主题、细腻的动画、克制的色彩运用
- **Vercel**：极简排版、大量留白、清晰的信息层级
- **Notion**：友好的桌面端交互、合理的空间利用

**设计关键词**：克制、精致、可预测、呼吸感

## 2. 字体系统

### 西文字体
- **标题**：Inter (600-700 weight)
- **正文**：Inter (400-500 weight)
- **数字/代码**：JetBrains Mono

### 中文字体
- **标题**：Noto Sans SC Medium / PingFang SC Semibold
- **正文**：Noto Sans SC Regular / Microsoft YaHei

### 字号层级
| 用途 | 字号 | 字重 | 行高 |
|------|------|------|------|
| 页面标题 | 1.5rem (24px) | 600 | 1.3 |
| 区块标题 | 1.125rem (18px) | 600 | 1.4 |
| 正文 | 1rem (16px) | 400 | 1.6 |
| 辅助文字 | 0.875rem (14px) | 400 | 1.5 |
| 标注 | 0.75rem (12px) | 400 | 1.4 |

├─────────────────────────────────────────────┤
│                                             │
│           ┌─────────────┐                   │
│           │  时间显示   │                   │
│           │  日期显示   │                   │
│           └─────────────┘                   │
│                                             │
│           ┌─────────────┐                   │
│           │  时间统计   │                   │
│           │  进度展示   │                   │
│           └─────────────┘                   │
│                                             │
│       ┌─────┬─────┬─────┬─────┐             │
│       │记录 │日历 │管理 │设置 │             │

### 内容区域
- **最大宽度**：600px（主页）、800px（列表页）、1000px（日历）
- **水平居中**，两侧留白
- **垂直方向**：flex 布局，主内容区居中

### 卡片/区块
- 圆角：12px（大卡片）、8px（按钮、输入框）
- 边框：1px solid 边框色
- 阴影：轻微阴影增加层次

## 5. 动效策略

### 时长规范
| 类型 | 时长 | 缓动函数 |
|------|------|----------|
| 快速反馈 | 150ms | cubic-bezier(0.4, 0, 0.2, 1) |
| 常规过渡 | 250ms | cubic-bezier(0.4, 0, 0.2, 1) |
| 复杂动画 | 350ms | cubic-bezier(0.4, 0, 0.2, 1) |

### 动效场景
- **按钮悬停**：背景色变化 + 轻微上移（2px）
- **页面切换**：淡入淡出
- **数据更新**：数字变化时轻微闪烁
- **弹窗出现**：缩放 + 淡入

### 减少动画
尊重系统 `prefers-reduced-motion` 设置，禁用所有动画。

## 7. 状态覆盖

### 按钮状态
| 状态 | 样式 |
|------|------|
| 默认 | 背景色 + 边框 |
| 悬停 | 背景加深 + 上移 2px |
| 按下 | 背景更深 + 下移 0px |
| 聚焦 | 外发光 2px 主色 |
| 禁用 | 透明度 0.6 + 禁用光标 |
| 加载中 | 显示 spinner + 禁用点击 |

### 输入框状态
| 状态 | 样式 |
|------|------|
| 默认 | 边框 + 背景 |
| 悬停 | 边框加深 |
| 聚焦 | 边框主色 + 外发光 |
| 错误 | 边框红色 + 错误提示 |
| 禁用 | 背景灰 + 禁用光标 |

## 8. 图标规范

**使用图标库**：Lucide Icons（https://lucide.dev）

- 风格：线性、圆润
- 尺寸：20px（默认）、24px（导航）、16px（小图标）
- 线宽：2px
- 颜色：跟随文字颜色

**禁止使用 emoji 作为功能图标**，仅可在装饰性文案中使用。

---

## 9. 交互规范

### 键盘导航
- Tab 切换焦点
- Enter 提交/确认
- Esc 关闭弹窗/取消
- 方向键在列表中导航

### 右键菜单
- 列表项支持右键菜单
- 包含：编辑、删除、复制等操作

### 快捷键
- Ctrl/Cmd + N：新增记录
- Ctrl/Cmd + S：保存
- Ctrl/Cmd + Z：撤销（如支持）

---

## 10. 无障碍

- 颜色不作为唯一信息传达方式（配合图标/文字）
- 文字与背景对比度 ≥ 4.5:1
- 可聚焦元素有明显焦点指示器
- 支持屏幕阅读器（语义化标签 + aria 属性）
