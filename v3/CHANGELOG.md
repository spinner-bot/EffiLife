# EffiLife 更新记录

本文件将产品版本与实际更新内容对应。开发进展在同一版本下持续补充；发布日期、验证结果和已知限制仅在取得证据后记录。

## [3.0.0] — 开发中

### 已完成

- 建立独立 v3/ 工作区与版本事实源，保留旧版和 Git 基线以便回退。
- 建立按小步骤提交、阶段验收后 no-ff 合并与推送的开发约定。
- 建立独立 Node LTS 工具链、可复现依赖锁定与版本一致性门禁。
- 实现 Plan 层级、稳定条目标识、父节点类别设置与子项显式类别保护。
- 实现统一行动命令：一次处理实际时间、未完成进展日志及可选完成状态。
- 支持跨任务最近观测的用时参考；参考值与实际记录分别保存，交错任务不会按整段日志间隔累计实际用时。
- 实现命令重试去重、失败不改变原状态、时间记录删除后的关联清理。
- 实现跨日与时区下的实际区间统计、重叠区间去重和原待办优先度公式的兼容迁移。
- 领域阶段验证：22 项自动化测试通过，严格 TypeScript 检查和版本检查通过。
- 实现 IndexedDB 原子提交、跨窗口写入串行化、已知有效备份和损坏主数据恢复。
- 实现数据包预览与校验导出、旧 EFL/JSON 导入，保留原始数据以便后续迁移其他设置。
- 导入保留未完成日志、模糊时间精度、已删除条目的历史引用与原编号；归档计划独立命名，避免身份冲突。
- 校验 ZIP 路径、大小写重复、符号链接、清单和 SHA-256，包扩展名统一配置。
- 持久化与兼容阶段累计 37 项自动化测试通过；浏览器和桌面完整动线待后续阶段验证。
- 建立现代化响应式应用壳、总览、计划树与日志、统一录入、时间记录、待办和集中设置的基础产品动线。
- 接入内置中英文、Inter/Noto Sans SC 本地字体及 25 套旧主题的可选择配色目录，保留装饰源码供扩展运行时承接。
- 支持父节点类别设置、未完成进展记录、实际用时关联、编辑、归档、时间与计划互相导航，以及存档导出/预览导入/备份恢复。
- 浏览器测试发现并修复导入的响应式对象克隆失败、移动信息面板收缩；回归测试补齐跨视图描述同步与根条目编号冲突。
- 累计 43 项自动化测试及 7 项真实 Chromium 浏览器测试通过；生产构建通过，五个基础页面七档宽度检查通过。
- 接入每日分配模板、日期手动覆盖、每周/每月/每年/每月第几周规则及默认方案；兼容迁移旧版时间计划和日历指定。
- 分配制按实际投入计算，切分制将当天已过去且未观测的区间归入背景类别；派生值明确标记，不生成实际记录。
- 补齐无效日期与夏令时不存在时刻校验、持续使用时日期更新、动态日历翻译覆盖，并改善弹窗初始焦点与关闭返回。
- 累计 50 项自动化测试、10 项真实 Chromium 浏览器测试和生产构建通过，新增分配制/切分制、跨窗口同步和未保存输入保护验证。
- 实现扩展包清单/兼容版本/能力与内容校验、本地分类型编号、显式升级或并存、卸载墓碑和权限活动审计。
- 设置可预览安装主题/资源包、逐项授权、停用和卸载；主题配色与受控 L1 CSS、包内语言和字体接入共享目录，支持清理与默认回退。
- 数据存档导入重置扩展高级授权；资源循环继承、身份冲突与加载失败保留宿主默认界面，修复同名主题选择歧义。
- 改善持续使用时的数据可靠性：读操作期间的新通知不会丢弃，成功写入直接显示已提交快照，广播失败不会误报保存失败。
- 累计 66 项自动化测试、12 项真实 Chromium 浏览器测试与生产构建通过；提供 HTML 扩展作者指南和可重复构建的主题/语言包示例。
- 实现 L2/L3 Worker 与不透明来源 iframe 沙箱、受控布局渲染、分能力宿主 API 和与领域写入原子提交的审计；事务内校验撤销与版本指纹，禁止扩展修改注册表和授权。
- 25 套内置主题保留配色与装饰，复杂主题的绘图辅助函数和粒子初始化闭包完整迁入隔离运行时；绘制尊重可见性和减少动态效果设置。
- 提供启动期间也可用的恢复控件、独立 URL/快捷键安全模式、超时与请求洪泛停止、持久化失败状态；修复延迟加载页面的嵌套确认层级遮挡。
- 累计 72 项自动化测试、17 项真实 Chromium 浏览器测试及生产构建通过；验证全部内置主题、授权/拒绝写入、脚本卡死恢复、存储/宿主 DOM 隔离和 CSP 网络阻断。新增可构建的功能包示例。

### 本版本目标

- 重构现代化应用壳、总览、计划、时间、待办与设置，统一行动录入。
- 保留 Plan 的主题组织与进展日志，支持未完成任务及交错执行的用时参考。
- 通过稳定应用服务与平台适配实现时间、事件数据关联；提供持久化、恢复和旧存档迁移。
- 建立可扩展语言、主题、字体、资源包与权限运行时；为多端建立共同契约。
- 建立真实版本校验、自动化行为与浏览器测试、构建和交付证据。
