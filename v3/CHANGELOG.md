## [3.2.0] — 时间类别与记录细节优化，本地验收候选（2026-11-12）

- 时间类别支持可选的“描述”，随命令、存档与导入校验一起持久化；把描述清空即删除该字段。
- 类别管理页改用实心圆点 + 粗体类别名的主角样式，并显示难度与描述，未填描述的类别也有明确提示。
- 更多下的类别管理、分配方案、日程规则、主题与外观、设置页在顶栏提供“返回”入口。
- 新增单条时间记录详情页 `/time/records/:id`：圆环图例与时间记录行都能进入，展示类别、日期、区间、时长、备注与关联计划/待办，并提供编辑和删除。
- 时间页类别圆环以分配方案的目标时长为满圈：未达标时按目标计算并显示还差多少，超过目标才按实际总量；已设定但当天没有记录的类别仍显示全白圆环与“还未开始”。
- 当前 Windows 前端验收：121 项单元测试、44 项真实 Chromium 测试通过，版本、严格类型与生产构建门禁通过。本轮未重建原生包，Windows/macOS/移动原生与 WebKitGTK 结果沿用 v3.1.0，不视为本轮复验。

## [3.0.1] — 本地验收候选（2026-11-12）

- 修复午夜 DST 日界线：缺失午夜取当日首个有效时刻，重复午夜取首次；跨整日跳过仍能正确结束前一天，不虚构不存在的日期。
- 旧记录、日志和完成时刻复用严格当地时间校验；不存在的时刻通过导入预览警告暴露，保留原始源，不再静默前移。旧跨夜记录按次日当地时间换算，不固定加 24 小时。
- 删除计划子树会原子解除相关待办的任务引用，保留待办和计划关联；确认文字说明解绑范围，已有行动历史仍受保护。
- ZIP 在解压前检查累计声明大小，读取时逐块计量实际输出并验证 CRC，停止不可信膨胀；取消 JSZip 的全包提前解压。导入预算集中配置，并在读取文件缓冲前检查输入大小。
- Tauri 主窗口启用默认拒绝的 CSP，禁止任意内联脚本和 eval；固定扩展中继使用精确内容哈希，保留不透明 iframe/Worker 隔离，兼容 Chromium 与 WebKit。内联样式保留以支持受控主题与组件布局。
- 分类仅修改颜色/难度时保留本地化键；显式改名才作为用户文本保存。编辑时间方案不再默认写当日覆盖，提供明确勾选；已有手动指定不自动改动。
- 99 项单元测试、28 项 Chromium、8 项 WebKitGTK、11 项实际桌面检查通过；生产构建、类型、版本及沙箱哈希门禁通过。交付指纹覆盖全部前端文件。
