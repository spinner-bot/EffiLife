## 初版完成范围

时间、主题计划、未完成进展日志与独立待办通过统一行动入口关联；现代响应式界面、语言/主题/字体扩展、存档迁移和恢复、受控扩展运行时、浏览器与 Linux 桌面交付均已有实际实现和验收证据。后续客户端、云同步、智能穿戴、统计报告、AI 自然语言与语音仍为远期范围，不将这些未来能力混入当前完成声明。

## 可校验交付

`scripts/package-delivery.py` 从已验证产物生成提交级不可覆盖目录和 ZIP，包含：

- Linux amd64 安装包与浏览器生产文件。
- HTML 使用指南、扩展作者指南、更新列表与阶段证据；本地中文字体与原 OFL。
- 三个可安装示例：主题 forest、语言资源 french、功能 life-card。
- 已解析应用依赖的上游许可文本与清单、Rust 标准库许可。
- 实际原生与 WebKit 结果、交付元数据和逐文件 SHA-256。

生成前校对产品版本、包内程序与原生测试中的 SHA-256、生产入口与 WebKit 测试中的 SHA-256；结束后重新读取 ZIP 全部载荷并比对校验和。验证了两个负向场景：替换 WebKit 入口指纹和原生程序指纹时均拒绝打包，原始证据随后恢复。上游文本中的 1970 时间戳在 ZIP 中按格式下限保存，文件字节保持原样。

产物留在 v3/.cache/delivery，不把生成的二进制堆入源码历史。最终交付目录、源提交与 ZIP SHA-256 另记于 docs/releases/3.0.0-acceptance.json，便于与实际文件核对。本地生成不代表已上传或公开发布。

解包后打开 [HTML 使用指南](../user-guide.html)，或按照 README 的独立 HTTP 预览入口打开 web/。桌面包使用系统 GTK/WebKit；当前验证的是包结构及解包后的真实程序，没有在工作站注册安装，也没有实测其他操作系统。
