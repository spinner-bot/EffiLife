# v3.1.0 第一轮优化：类别、管理动线与记录展示

作者：Codex  (sqs_A100)

用户结束首轮反馈收集并授权实施。范围与决策见 `../round-1-plan.html`，原始反馈见 `../feedback/experience.html`。本阶段完成：

- FB-001/003–007/011：类别选择就地新建，共用编辑器；新计划保存背景类别，分组可覆盖或恢复继承；子项展示彩色圆角标签，主要位置不再展示索引；分组与子项类别操作分别命名，批量范围明确。类别难度附待办优先度解释。
- FB-002/012/017–021：更多入口集中时间类别、分配方案、日程规则和外观，最后进入设置；默认方案与所选日期指定有独立帮助弹窗；时间面板只展示数据，将日期选择收纳至菜单，删除移至专门管理页。普通规则拖动排序并直接保存，兜底规则固定最后且不可删除；删除兜底引用方案须选择替代方案。
- FB-009/010/014/022：顶栏时间/日期、12/24 小时制、本地化 AM/PM、居中/右置持久化；用时输入即时同步区间、区间编辑反算用时，保存再次断言一致性；时间详情每个有记录的类别一个圆环，片段与具名记录关联，跨日裁剪，中心总时长按区间并集计算，重叠构成附解释。总览保留全天圆环。时间记录采用彩色标签+名称、粗体时间+描述两层，待办同样调整主次层级。

验证：110 项单元测试、35 项 Chromium 浏览器测试通过；版本、CSP 字节哈希、严格类型和生产构建通过。浏览器覆盖弹窗中创建类别不丢原表单、继承及刷新、真实鼠标规则排序和占位、帮助弹窗、空用时阻止保存、时间编辑后自动重算、类别圆环、320px 时钟及一分钟推进。原有扩展权限、隔离、CSP、导入恢复、迁移、跨窗口同步回归通过。

测试循环发现并修正了默认类别控件说明被混入无障碍名称，以及“更多”末项误用宣传标题而非“设置”文字。新增浏览器测试也调整为按组合框角色定位原生 select，避免将 option 文本误当成 label。

仍在实施：FB-008 计划树拖动、FB-015/016 外观算法与高级参数、主题背景丰富化。DEV-001 待办整体重设计继续等待用户进一步试用建议；本轮不凭空扩充该目标。

以上为阶段证据，不是 v3.1.0 全部交付完成。新层级的 Linux Tauri / WebKitGTK 与打包验收将在本轮最后重新执行；Windows/macOS 原生环境仍未验证。
