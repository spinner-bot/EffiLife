# 0005 — 扩展注册、声明式资源与持续使用可靠性

- 日期：2026-11-11
- 作者：Codex  (sqs_A100)
- 产品版本：3.0.0（开发中）

## 已交付行为

设置页可预览扩展 ZIP 清单、作者、许可、版本及逐项能力；默认只授予 L0。主题包提供配色和可选视觉 CSS，资源包提供语言和本地字体。升级要求明确选择并提高版本，缺少新增必需能力时停用。撤销、启停、卸载进入审计；移除使用中的资源恢复默认设置。

本地包无论自称何种来源或 ID，都由安装渠道登记为 local，按 kind 从 100000 发号；卸载形成墓碑，不复用。清单路径、API/应用版本、未知能力、ZIP 结构、声明的 SHA-256、配色、语言和字体签名均校验。字体原始字节保留，身份包含 kind、安装编号和别名。

L1 CSS 采用严格视觉属性语法与主题作用域，禁止布局几何、外链、转义和 at-rule。继承解析不依赖安装顺序，循环或缺失父主题明确失败。资源登记冲突回滚该包的部分登记。主题选择显示作者、版本与编号，区分与内置主题同名或并存的本地主题。

导入数据存档会撤销 L1 及以上授权；持有存档不能自动授予其中扩展执行能力。导入预览展示此变化。本地有效备份恢复仍保留原有授权语义。

## 数据可靠性修复

- 刷新期间收到新通知会继续读取，等待者在最新读取完成后返回。
- 领域事务返回已提交快照，界面无需额外读取才能确认成功；广播异常不会误报写入失败。
- 应用服务把响应式输入转成普通数据，避免克隆失败；字体异步加载的过期选择不会覆盖新选择。
