# v3.1.0 第一轮优化：结构拖动与主题外观

作者：Codex  (sqs_A100) · 2026-11-12

承接 0013 的类别、管理和记录阶段，落实 FB-008、FB-015/016，并进行视觉复核。

- 计划树改为可投影的扁平可见列表。手柄发起 PointerEvent 拖动，整组携带完整后代；灰色落位区显示目标归属，左右位移决定层级，列表使用 FLIP 平滑移动。松手直接提交原子移动命令，失败提示、成功静默。保留键盘方向键与减少动效支持。
- 移动只调整父级与受影响的兄弟顺序，不重建节点身份，不改日志、历史时间或待办引用。禁止循环、任务父级、归档修改和无效目标。没有显式类别的节点移动后按新父级继承，历史记录类别保持原值。
- 实色、通透玻璃、磨砂柔光使用不同参数契约与效果实现；每套主题拥有独立默认值和持久化覆盖。选中材质及主题框提供齿轮高级设置，悬停或键盘聚焦展开名称；弹窗预览后保存，可恢复主题默认。
- 为基础主题增加克制的光晕、缓波、微尘与网格背景；保留既有复杂主题绘制器。动画速度与强度实际生效，密度仅向支持粒子或环境图形的主题展示；固定粒子工厂不提供虚假的密度选项。遵循系统减少动态效果，关闭动画时不创建对应装饰 Worker。
- 保持不透明 iframe / Worker、CSP 哈希和默认拒绝权限边界；新材质影响卡片，不影响独立安全恢复入口。恢复默认外观同时清除材质覆盖。
- 视觉复核调整单类别详情为横向紧凑布局，缩小长时长中心文字并压紧树行距。保留整份计划显式统一类别操作，与修改默认值分开；无意义的覆盖复选框没有恢复。

测试循环发现并修正：

1. 手柄公共触摸样式误放在规则页延迟加载样式中，直接进入计划时真实触摸触发 pointercancel。公共样式随应用加载，稳定容器持有指针捕获；真实 CDP touchStart / touchMove / touchEnd 测试通过，证据包含事件生命周期。
2. CSS 压缩在前缀声明顺序不当时仅保留 WebKit 前缀，Chromium 实际模糊为 none。调整顺序后产物保留标准与前缀声明，实际 computedStyle 和跨刷新回归通过。
3. 异构 JSON 参数目录的类型检查曾失败；一次未串联失败退出的脚本让浏览器读取旧构建，该次结果不作为新外观证据。目录加载增加参数契约断言，此后使用构建成功才继续的 verify 链验证。

阶段验证：116 项单元测试，40 项完整 Chromium 测试通过；最后的整份计划类别操作另随最终构建复跑。覆盖真实鼠标多层落位、组携带后代与刷新、真实触摸、材质参数与动画帧变化、主题间独立持久化、恢复默认、减少动效和窄屏。最终 Linux Tauri / WebKitGTK、产物指纹和安装包结果以验收 JSON 为准，尚不把阶段通过等同于发布完成。
