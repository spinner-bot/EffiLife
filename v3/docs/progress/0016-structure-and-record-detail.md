# 时间类别与记录细节：v3.2.0

作者：Codex  (sqs_A100) · 2026-11-12

本轮处理用户新提出的五条优化，全部在 v3 内实现：

1. 时间类别新增可选描述，随命令层、存档校验与导入导出一起保存；清空描述即删除字段，不保留空字符串。
2. 类别管理页改为实心圆点 + 粗体类别名的主角样式，并显示难度与描述；未填写描述时显示明确提示，空类别不再只剩一条标签。
3. 更多层级下的类别管理、分配方案、日程规则、主题与外观、设置页在顶栏新增返回入口。
4. 新增单条记录详情页 `/time/records/:id`。此前圆环图例只改写查询参数、页面不变，记录行点击也没有反应；现在两处都会进入详情页，展示类别、日期、区间、时长、备注、关联计划与待办，并提供编辑和删除。
5. 时间页类别圆环以分配方案的目标时长为满圈。未达标时按目标计算并在中心显示还差多少，超过目标才回到实际总量；已设定但当天没有记录的类别仍显示全白圆环和“还未开始”。

验证：本机 Windows 环境 `npm run verify` 通过 —— 121 项单元测试、44 项真实 Chromium 测试，版本、严格类型与生产构建门禁通过。新增 5 条单元断言（描述持久化、目标圆环布局）与 4 条浏览器动线（类别管理显示、二级返回、记录详情、目标与未开始圆环）。

边界：本轮未重新构建原生包，未复验 Tauri 桌面与 WebKitGTK 检查，也没有独立人工复核；上述结论仅代表当前 Windows 前端的自动化结果。
