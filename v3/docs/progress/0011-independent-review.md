## 对原结论的修正

独立审查中的午夜 DST、旧当地时间迁移与任务引用删除属于正确性缺陷，不能称为单纯加固。已先增加失败复现，再修复；旧版测试主要覆盖 New York，未覆盖缺失午夜的时区。v3.0.0 的原始产物和哈希保留，发布记录明确标记已被本修复候选替代，不再沿用其长期真实数据可靠性判断。

## 七项处理

| 审查项 | 修复与验证 |
|---|---|
| 1. 午夜 DST | 日界线从两侧时区偏移解析。午夜缺失取首个有效时刻，重复午夜取首次；整日跳过不虚构一天，也不破坏前一天结束边界。Santiago、Havana 的当日及前一天、Havana 重复午夜、Apia 跳日均有领域测试。两种午夜 DST 日期的真实首页、方案保存和刷新通过。 |
| 2. ZIP 解压 | 解压前累计目录声明大小，检查本地头、路径、条目数和异常压缩；禁用 JSZip 的全量提前 CRC 解压。请求文件按流读取，逐块检查实际大小并验证 CRC，伪造小目录大小不能绕过。文件缓冲分配前也检查输入大小。 |
| 3. 旧时间迁移 | 复用严格 zonedInstant，不存在或无效的时刻进入预览警告；跳过对应记录或完成时刻并保留原始源。仅日期的模糊日志使用当日首有效边界，继续标记模糊。另修跨夜结束按次日当地时间换算，不固定加 24 小时。 |
| 4. 待办外键 | 删除任务或祖先时，事务内解除待办的 relatedTaskId，保留待办和 relatedPlanId；确认文字明确说明。带实际行动历史的任务继续受既有保护。领域和真实迁移界面流程验证删除后可刷新且待办保留。 |
| 5. 主窗口 CSP | 默认拒绝，允许本地脚本、固定可信中继哈希与必要 IPC；禁止任意内联脚本和 eval。内联样式保留以支持 Vue 布局及受控主题。沙箱保持 opaque iframe/Worker，布局仍经清洗、网络仍禁止。实际原生脚本注入被拒绝，保存、导入、主题及重启通过。 |
| 6. 分类本地化 | 元数据编辑不携带重命名字段，保留 labelKey；明确改名才转为用户文本。浏览器验证改难度后仍可切换 Work/工作，显式自定义名称保留。 |
| 7. 模板与日期 | 编辑已有模板默认不写 overrides；通过独立勾选明确指定当前日期。新建默认勾选并展示。浏览器验证编辑模板后自动日期仍跟随后续默认规则，原手动指定保留。 |

## 导入约定的明确调整

这是对旧设计“暂不设大小限制”的修订：当前默认输入 64 MiB、ZIP 单条解压 32 MiB、累计解压 128 MiB，最多 9999 条目；大于等于 1 MiB 的条目检查压缩比上限 200。配置集中于 shared/import-budgets.json，适配器可传入预算，未把限制编码进包格式。不是严格的操作系统内存配额，JSON 对象、字符串与 base64 仍有额外开销。数据包只读取需要的文件；扩展为保留完整内容仍会顺序读取全部载荷，统一计量。

累计声明超限测试验证在 JSZip 加载前拒绝，两类导入均受保护；另覆盖伪造原始长度的真实膨胀、CRC 不符、异常压缩比和输入预算。未通过创建巨大解压对象来测试内存耗尽。

## WebKit 的实际差异

Chromium 通过的外部中继资源在 WebKit 不透明 iframe 中被 'self' 判定阻断。最终采用内联固定可信中继加精确 SHA-256；父 CSP 和子 CSP 均授权这段固定内容，不放开任意脚本。scripts/sync-frame.mjs 根据唯一 JS/CSS 源生成文档与策略，build --check 拒绝未同步结果。中继之外的包代码通过 MessagePort 传入 Worker，不插入该 HTML。

## 已有数据边界

不会自动猜测并重写已迁入的 UTC 值；请保留导出备份并核对原始来源。也不会自动清除历史日期覆盖，因为无法判断其是否为用户有意指定，可从当天方案选择恢复自动匹配。已经作为自定义名字保存的分类不会被强制重新翻译。

Linux 的实际检查仍使用独立测试目录、软件渲染及本地 SDK。root 测试关闭 WebKit Linux 进程沙箱，不代表 OS 沙箱认证；未在工作站注册系统安装，Windows/macOS/移动平台仍未实测。
