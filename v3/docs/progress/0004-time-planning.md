# 0004 — 每日分配与日历规则

- 日期：2026-11-11
- 作者：Codex  (sqs_A100)
- 产品版本：3.0.0（开发中）

## 产品行为

时间页支持创建和修改分配模板，按类别指定目标小时数，并为选中日期单独指定方案或恢复跟随规则。模板可设为默认；其他规则覆盖每周、月份、年度日期和每月第几个星期几，按列表顺序首次匹配，默认规则最后兜底。删除模板同时清理相关规则与日期覆盖。

分配制以实际记录计算进度。切分制在此基础上将当天已过去且没有实际记录覆盖的区间归入背景类别；重叠实际区间不重复抵扣，未来日期不产生背景时长。界面区分实际和背景归入，派生值不会写成用户实际记录，也不会创建 Plan 日志。

旧版时间模板、规则、手动日期安排可迁入；旧包原文继续保留。新增字段可选，已有 v3 存档仍可读取。模板与当日指定、默认规则在同一命令中原子保存，重试不会重复创建。

- 10 项真实 Chromium 浏览器测试通过，生产构建及严格类型检查通过。
- 新增真实动线验证：创建分配方案且无虚构实际记录；改为切分制后出现明确的背景归入并持久化；两个已打开窗口同步；录入初始焦点、未保存确认和关闭后焦点返回。
- 已修复弹窗优先聚焦关闭按钮的问题；有可编辑内容时先进入输入区，关闭后返回来源控件，嵌套放弃确认保留草稿。
