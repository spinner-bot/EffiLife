## 系统边界

v3/ 为全部新工作入口。采用 Vue 3 + TypeScript 展示层、纯领域规则、应用操作服务、持久化/平台适配和资源注册系统。领域语义可被桌面和后续客户端共同使用，界面不直接改写底层存储。

## 关键产品约束

1. 时间与事件是关联视角，待办保持零散事项的独立使用场景。
2. 一份 Plan 围绕明确主题，可分节分组；条目有稳定身份，显示编号不作外键。
3. log 是未完成进展的一等记录。最终完成与记录进展是不同动作；日志可提供本次用时的参考。
4. 任务可能穿插执行。同一条目两次日志的时间差不直接等于连续实际投入；参考值带来源与置信状态，实际时间以明确记录/确认的区间为准。
5. 一次行动可同时产生时间记录和相关进展/完成状态，需原子提交、可恢复、可重试而不重复。
6. 总览服务于看，统一入口服务于记录；高频动线减少页面和菜单往返。
7. 语言、主题、字体和包格式均从注册机制或统一配置读取。25 套旧主题保留并迁移；权限边界沿用已审阅设计。
8. 从真实空状态启动，演示与测试样例显式隔离。

## 实施方式

每个文件或完整小改动立即提交；每个阶段写入 docs/progress/ 并更新 CHANGELOG.md。按新增行为设计有意义的测试，测试通过后推进下一项；出现失败先定位修复，记录真实结果。

现有重构资料参考 ../refactor/11-user-design.md、../refactor/13-system-architecture.md 等仓库旧路径时，应以仓库根为相对起点；v3 内后续文档使用实际存在的相对链接。
