EffiLife 3.0.0 · API 1 · 开发中 · 2026-11-11

让资源独立扩展，
让授权清楚可撤销。

主题、语言与字体通过同一个安装入口进入应用。来源由安装渠道决定，包内填写的编号不会成为本地安装身份。所有包内容都先预览，再安装；生活数据由领域命令与事务管理。

从可运行的示例开始

源码示例位于 林间留白主题和 法语资源。在仓库根目录执行：

python3 v3/scripts/run.py node scripts/build-examples.mjs

产物位于 v3/dist/examples/，可以在设置 → 扩展与资源中安装。构建脚本读取集中扩展名配置，生成逐文件 SHA-256，使用固定归档时间以便重复构建。扩展名事实源是 shared/package-formats.json。

清单契约

{
  "type": "theme",
  "name": { "zh-CN": "我的主题", "en-US": "My Theme" },
  "author": "作者",
  "license": "MIT",
  "version": "1.0.0",
  "formatVersion": 1,
  "apiVersion": 1,
  "minAppVersion": "3.0.0",
  "permissions": ["appearance.tokens", "appearance.css"],
  "requiredPermissions": ["appearance.tokens"],
  "tokens": "tokens.json",
  "styles": ["styles/visual.css"]
}

清单位于 ZIP 根目录的 manifest.json。路径仅使用包内相对路径，不接受外链、绝对路径、上级目录、符号链接或大小写冲突。可通过 checksums 声明文件路径与 SHA-256；声明后必须匹配。未知能力、接口版本或不兼容的应用版本会被拒绝。

本地编号按包类型从 100000 开始分配，卸载后不复用。相同名称和作者可以明确选择升级或并存；升级必须提高版本，新增必需能力不会自动获准。

外观与资源能力

能力内容规则
appearance.tokens配色、可选 mode主题必需；默认允许，文字对比度会校正
appearance.css作用域内视觉 CSS可选、单独授权；不允许几何属性、外链、at-rule 或转义语法
resources.register语言和字体资源注册必需；默认允许，冲突回滚并提示

配色文件结构为 {"palette":{"background":"#102a20","surface":"#17382c","text":"#f4fff9","muted":"#bdd3c7","accent":"#47b894"}}。颜色使用六位十六进制；未提供的颜色继承基础主题。可通过清单 extends 引用基础主题的安装编号，解析器检测循环和缺失父主题。

L1 CSS 当前允许颜色、背景色/渐变、边框颜色/圆角、阴影、透明度等视觉属性。每个选择器自动附加当前主题作用域，不改变宿主几何布局。只有明确授权后才会装载；撤销即时卸载。

资源清单使用 resources 数组，条目含 kind（locale 或 font）、path、alias、name、license。语言文件包含 BCP 47 id、direction 与字符串 messages 字典，缺少的字段回退英文。字体使用包内 WOFF/WOFF2/TTF/OTF 原始文件，由浏览器本地加载，停用时释放。字体身份包含包类型、编号和别名，避免不同类型包的编号冲突。

授权、恢复与后续运行时

安装、升级、授权、启停和卸载均记录审计。必需能力撤销后自动停用；移除当前主题、语言或字体时回退默认值。数据存档导入会重置 L1 及以上授权，存档本身不能授予可执行权限。

L2 装饰与 L3 应用接口已接入隔离 Worker。脚本通过 MessageChannel 与受信任的 iframe 中继通信；iframe 不共享来源，禁止直接访问宿主 DOM、存储或网络。L3 可以提供任意容器排布的 HTML/CSS 界面，HTML 会移除脚本、外链、事件处理属性和可导航资源元素；只有受控中继接触 iframe DOM。主题替换整个界面，功能包使用独立卡片。

高级授权需要二次确认。恢复默认按钮位于扩展作用域外；脚本启动中也可使用。Alt+Shift+0 或地址参数 ?safe=1 可进入不加载扩展的安全模式；点击恢复会停用扩展并恢复默认主题、字体与语言。无响应脚本由宿主停止，失败状态持久化，刷新不会反复执行。

脚本 API 1

功能包清单使用 entry；主题使用 scripts 数组。代码是普通 JavaScript，不执行模块导入。示例见 生活一瞥功能卡片。

EffiLife.onMount(async () => {
  const data = await EffiLife.request('data.read');
  EffiLife.render({
    html: '<main><h1>' + data.plans.length + ' plans</h1></main>',
    css: 'main{padding:24px;color:#203045;background:#f7f9fc}'
  });
});
EffiLife.onFrame(({ctx,width,height,time,theme}) => {
  // 需要 overlay.canvas；受可见性与减少动态效果设置控制。
});
EffiLife.onAction(async event => {
  // data-action 触发 click/submit；submit 的表单值在 event.values。
});
EffiLife.onChange(state => {
  // 生命周期/尺寸/主题变动；app.events 授权后还包含更新修订。
});
request 方法权限与参数
data.readapp.data.read；仅生活数据，不含注册表、收据与审计
data.writeapp.data.write；参数为领域命令，例如 createPlan / recordAction / saveTodo
settings.read / settings.write对应设置权限；写入仅 locale、fontId、timeZone、weekStartsOn
theme.setapp.theme；参数为主题编号
navigateapp.navigation；参数为应用内路径

写入在事务内部再次校验当前版本指纹与授权，撤销与写入竞态不能绕过检查。写入与审计原子提交，传输重试去重；注册表、授权与审计不属于扩展可写域。读取或写入失败返回带 code 的 Error。未知接口和越权调用明确拒绝。

绘制回调最多 30 FPS，减少动态效果时只绘制静态帧；不可见时暂停。心跳超时为 15 秒，通道及视图片段有结构和频率限制。Worker 不提供严格的每实例内存配额，这些机制不能等同于操作系统进程沙箱。当前运行证据来自 Chromium；其他 WebView 与原生交付继续单独验收。

实现依据：CSP 与 blob Worker 策略继承、不透明来源隔离、OffscreenCanvas 转交。浏览器回归额外验证从原型恢复的原生 fetch 仍被 CSP 阻止，未产生网络请求。
