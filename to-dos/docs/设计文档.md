# to-dos 模块设计文档

> 版本 0.1.0 | 待办事项管理模块

---

## 1. 模块定位

轻量级待办事项管理模块，专注于任务的创建、追踪与归档。作为 EffLife 效率工具集的三大支柱之一，与 time-helper（时间记录）和 plan-helper（计划管理）协同工作。

---

## 2. 数据结构

### 2.1 Todo 对象

每个待办事项包含以下字段：

```json
{
  "id": "td_0001",
  "title": "完成设计文档",
  "description": "详细描述...",
  "priority": 2,
  "category": "work",
  "tags": ["urgent", "documentation"],
  "status": "pending",
  "created_at": "2026-09-20T10:30:00",
  "updated_at": "2026-09-20T14:00:00",
  "due_date": "2026-09-25",
  "completed_at": null,
  "archived": false,
  "parent_id": null,
  "sub_ids": []
}
```

### 2.2 字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `id` | string | 是 | 唯一编号，格式 `td_XXXX` |
| `title` | string | 是 | 任务标题 |
| `description` | string | 否 | 详细描述 |
| `priority` | int | 是 | 优先级 0-4（0=无, 1=低, 2=中, 3=高, 4=紧急） |
| `category` | string | 否 | 分类（如 work / study / life） |
| `tags` | string[] | 否 | 标签列表 |
| `status` | string | 是 | 状态：pending / in_progress / completed / cancelled |
| `created_at` | string | 是 | ISO 8601 创建时间 |
| `updated_at` | string | 是 | ISO 8601 更新时间 |
| `due_date` | string \| null | 否 | 截止日期 YYYY-MM-DD |
| `completed_at` | string \| null | 否 | 完成时间 |
| `archived` | bool | 是 | 是否已归档 |
| `parent_id` | string \| null | 否 | 父任务 ID（支持子任务） |
| `sub_ids` | string[] | 是 | 子任务 ID 列表 |

### 2.3 优先级定义

| 值 | 名称 | 含义 |
|----|------|------|
| 0 | none | 无优先级 |
| 1 | low | 低优先级 |
| 2 | medium | 中优先级（默认） |
| 3 | high | 高优先级 |
| 4 | urgent | 紧急 |

### 2.4 状态定义

| 状态 | 含义 |
|------|------|
| `pending` | 待处理 |
| `in_progress` | 进行中 |
| `completed` | 已完成 |
| `cancelled` | 已取消 |

## 3. 数据存储

### 3.1 目录结构

```
to-dos/data/
├── todos/
│   └── {id}.json          # 每个 todo 一个文件
├── archive/
│   └── YYYY-MM/
│       └── {id}.json      # 按完成月份归档
└── system/
    ├── config.json         # 模块配置
    ├── registry.json       # 索引注册表
    └── categories.json    # 分类定义
```

### 3.2 registry.json

```json
{
  "next_id": 1,
  "active_ids": ["td_0001", "td_0002"],
  "archived_ids": ["td_0003"],
  "stats": {
    "total_created": 3,
    "total_completed": 1,
    "total_cancelled": 0
  }
}
```

## 4. API 规范

### 4.1 核心 API

#### 任务 CRUD

| 方法 | 签名 | 说明 |
|------|------|------|
| `create` | `create(title, priority=2, **kwargs) -> Todo` | 创建新任务 |
| `get` | `get(id) -> Todo \| None` | 获取单个任务 |
| `update` | `update(id, **fields) -> Todo` | 更新任务字段 |
| `delete` | `delete(id) -> bool` | 删除任务（软删除→归档） |

#### 状态操作

| 方法 | 签名 | 说明 |
|------|------|------|
| `start` | `start(id) -> Todo` | 标记为进行中 |
| `complete` | `complete(id) -> Todo` | 标记为完成并归档 |
| `cancel` | `cancel(id) -> Todo` | 取消任务 |
| `reopen` | `reopen(id) -> Todo` | 重新打开已完成的任务 |

#### 查询

| 方法 | 签名 | 说明 |
|------|------|------|
| `list_all` | `list_all(status=None, priority=None, category=None) -> list[Todo]` | 列出所有任务 |
| `list_active` | `list_active() -> list[Todo]` | 列出未归档任务 |
| `list_overdue` | `list_overdue() -> list[Todo]` | 列出已过期任务 |
| `list_by_category` | `list_by_category(category) -> list[Todo]` | 按分类列出 |
| `search` | `search(query) -> list[Todo]` | 全文搜索 |
| `stats` | `stats() -> dict` | 获取统计信息 |

#### 分类管理

| 方法 | 签名 | 说明 |
|------|------|------|
| `add_category` | `add_category(name, color=None) -> dict` | 添加分类 |
| `remove_category` | `remove_category(name) -> bool` | 删除分类 |
| `list_categories` | `list_categories() -> list[dict]` | 列出所有分类 |

#### 子任务

| 方法 | 签名 | 说明 |
|------|------|------|
| `add_subtask` | `add_subtask(parent_id, title, **kwargs) -> Todo` | 添加子任务 |
| `list_subtasks` | `list_subtasks(parent_id) -> list[Todo]` | 列出子任务 |

### 4.2 跨模块 API（预留）

```python
# 与 plan-helper 联动
def get_tasks_for_plan(plan_id: str) -> list[Todo]: ...
def link_to_plan(todo_id: str, plan_id: str) -> bool: ...

# 与 time-helper 联动
def get_time_spent(todo_id: str) -> dict: ...
def log_time(todo_id: str, duration: int) -> bool: ...
```

## 5. 技术选型

| 层级 | 技术 | 理由 |
|------|------|------|
| 后端 | Python 3 | 与 plan-helper 一致，共享数据格式 |
| 前端 | Vue 3 + TypeScript + Vite | 与 time-helper/desk 一致 |
| 样式 | Tailwind CSS | 与 time-helper/desk 一致 |
| 状态管理 | Pinia | 与 time-helper/desk 一致 |
| 数据存储 | JSON 文件 | 与项目整体一致 |
