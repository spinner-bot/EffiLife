# to-dos 界面设计方案

## 美学方向

参考 **Linear** 和 **Notion** 的设计语言：
- 极简、克制、信息密度高
- 强调内容本身，弱化装饰元素
- 清晰的层级和留白

## 字体系统

```
标题：Inter / Noto Sans SC SemiBold (18-24px)
正文：Inter / Noto Sans SC Regular (14px)
辅助：Inter / Noto Sans SC Regular (12px)
```

### 待办卡片设计

```
┌─────────────────────────────────────────────────────────┐
│  ◯  完成项目文档                              🔴 明天    │
│      #work  #urgent                                     │
│      ▸ 3/5 子任务已完成                                  │
└─────────────────────────────────────────────────────────┘
```

- 左侧：复选框（大圆形，点击完成）
- 中间：标题 + 标签 + 子任务进度
- 右侧：优先级指示 + 截止日期

## 组件清单

### 页面组件
1. **TodosView** - 主页面，看板布局
2. **TodoList** - 待办列表
3. **TodoItem** - 单个待办卡片
4. **TodoDetail** - 待办详情弹窗

### 功能组件
5. **TodoForm** - 创建/编辑表单
6. **CategorySidebar** - 分类侧栏
7. **FilterBar** - 筛选栏
8. **StatsCard** - 统计卡片

### UI 组件
9. **Checkbox** - 复选框
10. **PriorityBadge** - 优先级标记
11. **DueDateBadge** - 截止日期标记
12. **TagBadge** - 标签

## 动效策略

- 完成待办：复选框缩放 + 轻微弹跳 + 文字划线
- 添加待办：卡片从顶部滑入
- 删除待办：卡片淡出 + 缩小
- 切换状态：背景色渐变过渡
- 所有过渡：250ms cubic-bezier(0.4, 0, 0.2, 1)

## 交互细节

1. **快速添加**：按 `N` 键直接弹出添加框
2. **键盘导航**：
   - `↑↓`：上下选择
   - `Enter`：打开详情
   - `Space`：切换完成状态
   - `Delete`：删除（需确认）
   - `Esc`：关闭弹窗
3. **拖拽排序**：支持拖拽调整顺序
4. **批量操作**：Ctrl+点击多选，显示批量操作栏
